1.1  Axioms for Sets

Sets, Relations, and Cardinality, Chapters 1 to 3 worked with sets under six working rules, (W1)–(W6) of Sets, Relations, and Cardinality, Section 1.1, and took the natural numbers as a given set inside the familiar real line, with induction as an axiom (Logic and Proof, Axiom 3.2.1). This volume builds the real numbers, so it may not lean on them: we start again from sets alone, and in this chapter every object is a set. This section asks which rules about sets are basic. It states six axioms, shows that they settle when two sets are equal, and produces the first sets from them: the empty set, unordered pairs, unions, intersections and differences.

1.1.1. Starting again from sets

Sets, Relations, and Cardinality, Section 1.1 listed its working rules and used them without asking where they came from. One of them, specification (Sets, Relations, and Cardinality, Definition 1.1.3), was the repair of a rule that fails: “every property defines a set” is contradictory, because the property x∉x would define a set that both is and is not an element of itself, and Sets, Relations, and Cardinality, Theorem 1.1.4 turns that contradiction into the fact that no set has every set as an element. So rules about sets cannot be chosen by what sounds harmless. They must be chosen with care and stated once, and everything else must then be derived from them.

That raises two questions, which this chapter answers in order. Which of the working rules are basic, and which follow from the others? And can the basic rules produce the objects Sets, Relations, and Cardinality, Chapters 1 to 3 took as given (ordered pairs, functions, the natural numbers), rather than only describe them? Section 1.2 builds ordered pairs out of sets; Section 1.3 builds the natural numbers.

To build numbers out of sets we must let sets be the only objects. From here to the end of the chapter, every object is a set, and every element of a set is again a set. Sets, Relations, and Cardinality, Section 1.1 used a different picture, in which numbers are given objects that are not sets, and it said that nothing in the main line would depend on how numbers are made. That picture stays valid for Sets, Relations, and Cardinality, Chapters 1 to 3; this chapter works in the other one, where 0 will be the empty set and 0∈1 will be a true statement. The chapter’s introduction says how the two pictures fit together.

The language. Statements about sets are written in the first-order language of Logic and Proof, Chapter 4 (Logic and Proof, Definition 4.2.2) with one predicate symbol, the two-place ∈, together with equality. There are no constant symbols and no function symbols. The variables range over sets. So “x∈y” and “x=y” are the atomic formulas, and everything else is built from them with the connectives and the quantifiers. A property P(x) of sets is a formula of this language in which the variable x may occur free; other free variables, called parameters, are allowed too, and stand for sets fixed in advance.

1.1.2. The axioms

We want sets that can be built, and we know one way not to build them: by an arbitrary property, with nothing to cut the set out of. So instead of one rule for every property, we list a few specific ways of making a new set from sets we already have, together with one set to start from.

A few ways to make sets, and one way to tell them apart.

Axiom 1.1.1 (The Axioms (Z1)–(Z6))
  • (Z1) Extensionality. Sets with the same elements are equal: for all sets A and B, if x∈A↔x∈B for every x, then A=B.
  • (Z2) Empty set. There is a set with no elements.
  • (Z3) Pairing. For all sets a and b there is a set whose elements are exactly a and b.
  • (Z4) Union. For every set S there is a set whose elements are exactly the elements of members of S.
  • (Z5) Power set. For every set X there is a set whose elements are exactly the subsets of X.
  • (Z6) Separation. For every set A and every property P(x) there is a set whose elements are exactly the x∈A with P(x).

In symbols, with S⊆X as an abbreviation of ∀y(y∈S→y∈X) (Sets, Relations, and Cardinality, Definition 1.1.2): (Z1)∀A∀B(∀x(x∈A↔x∈B)→A=B),(Z2)∃E∀x¬(x∈E),(Z3)∀a∀b∃C∀x(x∈C↔(x=a∨x=b)),(Z4)∀S∃U∀x(x∈U↔∃S(S∈S∧x∈S)),(Z5)∀X∃Q∀S(S∈Q↔S⊆X). (Z6) is not one axiom but one for each property, an axiom schema. For every formula φ whose free variables are among x,p1,…,pk and in which the letter B does not appear, (Z6)∀p1⋯∀pk∀A∃B∀x(x∈B↔(x∈A∧φ)). The letter B here is bound, and may be renamed (Logic and Proof, Section 4.2) to any letter that appears nowhere else in (Z6) (not in φ, and neither x nor A). So a property may mention a given set called B, as A∖B below does, once the new set is given another letter, say D: ∀B∀A∃D∀x(x∈D↔(x∈A∧x∉B)).

In words, clause by clause, with what each one licenses.

  • (Z1) is the only axiom that proves two sets equal by comparing their elements: it turns “same elements” into A=B. Sets, Relations, and Cardinality, Section 1.1 stated it as the meaning of equality of sets (Sets, Relations, and Cardinality, Definition 1.1.1); here it is an axiom, and only its direction “same elements, hence equal” needs to be assumed. The other direction, from A=B to x∈A↔x∈B, is the equality rule =E of Logic and Proof, Definition 4.7.1, a rule of logic.
  • (Z2) gives the one set we start from. Each of (Z3)–(Z6) makes a set out of sets already given.
  • (Z3) makes a set out of two given sets a, b. The two need not differ: with b=a its set has the single element a.
  • (Z4) flattens one level: from a set S of sets it makes the set of what lies inside the members of S. With (Z3) it gives the union of two sets (below).
  • (Z5) collects all subsets of X into one set; it is the working rule (W4).
  • (Z6) cuts a set out of a set A already given, by a property. It is specification (Sets, Relations, and Cardinality, Definition 1.1.3), now an axiom. The letter B must not appear in φ, or the property could refer to the set being made: with φ the formula x∉B, and B the very set that (Z6) produces, it would say x∈B↔(x∈A∧x∉B), which no set B satisfies when A has an element.

Properties written with defined symbols. The formulas of (Z6) contain only ∈ and =. We shall write properties with defined symbols as well (⊆, ∅, {a,b}, and later ∪, pairs and functions), and that is harmless: each defined symbol is shorthand that unwinds into ∈ and =. For instance “x=∅” unwinds to ∀y¬(y∈x), and “x={a,b}” to ∀y(y∈x↔(y=a∨y=b)). A property is admissible in (Z6) when its unwinding is a formula of the language, which is the case for every property in this chapter.

One way to tell sets apart, and one way to make them unique. Each of (Z2)–(Z6) says that there is a set with a certain membership condition. By (Z1) there is then exactly one: two sets with the same membership condition have the same elements, so they are equal. We use this move so often that we state it once:

To show that a set is unique, show that any two sets with its membership condition have the same elements, and apply (Z1).

The first sets. Here are the axioms at work, each set checked against the membership condition that made it.

  • The empty set. (Z2) gives a set with no elements; Proposition 1.1.2 below shows it is unique, and we write it ∅.
  • A singleton. (Z3) with a=b=∅ gives a set whose elements are exactly the x with x=∅∨x=∅, that is, x=∅. This is {∅}. It is not ∅: it has the element ∅, and ∅ has none.
  • A two-element set. (Z3) with a=∅ and b={∅} gives {∅,{∅}}, whose elements are exactly ∅ and {∅}. These two are different, by the previous item, so this set has two elements.
  • A union. (Z4) with S={∅,{∅}} gives the set of everything that lies in ∅ or in {∅}. Nothing lies in ∅, and only ∅ lies in {∅}. So the union is {∅}: one element, although S has two.
  • A power set. (Z5) with X={∅} gives the set of subsets of {∅}. There are two, ∅ and {∅} itself (the argument of Sets, Relations, and Cardinality, Example (Small power sets), which uses only extensionality and excluded middle, applies word for word). So P({∅})={∅,{∅}}, the set of the third item.
  • A separation. (Z6) with A={∅,{∅}} and the property x≠∅ gives {{∅}}: of the two elements of A, only {∅} differs from ∅.

The degenerate case is the empty set itself, and it matters: each natural number will be built from ∅ by these axioms, one at a time. The set of all of them needs one more starting point, the Axiom of Infinity (Section 1.3).

A non-example by minimal change. Delete the ambient set from (Z6): “for every property P(x) there is a set whose elements are exactly the x with P(x)”. This is the naive rule of Sets, Relations, and Cardinality, Section 1.1, and it fails at once. With P(x) the property x∉x it gives a set R with R∈R↔R∉R, a contradiction; and even with the harmless-looking property x=x it gives a set of which every set is an element, which Sets, Relations, and Cardinality, Theorem 1.1.4 rules out. What fails is exactly the clause “x∈A” that was deleted. Every other part of (Z6) survives the change; the ambient set is what makes it safe.

Why this list. Each axiom earns its place by something later in the chapter. Pairing and Union give finite sets and the union of two sets; Power set and Separation give the product A×B (Section 1.2) and, with it, relations and functions; Extensionality makes every construction unique. Four further axioms complete the usual system of set theory with choice, and only one of them is needed here:

  • Infinity says that some set contains ∅ and is closed under one particular step. It is (Z7), stated in Section 1.3, once there is a step to iterate. Without it, the axioms above produce each finite set we write down, one at a time. That they cannot produce a set holding infinitely many of them is a theorem of set theory, which this book states and does not prove.
  • Replacement and Foundation are not needed to build the natural numbers, and are left to the volume on set theory, which revisits this chapter.
  • Choice is Sets, Relations, and Cardinality, Axiom 3.3.1 of Sets, Relations, and Cardinality, Chapter 3. Nothing in this chapter uses it.

We do not ask whether the axioms are consistent, or (apart from exercise C1) whether one of them follows from the others. Those are questions about the axioms, and this chapter only uses them.

Warning. Two traps in the list. First, (Z3) gives an unordered pair: {a,b}={b,a}, since x=a∨x=b and x=b∨x=a say the same thing. So {a,b} cannot record which of a, b came first, and Section 1.2 needs a different construction for the ordered pair. Second, (Z6) needs the ambient set A: the rule without it is exactly the one Sets, Relations, and Cardinality, Theorem 1.1.4 refutes.

1.1.3. The first consequences

The existence axioms say “there is a set”; the first proposition says “there is exactly one”, and so lets us give each such set a name. It also rebuilds from the axioms the operations of Sets, Relations, and Cardinality, Definition 1.2.1 and, for a set of sets S, the ⋃S and ⋂S of Sets, Relations, and Cardinality, Definition 1.2.4; indexed families wait for Section 1.2.

Proposition 1.1.2 (The Sets Named by the Axioms)
  • (a) There is exactly one set with no elements. It is written ∅.
  • (b) For all sets a and b the set of (Z3) is unique. It is written {a,b}, and {a}:={a,a}, the set whose only element is a.
  • (c) For every set S the set of (Z4) is unique. It is written ⋃S, and A∪B:=⋃{A,B} for sets A, B, so that x∈A∪B if and only if x∈A or x∈B. The sets A∩B:={x∈A:x∈B} and A∖B:={x∈A:x∉B} exist by (Z6). For a non-empty set S, the set ⋂S:={x∈A0:x∈S for every S∈S} exists by (Z6) for any A0∈S, it does not depend on A0, and x∈⋂S if and only if x∈S for every S∈S.
  • (d) For all sets a,b,c,d, {a,b}={c,d}⟺(a=c∧b=d)∨(a=d∧b=c). In particular {a}={c,d} if and only if a=c and c=d.

Idea. Parts (a)–(c) are the uniqueness move three times: the axiom named gives a set, and any two sets with the same membership condition are equal by (Z1). For ⋂S, the condition “x∈A0” adds nothing, since A0 is itself one of the S∈S; so the condition does not mention A0 at all. Part (d) is different: it compares elements. From a∈{a,b}={c,d} we get a=c or a=d, and each case is finished by locating b and then the remaining element of {c,d}.

Proof.

  • (a) A set with no elements exists by (Z2). If E and E′ both have no elements, then for every x, both x∈E and x∈E′ are false, so x∈E↔x∈E′; hence E=E′ by (Z1). This is the argument of Sets, Relations, and Cardinality, Proposition 1.1.3, with (Z1) in place of Sets, Relations, and Cardinality, Definition 1.1.1.

  • (b) Let C and C′ be sets as in (Z3) for the same a, b. For every x, x∈C and x∈C′ are each equivalent to x=a∨x=b, so C=C′ by (Z1). With b=a the condition is x=a∨x=a, which is equivalent to x=a; so the only element of {a} is a.

  • (c) The set of (Z4) is unique by the same argument, its condition being ∃S(S∈S∧x∈S). For S={A,B}, an S∈{A,B} is A or B, by (b); so x∈A∪B if and only if x∈A or x∈B. The sets A∩B and A∖B are instances of (Z6), with ambient set A and parameter B (after renaming the bound letter of (Z6)), and are unique by (Z1).

    Now let S be non-empty, and let A0∈S. By (Z6) with ambient set A0 and parameter S, the set ⋂S above exists. Its membership condition simplifies: x∈A0∧∀S(S∈S→x∈S)⟺∀S(S∈S→x∈S). From left to right, drop the first conjunct. From right to left, apply the condition at S=A0, which is a member of S, to get x∈A0. The right-hand side does not mention A0. So if A1 is another member of S, the sets built from A0 and from A1 have the same elements, and they are equal by (Z1).

  • (d) (⇐) If a=c and b=d, then {a,b}={c,d} by =E. If a=d and b=c, then {a,b}={d,c}, and {d,c}={c,d} because x=d∨x=c is equivalent to x=c∨x=d, so the two sets have the same elements (Z1).

(⇒) Suppose {a,b}={c,d}. Since a∈{a,b}, we have a∈{c,d}, so a=c or a=d. We take the two cases in turn (∨E).

Case 1: a=c. Since b∈{c,d}, b=c or b=d. If b=d, then a=c and b=d, the first disjunct. If b=c, then b=c=a, so {a,b}={a}. Now d∈{c,d}={a,b}={a}, so d=a, and hence b=a=d. Again a=c and b=d.

Case 2: a=d. Since b∈{c,d}, b=c or b=d. If b=c, then a=d and b=c, the second disjunct. If b=d, then b=d=a, so {a,b}={a}. Now c∈{a}, so c=a, and b=a=c. So a=d and b=c, the second disjunct again.

In each case one of the two disjuncts holds.

For the last claim, apply what was just proved with b=a: {a}={a,a}={c,d} if and only if (a=c∧a=d)∨(a=d∧a=c). Both disjuncts say that a=c and a=d, that is, a=c and c=d.

Two consequences of (d) are used constantly. With c=d it says that {a}={c} only if a=c: a singleton determines its element. And with c=a it says that {a,b}={a,d} only if b=d: in the first disjunct b=d directly, and in the second a=d and b=a, so again b=d. Section 1.2 uses both.

The sets of Sets, Relations, and Cardinality, Chapter 1, rebuilt. The union A∪B of part (c) has the membership condition of Sets, Relations, and Cardinality, Definition 1.2.1 (a), and the intersection and difference are defined exactly as in parts (b) and (c) of that definition; so by (Z1) these are the sets Sets, Relations, and Cardinality, Chapter 1 used. Likewise, if S is a non-empty set of subsets of a set X, the ⋂S of part (c) and the ⋂S of Sets, Relations, and Cardinality, Definition 1.2.4, cut out of X, have the same membership condition, “x lies in every member of S”, and so they are the same set. The new version needs no ambient X: any member A0 of S does the job. For the empty S it would have to contain every set, and no set does (Sets, Relations, and Cardinality, Theorem 1.1.4); exercise B2 returns to this.

Quick check. Compute ⋃∅, ⋃{∅} and ⋃{{∅},{∅,{∅}}}.

Solution. ⋃∅=∅: an element would have to lie in some member of ∅, and ∅ has no members. ⋃{∅}=∅: the only member is ∅, which has no elements. ⋃{{∅},{∅,{∅}}}={∅,{∅}}: the first member contributes ∅, the second contributes ∅ and {∅}, and repeats do not count.

With Proposition 1.1.2 every set we have named so far is a set of the axioms, and so are the operations of Sets, Relations, and Cardinality, Section 1.2 on sets and on sets of sets: ∪, ∩, ∖, the power set (Z5), ⋃S, and ⋂S for non-empty S. Unions and intersections of an indexed family (Ai)i∈I need the family as a function, which needs ordered pairs; Section 1.2 returns to them. What is not yet built is an ordered pair; the warning above says why {a,b} will not do, and Section 1.2 builds one.

1.1.4. Exercises

A. Check your understanding

Exercise (A1)
  • (a) For each of the sets {∅}, {∅,{∅}}, P(∅), ⋃{∅}, and {x∈A:x∉x} for a given set A, name the axioms that produce it.
  • (b) True or false: for all sets a and b, {a}={b} implies a=b. Justify your answer.
  • (c) Prove that ⋃{a}=a for every set a.
  • (d) Is there a set T such that {x}∈T for every set x? Justify your answer.

Solution.

  • (a) {∅}: (Z2) for ∅, then (Z3) with both inputs ∅. {∅,{∅}}: (Z2), then (Z3) twice, once for {∅} and once with the inputs ∅ and {∅}. P(∅): (Z2), then (Z5); it is {∅}, since the only subset of ∅ is ∅. ⋃{∅}: (Z2), (Z3), then (Z4); it is ∅. {x∈A:x∉x}: (Z6) with ambient set A and the property ¬(x∈x). Uniqueness, in every case, is (Z1).

  • (b) True. Apply Proposition 1.1.2 (d) with c=d=b: {a}={b,b} gives a=b (and b=b).

  • (c) For every x: x∈⋃{a} if and only if x∈S for some S∈{a}. The only S∈{a} is a (Proposition 1.1.2 (b)), so this holds if and only if x∈a. The two sets have the same elements, so ⋃{a}=a by (Z1).

  • (d) No. Suppose T were such a set. By (Z4), ⋃T is a set. Let x be any set. Then x∈{x} and {x}∈T, so x∈⋃T. So every set is an element of ⋃T, which contradicts the second claim of Sets, Relations, and Cardinality, Theorem 1.1.4. Hence no such T exists.

B. Practice

Exercise (B1: Power sets and unions)
  • (a) Compute P(P(∅)).
  • (b) Prove that ⋃P(X)=X for every set X.

Solution.

  • (a) P(∅)={∅}, since the only subset of ∅ is ∅. So P(P(∅))=P({∅})={∅,{∅}}, as computed in the list of first sets after Axiom 1.1.1.

  • (b) We show both inclusions and apply Sets, Relations, and Cardinality, Proposition 1.1.1 (whose proof is (Z1) and logic).

(⊆) Let x∈⋃P(X). Then x∈S for some S∈P(X), that is, for some S⊆X. Hence x∈X.

(⊇) Let x∈X. The set {x} is a subset of X, since its only element is x (Proposition 1.1.2 (b)). So {x}∈P(X), and x∈{x}; hence x∈⋃P(X).

Exercise (B2: Intersections of sets of sets)
  • (a) Let S={X,Y} with X={∅,{∅}} and Y={{∅},{{∅}}}. Compute ⋂S twice: once with A0=X in Proposition 1.1.2 (c), once with A0=Y.
  • (b) Explain in one or two sentences why the two computations had to agree.
  • (c) Explain why the definition of ⋂S makes no sense for S=∅.

Solution.

  • (a) With A0=X: of the two elements of X, ∅ is not in Y (the elements of Y are {∅} and {{∅}}, both non-empty), and {∅} is in Y and in X. So ⋂S={{∅}}. With A0=Y: {∅} lies in X and in Y; {{∅}} does not lie in X, since it differs from ∅ (it has an element) and from {∅} (its element {∅} is not ∅). So again ⋂S={{∅}}.

  • (b) An element of either set must lie in every member of S, and that condition already forces it into A0, because A0 is a member. So the condition “x∈A0” adds nothing, and both computations describe the same elements.

  • (c) There is no A0∈∅ to cut the set out of. Without an ambient set, the condition “x∈S for every S∈∅” holds for every set x, vacuously; so ⋂∅ would be a set of which every set is an element, and there is no such set (Sets, Relations, and Cardinality, Theorem 1.1.4).

C. Going deeper

Exercise (C1: What the empty-set axiom really says; intersections as greatest lower bounds)
  • (a) Show that (Z2) follows from (Z6), once some set A is known to exist.
  • (b) Let S be a non-empty set. Show that ⋂S⊆S for every S∈S, and that every set C with C⊆S for all S∈S satisfies C⊆⋂S. Deduce that ⋂{A,B}=A∩B for all sets A, B.

Solution (Hint 1). For (a), cut a set out of A by a property that nothing has. For (b), unwind the membership condition of ⋂S from Proposition 1.1.2 (c).

Solution (Hint 2). For (a): consider {x∈A:x≠x}. For (b): let x∈⋂S and S∈S; what does the condition say at this S?

Solution.

  • (a) Let A be a set. By (Z6) with the property ¬(x=x), the set E:={x∈A:x≠x} exists. If x∈E, then x≠x, which contradicts x=x (=I, Logic and Proof, Definition 4.7.1). So E has no elements, and (Z2) holds. Thus in the presence of (Z6), (Z2) says only “there is a set”. The Axiom of Infinity of Section 1.3 also says that a set exists, so it could replace (Z2) altogether; that is how the full system is often stated, with the clause “∅∈I” of Section 1.3 read as “I has an element with no elements”, so that the symbol ∅ is not needed before (Z2) is. (In the logic of Logic and Proof, Chapter 4 even “there is a set” can be derived: =I gives x=x, and ∃I gives ∃x(x=x), because every domain is non-empty, Logic and Proof, Section 4.11. We keep (Z2) anyway, so that the axioms say plainly where the first set comes from.)

  • (b) Let x∈⋂S and S∈S. By the membership condition of Proposition 1.1.2 (c), x lies in every member of S, in particular in S. So ⋂S⊆S.

Now let C be a set with C⊆S for every S∈S, and let x∈C. Then x∈S for every S∈S. Choose A0∈S (possible, as S is non-empty); then x∈A0 as well, and so x satisfies the defining condition of ⋂S. Hence C⊆⋂S.

For S={A,B}, which is non-empty, the members are exactly A and B (Proposition 1.1.2 (b)). By the first part with S=A and with S=B, ⋂{A,B}⊆A and ⋂{A,B}⊆B, so ⋂{A,B}⊆A∩B. Conversely, A∩B⊆A and A∩B⊆B, so A∩B⊆S for every S∈{A,B}, and the second part gives A∩B⊆⋂{A,B}. Hence ⋂{A,B}=A∩B (Sets, Relations, and Cardinality, Proposition 1.1.1).

In words, (b) says that ⋂S is the largest set contained in every member of S: it is contained in each of them, and it contains every other set that is.

Marking scheme. (10 points) - 3: (a) produces a set with no elements by (Z6) from a given set, with a property that no set has, and proves it has no elements. - 2: (b) shows ⋂S⊆S from the membership condition, at the given S. - 3: (b) shows C⊆⋂S, placing x in the ambient member A0 as well as in every S. - 2: deduces ⋂{A,B}=A∩B using that the members of {A,B} are exactly A and B: by double inclusion, ⋂{A,B}⊆A∩B from the first half of (b) at S=A and S=B, and A∩B⊆⋂{A,B} from the second half with C=A∩B, then Sets, Relations, and Cardinality, Proposition 1.1.1 (or (Z1)). A solution that compares membership conditions directly earns the same 2.

Fatal errors (0 for the step): using a set of all sets, or ⋂∅; in (a), assuming ∅ exists in order to prove (Z2).
