1.4  The Natural Numbers Satisfy Peano’s Axioms

The previous section built ω and proved induction on it (Theorem 1.3.3). Sets, Relations, and Cardinality, Chapter 2 used two further facts about the natural numbers without a second thought: 0 is not of the form n+1, and m+1=n+1 forces m=n. For the sets of this chapter neither is automatic, and the obvious argument for the second fails, as we shall see. This section proves both for natural numbers, using one property of their membership structure; it then names the list of properties we have reached, Peano’s axioms, and shows that each of its last three items, (P3), (P4) and (P5), does a job that the other two cannot do.

1.4.1. Transitive sets

We want to prove: if m,n∈ω and S(m)=S(n), then m=n. The tempting move is to cancel, reading m∪{m}=n∪{n} as “the same thing was added to both”. But union does not cancel: {1}∪{0}={0}∪{1}, and 0≠1. What S(m)=S(n) does give is membership. Since m∈S(m)=S(n), either m∈n or m=n; and likewise n∈m or n=m. So the one bad case is m∈n and n∈m at once, two sets each inside the other.

For the numerals, membership only ever points to earlier numerals, and the elements of an element are earlier still. In 3={0,1,2}, the element 2 has the elements 0 and 1, and both are again elements of 3. This is the property we name.

A transitive set contains the elements of its elements.

Definition 1.4.1 (Transitive set)

A set x is transitive if every element of x is a subset of x: for every y∈x, y⊆x.

In words: unpacking y⊆x (Sets, Relations, and Cardinality, Definition 1.1.2), x is transitive when, for all sets y and z, z∈y  and  y∈x ⟹ z∈x. Membership passes through x in two steps: whatever is an element of an element of x is already an element of x. The name comes from this display, which has the shape of the transitivity of a relation (Sets, Relations, and Cardinality, Definition 2.4.1) with ∈ as the relation and x fixed at the end.

Examples, simplest first.

  • ∅ is transitive, vacuously: it has no element y at which the condition could fail. This degenerate case is the base of every induction below.
  • 1={0} is transitive: its only element is 0=∅, and ∅⊆1.
  • 3={0,1,2} is transitive: 0=∅⊆3, 1={0}⊆3, and 2={0,1}⊆3.

A non-example by minimal change: remove 1 from 3. The set {0,2} is not transitive, because its element 2={0,1} has the element 1, and 1∉{0,2} (1 differs from 0 and from 2, Example (The first natural numbers as sets)). Deleting one element broke the property at exactly one place.

Remark. Transitivity is a property of the set, and it fails for sets that look harmless. The set {1}={{∅}} is not transitive: 1∈{1}, but 1={0} is not a subset of {1}, since 0∉{1} (as 0≠1).

If m is transitive, then n∈m gives n⊆m, so m∈n and n∈m together give m∈m. So the bad case above reduces to a set that is an element of itself. The lemma below rules that out for natural numbers, and with it the bad case.

Lemma 1.4.1 (Natural Numbers Are Transitive Sets)
  • (a) Every n∈ω is a transitive set.
  • (b) ω is a transitive set: every element of a natural number is a natural number.
  • (c) n∉n for every n∈ω.
  • (d) Every n∈ω with n≠0 is S(k) for some k∈ω.
  • (e) 0∈n for every n∈ω with n≠0.

Idea. Each part is one use of the move of the previous section, show the set is inductive, in its property form Theorem 1.3.3 (b). The base is always 0=∅, where the claim is empty or immediate. The steps of (a)–(c) start from “y∈S(n) means y∈n or y=n” and treat the two cases. Part (c) is the only one that uses an earlier part: it argues by contradiction inside the step, and transitivity (a) is what turns a membership one level down into the forbidden n∈n. In (d) and (e) the statement is false at 0, so the property carried is a disjunction “n=0 or …”. Before reading on: in the proof of (c), why does S(n)∈n give n∈n?

Proof. Each part is proved by Theorem 1.3.3 (b), with the property named at its start.

(a) Let P(n) be “n is transitive”. P(0) holds because ∅ has no elements. Let n∈ω be transitive, and let y∈S(n). If y∈n, then y⊆n because n is transitive, and n⊆S(n); so y⊆S(n). If y=n, then y=n⊆S(n). In both cases y⊆S(n), so S(n) is transitive.

(b) Let P(n) be “n⊆ω”. P(0) holds because ∅⊆ω. Let n∈ω with n⊆ω. The elements of S(n)=n∪{n} are the elements of n, which lie in ω by hypothesis, and n itself, which lies in ω by the choice of n. So S(n)⊆ω. Hence n⊆ω for every n∈ω, which says that ω is transitive.

(c) Let P(n) be “n∉n”. P(0) holds because ∅ has no elements. Let n∈ω with n∉n, and suppose S(n)∈S(n). Then S(n)∈n or S(n)=n.

  • If S(n)∈n, then S(n)⊆n, because n is transitive by (a); and n∈S(n), so n∈n.
  • If S(n)=n, then n∈S(n)=n.

Both cases contradict n∉n. So S(n)∉S(n), by ¬I (Logic and Proof, Definition 2.2.1).

(d) Let P(n) be “n=0, or n=S(k) for some k∈ω”. P(0) holds by the first alternative. For every n∈ω, P(S(n)) holds by the second alternative, with k:=n. So P(n) holds for every n∈ω, and for n≠0 the second alternative is the claim.

(e) Let P(n) be “n=0 or 0∈n”. P(0) holds by the first alternative. Let n∈ω with P(n). If n=0, then S(n)={0}, which has 0 as an element. If 0∈n, then 0∈n⊆S(n). Either way 0∈S(n), so P(S(n)) holds. So P(n) holds for every n∈ω, and for n≠0 the second alternative is the claim. This proves the lemma.

The step of (d) never used P(n). As with the predecessor in Sets, Relations, and Cardinality, Chapter 2 (Sets, Relations, and Cardinality, Example (An induction that ignores its hypothesis)), the step’s conclusion was reached outright, and induction is still what guarantees that 0 and the successors are all there is. Part (b) says that the natural numbers are built only from natural numbers: unwrapping a natural number never leads outside ω. Part (c) is the fact the bad case needed.

1.4.2. Peano’s axioms for the natural numbers

Here is the list. Its five items are traditionally called Peano’s axioms; for ω they are theorems.

Theorem 1.4.2 (Peano’s Axioms Hold in ω)
  • (P1) 0∈ω.
  • (P2) For every n∈ω, S(n)∈ω.
  • (P3) For every n∈ω, S(n)≠0.
  • (P4) For all m,n∈ω, if S(m)=S(n), then m=n.
  • (P5) Every A⊆ω with 0∈A and S(n)∈A for every n∈A is equal to ω.

Moreover, {(n,S(n)):n∈ω} is a set, and with codomain ω it is a function S:ω→ω, which is injective and does not take the value 0.

Idea. (P1), (P2) and (P5) are the previous section restated: ω is inductive, and induction holds. (P3) is one line, since n∈S(n) and nothing is an element of ∅. (P4) is the argument of the opening of this section: S(m)=S(n) leaves only the case m∈n and n∈m to exclude, and transitivity with m∉m excludes it.

Proof. (P1) and (P2) say that ω is inductive, which is Theorem 1.3.2 (a). (P5) is Theorem 1.3.3 (a).

(P3) Let n∈ω. Then n∈S(n). If S(n)=0, then n∈0 by =E (Logic and Proof, Definition 4.7.1), which is impossible, since 0=∅ has no elements. So S(n)≠0, by ¬I (Logic and Proof, Definition 2.2.1).

(P4) Let m,n∈ω with S(m)=S(n). Since m∈S(m)=S(n), we have m∈n or m=n; likewise, since n∈S(n)=S(m), we have n∈m or n=m. Suppose m≠n. Then m∈n and n∈m. Since m is transitive (Lemma 1.4.1 (a)) and n∈m, we get n⊆m; so m∈n⊆m, that is, m∈m. This contradicts Lemma 1.4.1 (c). Hence m=n, by RAA (Logic and Proof, Definition 2.5.1).

For the function: let G:={p∈ω×ω:p=(n,S(n)) for some n∈ω}, a set by Separation (Z6) inside the product ω×ω of Proposition 1.2.2; the pairs (n,S(n)) lie in that product by (P2). We check the two clauses of Sets, Relations, and Cardinality, Definition 1.4.1. (Fn1): for n∈ω, (n,S(n))∈G. (Fn2): if (n,y)∈G and (n,y′)∈G, then (n,y)=(k,S(k)) and (n,y′)=(k′,S(k′)) for some k,k′∈ω; by Theorem 1.2.1, k=n=k′, and then y=S(n)=y′. So (G,ω) is a function ω→ω, whose value at n is S(n). It is injective by (P4) (Sets, Relations, and Cardinality, Definition 1.4.3), and 0 is not a value by (P3). This proves the theorem.

The function S:ω→ω and the operation x↦S(x) on all sets share a letter, and they agree wherever both are defined. Only the first is a set. The operation has no graph: a set containing the pair (x,S(x))={{x},{x,S(x)}} for every set x would give, after two unions, a set containing every set, which Sets, Relations, and Cardinality, Theorem 1.1.4 forbids.

One more consequence is used constantly. By Lemma 1.4.1 (d), every n∈ω with n≠0 is S(k) for some k∈ω, and by (P4) this k is unique: if S(k)=n=S(k′), then k=k′. So every non-zero natural number has exactly one predecessor, and 0 has none, by (P3).

Quick check. Is the function S:ω→ω surjective? Is ω∈ω?

Solution. No to both. S is not surjective: 0∈ω, and by (P3) no n∈ω has S(n)=0. (Every other natural number is a value, by Lemma 1.4.1 (d).)

If ω∈ω, then ω would be a natural number n with n∈n, which Lemma 1.4.1 (c) rules out. So ω∉ω. In particular ω is a set that is not a natural number, although all its elements are.

1.4.3. Peano systems

Sets, Relations, and Cardinality, Chapter 2 worked with a set N of real numbers, and this chapter with a set ω of sets. Both come with a starting element and a step. The last section of the chapter asks whether they are “the same”, and to ask it we need to say what any such structure must satisfy. The answer is the list just proved, with ω, 0 and S replaced by letters.

A Peano system is a set with a start and a step, where the step is one-to-one, never returns to the start, and reaches everything.

Definition 1.4.2 (Peano system)

A Peano system (M,e,s) consists of a set M, an element e∈M, and a function s:M→M, such that:

  • (P3) s(x)≠e for every x∈M;
  • (P4) s is injective;
  • (P5) every subset A⊆M with e∈A and s(x)∈A for every x∈A is equal to M.

In words: (P1) and (P2) are built into the data, since e∈M and s maps M into M. (P3) says the step never leads back to the start. (P4) says two different elements never step to the same element. (P5) is induction for M: a subset that contains the start and is closed under the step is everything, so every element of M is reached from e by steps. We write (M,e,s) and not (N,e,s), so that the letter never suggests N. The notation (M,e,s) lists the three pieces of data; it is not a set built from them (if one object is wanted, take the pair ((M,e),s) of Definition 1.2.1).

The first example is the one we have, and the second shows that the elements need not be numbers.

  • (ω,0,S) is a Peano system, by Theorem 1.4.2: S:ω→ω is a function, and (P3)–(P5) are those of the theorem.
  • Tagged numbers. Let M:=ω×{0}, a set by Proposition 1.2.2, let e:=(0,0), and let s(n,0):=(S(n),0). Every element of M is (n,0) for exactly one n∈ω (Theorem 1.2.1), so s is well defined, and its graph is a set by (Z6) inside M×M. (P3): (S(n),0)=(0,0) would give S(n)=0 by Theorem 1.2.1, against (P3) for ω. (P4): (S(m),0)=(S(n),0) gives S(m)=S(n), so m=n by (P4) for ω. (P5): let A⊆M contain e and be closed under s. The set B:={n∈ω:(n,0)∈A} has 0 as an element and is closed under S, so B=ω by Theorem 1.3.3 (a), and A=M. Here e=(0,0)={{0}} is not ∅, and no element of M is a natural number, as we shall see at the end of the section.

Why these three clauses and no others? Each one does work that the other two cannot do: for each clause there is a structure satisfying the other two and failing it.

Example (Each axiom is needed)

Show that each of the following structures (M,e,s), with s:M→M, satisfies two of (P3), (P4), (P5) and fails the third.

  • (i) M:={0}, e:=0, s(0):=0.
  • (ii) M:={0,1}, e:=0, s(0):=1, s(1):=1.
  • (iii) (The natural numbers beside a two-sided chain.) M:=ω×3, whose elements are the pairs (n,i) with n∈ω and i∈3={0,1,2}; e:=(0,0); and s(n,0):=(S(n),0),s(n,1):=(S(n),1),s(0,2):=(0,1),s(S(k),2):=(k,2), for n,k∈ω.

Solution.

  • (i) Fails (P3): s(0)=0=e. (P4) holds: M has one element, so two inputs with equal outputs are equal. (P5) holds: a subset of {0} containing e=0 is {0}.

  • (ii) Fails (P4): s(0)=s(1) with 0≠1. (P3) holds: both values are 1≠0=e. (P5) holds: if A⊆{0,1} has 0 as an element and is closed under s, then s(0)=1∈A, so A={0,1}.

  • (iii) First, s is a function M→M. Each element of M is (n,i) for exactly one n∈ω and one i∈3, by Theorem 1.2.1. For i=2, the first coordinate is 0 or S(k) with k∈ω (Lemma 1.4.1 (d)); never both, by (P3) for ω; and the k is unique, by (P4) for ω. So exactly one line of the definition applies to each element, and it names one value. The values lie in M, since S(n),0,k∈ω. The graph is a set by (Z6) inside M×M.

To check (P3) and (P4), sort the values by their second coordinates, which are 0, 1 and 2, three different sets (Example (The first natural numbers as sets)): second coordinate 0:s(n,0)=(S(n),0),second coordinate 1:s(n,1)=(S(n),1)  and  s(0,2)=(0,1),second coordinate 2:s(S(k),2)=(k,2).

(P3) holds. A value equal to e=(0,0) would have second coordinate 0, so it would be (S(n),0) with S(n)=0, against (P3) for ω.

(P4) holds. Suppose s(x)=s(x′). The two values have the same second coordinate, so they come from the same row of the display. In the first row, (S(n),0)=(S(n′),0) gives n=n′ by Theorem 1.2.1 and (P4) for ω. In the third row, (k,2)=(k′,2) gives k=k′, so S(k)=S(k′). In the second row, (S(n),1)≠(0,1) because S(n)≠0; so either both values are of the form (S(n),1), and n=n′ as before, or both are (0,1), and both inputs are (0,2). In every case x=x′.

(P5) fails. Let A:=ω×{0}, a subset of M (Proposition 1.2.2). It contains e=(0,0), and it is closed under s, since s(n,0)=(S(n),0)∈A. But (0,1)∈M is not in A, because its second coordinate 1 is not 0. So A≠M.

The picture shows (iii), with an arrow from each element to its image under s.

The top row is a copy of ω, starting at e. The bottom row is a chain running forever in both directions: read (n,1) as “n” and (k,2) as “−(k+1)”, and s adds one everywhere, with (0,2), playing −1, stepping to (0,1), playing 0. Every element has exactly one arrow out and at most one arrow in, which is (P4); only e has no arrow in, which is (P3). What fails is that the bottom row cannot be reached from e. Induction, (P5), is the clause that says “nothing else”.

So (P3) and (P4) alone cannot prevent extra elements: in (iii) the whole bottom row is extra. That is why the definition of ω needed “least”, and why induction is part of the list.

1.4.4. Pairs are not natural numbers

Sets, Relations, and Cardinality, Chapter 1 adopted a working convention, stated after Sets, Relations, and Cardinality, Definition 1.3.1: a pair is not a number. In that chapter numbers were given and pairs were postulated, and the convention said they were different kinds of object. Now both are sets: a pair is the set {{a},{a,b}} of Definition 1.2.1, and a natural number is an element of ω. For natural numbers the convention becomes a theorem.

Proposition 1.4.3 (No Pair Is a Natural Number)

For all sets a and b, the pair (a,b) is not an element of ω.

Idea. Every natural number other than 0 has ∅ as an element, by Lemma 1.4.1 (e). A pair is not ∅, and it does not have ∅ as an element, because both of its elements contain a.

Proof. Let a,b be sets, and suppose (a,b)={{a},{a,b}}∈ω (Definition 1.2.1). The pair has the element {a}, so (a,b)≠∅=0. By Lemma 1.4.1 (e), 0=∅∈(a,b), so ∅={a} or ∅={a,b}. Both are impossible, since a∈{a} and a∈{a,b}, while ∅ has no elements. This contradiction shows (a,b)∉ω.

So, for instance, the tagged numbers (n,0) in the second example of a Peano system above are never natural numbers, and Sets, Relations, and Cardinality, Chapter 1’s answer that ((1,2),3)≠(1,(2,3)) because “a pair is not a number” is borne out by Proposition 1.4.3 once the numbers 1, 2, 3 are read as elements of ω, as the later chapters of this volume read N (Section 1.7). The same statement for n-tuples with n≥3 needs a definition of n-tuples, which comes later in this chapter, together with the order on ω.

Warning. The encoding produces true statements that sound absurd. Since {0}=1 and {0,1}=2, (0,1)={{0},{0,1}}={1,2}, so “1∈(0,1)” is true of the pair (0,1), although 1 is not in the open interval (0,1) of real numbers, and “0∈(0,1)” is false of the pair. Such a statement is a fact about how pairs were encoded as sets, not about pairs: with Wiener’s encoding {{{a},∅},{{b}}}, met in Section 1.2 (Exercise (C3: Wiener’s encoding)), the pair of 0 and 1 is {2,{{1}}}, which does not have 1 as an element. A proof about pairs should use only their characteristic property, Theorem 1.2.1. The places in this section that look inside a pair (the remark after Theorem 1.4.2 that the operation x↦S(x) has no graph, the closing remark of the tagged-numbers example that (0,0)={{0}} is not ∅, Proposition 1.4.3, and this warning) are about the encoding itself.

With Peano’s axioms in hand, the next section proves the recursion theorem on ω and uses it to define addition and multiplication.

1.4.5. Exercises

A. Check your understanding

Exercise (A1)
  • (a) For each of the three structures in Example (Each axiom is needed), which of (P3), (P4), (P5) fails?
  • (b) In the proof of (P4) in Theorem 1.4.2, where is Lemma 1.4.1 (a) used, and where is (c)?
  • (c) Is ω∪{ω} inductive? Justify your answer.
  • (d) Is {0,1,{1}} a transitive set? Is it an element of ω?

Solution.

  • (a)
    • (i) fails (P3); (ii) fails (P4); (iii) fails (P5). Each satisfies the other two (Example (Each axiom is needed)).

  • (b) Part (a) is used to pass from n∈m to n⊆m: m is a natural number, hence a transitive set. Part (c) is used at the end: the argument reaches m∈m, and (c) says m∉m, which gives the contradiction.

  • (c) No. The set ω∪{ω}=S(ω) has ∅ as an element and is closed under S on its elements from ω, but S(ω) itself is not an element of ω∪{ω}. First, S(ω)≠ω: ω∈S(ω), while ω∉ω (the Quick check after Theorem 1.4.2). Second, S(ω)∉ω: otherwise S(ω)⊆ω because ω is transitive (Lemma 1.4.1 (b)), and ω∈S(ω) would give ω∈ω. So the closure clause fails at the element ω.

  • (d) It is transitive: 0=∅ is a subset of every set; 1={0} is a subset, since 0 is listed; {1} is a subset, since 1 is listed. It is not an element of ω: by Lemma 1.4.1 (b), every element of a natural number is a natural number, and {1} is not one. Indeed {1}≠0, and if {1}=S(k)=k∪{k} with k∈ω, then k∈{1}, so k=1, and S(1)={0,1}≠{1} since 0∉{1}; this contradicts Lemma 1.4.1 (d). So being transitive does not make a set a natural number.

B. Practice

Exercise (B1: Put the proof in order)

Let m,n∈ω. The following lines contain a proof that if S(m)=S(n), then m=n, shuffled, together with two lines that do not belong. Write the seven correct lines in an order that makes a proof, say which other orders are also admissible, and say why each of the other two lines fails.

  • (i) So m∈n⊆m, that is, m∈m.

  • (ii) Suppose S(m)=S(n).

  • (iii) We have m∪{m}=n∪{n}, so m=n by canceling ∪{⋅} on both sides.

  • (iv) Since n∈S(n)=S(m), we have n∈m or n=m.

  • (v) Suppose m≠n; then m∈n and n∈m.

  • (vi) This contradicts m∉m (Lemma 1.4.1 (c)); so m=n.

  • (vii) From m∈n and n∈m we get m=n, since ∈ is antisymmetric.

  • (viii) Since m is transitive (Lemma 1.4.1 (a)) and n∈m, we have n⊆m.

  • (ix) Since m∈S(m)=S(n), we have m∈n or m=n.

Solution. An admissible order is (ii), (ix), (iv), (v), (viii), (i), (vi):

Suppose S(m)=S(n). Since m∈S(m)=S(n), we have m∈n or m=n. Since n∈S(n)=S(m), we have n∈m or n=m. Suppose m≠n; then m∈n and n∈m. Since m is transitive and n∈m, we have n⊆m. So m∈n⊆m, that is, m∈m. This contradicts m∉m; so m=n.

The only other admissible order exchanges (ix) and (iv), which use only (ii) and not each other. Everything else is forced: (v) needs both (ix) and (iv) to reduce each disjunction to its first alternative; (viii) needs the n∈m of (v); (i) needs the m∈n of (v) and the inclusion of (viii); (vi) closes the RAA box opened by (v), whose assumption is m≠n, the negation of the goal (Logic and Proof, Definition 2.5.1).

The distractor (iii) cancels where no cancellation law exists. For sets in general, x∪{y}=x′∪{y′} does not give y=y′: {1}∪{0}={0}∪{1} with 0≠1. For natural numbers the conclusion m=n happens to be true, but that is the statement being proved, not a reason for it.

The distractor (vii) cites a “fact” that is not available. No result so far says that m∈n and n∈m cannot both hold, and for natural numbers that is exactly what lines (viii), (i) and (vi) establish. Citing it is the circular step (N9) of Logic and Proof, Example (What is not allowed): the line uses, as a reason, what the proof is there to show.

Exercise (B2: Two steps at a time)

Let d:=S∘S:ω→ω (Sets, Relations, and Cardinality, Definition 1.4.2), so that d(n)=S(S(n)). Show that (ω,0,d) satisfies (P3) and (P4) of Definition 1.4.2, and that it does not satisfy (P5).

Hint: look at the set ω∖{1}.

Solution. (P3): for n∈ω, d(n)=S(S(n))≠0 by (P3) of Theorem 1.4.2, applied to S(n)∈ω.

(P4): if d(m)=d(n), then S(S(m))=S(S(n)), so S(m)=S(n) by (P4) of Theorem 1.4.2, and then m=n by (P4) again. (Equivalently: d is a composite of two injections, so it is injective by Sets, Relations, and Cardinality, Theorem 1.4.4 (a).)

(P5) fails. Let A:=ω∖{1}. It contains 0, since 0≠1. It is closed under d: let n∈A; then d(n)∈ω, and d(n)≠1, because S(S(n))=1=S(0) would give S(n)=0 by (P4), against (P3). But A≠ω, since 1∈ω and 1∉A. So a subset of ω with 0 as an element and closed under d need not be all of ω. The step d skips 1, and starting from 0 it reaches only the “even” numbers.

C. Going deeper

Exercise (C1: A Peano system with a different start)

Give an example of a Peano system (M,e,s) with M⊆ω and e≠0. Check every clause of Definition 1.4.2.

Solution. Any correct answer has: a set M⊆ω; an element e∈M with e≠0; a function s:M→M, so that every value lies in M; and the three clauses (P3), (P4), (P5) for these data.

Take M:=ω∖{0}, e:=1, and s(n):=S(n) for n∈M.

  • The data. 1∈M, since 1∈ω and 1≠0. For n∈M, S(n)∈ω by (P2) and S(n)≠0 by (P3) of Theorem 1.4.2, so S(n)∈M. The graph {(n,S(n)):n∈M} is a set by (Z6) inside M×M. (Fn1) holds, since (n,S(n)) is in the graph for each n∈M; (Fn2) holds as in the proof of Theorem 1.4.2, by Theorem 1.2.1. So s:M→M is a function (Sets, Relations, and Cardinality, Definition 1.4.1).
  • (P3). If s(n)=1 for some n∈M, then S(n)=S(0), so n=0 by (P4) for ω; but 0∉M.
  • (P4). If S(m)=S(n) with m,n∈M, then m=n by (P4) for ω.
  • (P5). Let A⊆M with 1∈A and S(n)∈A for every n∈A. The set A′:=A∪{0}⊆ω is inductive: 0∈A′; S(0)=1∈A⊆A′; and for n∈A, S(n)∈A⊆A′. By Theorem 1.3.3 (a), A′=ω. Every n∈M lies in A′ and is not 0, so n∈A. Hence A=M.

Other answers can be checked against the four properties at the start. For instance, M:=ω∖{0,1}, e:=2, s(n):=S(n) also works, by the same argument with {0,1} added in (P5).

Exercise (C2: Closed subsets of the chain)

Let (M,e,s) be the structure (iii) of Example (Each axiom is needed). Call A⊆M good if e∈A and s(x)∈A for every x∈A.

  • (a) Show that every good set contains ω×{0}.
  • (b) Show that each of the following sets is good, where m,k∈ω: G0:=ω×{0},G∞:=M,Rm:=G0∪{(n,1):n∈ω, m∈S(n)},Lk:=G0∪(ω×{1})∪{(j,2):j∈S(k)}.
  • (c) Show that a good set that contains (k,2) contains Lk.

Solution (Hint 1). For (a), apply induction to the set of n∈ω with (n,0)∈A. For (c), the arrows of the bottom row point toward (0,1): from (S(k),2) the step goes to (k,2).

Solution (Hint 2). For (c), prove by induction on k∈ω the property: “for every good A, if (k,2)∈A, then Lk⊆A”.

Solution.

  • (a) Let A be good, and let B:={n∈ω:(n,0)∈A}. Then 0∈B, because (0,0)=e∈A; and if n∈B, then (S(n),0)=s(n,0)∈A, so S(n)∈B. By Theorem 1.3.3 (a), B=ω, so ω×{0}⊆A.

  • (b) All four sets contain e=(0,0)∈G0. Closure is checked element by element, using the definition of s.

    • G0: s(n,0)=(S(n),0)∈G0.
    • G∞=M: s maps M into M.
    • Rm: elements of G0 are handled as before. If (n,1)∈Rm with m∈S(n), then s(n,1)=(S(n),1), and m∈S(n)⊆S(S(n)); so s(n,1)∈Rm.
    • Lk: elements of G0 as before; s(n,1)=(S(n),1)∈ω×{1}. Every j∈S(k) lies in ω, since S(k)∈ω by (P2) of Theorem 1.4.2 and ω is transitive (Lemma 1.4.1 (b)); so Lk⊆M. For (j,2) with j∈S(k): if j=0, then s(0,2)=(0,1)∈Lk; if j=S(i) with i∈ω (Lemma 1.4.1 (d)), then s(j,2)=(i,2), and i∈S(i)=j∈S(k), so i∈S(k) because S(k) is transitive (Lemma 1.4.1 (a)); hence (i,2)∈Lk.
  • (c) We prove by Theorem 1.3.3 (b) the property P(k): “for every good A, if (k,2)∈A, then Lk⊆A”.

Base. Let A be good with (0,2)∈A. Then (0,1)=s(0,2)∈A. The set {n∈ω:(n,1)∈A} has 0 as an element and is closed under S, since s(n,1)=(S(n),1); so it is ω by Theorem 1.3.3 (a), and ω×{1}⊆A. With (a) and S(0)={0}, this gives L0⊆A.

Step. Let k∈ω with P(k), and let A be good with (S(k),2)∈A. Then (k,2)=s(S(k),2)∈A, so Lk⊆A by P(k). Now LS(k)=Lk∪{(S(k),2)}, because j∈S(S(k)) means j∈S(k) or j=S(k). Both parts lie in A, so LS(k)⊆A, which is P(S(k)).

So the good sets include G0, the sets Rm (whose part in the bottom row starts at (m,1) and runs to the right), the sets Lk (whose part in the bottom row starts at (k,2)), and M. Read on the two-sided chain, these are the empty part, the rays starting at some point, and the whole chain. That they are all the good sets is also true, but the proof needs a least element of a non-empty set of natural numbers, which comes later in this chapter with the order on ω. Part (c) already shows that a good set containing every (k,2) contains every Lk, hence all of M. Every good set other than M is a witness to the failure of (P5).
