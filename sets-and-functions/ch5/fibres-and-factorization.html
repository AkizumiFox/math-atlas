5.2  Fibers and the Canonical Factorization

Section 4.2 cut a set into classes, and Section 5.1 cut functions down and glued them together. This section joins the two threads. Every function sorts its domain into piles by value, the fibers, and we prove that the piles carry all the information the function has, apart from the names of the values: every function is a quotient map, then a bijection, then an inclusion. Read in reverse, the same argument says exactly which functions on a set pass to a function on a quotient set, and gives a method for defining one.

5.2.1. Functions on the clock

Section 4.2 built the clock Z/12, whose elements are the twelve hours [0],[1],…,[11]. Some questions about an integer are really questions about its hour. “Is a even?” is one: 14 and 2 name the same hour, and both are even; 13 and 1 name the same hour, and both are odd. In general, let g:Z→Y be a function with g(a)=g(a′)whenever 12∣a−a′, so that g takes one value on each class modulo 12. Then g “is” a function of the hour: to compute it at an hour, pick any integer naming that hour and apply g. The condition is stated for all pairs in one class at once. A condition such as g(a+12)=g(a) for every a says the same thing in the end, but getting from it to g(a+12k)=g(a) for every k∈Z takes an induction in each direction.

Other functions are not functions of the hour. “Is a positive?” gives different answers at 2 and at −10, which name the same hour, so no function on Z/12 can answer it.

There is a second way into the same idea, from the side of an arbitrary function. A function f:X→Y sorts its domain: put two points in one pile when f gives them the same value. Section 4.2 met these piles as the classes of the relation ∼f (Example (The fibers of a function)). So every function produces a quotient set of its domain.

Two questions organize the section.

  • (Q1) Given an equivalence relation ∼ on X, when does a function on X pass to a function on X/∼, and is the function it passes to unique?
  • (Q2) What does a function look like once its domain has been sorted by value?

We answer (Q2) first, because its answer contains the answer to (Q1).

5.2.2. The fibers of a function

Recall the relation of Example (The fibers of a function). For f:X→Y and x,x′∈X, x∼fx′ means f(x)=f(x′). It is an equivalence relation on X, and the class of a∈X is the fiber of f over f(a), [a]={x∈X:f(x)=f(a)}=f−1({f(a)}), a preimage in the sense of Definition 1.7.2. A fiber over a point of Y that f never takes is empty, and so is not a class.

The fibers of a function are the piles it sorts its domain into, one pile for each value it takes.

Proposition 5.2.1 (The Fibers of a Function)

Let f:X→Y be a function.

  • (a) The fibers f−1({y}) over the points y∈f(X) are exactly the classes of ∼f, and they form a partition of X.
  • (b) The rule y↦f−1({y}) is a bijection f(X)→X/∼f. Hence |f(X)|=|X/∼f|.

Idea. Part (a) is already proved: Example (The fibers of a function) identified the classes with the fibers, and Theorem 4.2.1 says the classes partition X. For (b), a fiber over a value is a class, so the rule lands in X/∼f; every class is the fiber over the value at its representative, which is surjectivity; and two different values have different fibers, because a point of the first fiber is not in the second.

Proof. (a) Let y∈f(X), say y=f(a) with a∈X (Definition 1.7.1). Then f−1({y})=f−1({f(a)})=[a], by the computation in Example (The fibers of a function); so each such fiber is a class. Conversely, each class is [a] for some a∈X, and [a]=f−1({f(a)}) with f(a)∈f(X). So the fibers over the points of f(X) are the elements of X/∼f, and these form a partition of X by Theorem 4.2.1 (d).

(b) By (a), each y∈f(X) is sent to an element of X/∼f, and to only one, so the rule is a function Φ:f(X)→X/∼f (Definition 1.5.1). It is surjective: an element of X/∼f is [a] for some a∈X, and [a]=Φ(f(a)) by (a). It is injective: let y,y′∈f(X) with y≠y′, and write y=f(a) with a∈X. Then a∈f−1({y}), while a∉f−1({y′}) because f(a)=y≠y′. So Φ(y)≠Φ(y′), and different values have different fibers. Hence Φ is a bijection (Definition 1.5.5), and |f(X)|=|X/∼f| by Definition 2.5.1.

So a function takes exactly as many values as it has fibers, in the sense of equinumerosity: the values and the piles can be paired off. The partition remembers which points share a value, and forgets only what the values are called.

Quick check. List the classes of ∼f for f(n)=n2−2n on {−1,0,1,2,3}, and match each class with its value.

Solution. The values are f(−1)=3, f(0)=0, f(1)=−1, f(2)=0, f(3)=3. So the classes are {−1,3} (value 3), {0,2} (value 0) and {1} (value −1): three classes for the three values in f(X)={−1,0,3}.

The proposition explains a computation of Section 4.2. In Example (Same size, revisited), the subsets of {1,2,3} were sorted by “same number of elements”. That relation is ∼f for the function f:P({1,2,3})→{0,1,2,3} sending each subset to its number of elements, a function by Proposition 2.5.6 (every subset has some number of elements, at most 3) and Corollary 2.5.4 (only one). Its four fibers are {∅}, the three singletons, the three pairs, and {{1,2,3}}, and its image is all of {0,1,2,3}. Part (c) of that example, the well-defined map from classes to numbers, is the bijection of (b) read backwards.

Quick check. List the fibers of f:{1,…,6}→{0,1,2}, where f(n) is the remainder of n on division by 3.

Solution. f−1({0})={3,6}, f−1({1})={1,4}, f−1({2})={2,5}. Three fibers, three values; every value is taken, so f(X) is the whole codomain.

5.2.3. Every function factors

Now (Q2). The quotient map q:X→X/∼f, q(x)=[x] (Definition 4.2.4), sends each point to its fiber. The bijection of Proposition 5.2.1 (b) goes from values to fibers; turn it around, and it sends the fiber [x] to the value f(x). Finally, a value of f lies in the image f(X), and the inclusion map ι:f(X)→Y, ι(y)=y (Definition 5.1.1), puts it back into the codomain. Composed, the three maps take x to [x], to f(x), to f(x). That is f.

Theorem 5.2.2 (Canonical Factorization)

Let f:X→Y be a function, let q:X→X/∼f be the quotient map, and let ι:f(X)→Y be the inclusion map. There is exactly one function f¯:X/∼f→f(X) with f=ι∘f¯∘q. It is given by f¯([x])=f(x), and it is a bijection.

Idea (Scratch work). The only candidate is forced. If ι(f¯(q(x)))=f(x), then f¯([x])=f(x), since ι changes no value. So uniqueness costs nothing, and the work is to show that the forced rule is a function and a bijection. The rule [x]↦f(x) reads a representative, so the first check is well-definedness, by the method of Example (Method: checking that a definition on classes is well defined). The twist is in the table’s third row: injectivity is the well-definedness line read backwards.

Givens Goal
[x]=[x′]⟺x∼fx′ (Theorem 4.2.1 (b)), and x∼fx′⟺f(x)=f(x′) f¯ a function, bijective, f=ι∘f¯∘q, unique
[x]=[x′] f(x)=f(x′): one class, one value, (Fn2), well defined
f(x)=f(x′) [x]=[x′]: injective, the same equivalence read right to left
y∈f(X), so y=f(a) with a∈X y=f¯([a]): surjective

Uniqueness: q is onto, so every class is [x] for some x; a second f¯′ with ι∘f¯′∘q=f has f¯′([x])=f(x) at every class. The proof writes this forwards.

Proof. A function. Every element of X/∼f is [x] for some x∈X, and f(x)∈f(X) by Definition 1.7.1; this gives (Fn1). Let [x]=[x′]. By Theorem 4.2.1 (b), x∼fx′, that is, f(x)=f(x′). So all representatives of one class give one value, which is (Fn2), and f¯([x]):=f(x) defines a function f¯:X/∼f→f(X) (Definition 1.5.1).

Injective. Let f¯([x])=f¯([x′]), that is, f(x)=f(x′). Then x∼fx′, and [x]=[x′] by Theorem 4.2.1 (b).

Surjective. Let y∈f(X). By Definition 1.7.1 there is a∈X with f(a)=y, and then f¯([a])=f(a)=y.

The factorization. Both f and ι∘f¯∘q have domain X and codomain Y, and for every x∈X, (ι∘f¯∘q)(x)=ι(f¯([x]))=ι(f(x))=f(x), by Definition 1.5.2. Hence f=ι∘f¯∘q by Proposition 1.5.1.

Uniqueness. Let f¯′:X/∼f→f(X) satisfy f=ι∘f¯′∘q. Every element of X/∼f is [x]=q(x) for some x∈X, and f¯′([x])=ι(f¯′(q(x)))=f(x)=f¯([x]), where the first equality holds because ι sends each point to itself. The two functions have the same domain and codomain, so f¯′=f¯ by Proposition 1.5.1. This proves the theorem.

Read the factorization from left to right: every function is a surjection (q, onto by Definition 4.2.4), followed by a bijection (f¯), followed by an injection (ι, which sends each point to itself, so different points stay different). All the identifying is done by q, all the renaming by f¯, and all the enlarging of the target by ι. The two properties of Section 1.5 sit at the two ends. The function f is injective exactly when q is: if f is injective and q(x)=q(x′), then x∼fx′ by Theorem 4.2.1 (b), so f(x)=f(x′) and x=x′; if q is injective and f(x)=f(x′), then x∼fx′, so q(x)=q(x′) by Theorem 4.2.1 (b), and x=x′. And f is surjective exactly when f(X)=Y, that is, when ι=idY.

Warning. The middle map is a bijection onto the image, not onto the codomain. With target Y, the rule [x]↦f(x) is still a well-defined injection, but it is surjective only when f is. For f(x)=x2 on R, the rule [x]↦x2 maps the classes {−x,x} onto [0,∞) and reaches no negative number of the codomain R.

The factorization also explains a failure from Section 1.5.

Example (Fractions as classes)

Let f:Z×Z>0→Q, f(a,b):=a/b. Describe ∼f, the three maps of Theorem 5.2.2, and decide whether “send a/b to its numerator a” passes through q.

Solution. The relation. (a,b)∼f(c,d) means a/b=c/d, and since b,d≠0 this holds exactly when ad=bc, by the arithmetic of fractions. It is the relation of Exercise B1 in Section 4.2 (Exercise (B1: Fractions as classes)), now seen as the fiber relation of a function; that it is an equivalence relation is also immediate from Example (The fibers of a function). The class of (1,2) is the fiber over 12: the pairs (1,2),(2,4),(3,6),…, all the ways of writing one half as a fraction.

The three maps. The quotient map q sends a pair to its class, “the fraction a/b up to rewriting”. The map f¯ sends a class to the rational number its pairs all name. And f is onto Q, since every rational number is a/b for some a∈Z and b∈Z>0; so f(X)=Q and ι=idQ. By Theorem 5.2.2, f¯ is a bijection from the set of classes onto Q: a rational number “is” a class of fractions, and nothing is lost by identifying the two.

The numerator. Let p(a,b):=a. If p were g∘q for some function g on the classes, then (a,b)∼f(c,d) would force p(a,b)=g([(a,b)])=g([(c,d)])=p(c,d). But (1,2)∼f(2,4), since 1⋅4=2⋅2, while p(1,2)=1≠2=p(2,4). So p does not pass through q, and no function on the classes, hence none on Q, sends each fraction to its numerator. This is the failure of Example (Relations that are not functions) (b), located: the numerator is a function of the pair, not of its fiber.

Quick check. In Example (Fractions as classes), which of q, f¯, ι are injective, and which are surjective?

Solution. q is surjective, and not injective, since q(1,2)=q(2,4). f¯ is both, by Theorem 5.2.2. ι is injective, as every inclusion is; here it is idQ, so it is also surjective.

5.2.4. Functions out of a quotient

Now (Q1). The canonical factorization built a function on the classes of ∼f from f itself. Nothing in its first step needed the relation to come from f: what made [x]↦f(x) a function was only that equivalent points have equal values. So the same argument works for any equivalence relation, as long as the function is constant on its classes.

Theorem 5.2.3 (Functions out of a Quotient)

Let ∼ be an equivalence relation on a set X, let q:X→X/∼ be its quotient map, and let g:X→Z be a function.

  • (a) There is a function g¯:X/∼→Z with g¯∘q=g if and only if g is constant on classes: for all x,x′∈X, if x∼x′, then g(x)=g(x′). In that case g¯ is unique, and g¯([x])=g(x).
  • (b) Suppose g is constant on classes. Then g¯ is injective if and only if, for all x,x′∈X, g(x)=g(x′) implies x∼x′.
  • (c) Suppose g is constant on classes. Then g¯ is surjective if and only if g is surjective.

Idea. This is the argument of Theorem 5.2.2 with ∼ in place of ∼f (Example (Method: checking that a definition on classes is well defined) for the existence, q onto for the uniqueness). The new part is the forward direction of (a): if g¯ exists, equivalent points have one class, so g=g¯∘q gives them one value. For (b) and (c), translate statements about classes into statements about representatives with Theorem 4.2.1 (b).

Proof. (a) (⇒) Suppose g¯∘q=g, and let x∼x′. Then q(x)=[x]=[x′]=q(x′) by Theorem 4.2.1 (b), so g(x)=g¯(q(x))=g¯(q(x′))=g(x′).

(⇐) Suppose g is constant on classes. Every element of X/∼ is [x] for some x∈X, with g(x)∈Z, which is (Fn1). If [x]=[x′], then x∼x′ by Theorem 4.2.1 (b), so g(x)=g(x′), which is (Fn2). Hence g¯([x]):=g(x) defines a function g¯:X/∼→Z (Definition 1.5.1). Both g¯∘q and g have domain X and codomain Z, and (g¯∘q)(x)=g¯([x])=g(x) for every x∈X, so g¯∘q=g by Proposition 1.5.1.

Uniqueness. If h:X/∼→Z also satisfies h∘q=g, then each element of X/∼ is q(x) for some x∈X, since q is onto (Definition 4.2.4), and h(q(x))=g(x)=g¯(q(x)). So h=g¯ by Proposition 1.5.1.

(b) By Definition 1.5.3, g¯ is injective when g¯(C)=g¯(D) implies C=D for all C,D∈X/∼. Every class is [x] for some x∈X, and g¯([x])=g(x); so the condition reads: for all x,x′∈X, g(x)=g(x′) implies [x]=[x′]. By Theorem 4.2.1 (b), [x]=[x′] is x∼x′.

(c) By Definition 1.5.4, g¯ is surjective when every z∈Z is g¯(C) for some class C. Since every class is [x] for some x∈X, and g¯([x])=g(x), this says that every z∈Z is g(x) for some x∈X: that g is surjective.

The canonical factorization is the case where ∼ is ∼f, with g the function X→f(X), x↦f(x). That g is constant on the classes of ∼f by the definition of ∼f; the converse condition of (b) holds for the same reason, so g¯ is injective; and g is onto f(X) by Definition 1.7.1, so g¯ is surjective by (c). The map g¯ is f¯.

Warning. “Constant on classes” runs from equivalence to equal values: x∼x′⇒g(x)=g(x′). Its converse, g(x)=g(x′)⇒x∼x′, is the injectivity condition of (b), and checking it instead proves nothing about existence. For congruence modulo 12 and g(a)=[a]24, the converse holds, since 24∣a−a′ gives 12∣a−a′; but 0≡12(mod12) while [0]24≠[12]24, so “[a]12↦[a]24” is not a function.

The theorem turns the check of Example (Method: checking that a definition on classes is well defined) into a complete method: it says what the check buys, and how to read off injectivity and surjectivity afterwards.

Example (Method: define a function on a quotient)

Template. (1) Write the function g on X that the rule computes from a representative. (2) Check that g is constant on classes (Example (Method: checking that a definition on classes is well defined)). (3) Conclude by Theorem 5.2.3: g¯ exists, is unique, and g¯∘q=g. (4) Read injectivity of g¯ as “equal values force equivalence”, and surjectivity of g¯ as surjectivity of g.

When to use it. Maps out of Z/n, out of classes of fractions, out of any “the same in some respect”.

The usual failure. Proving (4)’s converse condition instead of (2); a g not defined on all of X; running the check for a map into a quotient, which needs none: compose with q.

Here is the method three times, twice on the clock and once on Z/2. As in Section 4.2, the subscript in [a]n names the modulus: it is the class of a in Z/n.

Example (Maps out of the clock)

  • (a) Let r:Z→{0,1} send each integer to its remainder on division by 2. Show that “[a]12↦r(a)” is a function Z/12→{0,1}, and decide whether it is injective and whether it is surjective.

  • (b) Do the same for “[a]2↦r(a)”, from Z/2.

  • (c) Show that “[a]12↦[a+1]12” is a bijection t:Z/12→Z/12.

Solution. The remainder r(a) is well defined by the uniqueness in Theorem 2.2.3. We use the remainder test of Section 4.2, after Proposition 4.2.4: a≡a′(modn) if and only if a and a′ leave the same remainder on division by n.

  • (a) Step (1). The rule computes r(a) from the representative a, so g=r. Step (2). Let a≡a′(mod12), so a−a′=12k with k∈Z. Then a−a′=2(6k) with 6k∈Z, so a≡a′(mod2), and r(a)=r(a′) by the remainder test. Step (3). By Theorem 5.2.3 (a), r¯([a]12):=r(a) is a function Z/12→{0,1}: “is the hour even?” is a question about the hour. Step (4). It is surjective by Theorem 5.2.3 (c), since r(0)=0 and r(1)=1. It is not injective, by part (b) of the theorem: r(0)=r(2), but 0≢2(mod12), since 2−0=2 lies strictly between 0 and 12 and so is not a multiple of 12 (Proposition 2.1.2 (c)). So r¯([0]12)=r¯([2]12) with [0]12≠[2]12.

  • (b) Step (2). If a≡a′(mod2), then r(a)=r(a′) by the remainder test. Step (4). Conversely, r(a)=r(a′) gives a≡a′(mod2), again by the remainder test, so the induced map Z/2→{0,1} is injective by Theorem 5.2.3 (b), and surjective by part (c), as in (a). It is a bijection: the two classes of Z/2 are the even and the odd integers, matched with the remainders 0 and 1.

  • (c) Steps (1)–(3). Here g(a):=[a+1]12, a function Z→Z/12. If a−a′=12k, then (a+1)−(a′+1)=a−a′=12k, so [a+1]12=[a′+1]12 (Theorem 4.2.1 (b)). So t([a]12):=[a+1]12 is a function Z/12→Z/12, the tick of the clock. A bijection. In the same way, (a−1)−(a′−1)=a−a′, so s([a]12):=[a−1]12 is a function Z/12→Z/12. For every a∈Z, s(t([a]))=s([a+1])=[a] and t(s([a]))=t([a−1])=[a]; so s∘t and t∘s are the identity of Z/12 (Proposition 1.5.1), and t is a bijection with inverse s (Theorem 1.6.4).

In (c) the codomain is itself a quotient set, and the check compared outputs as classes. In (a) and (b) the codomain is {0,1}, and outputs were compared as numbers. Step (2) of the method is the same check in both cases; only the meaning of “equal outputs” changes with the codomain.

↺Second readingSurjections are quotient maps, and choosing representatives

If f:X→Y is onto, then ι=idY, and Theorem 5.2.2 reads f=f¯∘q with f¯:X/∼f→Y a bijection. So every surjection is a quotient map up to renaming the classes: to give an onto map out of X is to give an equivalence relation on X and names for its classes. In the other direction, q itself is onto, so it has a right inverse c:X/∼→X by Theorem 3.2.2, which uses Axiom 3.2.1. Then q(c(C))=C, that is, c(C)∈C for every class C: a right inverse of a quotient map is a choice of one representative from each class. For Z/n no axiom is needed, since the remainder picks one, c([a]):= the remainder of a on division by n (Proposition 4.2.4).

Quick check. Is the rule [a]10↦[a]5 a well-defined function Z/10→Z/5? Is it injective? Is it surjective?

Solution. Take g:Z→Z/5, g(a)=[a]5. Well defined: yes. If a−a′=10k with k∈Z, then a−a′=5(2k), so g(a)=g(a′) (this was Exercise B3 (c) of Section 4.2). Injective: no. g(0)=[0]5=[5]5=g(5), but 0≢5(mod10), since 0<5<10; by Theorem 5.2.3 (b), the classes [0]10≠[5]10 have one image. Surjective: yes, by (c), because g is the quotient map of congruence modulo 5, which is onto.

5.2.5. Exercises

A. Check your understanding

Exercise (A1)
  • (a) For f:R→R, f(x)=x2−1, find the fibers over 3, over −1 and over −2. Which of them are classes of ∼f?
  • (b) Let f:{a,b,c,d}→{1,2,3} send a and c to 1, and b and d to 3. Write down X/∼f, f(X), f¯ and ι of Theorem 5.2.2.
  • (c) Which of the functions a↦[a]2, a↦[a]8 and a↦[a2]8, from Z, are constant on the classes of congruence modulo 4?

Solution.

  • (a) x2−1=3 means x2=4, so the fiber over 3 is {−2,2}. x2−1=−1 means x2=0, so the fiber over −1 is {0}. x2−1=−2 would need x2=−1, and no real square is negative, so the fiber over −2 is ∅. The first two are classes, since 3=f(2) and −1=f(0) lie in f(R); the empty fiber is not a class, because −2∉f(R) and every class is non-empty (Theorem 4.2.1 (a)).

  • (b) The fibers over the values are {a,c} and {b,d}, so X/∼f={{a,c},{b,d}}. The image is f(X)={1,3}. The bijection is f¯({a,c})=1, f¯({b,d})=3, and ι:{1,3}→{1,2,3} sends 1↦1 and 3↦3. The value 2 is in the codomain but outside the image, which is why ι is not surjective.

  • (c) Let a′=a+4k with k∈Z, the general element of the class of a modulo 4. a↦[a]2: yes, since a′−a=4k=2(2k). a↦[a]8: no. 0≡4(mod4), but [0]8≠[4]8, since 4−0=4 lies strictly between 0 and 8. a↦[a2]8: yes, since a′2−a2=8ak+16k2=8(ak+2k2), with ak+2k2∈Z.

B. Practice

Exercise (B1: The absolute value, factored)

Let f:R→R, f(x)=|x|. Describe the classes of ∼f, the image f(R) and the bijection f¯. Then show that [x]↦x2 is a well-defined injective function R/∼f→R.

Solution. The pieces. |x|=|x′| holds exactly when x′=x or x′=−x, so the class of x is {−x,x}, which is {0} for x=0. Every value |x| is ≥0, and every t≥0 is |t|, so f(R)=[0,∞). The bijection of Theorem 5.2.2 is f¯({−x,x})=|x|, from the set of classes onto [0,∞).

Well defined. Let g(x):=x2. Since x2=|x|2, x∼fx′ gives x2=|x|2=|x′|2=x′2. So g is constant on classes, and [x]↦x2 is a function by Theorem 5.2.3 (a).

Injective. Let x2=x′2. Then |x|2=|x′|2 with |x|,|x′|≥0, and Logic and Proof, Theorem 2.4.5, applied in both orders, gives |x|≤|x′| and |x′|≤|x|. So |x|=|x′|, that is, x∼fx′. By Theorem 5.2.3 (b), the induced function is injective. (It is not surjective onto R: no class goes to −1.)

Exercise (B2: Same fibers)

Let f:X→Y and g:X→Z be functions. Prove that ∼f=∼g if and only if there is a bijection h:f(X)→g(X) with g(x)=h(f(x)) for every x∈X.

Solution. (⇐) Let h be such a bijection, and let x,x′∈X. If f(x)=f(x′), then g(x)=h(f(x))=h(f(x′))=g(x′). If g(x)=g(x′), then h(f(x))=h(f(x′)), and f(x)=f(x′) because h is injective. So x∼fx′⟺x∼gx′: the two relations contain the same pairs, and are equal (Definition 1.2.1).

(⇒) Suppose ∼f=∼g; write ∼ for both, so the two quotient sets are one set X/∼. By Theorem 5.2.2 there are bijections f¯:X/∼→f(X) and g¯:X/∼→g(X) with f¯([x])=f(x) and g¯([x])=g(x). The inverse f¯−1:f(X)→X/∼ is a bijection (Definition 1.6.2, Theorem 1.6.4), so h:=g¯∘f¯−1:f(X)→g(X) is a bijection by Theorem 1.5.4 (c). For every x∈X, f¯−1(f(x))=[x], since f¯([x])=f(x); so h(f(x))=g¯([x])=g(x).

Exercise (B3: A coarser relation)

Let ∼ and ≈ be equivalence relations on a set X such that x∼x′ implies x≈x′. Show that [x]∼↦[x]≈ is a well-defined surjection X/∼→X/≈. Give the instance Z/12→Z/4.

Solution. Apply Theorem 5.2.3 to the relation ∼ and to g:=q≈:X→X/≈, the quotient map of ≈. It is constant on ∼-classes: if x∼x′, then x≈x′ by hypothesis, so [x]≈=[x′]≈ by Theorem 4.2.1 (b). By part (a), [x]∼↦[x]≈ is a function, and by part (c) it is surjective, since q≈ is onto (Definition 4.2.4).

For Z/12→Z/4, the hypothesis is: 12∣a−a′ implies 4∣a−a′. This holds by Proposition 1.1.1, since 4∣12 (12=3⋅4). So [a]12↦[a]4 is a well-defined surjection: each hour is sent to its position within a block of four hours (0, 4 and 8 go to [0]4).

Exercise (B4: Prove or disprove)

Prove or disprove each statement.

  • (a) If g:X→Z is constant on the classes of an equivalence relation ∼ on X and g is surjective, then g¯:X/∼→Z is a bijection.
  • (b) For every function f:X→Y, |f(X)|=|X/∼f|.
  • (c) If f:X→Y is injective, then the quotient map X→X/∼f is a bijection.
  • (d) The rule [a]4↦[3a]12 is a bijection Z/4→Z/12.
  • (e) If f,g:X→Y satisfy ∼f=∼g, then f=g.

Solution.

  • (a) False. Let X={1,2}, let ∼ be equality, and let g:X→{0} be the constant function. It is constant on classes (every function is, for equality) and surjective. But g¯([1])=0=g¯([2]) with [1]={1}≠{2}=[2], so g¯ is not injective. Surjectivity of g gives surjectivity of g¯ only, by Theorem 5.2.3 (c).

  • (b) True. This is Proposition 5.2.1 (b).

  • (c) True. If x∼fx′, then f(x)=f(x′), so x=x′ by injectivity; hence [x]={x} for every x. The quotient map q is injective: q(x)=q(x′) gives x∼fx′ by Theorem 4.2.1 (b), so x=x′. And q is onto by Definition 4.2.4.

  • (d) False. Let g(a):=[3a]12. It is constant on classes modulo 4: if a−a′=4k, then 3a−3a′=12k. The induced map is injective by Theorem 5.2.3 (b): if [3a]12=[3a′]12, then 3(a−a′)=12k for some k∈Z, so a−a′=4k after cancelling 3. But it is not surjective, so by part (c) of the theorem, look for a class that g misses. If [1]12=[3a]12, then 1−3a=12k for some k∈Z, so 1=3(a+4k) and 3∣1. That is impossible: 1=0⋅3+1 with 0≤1<3, so by the uniqueness in Theorem 2.2.3 the remainder of 1 on division by 3 is 1, not 0. So [1]12 is missed.

  • (e) False. Take X=Y=R, f=idR and g(x)=2x. Both are injective, so ∼f and ∼g are both equality on R, but f(1)=1≠2=g(1). Equal fiber relations make the functions differ only by a renaming of values, which is Exercise B2.

C. Going deeper

Exercise (C1: Equal fibers)

Let k,m,n∈N, let X be a set with n elements, and let f:X→{1,…,k} be a function such that the fiber f−1({i}) has exactly m elements for every i∈{1,…,k}. Prove that n=km.

Solution. For k∈N, let P(k) be the statement: for every n∈N, every set X with n elements, and every f:X→{1,…,k} all of whose fibers over 1,…,k have m elements, n=km. We prove P(k) for every k by Logic and Proof, Axiom 4.2.1, with m fixed.

Base case P(0). Here {1,…,0}=∅, so f is a function X→∅, and X=∅ by Proposition 1.5.2 (b). Then n=0: for n≥1, a bijection {1,…,n}→∅ would give 1 a value in ∅. So n=0=0⋅m.

Inductive step. Suppose P(k), and let X have n elements and f:X→{1,…,k+1} have every fiber of m elements. Put X′:=f−1({1,…,k}) and F:=f−1({k+1}). Every x∈X has f(x)≤k or f(x)=k+1, and not both, so X=X′∪F and X′∩F=∅. By Proposition 2.5.6, X′ has j elements for some j∈N. Let f′:X′→{1,…,k}, f′(x):=f(x); this is a function, because f(x)∈{1,…,k} for x∈X′. For i≤k, its fiber is f′−1({i})={x∈X′:f(x)=i}=f−1({i}), since every x with f(x)=i lies in X′; so it has m elements. By P(k), j=km. The fiber F has m elements by hypothesis, so Proposition 2.5.5 gives that X=X′∪F has km+m=(k+1)m elements. Since X also has n elements, n=(k+1)m by Corollary 2.5.4. This proves P(k+1).

The statement says that a function whose fibers all have one size cuts X into equal piles, so the size of X is the number of piles times the pile size. With fibers of different sizes the same induction gives the sum of the fiber sizes.

Marking scheme. (10 points)

  • 2: states the induction hypothesis with X and f quantified inside it.
  • 2: the base case k=0: X=∅ and n=0.
  • 3: the step: X′ and F are disjoint with union X, the fibers of f′ are fibers of f, and j=km.
  • 3: the conclusion by Proposition 2.5.5 and Corollary 2.5.4.

Fatal errors (0 for the step): induction with X fixed; applying P(k) to a function whose fibers were not shown to have m elements.

Exercise (C2: Find the error)

A student proves the uniqueness clause of Theorem 5.2.3 (a) as follows.

  1. Suppose g¯:X/∼→Z and h:X/∼→Z both satisfy g¯∘q=g and h∘q=g. (2) Then g¯∘q=h∘q. (3) The quotient map q is injective, so q can be cancelled on the right, and g¯=h.

Is the conclusion true? Which line fails, and why? Give a counterexample to the failing step, and repair the proof.

Solution. The conclusion is true: it is the uniqueness clause, proved in the text. Lines (1) and (2) are correct. Line (3) fails twice. First, q is injective only when every class is a single point (the second reading after Theorem 4.2.1), which the theorem does not assume. Second, even for an injective map p, u∘p=v∘p need not give u=v.

Counterexample to the step. For congruence modulo 12 on Z, q(0)=[0]=[12]=q(12) with 0≠12, so q is not injective, and the claim “q is injective” is false in the very case the clock needs. Counterexample to the inference. The inclusion ι:{0}→{0,1} is injective; let u=id{0,1} and v be the constant function 0. Then u∘ι=v∘ι but u≠v.

Repair. What cancels q on the right is that q is onto. Replace (3) by: “Let C∈X/∼. Since q is surjective (Definition 4.2.4), C=q(x) for some x∈X, and then g¯(C)=g¯(q(x))=h(q(x))=h(C) by (2). The two functions have the same domain and codomain, so g¯=h by Proposition 1.5.1.” Injectivity of q would let one cancel q on the left, in q∘u=q∘v, which is a different situation.

Marking scheme. (10 points)

  • 2: says the conclusion is true.
  • 3: identifies line (3), and says either that q need not be injective or that injectivity does not license cancelling on the right (surjectivity does).
  • 2: gives a concrete non-injective quotient map, such as q(0)=q(12) modulo 12.
  • 3: repairs the proof by surjectivity of q: every class is q(x), where both functions take the value g(x).

Fatal errors (0 for the step): calling the conclusion false; a repair that assumes classes are singletons.

Exercise (C3: Exit check: depends only on f)

Let f:X→Y and g:X→Z be functions such that, for all x,x′∈X, f(x)=f(x′) implies g(x)=g(x′).

  • (a) Prove that there is exactly one function h:f(X)→Z with g(x)=h(f(x)) for every x∈X.
  • (b) For f:R→R, f(x)=x2, decide whether g(x)=x4 and whether g(x)=x3 are of the form h∘f for some function h:f(R)→R.

Solution.

  • (a) Existence. The hypothesis says that g is constant on the classes of ∼f. By Theorem 5.2.3 (a), there is a function g¯:X/∼f→Z with g¯([x])=g(x). By Theorem 5.2.2, f¯:X/∼f→f(X), f¯([x])=f(x), is a bijection, so it has an inverse f¯−1:f(X)→X/∼f (Theorem 1.6.4), and f¯−1(f(x))=[x] for every x∈X. Put h:=g¯∘f¯−1. Then, for every x∈X, h(f(x))=g¯(f¯−1(f(x)))=g¯([x])=g(x).

    Uniqueness. Let h,h′:f(X)→Z both satisfy the condition. Let y∈f(X); by Definition 1.7.1, y=f(x) for some x∈X. Then h(y)=g(x)=h′(y). The two functions have the same domain and codomain, so h=h′ by Proposition 1.5.1.

  • (b) g(x)=x4 is of this form: x4=(x2)2, so h(t):=t2 on f(R) works, and by (a) it is the only such h. g(x)=x3 is not: if x3=h(x2) for every x, then 1=13=h(1)=h((−1)2)=(−1)3=−1, which is false. The hypothesis of (a) fails at the pair 1,−1: f(1)=f(−1), while g(1)≠g(−1).

Marking scheme. (10 points)

  • 2: recognizes the hypothesis as “g is constant on the classes of ∼f” and obtains g¯ with g¯([x])=g(x) (or defines h(f(x)):=g(x) directly and checks it is well defined).
  • 2: uses the bijection f¯ onto f(X), or an equivalent argument, so that h is defined at every point of f(X) and only there.
  • 2: verifies h(f(x))=g(x) for every x.
  • 2: uniqueness, using that every point of f(X) is a value f(x).
  • 2: part (b): h(t)=t2 for x4; the witness pair 1,−1 for x3.

A direct proof that defines h(y):=g(x) for any x with f(x)=y earns the first two steps if it checks that the value does not depend on the choice of x (that is the hypothesis) and that every y∈f(X) has such an x. Fatal errors (0 for the step): defining h on all of Y without a value for points outside f(X); proving the converse implication g(x)=g(x′)⇒f(x)=f(x′) instead of using the hypothesis.
