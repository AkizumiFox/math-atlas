6.1  The Axiom of Choice

Chapter 4 avoided picking one element from each of infinitely many sets: every function it built was given by a formula, a least element, or a list fixed in advance. This chapter adds the one principle that allows such picking, the axiom of choice, and gathers the theorems that need it. Section 4.2 listed N×N, Z and Q, and showed that a union of two countable sets is countable (Proposition 4.2.5). The next question is a union of countably many countable sets. The natural proof is short, and one of its steps cannot be justified by any rule met so far. This section isolates that step, adds the axiom that licenses it, shows how to tell a proof that needs the axiom from one that only seems to, and proves the four results this book draws from it: right inverses, comparing sizes by surjections, countable unions, and the place of N among the infinite sets.

6.1.1. A union of countably many lists

Let A0,A1,A2,… be countable sets, a family (An)n∈N in the sense of Definition 1.3.3. We want to prove that ⋃n∈NAn is countable.

Here is the proof most people write first. List each set: An={an,0,an,1,an,2,…}. Put an,m in row n and column m of an infinite grid. Every element of the union stands somewhere in the grid, and the grid is indexed by N×N, which is countable (Theorem 4.2.6). So the union is the image of a countable set, and it is countable.

Every step but the first, “list each set”, is a result of Section 4.2. Where do the lists come from?

6.1.2. The axiom of choice

None of the working rules (W1)–(W6) of Section 1.2 forms a set out of infinitely many arbitrary picks. The principle we add is the simplest statement that does.

From any family of non-empty sets, one may pick one element from each set, all at once.

Axiom 6.1.1 (Axiom of Choice)

Let I be a set, and let (Ai)i∈I be a family of sets such that Ai is non-empty for every i∈I. Then there exists a function c:I→⋃i∈IAiwithc(i)∈Ai  for every i∈I. Such a function c is called a choice function for the family.

In symbols, with YX the set of functions of Section 2.1 and U:=⋃i∈IAi: ∀i∈I (Ai≠∅) → ∃c∈UI  ∀i∈I  c(i)∈Ai.

In words: the hypothesis says that each set of the family has an element; the conclusion says that one function picks an element of every Ai at the same time. The codomain, a set by (W3), only gives c somewhere to take its values. The axiom asserts that c exists and gives no recipe for it.

Its status. For finitely many indices the axiom adds nothing (proved below); for infinitely many it is a genuinely new principle. It can be neither proved nor refuted from the other axioms of set theory (Gödel, Cohen). Section 6.2 states Zorn’s lemma, and Section 6.3 proves that Zorn’s lemma gives the axiom and the well-ordering theorem; Axiomatic Set Theory, Chapter 4 proves the converse, and Chapter 5 surveys the independence results. This book uses the axiom openly on the main line, among other places: in this section, for right inverses, countable unions and infinite sets; in Analysis on the Real Line, Chapter 1, for sup approximations (the remark below); in Measure, Integration, and Real Analysis, Chapter 2, for the Vitali set; in the same volume, Chapter 10, through Zorn’s lemma, for the Hahn–Banach theorem; and in Functional Analysis, Chapter 2, for Tychonoff’s theorem. Each use is flagged at its line.

Remark. A corollary in Analysis on the Real Line, Chapter 1 gives, for each n≥1 separately, some an∈A with an>supA−1n: one ∃E per n, and no axiom. Forming the sequence (an)n≥1 from these is a choice function for the family ({a∈A:a>supA−1n})n∈Z>0, an instance of Axiom 6.1.1 with the countable index set I=Z>0. Analysis on the Real Line, Chapter 1 flags exactly this step.

Examples.

  1. The empty family. If I=∅, the empty function ∅→⋃i∈∅Ai=∅ (Proposition 2.1.2 (a)) is a choice function: the condition “for every i∈∅” holds vacuously. No axiom is needed.
  2. A family with a rule. Let I=Z>0 and An:={k∈N:n∣k, k≠0}, the positive multiples of n. Each An contains n. The rule c(n):=n is a choice function, defined by specification (Definition 1.2.3); no axiom is needed.
  3. A family with no rule in sight. Let I be the set of non-empty subsets of R, and AS:=S for S∈I. A choice function picks an element of every non-empty set of reals. “The least element” fails, since (0,1) has none, and no rule that works for every S is known. Here the axiom supplies what the other rules do not.

A non-example by minimal change. In Example 2, add the index n=0. The positive multiples of 0 form the empty set (0∣k means k=0), so A0=∅, and no function can have c(0)∈A0. Only the clause “Ai is non-empty for every i” fails, and without it the conclusion is false. That is why the proofs below remove the empty sets from a family before they choose. (Dropping “all at once” instead would leave nothing beyond the hypothesis.)

6.1.3. When choice is not needed

Two kinds of construction look like choice and are not; telling them apart from a real use is the skill this section is for.

Finitely many sets. For every finite set I and every family (Ai)i∈I of non-empty sets, a choice function exists, with no appeal to the axiom. For I={1,2,3}, three applications of ∃E name ai∈Ai, and {(1,a1),(2,a2),(3,a3)} is the graph of a choice function. For a finite set of arbitrary size we induct on its number of elements (Definition 4.1.2). Let P(n) be: “for every set I with n elements and every family (Ai)i∈I of non-empty sets, there is a choice function”. Base case P(0): a set with 0 elements is the image of a bijection from {1,…,0}=∅, so it is empty, and the empty function is a choice function (Example 1). Inductive step: assume P(n), and let I have n+1 elements. Then I≠∅, since a bijection {1,…,n+1}→I has a value at 1; pick i0∈I by ∃E. The set I′:=I∖{i0} has n elements (Corollary 4.1.7), so P(n) gives a choice function c′ for (Ai)i∈I′. Since Ai0≠∅, one more ∃E names a0∈Ai0. The graph of c′ together with the pair (i0,a0), with codomain ⋃i∈IAi, is a function on I′∪{i0}=I, because i0∉I′; and it is a choice function. So P(n+1) holds, and Logic and Proof, Axiom 4.2.1 gives P(n) for every n∈N. Each step uses two ∃E’s and no new principle; the induction says nothing about an infinite I, which has no number of elements.

A rule that picks. If one description names an element of each Ai, the choice function is defined by specification (W1), as the set of pairs (i,a) with a the element named for i. Typical rules: the least element of a non-empty set of natural numbers (Theorem 3.1.3); the non-negative square root of a positive real; in a bisection, the left half if it has the property in question, and otherwise the right half. The first rule is how Theorem 4.2.2 passed from a surjection N→A to an injection A→N with no axiom: the least preimage is named, not chosen.

Warning. Choice is not “picking an element”. “Let a∈A” is a single ∃E and needs no axiom; neither does picking from ten sets. The axiom is needed only for picking one element from each of infinitely many sets, with no rule. A proof that says “choose” need not use it, and one that never says “choose” may: “for each n, let gn be a list of An” is a use, however it is worded.

The warning is the whole method; here it is as a checklist.

Example (Method: name the choice)

Template. At each line that produces an object for each of many indices at once, ask whether one rule names it for every index: a formula, “the least”, “the unique”, or one list fixed in advance. If so, define the function by specification; no choice is used. If not, form the family (Si) of non-empty sets of candidates and write “by Axiom 6.1.1 there is c with c(i)∈Si” at that line, in bold.

When to use it. A proof says “for each n, let …”, builds a sequence or a family of lists, or inverts a surjection.

The usual failure. An unflagged “for each n, choose”. Flagging a single ∃E, or a rule, as a use. An empty Si left in the family (the non-example above).

Quick check. A proof says: “For each n∈N the set {k∈N:k2>n} is non-empty; choose kn in it.” Does this line need Axiom 6.1.1? Rewrite it so that it plainly does not.

Solution. No: it need not. The least element (Theorem 3.1.3) names kn, and so does the formula kn:=n+1, since (n+1)2=n2+2n+1>n. Either rewrite defines n↦kn by specification.

Example (Choice or a rule?)

Which of the following needs Axiom 6.1.1?

  • (a) A function sending each non-empty finite set of reals to one of its elements.
  • (b) A function sending each open interval {x∈R:a<x<b} with a<b to a rational number in it.
  • (c) A function sending each countably infinite subset A⊆R to a bijection N→A.
  • (d) For a given family (An)n∈N of non-empty subsets of Q, a sequence with an∈An for every n.

Solution.

  • (a) No: S↦maxS, which exists by Proposition 3.3.8.

  • (b) No, once one list of Q is fixed. Take a surjection q:N→Q (Theorem 4.2.8, one ∃E). Between two reals lies a rational (a school fact; Analysis on the Real Line, Chapter 1 proves it), so {n∈N:a<q(n)<b} is non-empty, and q of its least element (Theorem 3.1.3) is named by a rule.

  • (c) Yes, as far as this book is concerned. Each A has bijections N→A (Definition 4.2.2), but no rule names one for an arbitrary A. The family (SA) of sets of bijections, indexed by the countably infinite subsets of R (a set, by specification in P(R)), consists of non-empty sets, and Axiom 6.1.1 gives the function.

  • (d) No: with the same fixed q, an:=q(min{k∈N:q(k)∈An}); the set is non-empty because An≠∅ and q is onto.

One fixed list turns “pick an element” into “take the first one on the list”, and that is a rule.

6.1.4. Right inverses

The first consequence settles the question Section 2.4 left open. By Proposition 2.4.2, a function with a right inverse is surjective; the converse is where choice enters.

Theorem 6.1.2 (Surjections Have Right Inverses)

Let f:X→Y be a surjective function. Then f has a right inverse: there is a function g:Y→X with f(g(y))=y for every y∈Y.

Idea. A right inverse must name a preimage of every y. The preimages of the points of Y form a family of sets indexed by Y, each non-empty because f is onto. A choice function for that family is exactly a right inverse. This is the method of Example (Method: name the choice): for an arbitrary f no rule names a preimage, so the line is flagged.

Proof. For y∈Y, let Py:=f−1({y})={x∈X:f(x)=y} (Definition 2.5.2). This defines a family (Py)y∈Y of subsets of X, indexed by Y. Each Py is non-empty, since f is surjective (Definition 2.2.2). By Axiom 6.1.1 there is a function c:Y→⋃y∈YPy with c(y)∈Py for every y∈Y. The union is a subset of X, so the graph of c is a subset of Y×X, and with codomain X it is a function g:Y→X with g(y)=c(y) (Definition 2.1.1). For every y∈Y, g(y)∈Py, that is, f(g(y))=y. So f∘g=idY, and g is a right inverse of f (Definition 2.4.1 (b)).

Together with Proposition 2.4.2: a function is surjective if and only if it has a right inverse. The theorem is in fact equivalent to the axiom: a right inverse of the projection (i,a)↦i, from the set of pairs with a∈Ai onto I, is a choice function in disguise.

Quick check. Let f:Z→N, f(k):=|k|. It is surjective. Does the existence of a right inverse of f need Axiom 6.1.1?

Solution. No. Each n∈N has the preimage n, and also −n when n>0; the rule “take the non-negative one” names one of them: g(n):=n. Then f(g(n))=|n|=n, so g:N→Z is a right inverse, defined by a formula. The axiom is needed only when no such rule is available.

6.1.5. Comparing sizes by surjections

Right inverses give a second reading of ≤. Section 4.4 compared sizes by injections, and turned an injection A→B into a surjection B→A (Proposition 4.4.2). This section supplies the converse, at the price of the axiom: the direction from a surjection to an injection uses Theorem 6.1.2.

Proposition 6.1.3 (Injections and Surjections)

Let A and B be sets with A≠∅. Then |A|≤|B| if and only if there is a surjection B→A.

Proof. (⇒) This half is Proposition 4.4.2 (Section 4.4); it uses no choice.

(⇐) Let g:B→A be a surjection. By Theorem 6.1.2, g has a right inverse h:A→B, so g∘h=idA; this step uses Axiom 6.1.1, through Theorem 6.1.2. Then g is a left inverse of h, so h is injective by Theorem 2.4.1 (a). Hence |A|≤|B|. This proves the proposition.

The hypothesis A≠∅ is needed for (⇒) only, as Section 4.4 showed with A=∅, B={b}. The choice in (⇐) is genuine in general, but not for B=N: a surjection from N has least preimages, a rule, which is how Theorem 4.2.2 went from (i) to (ii) without the axiom.

Quick check. Is |{0,1}N|≤|P(N)|? Give an injection, and say whether your answer needed Proposition 6.1.3.

Solution. Yes. Send a sequence a∈{0,1}N to the set {n∈N:a(n)=1}. If two sequences give the same set, they take the value 1 at the same places, and so the value 0 at the same places too; hence they are equal (Proposition 2.1.1), and the map is injective. No appeal to Proposition 6.1.3 is needed: the definition asks for an injection, and we wrote one down. (The map is in fact a bijection, with inverse S↦1S, by Theorem 2.3.5 with X=N.)

6.1.6. Countable unions

Now the theorem the section opened with. The second form, with any countable index set, is the one used in practice.

Theorem 6.1.4 (Countable Unions of Countable Sets)

  • (a) Let (An)n∈N be a family of sets such that An is countable for every n∈N. Then ⋃n∈NAn is countable.

  • (b) Let I be a countable set and (Ai)i∈I a family of sets such that Ai is countable for every i∈I. Then ⋃i∈IAi is countable.

Idea (Scratch work). This is the grid of the opening, with the lists supplied by the axiom. ① Throw away the empty sets: the axiom needs non-empty ones, and they add nothing to the union. ② For each remaining n, the surjections N→An form a non-empty set; choose one from each, all at once. ③ The chosen lists turn the grid J×N into a surjection onto the union, and the grid is countable by Section 4.2.

Part (b) is part (a) after renumbering the index set by a list. As givens and goal, for (a):

Givens Goal
An countable for every n ⋃n∈NAn countable
J:={n:An≠∅}; J×N countable (Corollary 4.2.7) a surjection F:J×N→⋃n∈NAn
for each single n∈J: some surjection N→An (one ∃E per n) F(n,m):= (a list of An)(m), which needs every list at once, as one function n↦c(n)
gap: from “for every n there is a list” to “there is one function giving a list for every n” closed by Axiom 6.1.1 on (Sn)n∈J, the only flagged line

Before reading on: which line uses choice, and why can ∃E not replace it?

Proof.

  • (a) Let U:=⋃n∈NAn and J:={n∈N:An≠∅}.

    If J=∅, every An is empty, so U=∅, which is countable by Definition 4.2.1.

    Suppose J≠∅. For n∈J, let Sn:={h∈AnN:h is surjective}, the set of surjections N→An (Definition 1.2.3, with AnN the set of functions of Section 2.1). Since An is countable and non-empty, Sn≠∅ (Definition 4.2.1). By Axiom 6.1.1, applied to the family (Sn)n∈J, there is a function c:J→⋃n∈JSn with c(n)∈Sn for every n∈J. This is the only line of the proof that uses the axiom.

    Define F:J×N→U by F(n,m):=c(n)(m). It takes values in U: c(n) maps into An⊆U. It is surjective: let x∈U; then x∈An for some n∈N (Definition 1.3.4), so An≠∅ and n∈J; since c(n) is a surjection onto An, there is m∈N with c(n)(m)=x, that is, F(n,m)=x.

    The set J is countable by Proposition 4.2.3, as a subset of N, which is countable (the identity is a surjection). So J×N is countable by Corollary 4.2.7 (a), and it is non-empty, since it contains (n0,0) for any n0∈J. By Definition 4.2.1 there is a surjection s:N→J×N. Then F∘s:N→U is surjective (Theorem 2.2.1 (b)), and U is countable.

  • (b) Let U:=⋃i∈IAi. If I=∅, then U=∅, which is countable. Otherwise Definition 4.2.1 gives a surjection s:N→I; fix one. For n∈N put Bn:=As(n), a countable set. Then ⋃n∈NBn=U. (⊆) An element of Bn lies in As(n) with s(n)∈I. (⊇) If x∈Ai with i∈I, then i=s(n) for some n∈N, because s is onto, and x∈Bn. By (a), U is countable.

The line in bold is the only use of the axiom. The surjections s of parts (a) and (b) are single objects, each named by one ∃E. What needed the axiom was a surjection for every n∈J at once: ∃E supplies c(n) only inside the box of a fixed n, and F needs all of them outside every such box. The set J is there because for An=∅ there is no function N→An at all (Proposition 2.1.2 (b)), so Sn=∅. The theorem completes the closure properties of countable sets: subsets, images, finite products, countable unions.

Neither hypothesis can be dropped: Section 4.3 shows that R is not countable, and R is the union of the single set R, and also of the countable sets {x}, x∈R.

Warning. The choice is of the lists, not of preimages. A surjection N→A gives least preimages by a rule (Theorem 4.2.2), but only once the surjection is in hand. In Theorem 6.1.4, what is missing is the surjection itself, one for each An, and the sets An need not be sets of natural numbers, so no “least” is available to name one.

6.1.7. Every infinite set contains a copy of the natural numbers

Every infinite set met so far contains a copy of N, and Section 4.5 showed what such a copy does (Proposition 4.5.1). Picking new elements one at a time looks like a proof that every infinite set has one; it is not one, since “one at a time” is a recursion whose step must pick a new element from every set X∖F, F finite, at once. So the proof chooses once, on all non-empty subsets of X. With Axiom 6.1.1 it becomes a proof, and it gives two results: N is the smallest infinite size, and a set is infinite exactly when it is the same size as a proper part of itself.

The question has a goal theorem: we want to show that an infinite set X has a countably infinite subset, that is, a subset equinumerous with N (Definition 4.2.2). Equivalently, we want an injection N→X: its image is then such a subset.

Theorem 6.1.5 (Infinite Sets Contain a Countably Infinite Subset)

Every infinite set X has a countably infinite subset. Equivalently, there is an injection N→X.

Idea. The natural attempt picks x0∈X, then x1∈X∖{x0}, then x2∈X∖{x0,x1}, and so on. Each pick is possible, because a finite set cannot exhaust the infinite X, and each single pick is one ∃E. But “and so on” is a definition by recursion, and Theorem 3.3.1 needs a function g that says, once and for all, which new element to take after any finite stage. That function must pick an element from every non-empty set of the form X∖F at once, with no rule for doing so when X is arbitrary. So we let Axiom 6.1.1 supply a choice function c on all non-empty subsets of X first, and then the recursion is an ordinary one, with c as its rule.

Proof. Let X be infinite. The family (S)S∈P(X)∖{∅}, indexed by the non-empty subsets of X with each index as its own member, consists of non-empty sets, and its union is X: every index is a subset of X, and each x∈X lies in the index {x}. By Axiom 6.1.1 there is a function c:P(X)∖{∅}→X with c(S)∈Sfor every non-empty S⊆X. This is the one line of the proof that uses the axiom.

Define g:N×P(X)→P(X) by g(n,F):=F∪{c(X∖F)} if F≠X, and g(n,F):=F if F=X. In the first case X∖F is non-empty, so c(X∖F) is defined; so g is a function. By Theorem 3.3.1, applied with the set P(X), the starting value ∅ and this g, there are sets Fn⊆X, for n∈N, with F0=∅ and Fn+1=g(n,Fn).

We show by induction (Logic and Proof, Axiom 4.2.1) that Fn has exactly n elements, for every n∈N. For n=0, F0=∅ has 0 elements (Definition 4.1.2). Suppose Fn has n elements. Then Fn is finite and X is not, so Fn≠X, and Fn+1=Fn∪{c(X∖Fn)} with c(X∖Fn)∈X∖Fn. This is a union of disjoint sets with n elements and 1 element, so Fn+1 has n+1 elements by Proposition 4.1.5.

In particular Fn≠X for every n∈N, so we may define xn:=c(X∖Fn)∈X∖Fn,and thenFn+1=Fn∪{xn}. Hence Fn⊆Fn+1 for every n, and by induction on k, Fm⊆Fm+k for all m,k∈N.

Now let m,n∈N with m<n. Then xm∈Fm+1⊆Fn, because m+1≤n (Lemma 3.1.1 (e)), so k:=n−(m+1)∈N (Lemma 3.1.1 (d)) and Fm+1⊆F(m+1)+k=Fn; and xn∉Fn. So xm≠xn. Hence n↦xn is an injection N→X. Its image {xn:n∈N}⊆X is equinumerous with N, since n↦xn is a bijection from N onto it. This proves the theorem.

The proof shows where the axiom enters and why one ∃E per step is not enough: ∃E names one element for one set, while the recursion needs g as a single function defined on every stage at once. Each Fn is then determined by c; the only arbitrary thing is c itself.

A non-example by a minimal change. Run the same construction on the finite set X={a,b}, with a≠b. The choice function c and the recursion still make sense, since g is defined on every F⊆X. But F1={c(X)} has one element, F2 adds the other, so F2=X, and from then on g leaves Fn unchanged. So x2=c(X∖F2)=c(∅) is not defined. The step that fails is “Fn is finite and X is not, so Fn≠X”, exactly where the hypothesis that X is infinite is used.

Remark. Compare Analysis on the Real Line, Chapter 1’s proof that the real numbers cannot be listed. There, a given list is used to build nested closed intervals, and each interval is obtained from the previous one by an explicit rule (keep an outer third that misses the next point of the list), so no choice principle is involved. Here X is an arbitrary infinite set, and there is no rule available for picking an element of an arbitrary non-empty subset of it; the choice function is the rule.

For a particular X a rule may exist: for X⊆N, “the least element” is one (Theorem 3.1.3), and then the proof needs no axiom. That the theorem cannot be proved in general from the other rules of set formation alone is a result of set theory; we state it without proof, and nothing depends on it.

6.1.8. Consequences: the smallest infinite size

The theorem says |N|≤|X| for every infinite X (Definition 4.4.1). Three consequences follow at once.

  • N is the smallest infinite size. If X is infinite and |X|≤|N|, then |X|=|N|, by Theorem 4.4.3 and the theorem. So no infinite set is strictly smaller than N.
  • Countable sets are exactly the sets of size at most |N|, by Theorem 4.2.2, (i) ⟺ (ii). Combining with the first point: a countable set is finite or equinumerous with N, which Theorem 4.2.2 (iii) already said.
  • An uncountable set is strictly bigger than N. If X is uncountable, then X is infinite (a finite set is countable, by Theorem 4.2.2), so |N|≤|X|; and |N|=|X| would make X countable. So |N|<|X|. For example |N|<|R|, since R is uncountable (Theorem 4.3.4).

Warning. “Infinite” and “uncountable” are different words. Q is infinite (it contains N, which is infinite by Example (Hilbert’s Hotel), and a subset of a finite set is finite, by Proposition 4.1.6) and countable (Theorem 4.2.8). Likewise “X contains a copy of N” is not “X is equinumerous with N”: R contains N, and |N|<|R| (as above).

Quick check. Let X be uncountable. Is X∖{x} uncountable for every x∈X? Why must X have an element at all?

Solution. X≠∅, because ∅ is countable by Definition 4.2.1. For x∈X, if X∖{x} were countable, then X=(X∖{x})∪{x} would be a union of two countable sets, countable by Proposition 4.2.5. So X∖{x} is uncountable.

6.1.9. Infinite sets are the same size as a proper part

Section 4.1 proved that a finite set is never equinumerous with a proper subset (Theorem 4.1.9), and Example (Hilbert’s Hotel) showed N doing exactly that. With Theorem 6.1.5, the hotel can be built inside any infinite set: run it on the copy of N, and leave everything else alone.

Theorem 6.1.6 (Infinite Sets and Proper Subsets)

A set X is infinite if and only if |X|=|Y| for some proper subset Y⊊X.

Idea. One direction is already done: Section 4.1 showed that finite sets have no proper subset of their own size. For the other, take the copy x0,x1,x2,… of N inside X and move every guest one room up, xn↦xn+1, as n↦n+1 does in the Quick check after Example (Hilbert’s Hotel). Room x0 is vacated, and every point outside the copy stays where it is.

Proof. (⇐) This is the contrapositive of Theorem 4.1.9: a finite set is not equinumerous with any proper subset, so a set that is equinumerous with one is not finite.

(⇒) Let X be infinite. By Theorem 6.1.5 (which uses Axiom 6.1.1) there is an injection s:N→X. By Proposition 4.5.1 (a), Y:=X∖{s(0)} has |Y|=|X|, and Y is a proper subset, as s(0)∈X∖Y. This proves the theorem.

Together with Section 4.1, this gives a characterization of “infinite” that never mentions N or counting: a set is infinite precisely when some proper part of it is as big as the whole. The finite intuition “a part is smaller than the whole” is exactly the property that separates finite sets from infinite ones. The direction (⇒) used Axiom 6.1.1, through Theorem 6.1.5; the direction (⇐) did not.

Quick check. Name a proper subset of R that is equinumerous with R, and give a bijection.

Solution. (−1,1), with the bijection x↦x/(1+|x|) of Example (The real line and its intervals). (Any interval with more than one point other than R itself works, by the same example.) No choice is needed for R: the bijection is a formula.

6.1.10. Exercises

A. Check your understanding

Exercise (A1)

These parts are about the proofs of Theorem 6.1.4, Theorem 6.1.5 and Theorem 6.1.6.

  • (a) Which line of the proof of part (a) of Theorem 6.1.4 uses Axiom 6.1.1? What are the index set I and the sets Ai of the axiom at that line?
  • (b) Why does the proof of Theorem 6.1.4 introduce the set J?
  • (c) Run the proof of Theorem 6.1.4 on An:={n,n+1} for n∈N, with the lists c(n)(m):=n for odd m and c(n)(m):=n+1 for even m. What is J, and what is F(3,2)?
  • (d) Is Axiom 6.1.1 needed to show that ⋃n∈NAn is countable when every An is a subset of N? Justify your answer.
  • (e) Where does the proof of Theorem 6.1.5 use Axiom 6.1.1? Why is one ∃E per step not enough?
  • (f) The proof of Theorem 6.1.6 passes the copy of N to Proposition 4.5.1 (a), whose proof moves each s(n) to s(n+1) and fixes every other point. Write down the resulting bijection X→X∖{s(0)} for X=Z and s(n)=n for n∈N.

Solution.

  • (a) The line “By Axiom 6.1.1, applied to the family (Sn)n∈J, there is a function c on J with c(n)∈Sn”. There I=J, the set of indices with An≠∅, and the sets of the axiom are the Sn, the sets of surjections N→An. The axiom chooses lists, not elements of the An.

  • (b) The axiom applies only to families of non-empty sets. If An=∅, there is no function N→An at all (Proposition 2.1.2 (b)), so Sn=∅, and the family (Sn)n∈N would not qualify. Empty sets add nothing to the union, so restricting to J loses nothing.

  • (c) Every An is non-empty, so J=N. The pair (3,2) has m=2 even, so F(3,2)=c(3)(2)=3+1=4. (Each c(n) is onto {n,n+1}: c(n)(1)=n and c(n)(0)=n+1.)

  • (d) No. The union is a subset of N, so it is countable by Proposition 4.2.3. (Even the proof can run without the axiom: hA(m):=m for m∈A and hA(m):=minA otherwise (Theorem 3.1.3) is a rule that maps N onto any non-empty A⊆N.)

  • (e) At the line “By Axiom 6.1.1 there is a function c with c(S)∈S for every non-empty S⊆X.” One ∃E names one element of one non-empty set; that would give x0, then x1, and any finite number of steps. But Theorem 3.3.1 needs the step as a function g, defined once for every stage F at once, before the sequence exists. Defining g means picking an element of X∖F for every such F simultaneously, and that is what the axiom provides.

  • (f) h(n)=n+1 for n∈N, and h(k)=k for k<0. It maps Z onto Z∖{0}: a positive m is h(m−1), and a negative k is h(k). No choice is needed here: the copy of N inside Z is given.

B. Practice

Exercise (B1: Which constructions need choice?)

Determine which of the following constructions need Axiom 6.1.1. Justify your answer.

  • (a) Choose a real number in each interval (n,n+1), n∈N.
  • (b) Choose an element of each non-empty subset of N.
  • (c) Choose an element of each non-empty subset of R.
  • (d) Choose one of the two square roots of each positive real number.

Solution.

  • (a) No. The rule n↦n+12 names an element of each interval, since n<n+12<n+1.

  • (b) No. The rule “the least element” names one, by Theorem 3.1.3: S↦minS is a choice function, defined by specification.

  • (c) Yes, as far as this book is concerned. The rule “the least element” fails, since (0,1) has no least element, and no rule is known that names an element of every non-empty set of reals. A proof that needs such a function uses the axiom, and says so.

  • (d) No. The rule “the positive one” names one root of each y>0: y↦y.

Exercise (B2: Finite sequences)

Prove that the set of all finite sequences of natural numbers is countable, and say whether your proof uses Axiom 6.1.1. Here a finite sequence of length k∈N is a function {1,…,k}→N, represented by its graph, a subset of Z>0×N; the sequence of length 0 is ∅.

Hint: Theorem 3.3.1, together with one fixed surjection N→N×N.

Solution. Let Seq be the set of x∈P(Z>0×N) such that x is the graph of a function {1,…,k}→N for some k∈N (Definition 1.2.3, Definition 1.3.2). This k is determined by x, since {1,…,k} is the set of first coordinates of x, and k is its number of elements (Corollary 4.1.4); call it the length of x, and let Seqk be the set of elements of length k. So Seq=⋃k∈NSeqk, and Seq0={∅}.

With choice. Each Seqk is countable (for k≥2 it is in bijection with Nk, by x↦(x(1),…,x(k)); Seq1 with N; Seq0 has one element), so Theorem 6.1.4 (a) applies. This route uses Axiom 6.1.1, through the theorem.

Without choice. Fix one surjection σ:N→N×N (Theorem 4.2.6, Definition 4.2.1; a single ∃E), and write σ(n)=(σ1(n),σ2(n)). For x∈Seq of length k and m∈N, let x⌢m:=x∪{(k+1,m)}, the sequence x with m appended; it has length k+1. Every y∈Seqk+1 is x⌢m for x the restriction of y to {1,…,k} and m=y(k+1).

Let X:=SeqN, the set of functions N→Seq, let a∈X be the constant function with value ∅, and define g:N×X→X by g(k,s)(n):=s(σ1(n))⌢σ2(n). By Theorem 3.3.1 there is a function k↦sk from N to X with s0=a and sk+1(n)=sk(σ1(n))⌢σ2(n) for all k,n∈N.

Claim: for every k∈N, sk maps N onto Seqk. By Logic and Proof, Axiom 4.2.1 on k. For k=0, every value of s0 is ∅, and Seq0={∅}. Assume the claim for k. Each value sk+1(n)=sk(σ1(n))⌢σ2(n) has length k+1, because sk(σ1(n)) has length k. Let y∈Seqk+1, say y=x⌢m with x∈Seqk. By the hypothesis there is j with sk(j)=x, and since σ is onto there is n with σ(n)=(j,m). Then sk+1(n)=sk(j)⌢m=y. This proves the claim.

Now n↦sσ1(n)(σ2(n)) maps N onto Seq: for y∈Seqk, the claim gives j with sk(j)=y, and some n has σ(n)=(k,j). So Seq is countable. One surjection was named, and the lists sk were defined from it by recursion: no choice is used. Either route earns full credit if the use of choice is reported correctly.

Exercise (B3: Prove or disprove)

Prove each true statement, naming each use of Axiom 6.1.1 as in Example (Method: name the choice), and refute each false one with a concrete counterexample.

  • (a) If An is finite for every n∈N, then ⋃n∈NAn is countable.
  • (b) If An is finite for every n∈N, then ⋃n∈NAn is finite.
  • (c) Every surjection f:N→Y has a right inverse that can be defined without Axiom 6.1.1.
  • (d) If An is countable for every n∈N, then ⋃n∈NAn is countably infinite.
  • (e) If An≠∅ for every n∈N and ⋃n∈NAn is finite, then Am∩An≠∅ for some m≠n.
  • (f) Every infinite set X admits a surjection X→N.
  • (g) If a set X admits a surjection X→N, then X is countable.

Solution.

  • (a) True. Finite sets are countable (Theorem 4.2.2, (iii) ⇒ (i)), and Theorem 6.1.4 (a) applies. That theorem uses Axiom 6.1.1.

  • (b) False. Take An:={n}: the union is N, which is infinite (Example (Hilbert’s Hotel)).

  • (c) True. For y∈Y, the set f−1({y})⊆N is non-empty, since f is onto, so g(y):=minf−1({y}) exists by Theorem 3.1.3. This is a rule, and f(g(y))=y.

  • (d) False. Take An:={0} for every n: the union is {0}, which is finite, hence not countably infinite: a bijection N→{0} would make N finite (Proposition 4.1.1, Definition 4.1.2), against Example (Hilbert’s Hotel).

  • (e) True, with no axiom. The set U:=⋃n∈NAn is non-empty (it contains the elements of A0) and finite, say with k≥1 elements via a bijection φ:{1,…,k}→U (one ∃E). Define c(n):=φ(min{j:φ(j)∈An}) (Theorem 3.1.3); the set is non-empty because An≠∅ and φ is onto. This is a rule, and c(n)∈An. If c were injective, N would be equinumerous with c(N)⊆U, which is finite (Proposition 4.1.6). Then N would be finite (Proposition 4.1.1, Definition 4.1.2), against Example (Hilbert’s Hotel). So c(m)=c(n) for some m≠n, and that element lies in Am∩An. This is the pigeonhole idea of Example (Method: the pigeonhole principle), with infinitely many pigeons.

  • (f) True, using the axiom. By Theorem 6.1.5 (which uses Axiom 6.1.1) there is an injection N→X. Since N≠∅, Proposition 4.4.2 gives a surjection X→N; that step uses no choice. (Concretely, with the injection written n↦xn: send xn to n and every other point to 0.)

  • (g) False. x↦⌊|x|⌋, the integer part of |x| (the m∈N with m≤|x|<m+1, a school fact), maps R onto N (each n∈N is the image of n), and R is uncountable (Theorem 4.3.4). A surjection onto N says X is at least as big as N, not at most.

Exercise (B4: Absorbing a countable set)

Let X be infinite, and let C be countable with C∩X=∅. Prove that |X∪C|=|X|.

Hint: absorb C into a countably infinite subset of X.

Solution. By Theorem 6.1.5 (using Axiom 6.1.1) there is an injection s:N→X; its image S:=s(N) is a countably infinite subset of X. Now Proposition 4.5.1 (b) gives |X∪C|=|X|. The axiom enters only through the copy s; the absorbing itself is a rule.

C. Going deeper

Exercise (C1: Exit check: countable unions)

Prove that if An is countable for every n∈N, then so is ⋃n∈NAn. Point to the step of your proof that uses Axiom 6.1.1.

Solution. Let U:=⋃n∈NAn and J:={n∈N:An≠∅}. If J=∅, then U=∅, which is countable. Let J≠∅. For n∈J, the set Sn of surjections N→An is non-empty (Definition 4.2.1). By Axiom 6.1.1, applied to (Sn)n∈J, there is a function c on J with c(n)∈Sn for every n∈J: a list of every An at once, which no finite number of ∃E’s gives. This is the step that uses the axiom.

Put F(n,m):=c(n)(m)∈An⊆U for (n,m)∈J×N. It is onto U: if x∈U, then x∈An for some n∈N (Definition 1.3.4), so n∈J, and c(n)(m)=x for some m, as c(n) is onto An. Since J⊆N is countable (Proposition 4.2.3), J×N is countable (Corollary 4.2.7 (a)) and non-empty, so some s:N→J×N is onto (Definition 4.2.1), and so is F∘s:N→U (Theorem 2.2.1 (b)). This is the proof of Theorem 6.1.4 (a).

Marking scheme. (10 points) - 1: handles the empty sets: the case where every An is empty, and the restriction to the non-empty ones before choosing. - 3: obtains, by Axiom 6.1.1, a surjection onto An for every n simultaneously, and says at that line that the axiom is used. - 2: defines a map from a set of pairs (or another index set) to the union. - 2: shows that this map is onto the union. - 2: shows that the index set is countable and non-empty, citing the product result, and concludes. Through injections ιn:An→N: 1 for noting that they exist for every n, empty An included (the empty function), so nothing is discarded; 3 for choosing all ιn by Axiom 6.1.1, flagged; 2 for x↦(nx,ιnx(x)) into N×N, with nx the least n with x∈An (Theorem 3.1.3); 2 for its injectivity; 2 for concluding with Theorem 4.2.6 and Theorem 4.2.2, (ii) ⇒ (i). Fatal errors (0 for the step): “for each n let fn be a list of An” with no mention of choice, an unflagged infinite ∃E that no rule licenses (0 for the choice step); listing N×N row by row, as in Example (Listing the rows one after another) (0 for the countability step).

Exercise (C2: Finite unions)
  • (a) Prove, without Axiom 6.1.1, that for every finite set I and every family (Ai)i∈I of countable sets, ⋃i∈IAi is countable.
  • (b) Explain in two sentences why your induction does not prove Theorem 6.1.4.

Solution.

  • (a) We use Logic and Proof, Axiom 4.2.1 on the number of elements of I. Let P(n) be: “for every set I with n elements and every family (Ai)i∈I of countable sets, ⋃i∈IAi is countable”.

    Base case. A set I with 0 elements is the image of a bijection from {1,…,0}=∅ (Definition 4.1.2), so it is empty and ⋃i∈IAi=∅, which is countable.

    Inductive step. Assume P(n), and let I have n+1 elements and (Ai)i∈I be a family of countable sets. A bijection {1,…,n+1}→I (Definition 4.1.2) has a value at 1, so I≠∅; pick i0∈I. Then I′:=I∖{i0} has n elements (Corollary 4.1.7), so B:=⋃i∈I′Ai is countable by P(n), applied to the family (Ai)i∈I′. Since I=I′∪{i0}, an element lies in some Ai with i∈I exactly when it lies in B or in Ai0, so ⋃i∈IAi=B∪Ai0, which is countable by Proposition 4.2.5. So P(n+1) holds, and Logic and Proof, Axiom 4.2.1 gives P(n) for every n. Each step makes finitely many ∃E’s, so no choice is used.

  • (b) The induction proves the statement for each finite number n of sets, and N is not finite (Example (Hilbert’s Hotel)), so no instance of P(n) is about the family (An)n∈N. Writing ⋃n∈NAn as the union of the finite unions A0∪⋯∪Ak does not help, since that needs a list of every finite union at once, which is a choice of infinitely many lists again.

Marking scheme. (10 points) - 2: states P(n), quantified over all sets I with n elements and all families of countable sets. - 1: base case. - 2: shows I≠∅, picks i0 and shows that I∖{i0} has n elements (Corollary 4.1.7). - 2: proves ⋃i∈IAi=B∪Ai0. - 1: applies P(n) and Proposition 4.2.5 to conclude. - 2: part (b), in two sentences. Fatal error (0 for the step): an induction that “reaches” n=N, or that treats N as a finite index set.

Exercise (C3: Removing a countable set)

Let X be uncountable and let C⊆X be countable. Deduce from Exercise (B4: Absorbing a countable set) that |X∖C|=|X|.

Solution. The set X∖C is uncountable: otherwise X=(X∖C)∪C would be a union of two countable sets, countable by Proposition 4.2.5, against the choice of X. An uncountable set is infinite, since finite sets are countable (Theorem 4.2.2). Now apply Exercise (B4: Absorbing a countable set) with X∖C in the role of X and C as the countable set, which is disjoint from X∖C: |(X∖C)∪C|=|X∖C|, and the left side is |X| because C⊆X. Here X∖C is given by no formula, so no explicit copy of N in it is available; the copy comes from Theorem 6.1.5, which uses Axiom 6.1.1. For X=R and C=Q (Theorem 4.2.8, Theorem 4.3.4) this is |R∖Q|=|R|, which Section 4.5, Exercise B5 (a) proves without the axiom, using the explicit copy n↦2+n.
