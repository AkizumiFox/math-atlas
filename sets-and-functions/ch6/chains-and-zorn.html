6.2  Zorn’s Lemma and How to Use It

Section 4.4 proved that injections both ways give a bijection, and left open whether, for any two sets, at least one injection exists. Section 5.3 ended with a question about partially ordered sets: if every chain has an upper bound, must there be a maximal element? One principle answers both. This section states it, Zorn’s lemma, which answers the second question; says why this volume does not prove it; turns it into a method of proof, the maximality template; and runs the template twice, for a set of representatives and for a total order containing a given partial order. Section 6.3 runs it on the first question, and on the axiom of choice itself.

6.2.1. Matching two sets, one pair at a time

Let A and B be sets, and suppose we want an injection from one of them into the other, in either direction. A natural plan is to match elements in pairs. Pick a0∈A and b0∈B and pair them. Then pick a1∈A∖{a0} and b1∈B∖{b0} and pair those. Continue until one side is used up. If A runs out first, every element of A has a partner, different elements have different partners, and the pairs form the graph of an injection A→B. If B runs out first, the same pairs read backwards form an injection B→A.

For finite sets the plan works, because each step uses one more element of each side, and a finite set is used up after as many steps as it has elements (Section 4.1). Take A={1,2,3} and B={x,y}. Pair 1 with x, then 2 with y. Now B is used up, and reading the pairs backwards gives x↦1, y↦2, an injection B→A.

For A=B=R the plan breaks down. Suppose we have made one step for each natural number. The elements of A used so far are a0,a1,a2,…, the image of the function n↦an on N, so they form a countable set (Proposition 4.2.4). But R is uncountable (Theorem 4.3.4), so A is not used up; neither is B. The instruction “continue until one side is used up” has no last step, and the words “and so on” stand in for a step that is never stated: (N13) of Logic and Proof, Example (What is not allowed), “an ‘and so on’ needs its step”. (The infinitely many unnamed choices of an and bn are a second problem, the one Section 6.1 met.)

Still, the attempt gets two things right, and they are the thesis of this section:

Every unfinished matching can be enlarged by one more pair, and a growing family of matchings, put together, is again a matching.

The first half is plain: if neither side is used up, an unused a and an unused b make one more pair. The rest of the section makes “growing family” exact and supplies a principle that turns these two facts into a finished matching. We return to the matching in Section 6.3.

6.2.2. Chains

Look at the matchings the plan produces, each a set of pairs. Of any two of them, one was built from the other by adding pairs, so one is a subset of the other: under ⊆, any two are comparable. That is what “growing family” means, and it makes sense in any partially ordered set.

Definition 6.2.1 (Chain)

Let (X,⪯) be a partially ordered set. A subset C⊆X is a chain if any two elements of C are comparable: for all x,y∈C, x⪯y or y⪯x.

So a chain is a subset on which ⪯ is total (Definition 5.3.1); in a totally ordered set, every subset is a chain.

Examples.

  • In (N,∣), the set {1,2,4,8,…}={2n:n∈N} is a chain: for m≤n, 2n=2n−m⋅2m, so 2m∣2n. The set {2,3} is not, since 2∤3 and 3∤2.
  • In (P({1,2,3}),⊆), the set {∅,{2},{2,3}} is a chain.
  • Degenerate cases: ∅ is a chain, vacuously, and so is every one-element set {x}, by (PO1).

Quick check. Decide: (a) Is {{1},{1,2},{3}} a chain in (P({1,2,3}),⊆)? (b) Is {0,1,5,25} a chain in (N,∣)? (c) Is {3,6,0}? (d) In (R,≤), which subsets are chains?

Solution.

  • (a) No: {1,2}⊈{3} and {3}⊈{1,2}.

  • (b) Yes. 1 divides every natural number, 25=5⋅5, and every natural number a divides 0=0⋅a; so any two of the four are comparable.

  • (c) Yes: 6=2⋅3, and 3∣0, 6∣0.

  • (d) All of them, since ≤ is total on R.

Why do chains matter for the matching? Take two pairs from the union of a growing family of matchings. Each pair comes from some matching of the family, and the two matchings are comparable, so both pairs lie in the larger of the two. Any condition that speaks about two pairs at a time can then be checked inside one matching. The same works for any finite number of elements, and that is the content of the next lemma.

The lemma speaks about a set of sets ordered by ⊆. That is always a partially ordered set: each member of a set of sets S is a subset of ⋃S, and ⊆ is a partial order on P(⋃S) (Example (Inclusion is a partial order, rarely total)), which stays one when restricted to the subset S, since (PO1)–(PO3) are statements about all elements.

Lemma 6.2.1 (Finitely Many Members of a Chain)
  • (a) Let C be a chain in a partially ordered set (X,⪯), let n≥1 and x1,…,xn∈C. Then some xk satisfies xj⪯xk for j=1,…,n.
  • (b) Let S be a set of sets, partially ordered by ⊆, and C⊆S a chain. Then C⊆⋃C for every C∈C; and if n≥1 and z1,…,zn∈⋃C, then some single C∈C contains all of z1,…,zn.

Proof. (a) By induction on n (Theorem 3.2.1 with n0=1). For n=1, take k=1: x1⪯x1 by (PO1). For the step, let x1,…,xn+1∈C, and by the induction hypothesis let xk with k≤n be above x1,…,xn. Since C is a chain, xn+1⪯xk or xk⪯xn+1. In the first case xk is above all n+1 elements. In the second, xn+1 is: xj⪯xk⪯xn+1 gives xj⪯xn+1 by (PO3) for j≤n, and xn+1⪯xn+1 by (PO1).

(b) The first claim is the definition of the union. For the second, induct on n (Theorem 3.2.1 with n0=1). For n=1: z1∈⋃C means that z1∈C for some C∈C, and one use of ∃E (Logic and Proof, Definition 5.6.1) names such a C. For the step, by the induction hypothesis some C′∈C contains z1,…,zn, and one use of ∃E gives C″∈C with zn+1∈C″. Since C is a chain, C′⊆C″ or C″⊆C′, and the larger of the two contains all of z1,…,zn+1.

Each step of the induction in (b) makes one use of ∃E, so no choice is involved. Writing “use ∃E n times” instead would be the “and so on” that (N13) flags; the induction is what supplies its step.

Quick check.

  • (a) Is there a chain of subsets of N, none of whose members contains both 0 and 1, whose union contains both? (b) Is there such a family of subsets that is not a chain?

Solution.

  • (a) No. If 0 and 1 lie in the union of a chain, then by Lemma 6.2.1 (b) with n=2 some member contains both.

  • (b) Yes: {{0},{1}} has union {0,1}, and neither member contains both. This is exactly what “chain” rules out.

6.2.3. Zorn’s lemma

Return to the question of Section 5.3: in a partially ordered set in which every chain has an upper bound, is there a maximal element? A naive attempt: start at any p0. If p0 is not maximal, there is p1≻p0; if p1 is not maximal, there is p2≻p1; and so on. The pn form a chain, which has an upper bound u; if u is not maximal, continue above u, and so on. Each single step is legitimate. But the chain p0≺p1≺⋯ may have an upper bound that is again not maximal, the next chain may too, and “continue past every such bound” is neither a finite process nor one indexed by N. It is (N13) once more: the “and so on” has no step. Instead of a proof, there is a principle, stated as its own result.

Theorem 6.2.2 (Zorn’s Lemma)

Let (P,⪯) be a non-empty partially ordered set in which every non-empty chain has an upper bound in P. Then P has a maximal element.

We do not prove Theorem 6.2.2. It cannot be proved from the rules of logic and the working rules for sets of Chapter 1 alone: it is equivalent to the axiom of choice (Axiom 6.1.1), which, as Section 6.1 records, can be neither proved nor refuted from the other axioms. Section 6.3 proves one half of the equivalence, that Zorn’s lemma gives the axiom of choice. The other half, which builds a maximal element from a choice function, needs a recursion longer than any indexed by N; Axiomatic Set Theory, Chapter 4 proves it. As with the axiom, we use the lemma openly and cite it at each use. Zorn (1935) put the principle in this form, which suits algebra, where the objects to be built are sets ordered by inclusion.

Why each hypothesis is needed. Each of three small examples breaks one hypothesis and has no maximal element.

  • (N,≤) is non-empty and total, and has no maximal element, since n<n+1. The chain hypothesis fails: the chain N has no upper bound in N.
  • The empty partially ordered set satisfies the chain hypothesis vacuously, since it has no non-empty chain, and it has no maximal element. “Non-empty” is needed.
  • The set of finite subsets of N, ordered by ⊆, is non-empty, as ∅ belongs to it, and has no maximal element. For finite F, N is not a subset of F, since a subset of a finite set is finite (Proposition 4.1.6) and N is infinite (Example (Hilbert’s Hotel)); for m∈N∖F, the set F∪{m} is finite (Proposition 4.1.5) and strictly larger. By the contrapositive of Zorn’s lemma, some non-empty chain has no upper bound in this set, and here one is visible: {{0,1,…,n−1}:n∈N}, that is, ∅,{0},{0,1},…. An upper bound would be a finite set containing every natural number, hence containing N, which is impossible.

Warning. Maximal, not greatest, and not unique. Zorn’s lemma produces a maximal element, by no formula, and says nothing about how many there are. By Proposition 5.3.2 a greatest element would be maximal, but the converse fails (Example (Maximal elements that are not greatest)). In the applications below there are usually many maximal objects and no greatest one; a proof that treats “the” maximal element as unique, or as above everything, has gone wrong.

Quick check. Let P={{1},{2},{1,3}}, ordered by ⊆. List the chains with at least two elements; check that every non-empty chain has an upper bound in P; name the maximal elements.

Solution. The only comparable pair of different elements is {1}⊆{1,3}, so the only chain with at least two elements is {{1},{1,3}}, with upper bound {1,3}. A one-element chain {p} has the upper bound p. The maximal elements are {2} and {1,3}: two of them, as the warning says, and no greatest element.

Remark (Every chain, or every non-empty chain). Some books ask for an upper bound of every chain, the empty one included. An upper bound of ∅ is any element of P (Definition 5.3.2), so that form contains “P≠∅” as a special case. The two forms say the same thing.

6.2.4. The maximality template

Zorn’s lemma is almost always used in one pattern.

Example (Method: the maximality template)

Template. To show that a complete object exists: (1) partial objects: let P be the set of partial objects, of which the complete ones are the finished case, ordered by ⊆ (extension); check P≠∅, usually with the empty or the given starting object. (2) chains: for a non-empty chain C⊆P, show ⋃C∈P; each defining condition mentions finitely many elements, which lie in one member (Lemma 6.2.1). (3) Zorn: P has a maximal element M (Theorem 6.2.2). (4) complete: suppose M is not complete; use the missing piece to build a strictly larger partial object, a contradiction.

When to use it. The object can be built piece by piece, each condition on it checks finitely many pieces at a time, and the pieces cannot be listed.

The usual failure. The union of a chain is not a partial object, because a condition mentions infinitely many pieces (“finite”, “countable”); step (4) builds an object that is not strictly larger, or not in P; and treating M as the greatest or the only complete object.

Here is its first run.

Example (A set of representatives)

Let ∼ be an equivalence relation on a set X. Show that there is a set S⊆X that meets every equivalence class in exactly one element.

Idea (Scratch work). By the method of Example (Method: the maximality template). A partial object should be a set that meets each class at most once, so that the complete ones meet each class exactly once. “At most once” reads: s∼t implies s=t, a condition on two elements at a time, so step (2) works. For step (4), a class [x] that is missed gives the larger set S∪{x}, and no choice is needed, since x is already in hand. As givens and goal:

Givens Goal
∼ an equivalence relation on X S⊆X meeting every class in exactly one element
P: the S⊆X with s∼t⇒s=t (each class met at most once), ordered by ⊆ Zorn’s hypotheses: P≠∅, and every non-empty chain has an upper bound in P
∅∈P; for a chain C, try ⋃C: the condition mentions two elements (Lemma 6.2.1 (b)) a maximal M∈P meets every class
M maximal; suppose the class [x] is missed M∪{x}∈P, strictly larger: a contradiction (Example (Method: choosing direct, contrapositive or contradiction))

Solution. Let P be the set of S⊆X such that for all s,t∈S, s∼t implies s=t; order it by ⊆. Then ∅∈P. For a non-empty chain C⊆P, any two elements s,t of ⋃C lie in one member (Lemma 6.2.1 (b)), so s∼t gives s=t: ⋃C∈P, an upper bound of C. By Theorem 6.2.2, take a maximal M∈P.

Suppose some class [x] (Definition 5.2.2) contains no element of M. Then x∉M, since x∈[x] by (Eq1). And M∪{x}∈P: let s,t∈M∪{x} with s∼t. If both lie in M, then s=t. If s=x and t∈M, then t∼x by (Eq2), so t∈[x]∩M, which is impossible; the case t=x, s∈M is the same with the letters exchanged; and if s=t=x, there is nothing to show. So M⊊M∪{x} in P, contradicting maximality. Hence M meets every class, and by the condition defining P in at most one element: S:=M works.

The axiom of choice gives the same set in one line, by choosing one element from each class; the template’s advantage shows when the pieces interact, as in the next subsection. On R, the relation x∼y⟺x−y∈Q is an equivalence relation (Section 5.2, after Example (The reals modulo the integers)). A set of representatives for it inside [0,1] is a set of real numbers that Measure, Integration, and Real Analysis, Chapter 2 shows has no length, and no formula for one is known.

Quick check. Let X=Z and m∼n⟺m−n is even. Describe the partial objects of Example (A set of representatives) that have two elements, and the maximal ones.

Solution. They are the sets {e,o} with e even and o odd: two even or two odd integers are related, since their difference is even, so a partial object holds at most one of each parity. Conversely, {e,o} is a partial object: with e=2a and o=2b+1, e−o=2(a−b−1)+1 is odd, hence not even (no integer is both, Theorem 1.1.2), so e≁o. These are exactly the maximal elements, since any third integer has the parity of e or of o (every integer is even or odd, Theorem 1.1.2), and ∅ and the one-element sets are not maximal, since each lies strictly inside some {e,o}. There are many maximal elements, such as {0,1} and {4,−7}, and no greatest one.

Warning. Check that the union is a partial object. Here is an almost-correct proof that N has a maximal finite subset. “Let P be the set of finite subsets of N, ordered by ⊆. A chain has its union as an upper bound. By Zorn’s lemma, P has a maximal element.” The conclusion is false, by the third example after Theorem 6.2.2. The failing line is the second: the union is an upper bound in P(N), but it need not be finite, so it need not lie in P. “Finite” is a condition on all the elements at once, and Lemma 6.2.1 handles only finitely many.

In the next run the pieces interact: one added comparison forces others.

6.2.5. Extending a partial order

Suppose a project consists of tasks, and some tasks must be done before others. Write u⪯v when task u must come no later than task v: either u=v, or u must be finished before v can start, directly or through a sequence of prerequisites. Counting each task as coming no later than itself makes ⪯ reflexive; passing prerequisites along makes it transitive; and no two different tasks can each be required before the other, or nothing could ever start. So ⪯ is a partial order. A schedule puts the tasks in one line, and it respects the prerequisites when its order, a total order, contains ⪯.

For finitely many tasks there is a procedure: pick a task with no unfinished prerequisite, do it, and repeat. Here is a small case. Five tasks, survey S, financing F, design D, permit P and building B, with four prerequisites: S before D,F before D,D before B,F before P. The order they generate consists of the five pairs (t,t), the four given pairs, and the two pairs (S,B) and (F,B) that the prerequisites pass along through D: eleven pairs in all. At the start, S and F have no prerequisites. Picking S, then F, leaves D and P free; picking D, then P, frees B. That gives the schedule S, F, D, P, B. Picking F first instead, then P, then S, then D, then B, gives a second schedule F, P, S, D, B. Each contains all eleven pairs: in both lists S and F come before D, D before B, F before P, and hence S and F before B. So schedules are not unique (there are seven in all), and the procedure needs the tasks in hand, one free task at a time, until none is left. For an infinite set with no list there is no last step, and the maximality template does the work instead. Its engine is a single move: two incomparable elements can be made comparable without breaking anything.

A partial order on X is a relation on X, a subset of X×X (Definition 1.4.3), so it makes sense to say that one partial order is contained in another.

Lemma 6.2.3 (Adding One Comparison)

Let ⪯ be a partial order on a set X, and let a,b∈X be incomparable. Let R:=⪯∪{(x,y)∈X×X:x⪯a and b⪯y}. Then R is a partial order on X, ⪯⊆R, and (a,b)∈R∖⪯.

Idea. R puts everything below a below everything above b. A new pair can break antisymmetry or transitivity only by producing b⪯a, and incomparability forbids that.

Proof. Call a pair (x,y) new if x⪯a and b⪯y, and old if x⪯y. Every pair of R is old or new. The pair (a,b) is new, since a⪯a and b⪯b by (PO1), and it is not old, since a and b are incomparable. By the definition of R, ⪯⊆R.

(PO1): x⪯x for every x∈X, and ⪯⊆R.

(PO2): let xRy and yRx. If both pairs are old, x=y by (PO2) for ⪯. If (x,y) is new and (y,x) old, then b⪯y⪯x⪯a, so b⪯a by (PO3), which incomparability excludes. If (x,y) is old and (y,x) new, then b⪯x⪯y⪯a, excluded in the same way. If both are new, then b⪯x (from (y,x)) and x⪯a (from (x,y)), so again b⪯a. Only the first case can occur, and it gives x=y.

(PO3): let xRy and yRz. If both pairs are old, x⪯z by (PO3). If (x,y) is old and (y,z) new, then x⪯y⪯a and b⪯z, so (x,z) is new. If (x,y) is new and (y,z) old, then x⪯a and b⪯y⪯z, so (x,z) is new. If both are new, x⪯a and b⪯z directly. In every case xRz.

Quick check. Apply Lemma 6.2.3 to ⊆ on P({1,2}) with a={1} and b={2}. Which pairs does R add to ⊆?

Solution. A new pair (x,y) needs x⊆{1} and {2}⊆y: x∈{∅,{1}} and y∈{{2},{1,2}}. Of these four pairs, all but ({1},{2}) already belong to ⊆. So R adds exactly one pair, and it is the total order ∅,{1},{2},{1,2}.

The lemma adds one comparison. The template adds them all at once.

Theorem 6.2.4 (Every Partial Order Extends to a Total Order)

Let ⪯ be a partial order on a set X. Then there is a total order T on X with ⪯⊆T.

This book’s word is “total” (Definition 5.3.1); “linear order” is a common synonym, and T is then called a linear extension of ⪯.

Idea. By the method of Example (Method: the maximality template). The partial objects are the partial orders on X containing ⪯. The union of a chain of them is one, since (PO2) and (PO3) each mention two pairs. A maximal one is total, because Lemma 6.2.3 enlarges any partial order that has an incomparable pair.

Proof. Let P be the set of partial orders R on X with ⪯⊆R, a set of subsets of X×X, ordered by ⊆. Then ⪯∈P, so P≠∅.

Let C⊆P be a non-empty chain and H:=⋃C⊆X×X. Since C has a member, and that member contains ⪯, so does H; in particular (PO1) holds for H. If (x,y),(y,x)∈H, some single R0∈C contains both (Lemma 6.2.1 (b)), so x=y by (PO2) for R0. If (x,y),(y,z)∈H, some R0∈C contains both, so (x,z)∈R0⊆H by (PO3) for R0. Hence H∈P, and it is an upper bound of C.

By Theorem 6.2.2, P has a maximal element T. Suppose T is not total, and let a,b∈X be incomparable for T. By Lemma 6.2.3, applied to T, there is a partial order R on X with T⊆R and T≠R. Since ⪯⊆T⊆R, R∈P, contradicting the maximality of T. So T is total.

Warning. One comparison at a time. It is tempting to skip Zorn’s lemma and settle every incomparable pair at once, each in some direction. That can fail. Take equality on X={1,2,3}, where no two different elements are comparable, and decide the three pairs as 1 before 2, 2 before 3, 3 before 1. Each decision alone is harmless, but together they break transitivity, and adding the pairs that transitivity demands puts 1 before 3 and 3 before 1, against (PO2). Lemma 6.2.3 adds one comparison and then passes the consequences along; the next comparison is made in the new order, where the earlier ones are already visible. The template is what turns this one-step move into a total order when the pairs cannot be listed.

Sometimes no Zorn is needed, because a formula gives the extension.

Example (A total order containing divisibility)

On N, let x⊑y mean: y=0, or x≠0 and x≤y. Show that ⊑ is a total order on N containing ∣, and that ≤ does not contain ∣.

Solution. In words, ⊑ is the usual order on the positive integers with 0 moved to the top.

(PO1): if x=0, then x⊑x by the first alternative; otherwise x≤x.

Total: let x,y∈N. If y=0, then x⊑y; if x=0, then y⊑x; if both are non-zero, x≤y or y≤x, by totality of ≤.

(PO2): let x⊑y and y⊑x. If y=0, then y⊑x cannot hold by the second alternative, which needs y≠0; so x=0=y. The case x=0 is the same with the roles exchanged. If both are non-zero, x≤y≤x, so x=y.

(PO3): let x⊑y and y⊑z. If z=0, then x⊑z. Otherwise the second alternative holds for (y,z): y≠0 and y≤z. Then x⊑y with y≠0 also holds by the second alternative: x≠0 and x≤y. So x≤z, and x⊑z.

Contains ∣: let a,b∈N with a∣b, say b=ka with k∈Z (Definition 1.1.2). If b=0, then a⊑b. If b≠0, then a≠0, since 0∣b would mean b=k⋅0=0. With a,b>0, k>0, so k≥1 and b=ka≥a: a⊑b.

≤ does not contain ∣: 2∣0, since 0=0⋅2, but 2≤0 fails.

Where a formula exists, it is the better proof. Theorem 6.2.4 matters for orders such as ⊆ on P(R), for which no formula for a total extension is known.

Quick check. Put 0,1,4,6,12 in ⊑-order. Which two of them are comparable under ⊑ but not under ∣?

Solution. 1⊑4⊑6⊑12⊑0. Every pair is comparable under ⊑, which is total. Under ∣: 1 divides all of them, all of them divide 0, 4∣12 and 6∣12. The remaining pair is 4, 6: 4⊑6, but neither divides the other. So 4 and 6 are the only such pair.

Section 6.3 runs the template three times more: on the matching that opened this section, on choice functions, and on well-orders.

6.2.6. Exercises

A. Check your understanding

Exercise (A1)
  • (a) Step (4) of Example (A set of representatives) adds one point x of a class that M misses. Why is naming x a single ∃E, and why does the proof make no other choice, although a set of representatives picks one point from each of possibly infinitely many classes?
  • (b) Run Example (A set of representatives) when ∼ has a single class, on X={1,2,3}: list P, name its maximal elements, and decide whether P has a greatest element.
  • (c) Lemma 6.2.3 asks for a, b incomparable. What goes wrong with R if b⪯a and a≠b?
  • (d) Give a partially ordered set that contains an infinite chain, in which every non-empty chain has an upper bound, and which has exactly two maximal elements.

Solution.

  • (a) x is one element of one non-empty set, the missed class, named inside the proof by contradiction: one ∃E (Logic and Proof, Definition 5.6.1). P is defined by specification and the union of a chain is defined outright; the maximal M is named by one ∃E from the conclusion of Theorem 6.2.2. The one point per class is picked by Zorn’s lemma, as M; the proof itself picks nothing more.

  • (b) A member of P meets the one class at most once, so it has at most one element, and every set with at most one element qualifies: P={∅,{1},{2},{3}}. The maximal elements are the three singletons. There is no greatest element: a greatest element would be maximal (Proposition 5.3.2 (a)), so it would be one of the singletons, and it would contain the other two.

  • (c) The pair (a,b) is new, since a⪯a and b⪯b. With (b,a)∈⪯⊆R, (PO2) for R would give a=b, which is false; so R is not a partial order.

  • (d) Take a:=−1 and b:=−2, integers not in N, and on N∪{a,b} let ⪯ consist of the usual order ≤ of N, the pairs n⪯a and n⪯b for all n∈N, and a⪯a, b⪯b. (PO1)–(PO3) hold: they hold inside N, and every other pair ends at a or b (for instance n≤m and m⪯a give n⪯a). N is an infinite chain. A non-empty chain containing a does not contain b, since the two are incomparable, so a bounds it; likewise for b; and a chain inside N is bounded by a. The maximal elements are a and b; no n is maximal, since n⪯n+1 and n≠n+1.

B. Practice

Exercise (B1: Maximal chains)

Let (X,⪯) be a partially ordered set and C0⊆X a chain. Prove that there is a chain C⊇C0 that is maximal: no chain contains C properly.

Solution (Hint). The partial objects are the chains containing C0.

Solution. Let P be the set of chains C⊆X with C0⊆C, ordered by ⊆; then C0∈P. Let K⊆P be a non-empty chain and H:=⋃K. Then H⊇C0, since K has a member and each member contains C0. Any x,y∈H lie in one member K∈K (Lemma 6.2.1 (b)), which is a chain, so x and y are comparable. So H∈P, and it is an upper bound of K. By Theorem 6.2.2, P has a maximal element C. If a chain D⊋C existed, then D⊇C0, so D∈P and C⊊D, contradicting maximality. So C is a maximal chain containing C0.

Exercise (B2: Name the move, then complete it)

Here is the frame of a proof that for every set F of non-empty sets there is a subfamily D⊆F of pairwise disjoint sets such that every member of F meets some member of D.

Let P be the set of subfamilies E⊆F whose members are pairwise disjoint (E∩E′=∅ for E≠E′ in E), ordered by ⊆. Then ∅∈P. For a non-empty chain of such subfamilies, two members E≠E′ of its union lie in one subfamily of the chain, so E∩E′=∅; the union lies in P and is an upper bound. By Zorn’s lemma, P has a maximal element D.

⋮

… Hence every member of F meets some member of D.

Name the move, then complete it.

Solution. The move is step (4) of Example (Method: the maximality template): a missing piece gives a strictly larger partial object. Suppose F∈F meets no member of D. Then F∉D: otherwise F would meet itself, as F∩F=F≠∅. And D∪{F} is pairwise disjoint, since F∩D=∅ for every D∈D by assumption. So D⊊D∪{F}∈P, against the maximality of D. The check F∉D is what makes the new family strictly larger, the failure the method box warns about. Hence every member of F meets some member of D.

Exercise (B3: Prove or disprove)

Prove each true statement and refute each false one.

  • (a) If every chain of a non-empty partially ordered set P has an upper bound in P, then P has a greatest element.
  • (b) Every non-empty finite partially ordered set has a maximal element.
  • (c) The set of subsets of N that contain no two consecutive numbers, ordered by ⊆, has a greatest element.
  • (d) If P is a non-empty partially ordered set in which every non-empty chain has an upper bound, then every p∈P lies below some maximal element of P.
  • (e) The set of countable subsets of R, ordered by ⊆, has a maximal element.

Hint for (d): apply Zorn’s lemma to the elements above p.

Solution.

  • (a) False. Take P={{1},{2}} under ⊆. Its chains are ∅ (any element of P bounds it, Definition 5.3.2), {{1}} and {{2}}, each with an upper bound in P. But P has no greatest element, since {1} and {2} are incomparable.

  • (b) True. Let P be non-empty and finite, and let C be a non-empty chain of P. Then C is finite (Proposition 4.1.6); list it as x1,…,xn with n≥1. By Lemma 6.2.1 (a), one xk is above all of them, an upper bound of C in P. By Theorem 6.2.2, P has a maximal element. (Section 5.3, Exercise R4 proves this without Zorn’s lemma, by induction.)

  • (c) False. The set E of even numbers and the set O of odd numbers both contain no two consecutive numbers. A greatest element G would contain E and O, so 0,1∈G, which are consecutive. (In fact E and O are both maximal: adding any n∉E to E puts n and n+1 in it (n is odd by Theorem 1.1.2, so n+1 is even), and adding any n∉O to O does the same. So Zorn’s lemma, if applied here, gives a maximal element, never a greatest one, as the warning after Theorem 6.2.2 says.)

  • (d) True. Let p∈P, and let Q:={q∈P:p⪯q}, ordered by ⪯; then p∈Q. A non-empty chain C of Q is a chain of P, so it has an upper bound u∈P; for any c∈C, p⪯c⪯u, so u∈Q by (PO3). By Theorem 6.2.2, Q has a maximal element m, and p⪯m. If m≺q for some q∈P, then p⪯q by (PO3), so q∈Q, against the maximality of m in Q. So m is maximal in P.

  • (e) False. Let C⊆R be countable. Then C≠R, since R is uncountable (Theorem 4.3.4); for x∈R∖C, the set C∪{x} is countable (Proposition 4.2.5) and strictly larger. So no countable set is maximal. (By the contrapositive of Zorn’s lemma, some non-empty chain of countable sets has no countable upper bound; the answer does not need one.)

Exercise (B4: A total order on the subsets of a three-element set)
  • (a) Write the eight subsets of {1,2,3} in a list such that A⊊B always puts A before B, and prove that it does.
  • (b) How many total orders on P({1,2}) contain ⊆?

Solution.

  • (a) ∅,{1},{2},{3},{1,2},{1,3},{2,3},{1,2,3}. The list is arranged by the number of elements. If A⊊B, then A has fewer elements than B (Proposition 4.1.6), so A comes in an earlier block of the list.

  • (b) Two. The empty set must come first, since ∅⊆Y for every Y, and {1,2} last, since every Y⊆{1,2}. The sets {1} and {2} are incomparable under ⊆, so they may come in either order. In each list ∅ comes first and {1,2} last, so every pair of ⊆ (the pairs (∅,Y), (Y,{1,2}) and (Y,Y)) appears in list order. A list of the four sets defines a total order, and different lists give different orders, so there are exactly two.

C. Going deeper

Exercise (C1: Find the error)

Claim: every chain C0 of a partially ordered set X lies in a maximal chain.

“Proof”: Let P be the set of chains containing C0, ordered by ⊆; then C0∈P. Let K be a non-empty chain in P. Every K∈K is a subset of ⋃K, so ⋃K is an upper bound of K. By Zorn’s lemma, P has a maximal element C. A chain containing C contains C0, so it lies in P; hence C is a maximal chain.

Is the conclusion true? Does the argument prove it?

Solution. The conclusion is true: it is Exercise B1.

The argument does not prove it. It never checks that ⋃K lies in P, in particular that it is a chain (that it contains C0 is immediate, since K is non-empty); the upper bound in Theorem 6.2.2 must belong to P. The step’s general form, “the union of a chain of partial objects lies in P”, is false: among the finite subsets of N, the chain {{0,…,n−1}:n∈N} has union N, which is not finite (the second warning of this section). Here the conclusion of the step happens to be true, which is exactly why it must be proved, not assumed. The repair is the chain step of B1: two elements of ⋃K lie in one member K∈K (Lemma 6.2.1 (b)), which is a chain, so they are comparable.

Marking scheme. (10 points) - 2: the conclusion is true, with B1 cited. - 3: the missing check named: ⋃K∈P. - 3: explains why the upper bound must belong to P (Zorn’s hypothesis); a counterexample to the general inference “the union of a chain of partial objects lies in P” is one way to do so. - 2: the repair via Lemma 6.2.1. Fatal errors (0 for the step): calling the conclusion false; “repairing” the proof by assuming that a union of chains is always a chain.

Exercise (C2: Exit check: when no choice is needed)
  • (a) Let ∼ be an equivalence relation on N. Without Zorn’s lemma or the axiom of choice, give a set S meeting every class exactly once, and prove that it does.
  • (b) Do the same for an equivalence relation on a set X with an injection j:X→N.
  • (c) Which ingredient of Example (A set of representatives) does your answer to (a) make unnecessary, and why?

Solution (Hint 1). Each class is a non-empty set of natural numbers. Which element of it can be named without choosing?

Solution.

  • (a) Let S:={mx:x∈N}, where mx is the least element of [x]. It exists by Theorem 3.1.3, since [x]⊆N contains x and so is non-empty, and it is unique (Proposition 5.3.1), so the rule names one value. Every class is met: mx∈[x]∩S. At most once: let mx,my∈S lie in the same class [z]. Then mx∈[x]∩[z], so [x]=[z], and likewise [y]=[z], since different classes are disjoint (Theorem 5.2.1). So [x]=[y], these classes have the same least element, and mx=my. Hence S meets each class [x] in mx and nowhere else.

  • (b) For x∈X, the set j([x])⊆N is non-empty, so it has a least element kx (Theorem 3.1.3), and since j is injective exactly one sx∈[x] has j(sx)=kx. Let S:={sx:x∈X}. The argument of (a) applies word for word, with sx for mx: equal classes give equal kx, hence equal sx.

  • (c) Zorn’s lemma, that is, the whole argument with P, chains and a maximal M: a rule names each representative, so nothing needs to be chosen (Example (Method: name the choice)).

Marking scheme. (10 points) - 3: (a) each class has a well-defined representative (well-ordering, and the rule names one value). - 3: (a) every class met, and met at most once (justified). - 2: (b) the least value of j, and injectivity naming one element. - 2: (c) Zorn’s lemma named as the unnecessary ingredient, because a rule names each representative. Fatal errors (0 for the step): “choose an element of each class” in (a) or (b), which is the axiom of choice.

Exercise (C3: Exit check: an order is the intersection of its total extensions)

Let ⪯ be a partial order on a set X, and let T be the set of total orders on X that contain ⪯. Prove that ⪯=⋂T.

Solution (Hint 1). For a pair (a,b) not in ⪯, you need one T∈T without it. If a and b are incomparable, find a partial order containing ⪯ and the pair (b,a).

Solution. By Theorem 6.2.4, T≠∅, so the intersection is defined, and ⪯⊆⋂T since every T∈T contains ⪯.

Let (a,b)∈X×X with (a,b)∉⪯. Then a≠b by (PO1). Since a⪯b fails, either b⪯a or a and b are incomparable.

Case b⪯a. Every T∈T contains (b,a). If it also contained (a,b), then a=b by (PO2) for T. So no T∈T contains (a,b), and since T≠∅, (a,b)∉⋂T.

Case a, b incomparable. Lemma 6.2.3, with b, a in place of a, b, gives a partial order R⊇⪯ with (b,a)∈R. Theorem 6.2.4 applied to R gives a total order T⊇R. Then T∈T and (b,a)∈T, so (a,b)∉T by (PO2), as a≠b. Hence (a,b)∉⋂T.

In both cases (a,b)∉⋂T, so ⋂T⊆⪯.

Marking scheme. (10 points) - 1: T≠∅, cited from Theorem 6.2.4. - 1: ⪯⊆⋂T. - 2: the two cases are exhaustive, because a⪯b fails. - 2: the case b⪯a, with (PO2) and a≠b. - 2: a partial order containing ⪯ and (b,a) (for example, the lemma with a and b exchanged). - 2: the extension of R to a total order and the conclusion. Fatal error (0 for the case concerned): applying the lemma to (a,b) unexchanged, which puts (a,b) into the extension instead of keeping it out.
