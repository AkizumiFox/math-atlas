6.3  Equivalent Forms of Choice

Three statements have now appeared. The axiom of choice (Axiom 6.1.1) picks one element from each set of a family of non-empty sets. Zorn’s lemma (Theorem 6.2.2) gives a maximal element when every chain has an upper bound. The third is new: every set can be well-ordered, so that each of its non-empty subsets has a least element and “take the least one” becomes a rule that picks. This section proves that Zorn’s lemma implies the other two, and that the well-ordering theorem implies the axiom again, by that rule. It also finishes the matching that opened Section 6.2: any two sets are comparable in size. The one missing implication, from the axiom to Zorn’s lemma, needs a recursion that runs past every natural number; Axiomatic Set Theory, Chapter 4 proves it, and with it the three statements are equivalent.

6.3.1. Zorn’s lemma gives choice

Theorem 6.3.1 (Zorn’s Lemma Gives Choice)

Assume Theorem 6.2.2. Let I be a set and (Ai)i∈I a family of non-empty sets. Then there is a function c:I→⋃i∈IAi with c(i)∈Ai for every i∈I.

This is the conclusion of Axiom 6.1.1, so the axiom follows from Zorn’s lemma.

Idea. By the method of Example (Method: the maximality template). A choice function can be built one index at a time, like the matching that opened Section 6.2. A partial choice function is a set G⊆I×U, U:=⋃i∈IAi, with (C1) (i,x)∈G⇒x∈Ai and (C2) (i,x),(i,y)∈G⇒x=y; let P be the set of them, ordered by ⊆. (C1) and (C2) mention at most two pairs, so unions of chains stay in P; a maximal one that missed an index i0 could take one x0∈Ai0. Choosing that x0 is one use of ∃E; Zorn’s lemma does the infinitely many.

Proof. Let U and P be as in the Idea. Then P⊆P(I×U) is a set, partially ordered by ⊆.

P is non-empty: ∅ satisfies (C1) and (C2) vacuously.

Chains have upper bounds: let C⊆P be a non-empty chain and H:=⋃C⊆I×U. If (i,x)∈H, it lies in some G∈C, so x∈Ai by (C1) for G. If (i,x),(i,y)∈H, some G∈C contains both (Lemma 6.2.1 (b) with n=2), so x=y by (C2) for G. So H∈P, and G⊆H for every G∈C: H is an upper bound of C in P.

Zorn: by Theorem 6.2.2, P has a maximal element M.

M is defined everywhere: suppose some i0∈I has no pair (i0,x)∈M. Since Ai0≠∅, take x0∈Ai0, and let M′:=M∪{(i0,x0)}. Then M′⊆I×U, since i0∈I and x0∈Ai0⊆U; M′ satisfies (C1), and it satisfies (C2), because the only pair of M′ with first coordinate i0 is (i0,x0). So M′∈P, M⊆M′, and M≠M′, as (i0,x0)∉M; this contradicts the maximality of M. Hence for every i∈I there is a pair (i,x)∈M, and by (C2) exactly one. By Definition 2.1.1, M is the graph of a function c:I→U, and c(i)∈Ai by (C1).

If I=∅, then P={∅}, and the proof produces the empty function, which is correct. Of the proof’s four steps, only the last uses that the Ai are non-empty; the other three follow the template (Example (Method: the maximality template)), with (C1) and (C2) as the conditions.

6.3.2. Back to comparing sizes

Section 4.4 defined |A|≤|B| as the existence of an injection A→B (Definition 4.4.1) and proved that injections both ways give a bijection (Theorem 4.4.3). It left open whether at least one of the two injections always exists. Section 6.2 tried to build one by matching elements pair by pair, and the attempt got two things right: an unfinished matching can be enlarged by one pair, and a growing family of matchings, put together, is again a matching. Those are steps (4) and (2) of the maximality template (Example (Method: the maximality template)), and Zorn’s lemma supplies the rest.

Theorem 6.3.2 (Any Two Sets Are Comparable)

For all sets A and B, |A|≤|B| or |B|≤|A|.

Idea. By the method of Example (Method: the maximality template). The partial objects are the partial matchings: relations G⊆A×B in which each element of A and each element of B occurs in at most one pair. The union of a chain of them is one, since each condition mentions two pairs at a time. A maximal matching uses up A or B, since otherwise one more pair fits; read in the right direction, it is an injection.

Proof. Let P be the set of relations G⊆A×B such that

  • (M1) if (a,b),(a,b′)∈G, then b=b′;
  • (M2) if (a,b),(a′,b)∈G, then a=a′;

ordered by ⊆. It is a set of subsets of A×B, so ⊆ is a partial order on it.

Partial objects. ∅∈P, since (M1) and (M2) hold vacuously; so P≠∅.

Chains. Let C⊆P be a non-empty chain and H:=⋃C⊆A×B. Any two pairs of H lie in a single member G∈C (Lemma 6.2.1 (b), with n=2). So if (a,b),(a,b′)∈H, then b=b′ by (M1) for G; and (M2) for H follows in the same way. Hence H∈P, and G⊆H for every G∈C: H is an upper bound of C in P.

Zorn. By Theorem 6.2.2, P has a maximal element M.

M uses up a side. Suppose some a0∈A occurs in no pair of M, and some b0∈B occurs in no pair of M. Then M′:=M∪{(a0,b0)} satisfies (M1) and (M2), because the new pair shares no coordinate with a pair of M. So M′∈P, M⊆M′, and M≠M′, since (a0,b0)∉M. This contradicts the maximality of M. Hence every a∈A occurs in a pair of M, or every b∈B does.

Case 1: every a∈A occurs. By (M1) it occurs in exactly one pair, so M is the graph of a function f:A→B (Definition 2.1.1). If f(a)=f(a′)=b, then (a,b),(a′,b)∈M, so a=a′ by (M2): f is injective, and |A|≤|B|.

Case 2: every b∈B occurs. Consider the inverse relation M−1={(b,a):(a,b)∈M}⊆B×A (Definition 1.4.3). Every b∈B occurs as a first coordinate of M−1, and by (M2) in exactly one pair; so M−1 is the graph of a function g:B→A. By (M1), g(b)=g(b′)=a gives b=b′: g is injective, and |B|≤|A|.

Section 6.2’s “continue until one side is used up” has become step (4): a maximal matching cannot be continued, and so a side is used up. The words “and so on” never appear.

Corollary 6.3.3 (Trichotomy for Sizes)

For all sets A and B, exactly one of |A|<|B|, |A|=|B|, |B|<|A| holds.

Proof. At least one. By Theorem 6.3.2, |A|≤|B| or |B|≤|A|. In the first case, either |A|=|B|, or not, and then |A|<|B| by Definition 4.4.1. The second case gives |B|=|A|, hence |A|=|B| (Proposition 4.1.1 (b)), or |B|<|A|.

At most one. |A|<|B| excludes |A|=|B| by Definition 4.4.1. |B|<|A| excludes |B|=|A|, and therefore |A|=|B|, by symmetry (Proposition 4.1.1 (b)). Finally, |A|<|B| and |B|<|A| together give injections A→B and B→A, so |A|=|B| by Theorem 4.4.3, contradicting |A|<|B|.

Comparability is itself equivalent to the axiom of choice, a fact proved in Axiomatic Set Theory, Chapter 4: this book needed choice for it, and no proof can avoid it. (The converse direction passes through well-orders, by a theorem of Hartogs that Axiomatic Set Theory proves.)

Quick check. Run the proof of Theorem 6.3.2 on A={1,2,3} and B={x,y}: describe the maximal elements of P, and say which case of the proof occurs.

Solution. A partial matching has at most two pairs, since each of x, y occurs at most once. The maximal elements are the six two-pair matchings {(a,x),(a′,y)} with a≠a′ in A (three choices of a, then two of a′). A matching with fewer pairs is not maximal: it leaves some element of A and some element of B unpaired, and one more pair fits. No maximal M pairs every element of A: that would be an injection A→B, impossible by Corollary 4.1.3 (a). So Case 2 occurs every time: M−1 is an injection B→A. This is the finite example of Section 6.2, where the matching (1,x), (2,y) ran out of B.

A maximal matching tells us which side is used up, not that the sizes differ. For A=B=N, the identity {(n,n):n∈N} is a maximal matching that uses up both sides. So is {(n,n+1):n∈N}: it pairs every element of A, and although 0∈B is unpaired, no element of A is left to pair it with. That matching is an injection and not a bijection, although |N|=|N|. The proof only promises an injection, and that is all it delivers.

6.3.3. The well-ordering theorem

Section 6.1 met one rule that picks, again and again: the least element of a non-empty set of natural numbers (Theorem 3.1.3). A set on which that rule works for every non-empty subset is a well-ordered set (Definition 5.3.6). If a set U carries a well-order, a family of non-empty subsets of U needs no axiom: take the least element of each. R with ≤ is not well-ordered, since (0,1) has no least element. The question is whether some other order on R, or on any set, is a well-order. For a countable set an answer can be written down.

Quick check. Find a well-order on Z. Hint: list 0,−1,1,−2,2,….

Solution. Let m⪯Zn mean: |m|<|n|, or |m|=|n| and m≤n. It is a total order: compare |m| and |n| first, then m and n. For a non-empty S⊆Z, the set {|s|:s∈S}⊆N has a least element k (Theorem 3.1.3). The least element of S for ⪯Z is −k if −k∈S, and k otherwise. So (Z,⪯Z) is well-ordered, and it lists Z in the order of the hint.

The same idea works for every countable set. An injection j:X→N well-orders X by “x before x′ when j(x)≤j(x′)”: a non-empty S⊆X has as least element the point whose image is least in j(S), so every countable set has a well-order with no axiom (Exercise B2 asks for the proof). For R no formula for a well-order is known (compare the family with no rule in sight, the third example after Axiom 6.1.1); the theorem shows that one exists.

Extending a well-order at the top: initial segments. The proof builds a well-order of X piece by piece, by the template. A partial object is a pair (A,R) with A⊆X and R a well-order on A (so R⊆A×A). For two of them, write (A,R)⊴(B,S) when

  • (E1) A⊆B and R⊆S, and
  • (E2) aSb for every a∈A and every b∈B∖A:

S keeps the order of R and puts every new element above all of A. Exercise C3 shows that this says A is an initial segment of (B,S): everything of B below an element of A lies in A, and S agrees with R on A. Let P be the set of partial objects; it is a set, since P⊆P(X)×P(X×X) (Definition 1.2.3, Definition 1.3.2). Then ⊴ is a partial order on P. It is reflexive, since for (A,R)⊴(A,R) the set A∖A is empty and (E2) holds vacuously. It is antisymmetric, since (E1) both ways gives A=B and R=S. It is transitive: let (A,R)⊴(B,S)⊴(C,T). (E1) for (A,R) and (C,T) follows from the two inclusions. For (E2), let a∈A and c∈C∖A. Either c∈B∖A, so aSc, and aTc by S⊆T; or c∈C∖B, so aTc by (E2) for (B,S)⊴(C,T), as a∈B.

Why not order the partial objects by inclusion alone, as the method box does? Inclusion alone is not enough; the warning below shows why.

Warning. Ordered by inclusion alone, the template breaks. Order the partial objects by (E1) only. For n∈N let An:={−n,…,−1,0}⊆Z and Rn the order ≤ on An. Each is a well-order, since ≤ is total and every non-empty subset of the finite set An is finite (Proposition 4.1.6) and so has a minimum (Proposition 3.3.8). Under (E1) they form a chain, and the union of the chain is ≤ on {k∈Z:k≤0}, which has no least element. So step (2) of the template fails: the union of the chain is not a partial object. “Every non-empty subset has a least element” speaks about infinitely many elements at once, the failure the method box names. (E2) repairs it: (An,Rn)⊴(An+1,Rn+1) fails, since −(n+1) is added below An.

Quick check. For which m≤n is (Am,Rm)⊴(An,Rn) in the warning’s example? Which clause fails for the others?

Solution. Only for m=n. For m<n, (E1) holds, and (E2) fails at b=−n∈An∖Am with a=0∈Am, since 0≤−n is false.

Theorem 6.3.4 (The Well-Ordering Theorem)

Every set X carries a well-order: there is a partial order ⪯ on X such that (X,⪯) is well-ordered (Definition 5.3.6).

Idea. By the method of Example (Method: the maximality template), with the partial objects (A,R) ordered by ⊴. Two things change from the box: the order is ⊴ rather than ⊆, and the union of a chain is taken coordinate by coordinate, with Lemma 6.2.1 (a) in place of (b). The chain step is where (E2) earns its place: a least element found in one member stays least in the union, because everything added later sits above it. A maximal partial object covers X, since a missed point can be put on top.

Proof. Let P and ⊴ be as above.

Partial objects. (∅,∅)∈P: the empty relation is a well-order on ∅, vacuously. So P≠∅.

Chains. Let C⊆P be a non-empty chain for ⊴; let A∗ be the union of the first coordinates of its members and R∗ the union of the second. Finitely many members of C have one member ⊴-above them all (Lemma 6.2.1 (a)), and by (E1) its sets contain theirs; so any two or three elements of A∗, and any two pairs of R∗, lie in a single member. Each pair of R∗ lies in some R⊆A×A⊆A∗×A∗, so R∗ is a relation on A∗, and it is reflexive, antisymmetric, transitive and total, each property checked inside one member.

Least elements. Let ∅≠S⊆A∗. Take s∈S and a member (A0,R0) with s∈A0, and let m be the R0-least element of the non-empty set S∩A0. For t∈S, take a member (A1,R1) with t∈A1. The two members are comparable. If (A1,R1)⊴(A0,R0), then t∈A0 and mR0t. If (A0,R0)⊴(A1,R1), then either t∈A0, as before, or t∈A1∖A0 and mR1t by (E2). In every case (m,t)∈R∗, and m∈S: m is the least element of S. So (A∗,R∗)∈P.

Upper bound. Let (A,R)∈C. (E1) holds for (A,R) and (A∗,R∗) by the definition of the unions. For (E2), let a∈A and b∈A∗∖A, with b∈A1 for a member (A1,R1). (A1,R1)⊴(A,R) would put b in A, so (A,R)⊴(A1,R1), and aR1b by (E2); hence (a,b)∈R∗. So (A∗,R∗) is an upper bound of C in P.

Zorn. By Theorem 6.2.2, P has a maximal element (M,RM).

Complete. Suppose M≠X, and take x∈X∖M (one ∃E). Put M′:=M∪{x} and R′:=RM∪{(a,x):a∈M′}. Then R′ is a well-order on M′. The new pairs all end at x, and (x,x) is the only pair of R′ that starts at x; so (PO1)–(PO3) and totality reduce to those of RM together with “everything is below x”. A non-empty S⊆M′ has as least element the RM-least element of S∩M if that set is non-empty, and x if S={x}. (E1) holds for (M,RM) and (M′,R′), and so does (E2), since M′∖M={x} and aR′x for every a∈M. So (M,RM)⊴(M′,R′), and x∉M makes the two different, against the maximality of (M,RM). Hence M=X, and RM is a well-order on X.

The proof never says which well-order it found, and there are many: on Z, the order ⪯Z of the Quick check “Find a well-order on Z” and its mirror image (k before −k) are two. For N the usual order is one, and ≤ on R is not; the theorem gives R a well-order for which no formula is known.

6.3.4. Well-orders give choice

Proposition 6.3.5 (Well-Orders Give Choice)

Let (Ai)i∈I be a family of non-empty sets, and let ⪯ be a well-order on U:=⋃i∈IAi. Then c(i):= the ⪯-least element of Ai defines a choice function c:I→U, with no appeal to Axiom 6.1.1.

Proof. Each Ai is a non-empty subset of U, so it has a least element (Definition 5.3.6), and only one (Proposition 5.3.1). So the set of pairs (i,a)∈I×U with a the least element of Ai is defined by specification (Definition 1.2.3). It has exactly one pair for each i∈I, so it is the graph of a function c:I→U (Definition 2.1.1), and c(i)∈Ai.

Each hypothesis is needed. Without “non-empty” there is no least element of Ai=∅, and no choice function at all (the non-example by minimal change in Section 6.1). With a total order that is not a well-order the rule can fail: for n≥1, An:=(0,1n) in (R,≤) has no least element, since x2<x for every x∈An.

With Theorem 6.3.4 this is a second road from Zorn’s lemma to the axiom of choice: Zorn gives a well-order of ⋃i∈IAi, and the well-order gives the choice function by a rule. The axiom has not disappeared. It is hidden in the well-order, which for an arbitrary set only Zorn’s lemma (or the axiom) supplies; for a countable set an injection into N gives one by a rule (Exercise B2).

Quick check. With the well-order ⪯Z on Z of the Quick check “Find a well-order on Z”, which element does c pick from {n∈Z:n2>10}? From {n∈Z:n>10}?

Solution. The first set is {n∈Z:|n|≥4}, since 32=9 and 42=16. Its least |n| is 4, and −4 is in it, so c picks −4. In the second set the least |n| is 11, and −11 is not in it, so c picks 11.

6.3.5. What is proved where

The implications between the forms of choice met in this chapter, and where each is proved:

Implication Where
Zorn’s lemma ⇒ axiom of choice Theorem 6.3.1
Zorn’s lemma ⇒ every set can be well-ordered Theorem 6.3.4
every set can be well-ordered ⇒ axiom of choice Proposition 6.3.5
Zorn’s lemma ⇒ any two sets are comparable Theorem 6.3.2
axiom of choice ⇔ every surjection has a right inverse Theorem 6.1.2 and the paragraph after it (Section 6.1)
axiom of choice ⇒ Zorn’s lemma Axiomatic Set Theory, Chapter 4
comparability ⇒ every set can be well-ordered Axiomatic Set Theory, Chapter 4 (Hartogs)

Once the last two rows are proved, all five statements are equivalent. This book takes the axiom and Zorn’s lemma as given, uses whichever form fits the problem, and flags each use. Linear Algebra, Section 1.8 (Linear Algebra, Theorem 1.8.2) runs the template once more, with independent sets as partial objects, to extend every independent set to a basis.

The runs of the template in this chapter, side by side:

Object Partial objects Why unions of chains stay partial objects Why a maximal one is complete
choice function (Theorem 6.3.1) graphs defined on part of I (C1), (C2) mention at most two pairs a missed index can be added
representatives (Example (A set of representatives)) sets meeting each class at most once the condition mentions two elements a missed class can be added
injection (Theorem 6.3.2) partial matchings (M1), (M2) mention two pairs if both sides have an unpaired element, they can be paired
total order (Theorem 6.2.4) partial orders containing ⪯ (PO2), (PO3) mention two pairs an incomparable pair can be compared (Lemma 6.2.3)
well-order (Theorem 6.3.4) well-orders of subsets, ordered by ⊴ Lemma 6.2.1 (a) and (E1): the order axioms mention at most three elements; least elements survive because of (E2) a missed point goes on top

6.3.6. Exercises

A. Check your understanding

Exercise (A1)

These questions are about the proofs of this section.

  • (a) Where does the proof of Theorem 6.3.2 use (M1), and where (M2)?
  • (b) In that proof, if A=∅, what is M, and which case occurs?
  • (c) In the proof of Theorem 6.3.1, where is “Ai≠∅” used, and which step fails without it?
  • (d) In the proof of Theorem 6.3.4, which step uses (E2), and what is (M,RM) when X=∅?
  • (e) For X={1,2}, list the partial objects (A,R) of that proof, and the maximal ones.
  • (f) Why does the proof of Proposition 6.3.5 need no appeal to Axiom 6.1.1?

Solution.

  • (a) The chain step uses both, to show that the union of a chain lies in P. The step “M uses up a side” uses both for M, to see that M∪{(a0,b0)} still satisfies them. Case 1 uses (M1) to get a function A→B and (M2) for its injectivity; Case 2 uses (M2) to get a function B→A and (M1) for its injectivity.

  • (b) A×B=∅, so P={∅} and M=∅. Case 1 occurs: every element of ∅ occurs in M, vacuously, and M is the graph of the empty function ∅→B, which is injective. If also B=∅, Case 2 holds as well.

  • (c) In the last step: x0∈Ai0 exists only because Ai0≠∅. Without it, M could miss i0 and still be maximal, and indeed no choice function exists if some Ai is empty.

  • (d) The chain step, twice: for least elements of the union (an element of a later member is above m), and for the union being ⊴-above each member. It is also checked in the last step. For X=∅: P={(∅,∅)}, and (M,RM)=(∅,∅), the empty well-order.

  • (e) Five: (∅,∅); ({1},{(1,1)}); ({2},{(2,2)}); ({1,2},{(1,1),(2,2),(1,2)}) (1 before 2); ({1,2},{(1,1),(2,2),(2,1)}) (2 before 1). The last two are maximal.

  • (f) “The least element of Ai” is one description that names a value for every i, so c is defined by specification (Example (Method: name the choice)).

B. Practice

Exercise (B1: Surjections one way or the other)

Let A and B be non-empty sets. Prove that there is a surjection A→B or a surjection B→A.

Solution. By Theorem 6.3.2, |A|≤|B| or |B|≤|A|. In the first case, since A≠∅, Proposition 6.1.3 gives a surjection B→A. In the second, since B≠∅, the same proposition with the roles exchanged gives a surjection A→B.

Marking scheme. (10 points) - 3: comparability cited, with the two cases. - 4: in the first case, a surjection B→A from Proposition 6.1.3, with A≠∅ used and the direction correct. - 3: the second case, with the roles exchanged and B≠∅ used.

Exercise (B2: Well-orders without Zorn)
  • (a) Let j:X→Y be injective and let ⪯Y be a well-order on Y. Show that “x⪯x′ when j(x)⪯Yj(x′)” is a well-order on X.
  • (b) Deduce, without Zorn’s lemma or Axiom 6.1.1, that every countable set has a well-order.
  • (c) Deduce that Q has a well-order.

Solution.

  • (a) (PO1), (PO3) and totality for ⪯ come from those of ⪯Y, applied to the images. (PO2): x⪯x′ and x′⪯x give j(x)⪯Yj(x′)⪯Yj(x), so j(x)=j(x′), and x=x′ by injectivity. For ∅≠S⊆X, the image j(S) is a non-empty subset of Y and has a least element j(s0) with s0∈S; then j(s0)⪯Yj(s), that is s0⪯s, for every s∈S.

  • (b) A countable X has an injection X→N (Theorem 4.2.2, (i) ⇒ (ii), a rule), and (N,≤) is well-ordered (Theorem 3.1.3); apply (a). One injection is named by one ∃E. (This is the route of Section 6.2, Exercise C2 (b), where an injection into N picked representatives; here it picks a whole order.)

  • (c) Q is countable (Theorem 4.2.8), so (b) applies.

Exercise (B3: Right inverses from a well-order)

Let f:X→Y be surjective. Using Theorem 6.3.4, define a right inverse of f by a rule, and say which result of Section 6.1 you have proved again and where its use of choice has gone.

Solution. Well-order X by ⪯ (Theorem 6.3.4). For y∈Y, the preimage f−1({y}) (Definition 2.5.2) is non-empty, since f is onto, so it has a least element g(y), and only one (Proposition 5.3.1). So g:Y→X is defined by specification, and f(g(y))=y for every y∈Y. This is Theorem 6.1.2. The choice has moved into the well-order, which came from Theorem 6.2.2; Proposition 6.3.5 with I=Y and Ay=f−1({y}) is the same argument.

Exercise (B4: Prove or disprove)

Prove each true statement and refute each false one.

  • (a) Every total order on a finite set is a well-order.
  • (b) If ⪯ is a well-order on X and Y⊆X, then ⪯ restricted to Y is a well-order on Y.
  • (c) ≥ is a well-order on N.
  • (d) A well-ordered set with a greatest element is finite.
  • (e) In a well-ordered set, every non-empty subset has a greatest element.

Solution.

  • (a) True. A non-empty subset S is finite (Proposition 4.1.6); list it as x1,…,xn, n≥1. Let ⪯ be the total order. The reverse relation ⪰ is a partial order (it satisfies (PO1)–(PO3) because ⪯ does) and S is a chain for it, so Lemma 6.2.1 (a) gives an xk with xj⪰xk for all j: the least element. (On ∅ there is no non-empty subset, so the condition holds vacuously.)

  • (b) True. Restriction keeps (PO1)–(PO3) and totality, which are statements about all elements, and a non-empty subset of Y is a non-empty subset of X; its least element lies in it, hence in Y.

  • (c) False. N itself has no ≥-least element: that would be a greatest natural number g, but g+1>g.

  • (d) False. The order ⊑ of Example (A total order containing divisibility) (positive integers in the usual order, 0 on top) is a well-order on the infinite set N with greatest element 0: a non-empty S has as least element its least positive member if it has one (Theorem 3.1.3), and 0 if S={0}.

  • (e) False. N in (N,≤) has no greatest element.

C. Going deeper

Exercise (C1: Find the error)

Claim: any two sets are comparable. “Proof”: If A or B is empty, the empty function is an injection. Otherwise choose a0∈A and b0∈B and pair them. Choose a1∈A∖{a0} and b1∈B∖{b0}, and so on. When one set runs out, the pairs so far are an injection from it into the other.

Is the conclusion true? Does the argument prove it?

Solution. The conclusion is true: it is Theorem 6.3.2. The argument does not prove it. It fails at “and so on … when one set runs out”, the gap that (N13) of Logic and Proof, Example (What is not allowed) flags: an “and so on” needs its step, and here the process has no last step in general. Indexed by N, it uses a countable set of elements of each side (Proposition 4.2.4), and for A=B=R neither side runs out, since R is uncountable (Theorem 4.3.4). That is a counterexample to the step “the process ends”. The argument also makes infinitely many choices with no rule (Section 6.1). The repair is the proof by the template, in which “cannot be continued” replaces “runs out”.

Marking scheme. (10 points) - 2: the conclusion is true, with a citation. - 3: the failing line (“and so on … runs out”) identified, with the reason that it has no step. - 2: a case where no step exhausts a side (for example any infinite A, B). - 1: why even the whole N-indexed process cannot exhaust R (countability). - 2: the repair by the maximality template.

Exercise (C2: Maximal chains give Zorn’s lemma)
  • (a) Let C be a maximal chain of a partially ordered set (X,⪯): a chain contained properly in no chain. Let u be an upper bound of C in X. Show that u∈C, that u is the greatest element of C, and that u is a maximal element of X.
  • (b) Deduce Theorem 6.2.2 from the statement that every chain lies in a maximal chain.

Solution.

  • (a) Every element of C is below u, so C∪{u} is a chain containing C; by maximality it is not larger, so u∈C. Then u∈C is above every element of C: it is the greatest element of C. Suppose u≺x for some x∈X. For every c∈C, c⪯u⪯x, so C∪{x} is a chain, and maximality gives x∈C. Then x⪯u, and with u⪯x, (PO2) gives x=u, contradicting u≺x. So u is maximal in X.

  • (b) Let P be a non-empty partially ordered set in which every non-empty chain has an upper bound. The empty set is a chain, so by the hypothesis (the statement of Section 6.2, Exercise B1, Exercise (B1: Maximal chains), applied with C0=∅), P has a maximal chain C. It is not empty: for p∈P, {p} is a chain properly containing ∅. So C has an upper bound u, and u is a maximal element of P by (a). Since Exercise B1 was proved from Zorn’s lemma, the two statements are equivalent.

Marking scheme. (10 points) - 1: u∈C in (a). - 1: u is the greatest element of C. - 3: u is maximal in X, using (PO2). - 2: a maximal chain C from the hypothesis (starting from ∅ or from {p}). - 1: C≠∅ (immediate if the chain was started from {p}). - 2: an upper bound of C, and the conclusion.

Exercise (C3: Exit check: initial segments)

Let (A,R) and (B,S) be partial objects of the proof of Theorem 6.3.4 (well-orders on subsets of X) with A⊆B. Prove that (A,R)⊴(B,S) if and only if

    • (i) R=S∩(A×A), and
    • (ii) whenever a∈A, b∈B and bSa, then b∈A.

Solution. (⇒) (i): R⊆S by (E1), and R⊆A×A; so R⊆S∩(A×A). Conversely, let (a,a′)∈S with a,a′∈A. R is total, so (a,a′)∈R or (a′,a)∈R. In the second case (a′,a)∈S, and (PO2) for S gives a=a′, so (a,a′)=(a,a)∈R by (PO1). (ii): if b∉A, then aSb by (E2), and with bSa, (PO2) gives b=a∈A, a contradiction.

(⇐) (E1): A⊆B is given, and R⊆S by (i). (E2): let a∈A and b∈B∖A. S is total, so aSb or bSa. The second gives b∈A by (ii), which is false. So aSb.

Marking scheme. (10 points) - 3: (i) in (⇒): 1 for R⊆S∩(A×A), 2 for the reverse inclusion by totality of R and antisymmetry of S. - 2: (ii) in (⇒), with (E2) and antisymmetry. - 1: (E1) in (⇐). - 4: (E2) in (⇐): 2 for comparing a and b (totality of S, or the least element of {a,b}), 2 for excluding bSa by (ii). - Fatal errors (0 for the part): proving only R⊆S∩(A×A) for (i); in (⇐), concluding aSb with no comparison of a and b at all.

R. Review

Exercise (R1)

Let D:={2,3,…,30}, partially ordered by divisibility. Find the maximal elements of D. Does D have a greatest element? A least element?

Solution. Divisibility is a partial order on N (Proposition 5.1.1), so on D. An element n∈D is maximal when no multiple kn with k≥2 lies in D (Definition 5.3.4), that is, when 2n>30: for n≤15, n∣2n∈D with 2n≠n, and for n≥16 every kn with k≥2 exceeds 30. So the maximal elements are 16,17,…,30.

There is no greatest element. A greatest element would be maximal (Proposition 5.3.2 (a)), so it would be one of 16,…,30, and every other maximal element would divide it; but 16∤17 and 17∤16.

There is no least element: it would divide 2 and 3, so it would be 1, and 1∉D.

Exercise (R2)

Let ⪯ be a well-order on X, with strict part ≺. Show that there is no function s:N→X with s(n+1)≺s(n) for every n∈N.

Solution. Suppose there were one. The image s(N) is non-empty, so it has a least element, of the form s(k) for some k∈N. But s(k+1)∈s(N) and s(k+1)≺s(k), against the minimality of s(k). The tool is the least-element argument of Example (No endless descent in the natural numbers), with the well-order of X in place of ≤ on N.

Exercise (R3)

Write the statement “(X,⪯) is well-ordered” with quantifiers, negate it into positive form, and use the negation to show that (Z,≤) is not well-ordered.

Solution. By Definition 5.3.6, well-ordered says that ⪯ is total and that the following least-element clause holds; the negation is therefore ⪯ not total, or the negated clause. The clause is ∀S(S⊆X∧S≠∅→∃m∈S∀s∈Sm⪯s). Its negation (Logic and Proof, Proposition 6.2.3, as in Logic and Proof, Example (Three negations from analysis)), the second alternative, is ∃S(S⊆X∧S≠∅∧∀m∈S∃s∈Ss≺m), where s≺m stands for “not m⪯s”, which for a total order means s⪯m and s≠m. For Z with ⪯ the usual ≤, take S:=Z: for each m∈Z, s:=m−1∈S has s<m. Since ≤ on Z is a total order, it is the least-element condition that fails.

Exercise (R4)

A function f:N→N is eventually zero if there is N∈N with f(n)=0 for every n≥N. Is the set of eventually zero functions countable?

Solution. Yes. The tool is a countable union of countable sets. For N∈N let ZN be the set of f:N→N with f(n)=0 for every n≥N; the set of eventually zero functions is Z:=⋃N∈NZN. Each ZN is countable:

  • Z0 has one element, the zero function, so it is countable.
  • For N=1, f↦f(0) is a bijection Z1→N: a function in Z1 is determined by its value at 0, and every value occurs.
  • For N≥2, f↦(f(0),…,f(N−1)) is a bijection ZN→N×⋯×N (N factors), by the same reasoning and the characteristic property of tuples; the product is countable by Corollary 4.2.7, and so is ZN (compose a surjection N→N×⋯×N with the inverse bijection, Proposition 4.2.4).

By Theorem 6.1.4, Z is countable. (That theorem uses Axiom 6.1.1; here it could be avoided, since each ZN comes with an explicit listing, but the question did not ask for that.)

Why the look-alike fails. A diagonal argument, as in Theorem 4.3.1, builds from a list f0,f1,… of eventually zero functions the function g(n):=fn(n)+1. It differs from every fn, but g(n)≥1 for every n, so g is not eventually zero: it is not in Z, and nothing is contradicted. A diagonal argument proves uncountability only when the diagonal object stays inside the set; this is the usual failure named in Example (Method: the diagonal).
