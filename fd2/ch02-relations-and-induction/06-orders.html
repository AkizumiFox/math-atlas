2.6  Partial Orders, Maximal and Greatest Elements

Section 2.5 studied the relations that behave like equality. This section studies the ones that behave like ≤: reflexive and transitive like an equivalence relation, but antisymmetric instead of symmetric, so that they have a direction. For numbers, “the largest element of a set” is clear. For sets under ⊆, or for natural numbers under divisibility, two elements can be incomparable, neither below the other, and “largest” splits into two different notions. We separate them, prove what links them, and then take a first look at least upper bounds. That is the vocabulary Analysis on the Real Line, Chapter 1 needs for the supremum.

2.6.1. Partial orders

Section 2.4 found three relations with the same three properties: ≤ on R, ⊆ on P(X) (Example (Eight relations, four properties)), and ∣ on N (Proposition 2.4.1). Each is reflexive, antisymmetric and transitive. Each says “below” in its own sense: smaller, contained in, a divisor of. What they share is what “being below” needs, and it deserves a name, so that a fact proved once holds for all three.

A partial order says which elements lie below which, without requiring every two to be comparable.

Definition 2.6.1 (Partial Order)

Let X be a set. A partial order on X is a relation ⪯ on X that is reflexive, antisymmetric and transitive on X (Definition 2.4.1):

  • (PO1) for every x∈X, x⪯x;
  • (PO2) for all x,y∈X, if x⪯y and y⪯x, then x=y;
  • (PO3) for all x,y,z∈X, if x⪯y and y⪯z, then x⪯z.

The pair (X,⪯) is a partially ordered set. Elements x,y∈X are comparable if x⪯y or y⪯x. The partial order is total if every two elements of X are comparable. The strict part of ⪯ is the relation ≺ on X given by x≺y⟺x⪯y  and  x≠y. We also write y⪰x for x⪯y.

In words: (PO1) everything is below itself. (PO2) is the clause that gives an order its direction: two elements below each other are the same element, so “below” cannot run both ways between different things. (PO3) lets “below” pass along a chain. “Total” adds that any two elements can be compared; “partial” is the word for not requiring it. The symbol ⪯ is a letter for an arbitrary partial order, chosen so that ≤ keeps its meaning on numbers.

The strict part is irreflexive and transitive. No x has x≺x, since that would need x≠x. If x≺y and y≺z, then x⪯z by (PO3); and x≠z, because x=z would give x⪯y and y⪯x, hence x=y by (PO2), contradicting x≠y. So x≺z.

Examples.

  • (R,≤) is a partially ordered set, and it is total: for real numbers x≤y or y≤x. Its strict part is <. The same holds for (N,≤) and (Z,≤), since restricting a total order to a subset keeps all four properties: each is a statement about all elements, and holds in particular for the elements of the subset.
  • (N,∣) is a partially ordered set by Proposition 2.4.1, and it is not total: 2∤3 and 3∤2, so 2 and 3 are incomparable.
  • (P(X),⊆) is a partially ordered set; the example after this list decides when it is total.
  • Degenerate cases: equality on any set X is a partial order, in which no two different elements are comparable; and the empty relation is a partial order on ∅, vacuously.

Non-examples by minimal change. Divisibility on Z is reflexive and transitive, but not antisymmetric: 2∣−2 and −2∣2, and 2≠−2 (Proposition 2.4.1). Passing from N to Z loses exactly (PO2). The relation < on R is antisymmetric (vacuously: x<y and y<x never both hold) and transitive, but not reflexive, since 0<0 fails. It is the strict part of ≤, not a partial order.

Why these clauses. Without (PO2), two different elements could each be below the other, and “the largest element” of a set could fail to be unique; the uniqueness proof in the next subsection uses (PO2) and nothing else. A relation that keeps (PO1) and (PO3) and drops (PO2) is often called a preorder; ∣ on Z is one. Totality is left out because the important examples, ⊆ and ∣, do not have it, and much of the interest lies in what changes without it.

Example (Inclusion is a partial order, rarely total)

Let X be a set. Show that ⊆ is a partial order on P(X), and that it is total if and only if X has at most one element.

Solution. A partial order. (PO1) A⊆A for every set A. (PO2) If A⊆B and B⊆A, then A=B by Proposition 1.1.1. (PO3) is Proposition 1.1.2. (These are the entries of Example (Eight relations, four properties).)

Total exactly when X has at most one element. Suppose X has two different elements a≠b. Then {a},{b}∈P(X), and {a}⊈{b}, since a∈{a} and a∉{b}; likewise {b}⊈{a}. So {a} and {b} are incomparable, and ⊆ is not total. For X={1,2}, the incomparable pair is {1}, {2}.

Conversely, suppose any two elements of X are equal. Let A⊆X. If A≠∅, take a∈A; then every x∈X equals a, so x∈A, and A=X. So every subset of X is ∅ or X. Any two of these are comparable, since ∅⊆X (Section 1.1, after Proposition 1.1.3) and each is a subset of itself. So ⊆ is total on P(X).

Warning. In a partial order, “x⪯y fails” does not give “y≺x”. In (P({1,2}),⊆), {1}⊈{2}, and {2}⊊{1} is false too: the two are incomparable. The habit from numbers, “not ≤ means >”, is the totality of ≤ on R, and it must not be carried into a partial order.

2.6.2. Bounds, greatest and maximal elements

From now on, (X,⪯) is a partially ordered set and A⊆X. The bounds come first, because both kinds of “largest” are measured against them.

Definition 2.6.2 (Upper and Lower Bounds)

An element u∈X is an upper bound of A if a⪯u for every a∈A, and a lower bound of A if u⪯a for every a∈A. The set A is bounded above if it has an upper bound in X, bounded below if it has a lower bound in X, and bounded if both.

An upper bound lives in X and need not belong to A: in (R,≤), 5 is an upper bound of [0,1]. Every element of X is an upper bound of ∅, vacuously. In (N,∣), an upper bound of {4,6} is a common multiple of 4 and 6, such as 12, 24 or 0.

Now the two notions of “largest”. The first is the familiar one: an element of the set that is above everything in the set. The second asks less: an element with nothing in the set strictly above it.

Definition 2.6.3 (Greatest and Least Elements)

An element g is a greatest element of A if g∈A and a⪯g for every a∈A. An element l is a least element of A if l∈A and l⪯a for every a∈A.

Definition 2.6.4 (Maximal and Minimal Elements)

An element m is a maximal element of A if m∈A and there is no a∈A with m≺a. An element m is a minimal element of A if m∈A and there is no a∈A with a≺m.

In words: a greatest element is an upper bound of A that belongs to A. A maximal element is one that cannot be beaten inside A, which is weaker: an element can be unbeaten simply because it is incomparable with its rivals. In symbols the difference is where the negation sits: g greatest:g∈A∧∀a∈A a⪯g,m maximal:m∈A∧¬∃a∈A m≺a. By Logic and Proof, Proposition 4.9.3 (b), ¬∃a∈A m≺a is ∀a∈A ¬(m≺a), and ¬(m≺a) says that m⪯a implies m=a. So “maximal” reads: everything in A that is above m is m. “Greatest” reads: everything in A is below g. The first only forbids elements above; the second demands that every element be compared.

For numbers the two coincide. In (R,≤), the set {1,4,9} has greatest element 9, its only maximal element, and least element 1. The interval [0,1) has least element 0 and neither a greatest nor a maximal element: for each a∈[0,1), the number (a+1)/2 lies in [0,1) and is strictly above a. A one-point set {x} has x as greatest, least, maximal and minimal element, and ∅ has none of the four, since each definition requires an element of A.

The first result explains the article in “the greatest element”.

Proposition 2.6.1 (Greatest and Least Elements Are Unique)

A subset A of a partially ordered set has at most one greatest element and at most one least element.

Proof. Let g and g′ be greatest elements of A. Since g′∈A and g is greatest, g′⪯g; since g∈A and g′ is greatest, g⪯g′. By (PO2), g=g′. For least elements the same argument applies with the inequalities reversed.

So we may speak of the greatest element and the least element of A when they exist. In (R,≤), the greatest element of a set is its maximum, maxA, and the least element its minimum, minA. This settles a point left open in Section 1.4: the least q0∈Z>0 with rq0∈Z in Example (Relations that are not functions) exists by Theorem 2.1.3: the set of such q lies in Z>0⊆N, and it is non-empty, since writing r=p/q with q∈Z>0 (as the solution of (b) there notes) gives rq=p∈Z. It is unique by the least-element half of the proposition, so the rule there names one value.

The second result compares the two notions.

Proposition 2.6.2 (Greatest and Maximal Elements)

Let (X,⪯) be a partially ordered set and A⊆X.

  • (a) A greatest element of A is a maximal element of A.
  • (b) If ⪯ is total, then a maximal element of A is a greatest element of A.

The same holds for least and minimal elements.

Idea. For (a), anything strictly above the greatest element would also be below it, and antisymmetry forbids that. For (b), a maximal element m must be compared with each a∈A, and totality says it can be: either a⪯m, as wanted, or m⪯a, and then maximality forces a=m.

Proof. (a) Let g be a greatest element of A. Then g∈A. Suppose some a∈A has g≺a, so g⪯a and g≠a. Since g is greatest, a⪯g. By (PO2), a=g, contradicting g≠a. So no such a exists, and g is maximal.

(b) Let ⪯ be total and m a maximal element of A, and let a∈A. By totality, a⪯m or m⪯a. Case 1: a⪯m. This is what we want. Case 2: m⪯a. If m≠a, then m≺a with a∈A, which maximality excludes. So m=a, and a⪯m by (PO1). In either case a⪯m. Since a∈A was arbitrary and m∈A, m is a greatest element.

For least and minimal elements, apply (a) and (b) to the partial order ⪰: its greatest and maximal elements are the least and minimal elements for ⪯, and it is total when ⪯ is. (That ⪰ satisfies (PO1)–(PO3), and is total when ⪯ is, comes from reading those clauses with the two variables exchanged. Its strict part is x≻y⟺y≺x, since x≠y is symmetric in x and y. So “no a∈A with m≻a” is “no a∈A with a≺m”, and “a⪰l for every a∈A” is “l⪯a for every a∈A”.)

Part (b) uses totality once, in the case split of its second sentence, and the case split is where it fails without it. The proof of Proposition 2.3.8 in Section 2.3 compares two elements at a time and keeps the larger. Its maximum half uses nothing about ≤ on R beyond reflexivity, transitivity and the comparability of any two elements, so it works word for word in any totally ordered set. The minimum half passes to −x1,…,−xn, which needs an ordered field; in a totally ordered set, apply the maximum half to the reverse order ⪰ instead, which is total by the last paragraph of the proof above. In particular the whole proposition holds in any ordered field, which is how Analysis on the Real Line, Chapter 1 reads it.

Without totality, (b) fails, and maximal elements need not be greatest.

Example (Maximal elements that are not greatest)

Find the maximal elements of each set, and decide whether it has a greatest element: (a) A={2,3,4,5,6} in (N,∣); (b) B={{1},{2}} in (P({1,2}),⊆).

Solution.

  • (a) Within A, the only strict divisibilities are 2∣4, 2∣6 and 3∣6. So 2≺4 and 3≺6, and 2, 3 are not maximal. Nothing in A is strictly above 4, 5 or 6: every element of A is positive, and a positive multiple kn of n∈{4,5,6} other than n has k>0 and k≠1, so k≥2 (Proposition 2.1.2 (c)), and then kn≥2n≥8, while every element of A is at most 6. So the maximal elements are 4, 5 and 6.

    There is no greatest element. By Proposition 2.6.2 (a), a greatest element would be maximal, so it would be 4, 5 or 6. But 5∤4, 4∤5 and 4∤6, so none of the three is above every element of A.

  • (b) {1} and {2} are incomparable (Example (Inclusion is a partial order, rarely total)), so neither is strictly above the other: both are maximal. Neither is greatest, since neither contains the other.

In (a), the minimal elements are 2, 3 and 5, and there is no least element either. The example is the minimal change from {1,2,3,4,5,6}, which has the least element 1 and still no greatest.

Warning. “Maximal” is not “greatest”. A set can have many maximal elements and no greatest, as in Example (Maximal elements that are not greatest); and a set can have no maximal element at all: N under ≤, where n+1∈N (by (NS)) is strictly above n. The answer also depends on the order, not just on the set: under divisibility, N has a greatest element, 0, since every a∈N divides 0=0⋅a.

Quick check. In P({1,2,3})∖{{1,2,3}}, ordered by ⊆, name the maximal elements. Is there a greatest element?

Solution. The maximal elements are the three two-element sets {1,2}, {1,3}, {2,3}: the only subset of {1,2,3} strictly containing a two-element set is {1,2,3}, which was removed, and every set with at most one element lies strictly inside some two-element set. There is no greatest element: it would be maximal (Proposition 2.6.2 (a)), hence a two-element set, and no two-element set contains the other two.

2.6.3. Least upper bounds, a first look

Here is the notion that the rest of the book is built on. When a set has no greatest element, its upper bounds may still have a least one, and that element plays the part of “the top of the set” from outside.

The supremum is the best upper bound: the least element of the set of upper bounds.

Definition 2.6.5 (Supremum and Infimum)

Let (X,⪯) be a partially ordered set and A⊆X. An element s∈X is a least upper bound, or supremum, of A in X if

  • (S1) s is an upper bound of A, and
  • (S2) s⪯u for every upper bound u of A.

An element i∈X is a greatest lower bound, or infimum, of A in X if i is a lower bound of A and u⪯i for every lower bound u of A.

In other words, a supremum of A is a least element of the set of upper bounds of A, and an infimum a greatest element of the set of lower bounds. By Proposition 2.6.1, applied to those sets, each is unique when it exists, and we write supA and infA. The words “in X” matter: the upper bounds are taken in X, and enlarging or shrinking X can create or destroy a supremum. The definition also carries no promise that supA exists, or that it belongs to A.

Two quick consequences. If A has a greatest element g, then g=supA: g is an upper bound, and every upper bound u has g⪯u because g∈A. And a supremum that belongs to A is a greatest element of A, by (S1). So a supremum is a greatest element exactly when it lies in the set; the new cases are the ones where it lies outside.

Suprema of sets. In (P(X),⊆), let A,B⊆X. Then sup{A,B}=A∪B. (S1): A⊆A∪B and B⊆A∪B, and A∪B∈P(X). (S2): let C∈P(X) be an upper bound, so A⊆C and B⊆C; every element of A∪B lies in A or in B, hence in C, so A∪B⊆C. The supremum A∪B belongs to {A,B} only when one of the two sets contains the other; for {{1},{2}} it is {1,2}, which is not in the set. Exercise B1 extends this to every family of subsets, and adds the infimum.

Suprema under divisibility. In (N,∣), an upper bound of {a,b} is a common multiple of a and b. The least upper bound turns out to be the least common multiple, and proving that it is least in the divisibility order, not merely the smallest number, is a job for the division algorithm.

Example (The supremum under divisibility is the least common multiple)

Let a,b∈N. Find sup{a,b} in (N,∣). Deduce that an integer divisible by 2 and by 3 is divisible by 6.

Solution. Case a,b∈Z>0. Let M:={m∈Z>0:a∣m and b∣m}, the positive common multiples. It is non-empty: ab∈N by Lemma 2.1.1 (b), ab>0 as a product of positive numbers, so ab∈Z>0 (Proposition 2.1.2 (b)), and ab=b⋅a=a⋅b is a multiple of both. Since M⊆Z>0⊆N, M has a least element L (Theorem 2.1.3), the least common multiple of a and b.

We show that L divides every integer common multiple c of a and b. By Theorem 2.2.3, c=qL+r with q,r∈Z and 0≤r<L. Write c=as, L=at with s,t∈Z; then r=c−qL=a(s−qt) with s−qt∈Z (Proposition 2.1.2 (a)), so a∣r, and in the same way b∣r. If r>0, then r∈Z>0 (Proposition 2.1.2 (b)), so r∈M and r<L, contradicting the choice of L. Hence r=0, and c=qL: L∣c. The argument never used c≥0.

Now L=sup{a,b}. (S1): a∣L and b∣L, since L∈M. (S2): an upper bound c∈N of {a,b} is a common multiple, so L∣c by the previous paragraph.

Case a=0 or b=0. Say a=0. An upper bound c has 0∣c, that is, c=k⋅0=0 for some k∈Z. And 0 is an upper bound, since n∣0=0⋅n for every n∈N. So 0 is the only upper bound, and sup{a,b}=0, the greatest element of (N,∣).

The instance. For a=2, b=3: 6∈M, and none of 1,2,3,4,5 is a multiple of both 2 and 3 (1,3,5 are odd, and 2,4 lie strictly between consecutive multiples of 3). So L=6, and every integer n with 2∣n and 3∣n has 6∣n, by the second paragraph with c=n.

The instance proves the fact that Section 1.2 used as a school fact: an integer divisible by 2 and by 3 is divisible by 6. It also shows the two orders on N disagreeing: sup{4,6} is 12 under divisibility and 6 under ≤.

A supremum that does not exist. In (Q,≤), the set {x∈Q:x>0, x2<2} is non-empty and bounded above (by 2, for instance: a rational x>2 has x2>4). It has no least upper bound in Q. We do not prove this here. Analysis on the Real Line, Chapter 1 proves it, and then takes the existence of suprema in R as its axiom: the supremum of Analysis on the Real Line, Chapter 1, defined in an ordered field, is Definition 2.6.5 for the order ≤ of that field; Analysis on the Real Line, Chapter 1 uses it in Q and in R. The ambient set decides: the same set has a supremum in (R,≤), namely 2.

2.6.4. Well-ordered sets

Section 2.1 proved that every non-empty subset of N has a least element (Theorem 2.1.3). In the language of this section, that is a property of the partially ordered set (N,≤), and it has a name.

Definition 2.6.6 (Well-Ordered Set)

A partially ordered set (X,⪯) is well-ordered, and ⪯ is a well-order on X, if ⪯ is total and every non-empty subset of X has a least element.

(N,≤) is well-ordered: ≤ is total, and Theorem 2.1.3 supplies the least elements. (Z,≤) is not: Z itself has no least element, since for every n∈Z also n−1∈Z (Proposition 2.1.2 (a)) and n−1<n. Nor is the set of positive rationals, which has no least element (q/2<q). The word “non-empty” is needed because ∅ has no least element in any order. Totality is in fact automatic: any two elements x,y form a non-empty set {x,y}, whose least element is below the other one. Upper bounds work too: in (N,≤) a non-empty set bounded above has a greatest element (Corollary 2.1.5). Exercise C1 gives a well-ordered set that does not look like N.

Remark. In a general partially ordered set, one may ask: if every chain (a subset on which ⪯ is total) has an upper bound, must there be a maximal element? For a non-empty partially ordered set the answer “yes” is Zorn’s lemma, and it cannot be proved from what we have: it is equivalent to the axiom of choice, which Chapter 3 states. A later chapter of this volume states Zorn’s lemma, and Axiomatic Set Theory proves it equivalent to the axiom of choice, together with the other equivalents, among them the claim that every set has a well-order.

2.6.5. Exercises

A. Check your understanding

Exercise (A1)
  • (a) Let (X,⪯) be a partially ordered set and A⊆X. Write “g is a greatest element of A” and “m is a maximal element of A” in symbols, and negate each.
  • (b) True or false, with a witness: every finite non-empty subset of a partially ordered set has a greatest element.
  • (c) Find sup{4,6} in (N,∣) and in (N,≤).
  • (d) On N×N, the lexicographic order is (a,b)⪯(c,d) if a<c, or a=c and b≤d. Given that it is a partial order, is it total?

Solution.

  • (a) g greatest: g∈A∧∀a∈A a⪯g. Its negation, by Logic and Proof, Proposition 2.5.5 and Logic and Proof, Proposition 4.9.3 (a): g∉A∨∃a∈A ¬(a⪯g).

    m maximal: m∈A∧¬∃a∈A m≺a. Its negation: m∉A∨∃a∈A m≺a, by Logic and Proof, Proposition 2.5.5 and Logic and Proof, Proposition 2.5.1. In words: g fails to be greatest if some element of A is not below it; m fails to be maximal if some element of A is strictly above it. The first failure can happen through incomparability; the second cannot.

  • (b) False. In (P({1,2}),⊆), the set {{1},{2}} is finite and non-empty and has no greatest element (Example (Maximal elements that are not greatest) (b)). What is true is that it has a maximal element: listed as {x1,…,xn}, which is what “finite” will mean in Chapter 3, it has one by Exercise R4.

  • (c) Under divisibility, sup{4,6}=12, the least common multiple (Example (The supremum under divisibility is the least common multiple)): 12 is a common multiple, and none of 1,…,11 is (the multiples of 6 below 12 are 6, and 4∤6). Under ≤, sup{4,6}=6, the greatest element.

  • (d) Yes. Let (a,b),(c,d)∈N×N. If a<c, then (a,b)⪯(c,d); if c<a, then (c,d)⪯(a,b); if a=c, then b≤d or d≤b, by totality of ≤, and the pairs are comparable. By trichotomy these cases cover everything.

B. Practice

Exercise (B1: Suprema of families of sets)

Let X be a set and (Ai)i∈I a family of subsets of X. In (P(X),⊆), prove that the set {Ai:i∈I} has supremum ⋃i∈IAi and infimum ⋂i∈IAi, the intersection taken in X. What are they when I=∅?

Solution. Write U:=⋃i∈IAi and N:=⋂i∈IAi (Definition 1.2.4). Both are subsets of X, so they lie in P(X).

Supremum. (S1) For each i∈I, every element of Ai lies in U, so Ai⊆U. (S2) Let C∈P(X) be an upper bound: Ai⊆C for every i∈I. Let x∈U. Then x∈Ai for some i∈I; name it i. Since Ai⊆C, x∈C. So U⊆C.

Infimum. N is a lower bound: for each i∈I, every x∈N lies in Ai, so N⊆Ai. Let D∈P(X) be a lower bound: D⊆Ai for every i. Let x∈D. Then x∈X, and x∈Ai for every i∈I, so x∈N. Hence D⊆N.

Empty index set. If I=∅, then U=∅ and N=X, since an intersection in X of no sets is X. This agrees with the definitions: every element of P(X) is an upper bound of the empty set, and the least of them is ∅; every element is a lower bound, and the greatest is X. The arguments above cover this case, since their “for every i” clauses hold vacuously.

Exercise (B2: Two maximal elements and a least one)

Give an example of a partially ordered set that has exactly two maximal elements and a least element, and check each property. Then list the properties that every answer must have.

Solution. An example. X={∅,{1},{2}} ordered by ⊆. It is a partial order, as a subset of (P({1,2}),⊆). The least element is ∅, since ∅⊆A for every A∈X (Section 1.1, after Proposition 1.1.3). The maximal elements are {1} and {2}: neither is strictly contained in an element of X. And ∅ is not maximal, since ∅⊊{1}. So there are exactly two. Another answer: {1,2,3} under divisibility, with least element 1 and maximal elements 2, 3.

What every answer must have. Let l be the least element and m1≠m2 the maximal elements.

  • m1 and m2 are incomparable: if m1⪯m2, then m1≺m2, since m1≠m2, and m1 would not be maximal; symmetrically for m2⪯m1.
  • So the order is not total, and there is no greatest element: a greatest element g would have m1⪯g, and maximality of m1 gives m1=g; likewise m2=g, contradicting m1≠m2.
  • l, m1, m2 are three different elements: if l=m1, then m1=l⪯m2, which the first point excludes; likewise l≠m2.

So an answer has at least three elements and two incomparable maximal ones above a common least element. A candidate failing any of these is not an answer.

Exercise (B3: Minimal is least in a total order)

Let (X,⪯) be a totally ordered set and A⊆X. Prove that a minimal element of A is a least element of A, by applying Proposition 2.6.2 (b) to the reverse order ⪰. Check each fact about ⪰ that you use.

Solution. The reverse order. ⪰ is the relation x⪰y⟺y⪯x. (PO1): x⪯x, so x⪰x. (PO2): if x⪰y and y⪰x, then y⪯x and x⪯y, so x=y. (PO3): if x⪰y and y⪰z, then z⪯y and y⪯x, so z⪯x, that is, x⪰z. Totality: for x,y∈X, x⪯y or y⪯x, that is, y⪰x or x⪰y. Its strict part is x≻y⟺y≺x, since x≠y is symmetric in x,y.

Translating. In the order ⪰, “x lies below y” is written x⪰y, and “strictly below” is x≻y. Now m is minimal for ⪯: m∈A and no a∈A has a≺m, that is, no a∈A has m≻a. That is exactly “m is maximal for ⪰”. Likewise “l is greatest for ⪰” says l∈A and a⪰l for every a∈A, that is, l⪯a for every a∈A: “l is least for ⪯”.

Conclusion. Let m be minimal in A for ⪯. Then m is maximal in A for the total order ⪰, so it is greatest for ⪰ by Proposition 2.6.2 (b), hence least for ⪯.

C. Going deeper

Exercise (C1: A well-order that is not like N)

Let ⪯ be the lexicographic order on N×N of Exercise A1 (d).

  • (a) Prove that ⪯ is a partial order.
  • (b) Prove that (N×N,⪯) is well-ordered.
  • (c) Show that (1,n)≺(2,1) for every n∈N, and that these elements (1,n) are pairwise different. In (N,≤), which elements lie strictly below a given k∈N?

Solution.

  • (a) (PO1) a=a and b≤b, so (a,b)⪯(a,b). (PO2) Let (a,b)⪯(c,d) and (c,d)⪯(a,b). If a<c, the second relation needs c<a or c=a, both impossible; likewise c<a is impossible. So a=c by trichotomy, and then b≤d and d≤b give b=d. (PO3) Let (a,b)⪯(c,d)⪯(e,f). If a<c or c<e, then a<e, since in each case the other comparison is ≤; so (a,b)⪯(e,f). Otherwise a=c=e and b≤d≤f, so again (a,b)⪯(e,f).

  • (b) Totality is A1 (d). Let S⊆N×N be non-empty. The set F:={a∈N:(a,b)∈S for some b∈N} of first coordinates is non-empty, so it has a least element a0 (Theorem 2.1.3). The set G:={b∈N:(a0,b)∈S} is non-empty, since a0∈F, so it has a least element b0. Then (a0,b0)∈S. Let (a,b)∈S. Then a∈F, so a0≤a. If a0<a, then (a0,b0)⪯(a,b). If a0=a, then b∈G, so b0≤b, and again (a0,b0)⪯(a,b). So (a0,b0) is the least element of S.

  • (c) For n∈N, 1<2 gives (1,n)⪯(2,1), and (1,n)≠(2,1) since 1≠2; so (1,n)≺(2,1). For n≠n′, (1,n)≠(1,n′) by the characteristic property of pairs. So one element, (2,1), has an element (1,n) strictly below it for each of the natural numbers n, all different. In (N,≤), the elements strictly below k are exactly 0,1,…,k−1 (none when k=0), by Lemma 2.1.1 (a) and (e): they form a list ending at k−1. So a well-ordered set need not look like N: here one element has a strictly smaller element for every natural number.

Exercise (C2: Infima and suprema under divisibility)

Work in (N,∣). Let a,b∈N, not both 0, and let d be the least element of D:={ka+lb:k,l∈Z}∩Z>0.

  • (a) Explain why d exists.
  • (b) Prove that d∣a and d∣b.
  • (c) Prove that every common divisor c∈N of a and b divides d, and conclude that d=inf{a,b}.
  • (d) Decide whether every non-empty subset of N has a supremum in (N,∣). Then decide the same question for (Z>0,∣).

Solution (Hint 1). For (b), apply the division algorithm to a and d.

Solution (Hint 2). Write a=qd+r with 0≤r<d, and write d=k0a+l0b.

Solution.

  • (a) D⊆Z>0⊆N. It is non-empty: if a≠0, then a=1⋅a+0⋅b and a∈Z>0, so a∈D; otherwise b≠0 and b∈D likewise. So D has a least element by Theorem 2.1.3, unique by Proposition 2.6.1.

  • (b) Write d=k0a+l0b with k0,l0∈Z. Since d∈Z>0, Theorem 2.2.3 gives a=qd+r with q,r∈Z and 0≤r<d. Then r=a−qd=(1−qk0)a+(−ql0)b, with integer coefficients (Proposition 2.1.2 (a)). If r>0, then r∈Z>0, so r∈D and r<d, contradicting the choice of d. Hence r=0, and a=qd: d∣a. The same argument with b in place of a gives d∣b.

  • (c) Let c∈N with c∣a and c∣b: a=cs, b=ct with s,t∈Z. Then d=k0cs+l0ct=c(k0s+l0t), so c∣d. In (N,∣), the lower bounds of {a,b} are the common divisors in N. By (b), d is one; by (c), every lower bound c has c∣d. So d is the greatest lower bound: d=inf{a,b}.

  • (d) In (N,∣): yes. Let T⊆N be non-empty. An upper bound of T is a common multiple c∈N of all elements of T, and 0 is one, since t∣0=0⋅t for every t.

Case 1: T has a positive common multiple. The positive common multiples form a non-empty subset of N, so they have a least element L (Theorem 2.1.3). It is an upper bound. Let c∈N be any upper bound. By Theorem 2.2.3, c=qL+r with 0≤r<L. For each t∈T, t∣c and t∣L, so t∣r=c−qL (as in Example (The supremum under divisibility is the least common multiple)). If r>0, then r is a positive common multiple smaller than L, which is impossible. So r=0 and L∣c. Hence supT=L. This is the argument of Example (The supremum under divisibility is the least common multiple), which never used that the set had two elements.

Case 2: T has no positive common multiple. Then 0 is its only upper bound, and supT=0, the least element of {0}. This case includes every T containing 0, since 0∣c forces c=0.

In (Z>0,∣): no. (It is a partial order, as the restriction of one.) Take T=Z>0. An upper bound would be some c∈Z>0 with t∣c for every t∈Z>0, in particular (c+1)∣c: c=k(c+1) with k∈Z. Since c>0 and c+1>0, k>0 (if k≤0, then k(c+1)≤0), so k≥1 (Proposition 2.1.2 (b)), and c=k(c+1)≥c+1, which is impossible. So T has no upper bound in Z>0, and no supremum. Removing 0 removed the element that bounded everything.

Marking scheme. (10 points)

  • 1: (a) D is non-empty (exhibits a or b in it) and D⊆N, so well-ordering applies.
  • 3: (b) the division algorithm with divisor d≥1; the remainder is again of the form ka+lb; minimality of d forces r=0.
  • 2: (c) a common divisor divides d, and the conclusion d=inf{a,b} checks both clauses of an infimum.
  • 3: (d) for N: 0 is always an upper bound; with a positive common multiple, the least one divides every upper bound (division algorithm again); without one, the supremum is 0.
  • 1: (d) for Z>0: a set with no upper bound, with proof.

Fatal errors (0 for the step): concluding d∣a from d≤a; in (d), taking the numerically smallest upper bound and not checking that it divides every upper bound; treating inf as the minimum under ≤.

Exercise (R1)

Let f:R→R, f(x)=x2+4x. Compute f([−3,1]) and f−1([−3,0]). Then compute f(R), and check that f(f−1([−5,0]))=[−5,0]∩f(R) by computing both sides.

Solution. Complete the square: f(x)=(x+2)2−4. We use, as school facts, that squares are non-negative and that every y≥0 has a square root y≥0, and, by Logic and Proof, Theorem 2.4.4, that for s,t≥0, s≤t exactly when s2≤t2.

f([−3,1])=[−4,5]. (⊆) If −3≤x≤1, then −1≤x+2≤3, so |x+2|≤3, 0≤(x+2)2≤9, and −4≤f(x)≤5. (⊇) For −4≤y≤5, take x:=−2+y+4. Then 0≤y+4≤3, so x∈[−2,1]⊆[−3,1], and f(x)=(y+4)−4=y.

f−1([−3,0])=[−4,−3]∪[−1,0]. For x∈R: −3≤f(x)≤0⟺1≤(x+2)2≤4⟺1≤|x+2|≤2, and splitting by the sign of x+2, this holds exactly when x+2∈[−2,−1]∪[1,2], that is, x∈[−4,−3]∪[−1,0].

f(R)=[−4,∞), by the argument for f([−3,1]): f(x)≥−4 always, and y≥−4 is f(−2+y+4).

The check. f−1([−5,0])={x:(x+2)2≤4}=[−4,0], since (x+2)2−4≥−4>−5 always. Then f([−4,0])=[−4,0], by the first computation’s method (x+2∈[−2,2], so (x+2)2∈[0,4], and each value is attained). On the other side, [−5,0]∩[−4,∞)=[−4,0]. Both sides are [−4,0], as Proposition 1.6.5 (b) predicts: the round trip removes exactly the part [−5,−4) of [−5,0] that f never reaches.

Exercise (R2)

Write in symbols, with bounded quantifiers, the statement “every element of A has an element of A strictly above it”, for a set A⊆R ordered by ≤. Write its negation with no ¬ in front of a quantifier, and decide which of the two holds for A=N and for A={1,…,5}.

Solution. The statement is ∀a∈A ∃b∈A a<b. By Logic and Proof, Proposition 4.9.3 (a) and then (b), its negation is ∃a∈A ∀b∈A ¬(a<b), and since ≤ is total on R, ¬(a<b) is b≤a: the negation is ∃a∈A ∀b∈A b≤a, “A has a greatest element”. Passing the ¬ through the quantifiers turns each ∀ into ∃ and each ∃ into ∀, and leaves the bounds a∈A, b∈A untouched; negating the bound instead is entry (N11) of Logic and Proof, Example (What is not allowed).

For A=N the statement holds: for a∈N, b:=a+1∈N by (NS), and a<a+1. For A={1,…,5} the negation holds, with a=5: every b∈A has b≤5.

Exercise (R3)

Call a formula biconditional if it is built from atoms using ↔ alone: each atom is biconditional, and if φ and ψ are biconditional, so is (φ↔ψ); nothing else is. Prove that every biconditional formula is true under the valuation that makes every atom true.

Solution. Let vT be the all-T valuation. We use Logic and Proof, Theorem 3.2.3 with the property P(φ): if φ is biconditional, then vT(φ)=T. The formulas ⊥, ¬φ and (φ∘ψ) with ∘ one of ∧,∨,→ are not biconditional, so P holds for them vacuously, and the corresponding clauses of the theorem need nothing more.

  • (i) For an atom p, vT(p)=T by the choice of vT.

  • (ii) for ∘=↔: suppose P(φ) and P(ψ), and that (φ↔ψ) is biconditional. Then φ and ψ are biconditional: by unique readability (Logic and Proof, Theorem 3.2.5), they are the only immediate parts, and a biconditional formula that is not an atom is built by the second clause from biconditional parts. So vT(φ)=T=vT(ψ), and by (V6) of Logic and Proof, Definition 3.3.2, vT(φ↔ψ)=T, since the two parts have the same value.

This covers every clause, and proves the claim. In particular no biconditional formula is equivalent to ¬p, which is false under vT: negation cannot be expressed with ↔ alone.

Exercise (R4)

Let (X,⪯) be a partially ordered set, let n≥1 be an integer, and let x1,…,xn∈X. Show that the set {x1,…,xn} has a maximal element.

Solution. The tool is induction from base 1 (Theorem 2.2.1 with n0=1), in the shape of Proposition 2.3.8: add one element at a time and keep track of a maximal element. Let P(n) say: for all x1,…,xn∈X, the set {x1,…,xn} has a maximal element.

Base. {x1}: no element a of it has x1≺a, since the only candidate is x1 and x1≺x1 never holds. So x1 is maximal.

Step. Let n≥1, assume P(n), and let x1,…,xn+1∈X. Put A:={x1,…,xn} and A′:={x1,…,xn+1}, where, as in Section 2.3, {x1,…,xn}:={xk:k∈{1,…,n}}, now for elements of X. Since {1,…,n+1}={1,…,n}∪{n+1} (Lemma 2.1.1 (e), as in the proof of Proposition 2.3.8), A′=A∪{xn+1}. By P(n), A has a maximal element m.

Case 1: m≺xn+1 fails. Then m is maximal in A′: m∈A′; no a∈A has m≺a, by maximality in A; and a=xn+1 is excluded by the case.

Case 2: m≺xn+1. Then xn+1 is maximal in A′. Suppose xn+1≺a with a∈A′. Then a≠xn+1, so a∈A; and m≺xn+1≺a gives m≺a, since the strict part of a partial order is transitive. This contradicts the maximality of m in A.

In either case A′ has a maximal element, so P(n+1) holds, and Theorem 2.2.1 gives P(n) for every n≥1.

The look-alikes. “Take the greatest element” fails, because a finite set need not have one (Example (Maximal elements that are not greatest)). “Take the largest, as in Proposition 2.3.8” fails for the same reason: that proof keeps the larger of M and xn+1, which needs the two to be comparable; here Case 1 covers incomparable elements by keeping m. “Take xn, the last one” confuses the order of the list with the order ⪯: nothing makes xn large.
