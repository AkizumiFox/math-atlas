3.6  Infinite Sets

Section 3.5 compared sizes with injections. Here we ask where N sits in that comparison. Every infinite set we have met contains a copy of N, and it is tempting to say that this must always happen by picking new elements one at a time; this section makes that picking exact. It turns out to need Axiom 3.3.1 again, this time applied to a family with one set for each non-empty subset of the given set, and it gives two results: N is the smallest infinite size, and a set is infinite exactly when it is the same size as a proper part of itself.

3.6.1. Every infinite set contains a copy of the natural numbers

The question has a goal theorem: we want to show that an infinite set X has a countably infinite subset, that is, a subset equinumerous with N (Definition 3.2.2). Equivalently, we want an injection N→X: its image is then such a subset.

Theorem 3.6.1 (Infinite Sets Contain a Countably Infinite Subset)

Every infinite set X has a countably infinite subset. Equivalently, there is an injection N→X.

Idea. The natural attempt picks x0∈X, then x1∈X∖{x0}, then x2∈X∖{x0,x1}, and so on. Each pick is possible, because a finite set cannot exhaust the infinite X, and each single pick is one ∃E. But “and so on” is a definition by recursion, and Theorem 2.3.1 needs a function g that says, once and for all, which new element to take after any finite stage. That function must pick an element from every non-empty set of the form X∖F at once, with no rule for doing so when X is arbitrary. So we let Axiom 3.3.1 supply a choice function c on all non-empty subsets of X first, and then the recursion is an ordinary one, with c as its rule.

Proof. Let X be infinite. The family (S)S∈P(X)∖{∅}, indexed by the non-empty subsets of X with each index as its own member, consists of non-empty sets, and its union is X: every index is a subset of X, and each x∈X lies in the index {x}. By Axiom 3.3.1 there is a function c:P(X)∖{∅}→X with c(S)∈Sfor every non-empty S⊆X. This is the one line of the proof that uses the axiom.

Define g:N×P(X)→P(X) by g(n,F):=F∪{c(X∖F)} if F≠X, and g(n,F):=F if F=X. In the first case X∖F is non-empty, so c(X∖F) is defined; so g is a function. By Theorem 2.3.1, applied with the set P(X), the starting value ∅ and this g, there are sets Fn⊆X, for n∈N, with F0=∅ and Fn+1=g(n,Fn).

We show by induction (Logic and Proof, Axiom 4.2.1) that Fn has exactly n elements, for every n∈N. For n=0, F0=∅ has 0 elements (Definition 3.1.2). Suppose Fn has n elements. Then Fn is finite and X is not, so Fn≠X, and Fn+1=Fn∪{c(X∖Fn)} with c(X∖Fn)∈X∖Fn. This is a union of disjoint sets with n elements and 1 element, so Fn+1 has n+1 elements by Proposition 3.1.5.

In particular Fn≠X for every n∈N, so we may define xn:=c(X∖Fn)∈X∖Fn,and thenFn+1=Fn∪{xn}. Hence Fn⊆Fn+1 for every n, and by induction on k, Fm⊆Fm+k for all m,k∈N.

Now let m,n∈N with m<n. Then xm∈Fm+1⊆Fn, because m+1≤n (Lemma 2.1.1 (e)), so k:=n−(m+1)∈N (Lemma 2.1.1 (d)) and Fm+1⊆F(m+1)+k=Fn; and xn∉Fn. So xm≠xn. Hence n↦xn is an injection N→X. Its image {xn:n∈N}⊆X is equinumerous with N, since n↦xn is a bijection from N onto it. This proves the theorem.

The proof shows where the axiom enters and why one ∃E per step is not enough: ∃E names one element for one set, while the recursion needs g as a single function defined on every stage at once. Each Fn is then determined by c; the only arbitrary thing is c itself.

A non-example by a minimal change. Run the same construction on the finite set X={a,b}, with a≠b. The choice function c and the recursion still make sense, since g is defined on every F⊆X. But F1={c(X)} has one element, F2 adds the other, so F2=X, and from then on g leaves Fn unchanged. So x2=c(X∖F2)=c(∅) is not defined. The step that fails is “Fn is finite and X is not, so Fn≠X”, exactly where the hypothesis that X is infinite is used.

Remark. Compare Analysis on the Real Line, Chapter 1’s proof that the real numbers cannot be listed. There, a given list is used to build nested closed intervals, and each interval is obtained from the previous one by an explicit rule (keep an outer third that misses the next point of the list), so no choice principle is involved. Here X is an arbitrary infinite set, and there is no rule available for picking an element of an arbitrary non-empty subset of it; the choice function is the rule.

For a particular X a rule may exist: for X⊆N, “the least element” is one (Theorem 2.1.3), and then the proof needs no axiom. That the theorem cannot be proved in general from the other rules of set formation alone is a result of set theory; we state it without proof, and nothing depends on it.

3.6.2. Consequences: the smallest infinite size

The theorem says |N|≤|X| for every infinite X (Definition 3.5.1). Three consequences follow at once.

  • N is the smallest infinite size. If X is infinite and |X|≤|N|, then |X|=|N|, by Theorem 3.5.3 and the theorem. So no infinite set is strictly smaller than N.
  • Countable sets are exactly the sets of size at most |N|, by Theorem 3.2.2, (i) ⟺ (ii). Combining with the first point: a countable set is finite or equinumerous with N, which Theorem 3.2.2 (iii) already said.
  • An uncountable set is strictly bigger than N. If X is uncountable, then X is infinite (a finite set is countable, by Theorem 3.2.2), so |N|≤|X|; and |N|=|X| would make X countable. So |N|<|X|. For example |N|<|R|, since R is uncountable (Theorem 3.4.4).

Warning. “Infinite” and “uncountable” are different words. Q is infinite (it contains N, which is infinite by Example (Hilbert’s Hotel), and a subset of a finite set is finite, by Proposition 3.1.6) and countable (Theorem 3.2.8). Likewise “X contains a copy of N” is not “X is equinumerous with N”: R contains N, and |N|<|R| (as above).

Quick check. Let X be uncountable. Is X∖{x} uncountable for every x∈X? Why must X have an element at all?

Solution. X≠∅, because ∅ is countable by Definition 3.2.1. For x∈X, if X∖{x} were countable, then X=(X∖{x})∪{x} would be a union of two countable sets, countable by Proposition 3.2.5. So X∖{x} is uncountable.

3.6.3. Infinite sets are the same size as a proper part

Section 3.1 proved that a finite set is never equinumerous with a proper subset (Theorem 3.1.9), and Example (Hilbert’s Hotel) showed N doing exactly that. With Theorem 3.6.1, the hotel can be built inside any infinite set: run it on the copy of N, and leave everything else alone.

Theorem 3.6.2 (Infinite Sets and Proper Subsets)

A set X is infinite if and only if |X|=|Y| for some proper subset Y⊊X.

Idea. One direction is already done: Section 3.1 showed that finite sets have no proper subset of their own size. For the other, take the copy x0,x1,x2,… of N inside X and move every guest one room up, xn↦xn+1, as n↦n+1 does in the Quick check after Example (Hilbert’s Hotel). Room x0 is vacated, and every point outside the copy stays where it is.

Proof. (⇐) This is the contrapositive of Theorem 3.1.9: a finite set is not equinumerous with any proper subset, so a set that is equinumerous with one is not finite.

(⇒) Let X be infinite. By Theorem 3.6.1 there is an injection n↦xn from N to X; let S:={xn:n∈N}. Each element of S is xn for exactly one n∈N, by injectivity. Define h:X→X∖{x0} by h(x):={xn+1if x=xn with n∈N,xif x∉S. This is a function into X∖{x0}: xn+1≠x0 because n+1≠0, and an x∉S is not x0.

h is injective. Two points of S: xm+1=xn+1 gives m+1=n+1, so m=n. Two points outside S: h is the identity there. One of each: h(xn)=xn+1∈S, while h(x)=x∉S, so the values differ.

h is onto X∖{x0}. Let y∈X∖{x0}. If y∉S, then y=h(y). If y∈S, then y=xm with m≠0, so n:=m−1∈N (Lemma 2.1.1 (c)) and y=xn+1=h(xn).

So h is a bijection, and Y:=X∖{x0} is a proper subset of X, as x0∈X∖Y, with |X|=|Y|. This proves the theorem.

Together with Section 3.1, this gives a characterization of “infinite” that never mentions N or counting: a set is infinite precisely when some proper part of it is as big as the whole. The finite intuition “a part is smaller than the whole” is exactly the property that separates finite sets from infinite ones. The direction (⇒) used Axiom 3.3.1, through Theorem 3.6.1; the direction (⇐) did not.

Quick check. Name a proper subset of R that is equinumerous with R, and give a bijection.

Solution. (−1,1), with the bijection x↦x/(1+|x|) of Example (The real line and its intervals). (Any interval with more than one point other than R itself works, by the same example.) No choice is needed for R: the bijection is a formula.

3.6.4. Exercises

A. Check your understanding

Exercise (A1)
  • (a) Where does the proof of Theorem 3.6.1 use Axiom 3.3.1? Why is one ∃E per step not enough?
  • (b) True or false, with a reason: every infinite subset of R contains a countably infinite subset; every uncountable set contains an uncountable proper subset.
  • (c) Write down the bijection X→X∖{x0} of the proof of Theorem 3.6.2 for X=Z and xn=n for n∈N.
  • (d) For X=N, is choice needed to find a countably infinite subset?

Solution.

  • (a) At the line “By Axiom 3.3.1 there is a function c with c(S)∈S for every non-empty S⊆X.” One ∃E names one element of one non-empty set; that would give x0, then x1, and any finite number of steps. But Theorem 2.3.1 needs the step as a function g, defined once for every stage F at once, before the sequence exists. Defining g means picking an element of X∖F for every such F simultaneously, and that is what the axiom provides.

  • (b) Both are true. The first is Theorem 3.6.1 applied to the infinite subset. For the second, let X be uncountable; then X≠∅, and for x∈X, X∖{x} is an uncountable proper subset, by the Quick check after the warning above.

  • (c) h(n)=n+1 for n∈N, and h(k)=k for k<0. It maps Z onto Z∖{0}: a positive m is h(m−1), and a negative k is h(k).

  • (d) No. N itself is countably infinite, via idN. (More generally, an infinite X⊆N can be listed in increasing order by Lemma 3.2.1, a rule.)

B. Practice

Exercise (B1: Removing finitely many points)

Let X be infinite and let F⊆X be finite. Prove that |X∖F|=|X|.

Solution. First, X∖F is infinite: otherwise X=(X∖F)∪F would be a union of two disjoint finite sets, finite by Proposition 3.1.5.

By Theorem 3.6.1 applied to X∖F (this uses Axiom 3.3.1), there is an injection n↦sn from N to X∖F; let S:={sn:n∈N}. Let F have k elements, and let φ:{1,…,k}→F be a bijection (Definition 3.1.2). No two of X∖(F∪S), F and S meet, and together they make up X; and X∖F is the union of the disjoint sets X∖(F∪S) and S. Define h:X→X∖F by h(x):={xif x∉F∪S,si−1if x=φ(i), i∈{1,…,k},sn+kif x=sn, n∈N. Each x falls under one case, with one i or one n, since φ and n↦sn are injective. The second case sends F bijectively onto {s0,…,sk−1}, and the third sends S bijectively onto {sm:m≥k}; these two image sets are disjoint and together make up S. The first case is the identity on X∖(F∪S). So h is a bijection, and |X∖F|=|X|. (For k=0, F=∅ and h is the identity.)

Exercise (B2: Absorbing a countable set)

Let X be infinite, and let C be countable with C∩X=∅. Prove that |X∪C|=|X|.

Hint: absorb C into a countably infinite subset of X.

Solution. By Theorem 3.6.1 (using Axiom 3.3.1) there is a countably infinite S⊆X. The set S∪C is countable by Proposition 3.2.5, and infinite, because it contains S (a subset of a finite set is finite, Proposition 3.1.6), which is infinite: if φ:{1,…,k}→S were a bijection and β:N→S is a bijection given by the theorem, then β−1∘φ would be a bijection {1,…,k}→N (Proposition 3.1.1, Theorem 1.4.4), against Example (Hilbert’s Hotel). By Theorem 3.2.2 (iii), S∪C is countably infinite. So |S∪C|=|N|=|S|, and Proposition 3.1.1 gives a bijection ψ:S∪C→S.

Now X∪C is the union of the disjoint sets X∖S and S∪C (disjoint because C∩X=∅), and X is the union of the disjoint sets X∖S and S. Define h:X∪C→X by h(x):=x for x∈X∖S and h(x):=ψ(x) for x∈S∪C. It is a bijection on each piece, onto the corresponding piece, so it is a bijection, and |X∪C|=|X|.

Exercise (B3: A big hole)

Give an example of an infinite set X and a proper subset Y⊊X with |Y|=|X| and X∖Y infinite. Check each property, and list the properties any answer must have.

Solution. An answer must have: (1) Y⊆X; (2) Y≠X; (3) a bijection X→Y, or injections both ways; (4) X infinite; (5) X∖Y infinite. (The hole X∖Y in the proof of Theorem 3.6.2 was the single point x0; this asks for more.)

Example: X=N, Y=2N. (1), (2): 2N⊆N and 1∉2N. (3): n↦2n is a bijection N→2N (Example (Hilbert’s Hotel)). (4): N is infinite (Example (Hilbert’s Hotel)). (5): X∖Y is the set of odd numbers (every m∈N is even or odd, not both, by Theorem 2.2.3), and n↦2n+1 is a bijection from N onto it; if it were finite, N would be finite too (compose with a bijection from {1,…,k}, Theorem 1.4.4), which it is not.

Another correct answer: X=R, Y=(0,∞). (1), (2): (0,∞)⊆R and 0∉(0,∞). (3): Example (The real line and its intervals). (4), (5): n↦−n is a bijection from N onto {−n:n∈N}, so this set is infinite, as in (5) above. It lies inside X∖Y=(−∞,0]⊆R, so by Proposition 3.1.6 neither (−∞,0] nor R is finite.

C. Going deeper

Exercise (C1: Increasing functions)

A function f:N→N is strictly increasing if f(m)<f(n) whenever m<n. Let I be the set of strictly increasing functions N→N. Prove that I is uncountable.

Below, the proof is started; the second half is blank. Name the move, then complete it.

Let n↦fn be any function from N to I. By Theorem 2.3.1, applied with the set N, the starting value f0(0)+1 and the function (n,x)↦max{x,fn+1(n+1)}+1 from N×N to N (a step that depends on n), there is a function g:N→N with g(0)=f0(0)+1,g(n+1)=max{g(n),fn+1(n+1)}+1. ―

Solution (Hint 1). Two things must be shown about g: that it lies in I, and that it differs from each fn somewhere. Where?

Solution (Hint 2). The second half begins: “For every n∈N, g(n+1)≥g(n)+1>g(n).”

Solution. The move is the diagonal: given any list, build an object that differs from the n-th entry at the n-th place. Here the object must also stay inside I, which is why g(n+1) is pushed above g(n) as well as above fn+1(n+1).

Completion. For every n∈N, g(n+1)=max{g(n),fn+1(n+1)}+1≥g(n)+1>g(n). From this, g(m)<g(n) whenever m<n, by induction on n (Theorem 2.2.1 with base m+1): g(m)<g(m+1), and g(m)<g(n)<g(n+1). So g∈I.

Next, g(n)>fn(n) for every n∈N: for n=0, g(0)=f0(0)+1; for n=k+1, g(k+1)≥fk+1(k+1)+1. So g(n)≠fn(n), and hence g≠fn, for every n∈N. So g∈I is not a value of n↦fn, and no function N→I is onto. Since I≠∅ (it contains idN), I is not countable.

Marking scheme. (10 points) - 1: names the diagonal move. - 4: shows g is strictly increasing: 2 for the step g(n)<g(n+1) for every n, and 2 for the passage to all m<n. - 3: shows g(n)>fn(n) for every n, treating n=0 and n=k+1 separately, and concludes g≠fn. - 2: concludes that no function N→I is onto and, noting I≠∅ (idN∈I), that I is not countable. Fatal errors (0 for the part concerned): taking g(n)<g(n+1) alone as strict increase, with no passage to all m<n; inferring g≠fn without exhibiting a point where they differ, or exhibiting one only for n≥1.

The max in g is needed: the plain diagonal g(n):=fn(n)+1 need not be strictly increasing (for f0(n)=5+n and f1(n)=n, it gives g(0)=6>g(1)=2).

Exercise (C2: The irrationals)

Deduce from Exercise (B2: Absorbing a countable set) that |R∖Q|=|R|.

Solution. The set R∖Q is uncountable: otherwise R=(R∖Q)∪Q would be a union of two countable sets (Theorem 3.2.8), countable by Proposition 3.2.5, against Theorem 3.4.4. An uncountable set is infinite, since finite sets are countable (Theorem 3.2.2). Now apply Exercise (B2: Absorbing a countable set) with X:=R∖Q and C:=Q, which is countable and disjoint from X: |(R∖Q)∪Q|=|R∖Q|, and the left side is |R|.

R. Review

Exercise (R1)

Prove that every integer n≥1 is a sum of distinct powers of 2: there are an integer r≥1 and natural numbers k1>k2>⋯>kr with n=2k1+2k2+⋯+2kr.

Solution. We use Theorem 2.2.2 with n0=1. Let n≥1, and suppose every integer m with 1≤m<n is such a sum.

The largest power of 2 not above n. The set T:={k∈N:2k>n} is non-empty, since 2n≥1+n>n by Theorem 2.3.7 with x=1. By Theorem 2.1.3 it has a least element m. Since 20=1≤n, 0∉T, so m≥1, and K:=m−1∈N (Lemma 2.1.1 (c)). As K<m, K∉T; so 2K≤n<2K+1. The step. Let s:=n−2K, so 0≤s<2K+1−2K=2K. If s=0, then n=2K, a sum with r=1. If s≥1, then s<n, because 2K≥1. By the hypothesis, s=2k1+⋯+2kr with k1>⋯>kr. Each 2ki≤s<2K, so ki<K (if ki≥K, then 2ki≥2K by Proposition 2.3.4 (e)). Hence n=2K+2k1+⋯+2kr,K>k1>⋯>kr, a sum of distinct powers of 2. By Theorem 2.2.2, every n≥1 is such a sum. For example 13=23+22+20.

The base 1 is the right one: 0 is not a sum of one or more powers of 2, since each power is positive.

Exercise (R2)

Show that ∀x∃yR(x,y)⊬∃y∀xR(x,y) by a counter-model whose domain is N. Say in words what the two sentences say when R(x,y) is read as “x<y”.

Solution. Let M have domain N and RM:={(d,e)∈N×N:d<e}. Both formulas are sentences, so no assignment matters.

The premise is true. ∀x∃y(x<y) says “every natural number has a larger one”. For each d∈N, e:=d+1∈N has d<e.

The conclusion is false. ∃y∀x(x<y) says “some natural number is larger than every natural number”. For any e∈N, the choice d:=e gives d<e false, so no e works.

So M is a counter-model, and ∀x∃yR(x,y)⊭∃y∀xR(x,y). By the soundness statement of Logic and Proof, Section 4.11 (the subsection “From counter-models to non-derivability”), a counter-model shows non-derivability: ∀x∃yR(x,y)⊬∃y∀xR(x,y).

This is the converse of Logic and Proof, Proposition 5.6.2 with the variables renamed and the two places of R exchanged (read R(x,y) as R(y,x)), and the counter-model is the one of Logic and Proof, Example (The swap of ∃ and ∀): there the domain was Z and R was read as >; with the roles of the variables exchanged, R read as < and the domain cut down to N, the same witnesses work, as checked above. In the premise the larger number y is chosen after x and depends on it; the conclusion asks for one y in advance.

Exercise (R3)

For an integer n≥1, how many truth functions with n inputs are there? Prove your answer.

Solution. There are 22n. A truth function with n inputs (Logic and Proof, Definition 4.8.4) assigns a truth value to each row (a1,…,an); read a row as the function i↦ai on {1,…,n}, and let L be the set of rows.

There are 2n rows. The map sending a row to {i∈{1,…,n}:ai=T} is a bijection L→P({1,…,n}): a row is determined by the places where it is T, and every set of places arises. Since {1,…,n} has n elements, Proposition 3.1.8 gives 2n subsets, so L has 2n elements (compose the bijections).

There are 22n truth functions. In the same way, a truth function f is determined by the set {ρ∈L:f(ρ)=T}⊆L, and every subset of L arises; so the truth functions are in bijection with P(L), which has 22n elements by Proposition 3.1.8 again. For n=1,2,3 this gives 4,16,256.

Exercise (R4)

A function f:N→N is eventually zero if there is N∈N with f(n)=0 for every n≥N. Is the set of eventually zero functions countable?

Solution. Yes. The tool is a countable union of countable sets. For N∈N let ZN be the set of f:N→N with f(n)=0 for every n≥N; the set of eventually zero functions is Z:=⋃N∈NZN. Each ZN is countable:

  • Z0 has one element, the zero function, so it is countable.
  • For N=1, f↦f(0) is a bijection Z1→N: a function in Z1 is determined by its value at 0, and every value occurs.
  • For N≥2, f↦(f(0),…,f(N−1)) is a bijection ZN→NN, by the same reasoning and the characteristic property of tuples; NN is countable by Corollary 3.2.7, and so is ZN (compose a surjection N→NN with the inverse bijection, Proposition 3.2.4).

By Theorem 3.3.3, Z is countable. (That theorem uses Axiom 3.3.1; here it could be avoided, since each ZN comes with an explicit listing, but the question did not ask for that.)

Why the look-alike fails. A diagonal argument, as in Theorem 3.4.1, builds from a list f0,f1,… of eventually zero functions the function g(n):=fn(n)+1. It differs from every fn, but g(n)≥1 for every n, so g is not eventually zero: it is not in Z, and nothing is contradicted. A diagonal argument proves uncountability only when the diagonal object stays inside the set.
