    15.1  Multilinear Maps

    Chapter 7 needed functions of several vectors that were linear in each vector separately, and called them multilinear forms (Definition 7.2.1). Every one of them landed in the field F: the determinant, the signed area, a product of functionals. This chapter needs the same idea with the output allowed to be any vector space, because three of the most familiar operations in the book — matrix multiplication, composition of linear maps, the cross product — are linear in each argument and return something that is not a scalar. So we begin by extending Chapter 7’s definition, count how many such maps there are, and then state the problem that the rest of the chapter exists to solve: a multilinear map is not a linear map, so none of the machinery of Chapters 2 to 5 is available to it.

    Throughout, F is a field, k≥1 is an integer, and all vector spaces are over F. From the third subsection on, every space named is finite-dimensional.

    15.1.1. From forms to maps

    Here are three operations the book has used constantly.

    • Matrix multiplication. For fixed sizes, (A,B)↦AB satisfies (A+A′)B=AB+A′B and A(B+B′)=AB+AB′, and scalars pull out of either factor.
    • Composition of linear maps. (S,T)↦ST satisfies the same four rules.
    • The cross product on R3, which is linear in each factor and returns a vector.

    Each is linear in one argument while the other is held fixed. Each therefore looks exactly like Definition 7.2.1 with k=2 — except that the value is a matrix, a linear map, or a vector, not a scalar. Chapter 7 had no reason to allow that, because it was building the determinant. We do, so we widen the definition. Nothing about Chapter 7’s statements changes; a multilinear form will simply be the special case where the target is F, and we will keep using Definition 7.2.1 by that name whenever the target really is F.

    A multilinear map is a function of several vectors that is linear in each one while the others are held fixed, with values in a vector space rather than in the field.

    Definition 15.1.1 (Multilinear Map)

    Let V1,…,Vk and W be vector spaces over the same field F, with k≥1. A function β:V1×V2×⋯×Vk→W is k-linear, or a multilinear map, if for every position i∈{1,…,k} and every choice of fixed vectors vj∈Vj for the positions j≠i, the function Vi→W,x↦β(v1,…,vi−1,x,vi+1,…,vk), is linear. A 2-linear map is called bilinear.

    When V1=⋯=Vk=V we say β is k-linear on V; when in addition W=F, the definition is word for word Definition 7.2.1, and we call β a multilinear form.

    In words, clause by clause. Same field: all k+1 spaces are over one F, since otherwise “linear” would mean different things in different slots. For every position: the condition is imposed k separate times, once per slot. Every choice of fixed vectors: the other k−1 arguments are frozen at arbitrary values, not at convenient ones. Is linear: written out, for all x,y∈Vi and all c∈F, β(…,x+y,…)=β(…,x,…)+β(…,y,…),β(…,cx,…)=cβ(…,x,…), where the dots stand for the same frozen vectors on both sides. The spaces V1,…,Vk are allowed to be different from each other and from W; nothing forces k to be related to any dimension.

    Two consequences are free. Putting c=0 in slot i gives β(…,0,…)=0: a multilinear map kills any tuple with a zero entry. And by induction on the number of terms, expanding one slot at a time, β(∑i1ai1xi1, …, ∑ikaikyik)=∑i1,…,ikai1⋯aikβ(xi1,…,yik), a sum over all tuples of indices, one index per slot. This identity is the whole of the section: it says that a multilinear map is determined by its values on tuples drawn from spanning sets, and that the number of such tuples is a product, not a sum.

    Example (Seven functions of several vectors)

    Decide which of the following are multilinear, and with which k.

    • (a) Any linear map T:V→W, viewed as a function of one vector.
    • (b) Scalar multiplication F×V→V, (c,v)↦cv, with F regarded as a vector space over itself.
    • (c) Matrix multiplication Mm×n(F)×Mn×p(F)→Mm×p(F), (A,B)↦AB.
    • (d) Composition L(W,Z)×L(V,W)→L(V,Z), (S,T)↦ST.
    • (e) The determinant (Fn)n→F sending (a1,…,an) to detA, where A has columns a1,…,an.
    • (f) The evaluation pairing V∗×V→F, (φ,v)↦φ(v).
    • (g) The cross product R3×R3→R3.

    Solution.

    • (a) With k=1 there is one position and no other argument to freeze, so the condition reads: x↦Tx is linear. That is the hypothesis. So a 1-linear map is exactly a linear map (Definition 2.1.1), and Definition 15.1.1 generalizes it.

    • (b) Fix v. Then c↦cv is linear by (VS6) and (VS7) of Definition 1.1.1, which give (a+b)v=av+bv and a(cv)=(ac)v. Fix c. Then v↦cv is linear by (VS5) and (VS7), the second of which gives c(av)=(ca)v=(ac)v=a(cv), using that F is commutative. So scalar multiplication is bilinear. It is the smallest interesting example, and it shows that the two input spaces need not be equal.

    • (c) Fix B. Then A↦AB is linear, since (A+A′)B=AB+A′B and (cA)B=c(AB) by Theorem 0.9.4. Fixing A gives the other slot. So matrix multiplication is bilinear, with three different spaces in play when m,n,p differ.

    • (d) Same check, with Theorem 2.4.2 (a) supplying linearity of ST and Theorem 2.4.2 (d) supplying the two slots. Bilinear.

    • (e) The determinant is n-linear in the columns, and alternating, by Theorem 7.4.3. It is the standard example of a multilinear form with k equal to the dimension. Here k=n is forced by the shape of a square matrix, not by the definition.

    • (f) Fix v. Then φ↦φ(v) is linear because the operations on V∗ are pointwise (Definition 5.1.2). Fix φ. Then v↦φ(v) is linear because φ is a linear functional. Bilinear. This one-line example is the source of the contraction operation of a later section.

    • (g) The cross product of Chapter 7 has components a2b3−a3b2 and its two cousins, each bilinear as in Example (Alternating Forms) (b). A vector of bilinear functions is bilinear, since linearity in a slot may be checked coordinate by coordinate. So it is bilinear, with values in R3 — an example that genuinely needs Definition 15.1.1 rather than Definition 7.2.1.

    Nonexample, by minimal change. Keep k=2, keep V1=V2=W=F, and change multiplication to addition: σ(a,b)=a+b. Freeze b=1. The resulting function a↦a+1 sends 0 to 1, so it is not linear (Theorem 2.1.1), and the clause “is linear” fails in the first slot. What still works is that σ is linear as a function on the product space F×F of Definition 4.4.1. That is precisely the distinction the next subsection is about.

    Why this definition. One could try to define a “map of several variables” by asking for linearity in all slots at once, that is, by asking for a linear map on V1×⋯×Vk. The result would be a different and much poorer notion: it would exclude multiplication, composition, the determinant, and every inner product, and would include only sums of linear maps applied to the separate slots. Freezing all but one slot is what keeps products in the theory. The name says the same thing: multi, once per slot; linear, in that slot alone.

    15.1.2. Multilinear is not linear

    The product V×W is itself a vector space, with (v,w)+(v′,w′)=(v+v′,w+w′) and c(v,w)=(cv,cw) (Definition 4.4.1). So a function β:V×W→Z has two different conditions it might satisfy, and they are stated on the same domain. They are not the same condition, and confusing them is the standard first error with tensors.

    Side by side, for β:V×W→Z:

    • Linear on the product means β((v,w)+(v′,w′))=β(v,w)+β(v′,w′) and β(cv,cw)=cβ(v,w). Both slots move together.
    • Bilinear means β(v+v′,w)=β(v,w)+β(v′,w), and the same in the second slot with the first frozen. One slot moves at a time.

    Warning. Do not add in both slots at once. For a bilinear β, the correct expansion has four terms: β(v+v′,w+w′)=β(v,w)+β(v,w′)+β(v′,w)+β(v′,w′). Concretely, with β(a,b)=ab on F×F: β(1+1,1+1)=4, not β(1,1)+β(1,1)=2. Scaling is worse: β(cv,cw)=c2β(v,w), so a bilinear map scales by the square. Pull out scalars one slot at a time, always.

    Quick check. Is β(x,y)=x1y1+x2 a bilinear map F2×F2→F?

    Solution. No. Freeze y. Then x↦y1x1+x2 is a linear functional, so the first slot is fine. Freeze x=e2. Then y↦0⋅y1+1=1 is the constant function 1, which sends 0 to 1 and so is not linear. The clause that fails is “is linear” at position i=2. The extra summand x2 does not involve y at all, and a bilinear map must vanish whenever an argument is 0.

    15.1.3. Values on basis tuples

    A linear map may be prescribed arbitrarily on a basis and is determined by those values (Theorem 2.1.6). The corresponding statement for multilinear maps replaces “basis vectors” by “tuples of basis vectors, one from each slot”, and the proof is the expansion identity above read in both directions.

    Theorem 15.1.1 (Multilinear Maps from Values on Basis Tuples)

    Let V1,…,Vk be finite-dimensional, with ordered bases Bi=(v1(i),…,vni(i)) for i=1,…,k, and let W be any vector space over F. For every family of vectors wi1i2…ik∈W,1≤i1≤n1, …, 1≤ik≤nk, there is exactly one k-linear map β:V1×⋯×Vk→W with β(vi1(1),…,vik(k))=wi1…ik for every tuple of indices.

    Idea. Uniqueness is the expansion identity: write each argument in its basis, expand one slot at a time, and every value of β is a combination of the prescribed ones. For existence we need a formula, and the coefficients in that expansion are exactly the coordinates, which Theorem 5.1.3 supplies as linear functionals. So multiply the right functionals together and use them as coefficients.

    Proof. Uniqueness. Let β and β′ be k-linear with the same values on all basis tuples, and let xi∈Vi. Write xi=∑jaj(i)vj(i). Expanding each slot in turn by Definition 15.1.1, β(x1,…,xk)=∑i1,…,ikai1(1)⋯aik(k)wi1…ik, and the same computation applies to β′. Hence β=β′.

    Existence. For each i, let (φ1(i),…,φni(i)) be the basis of Vi∗ dual to Bi, so that φa(i)(vb(i))=δab and φj(i)(x) is the j-th coordinate of x (Theorem 5.1.3). Define β(x1,…,xk):=∑i1,…,ikφi1(1)(x1)⋯φik(k)(xk)wi1…ik, a finite sum of vectors of W, so a well-defined element of W.

    It is k-linear: freeze every slot but the m-th. Each summand is then the vector wi1…ik multiplied by a fixed scalar times φim(m)(xm), and φim(m) is linear; a finite sum of linear functions of xm, each scaled by a fixed vector, is linear in xm. This holds for every m, which is the condition of Definition 15.1.1.

    Its values are the prescribed ones: at xi=vji(i) the coefficient φi1(1)(vj1(1))⋯φik(k)(vjk(k)) is 1 when i1=j1,…,ik=jk and 0 otherwise, so only the term wj1…jk survives. This proves the theorem.

    So a multilinear map is “nothing but” a family of vectors of W indexed by tuples of basis indices, exactly as a linear map is nothing but a family indexed by single basis indices. The count of tuples is where the product in the next theorem comes from.

    15.1.4. The space of multilinear maps

    Two multilinear maps with the same slots and the same target can be added and scaled pointwise, and the results are again multilinear. That makes them a vector space, and we name it before counting it.

    Definition 15.1.2 (The Space of Multilinear Maps)

    Let V1,…,Vk and W be vector spaces over F. Write M(V1,…,Vk;W) for the set of all k-linear maps V1×⋯×Vk→W, with the pointwise operations (β+γ)(x1,…,xk):=β(x1,…,xk)+γ(x1,…,xk), and (cβ)(x1,…,xk):=cβ(x1,…,xk). The semicolon separates the inputs from the output.

    Well-definedness. The set of all functions V1×⋯×Vk→W is a vector space under the pointwise operations, by the argument of Example (The Standard Vector Spaces) (d) with F replaced by W: two functions are equal when they agree at every point, so each axiom is checked one point at a time and reduces to the corresponding axiom in W. Inside it, M(V1,…,Vk;W) passes Theorem 1.2.1. The zero function is k-linear, since freezing slots leaves the zero map. If β,γ are k-linear and c∈F, then freezing all slots but the m-th turns β+γ and cβ into a sum and a scalar multiple of linear maps Vm→W, which are linear by Theorem 2.4.1. So M(V1,…,Vk;W) is a subspace, hence a vector space.

    Two special cases are old friends. For k=1, M(V;W)=L(V,W) by Example (Seven functions of several vectors) (a). For W=F, the elements are the multilinear forms of Definition 7.2.1; Chapter 7 wrote the space of alternating n-linear forms on Fn and proved it one-dimensional (Corollary 7.4.4), which is a subspace of M(Fn,…,Fn;F).

    Theorem 15.1.2 (Dimension of the Space of Multilinear Maps)

    Let V1,…,Vk and W be finite-dimensional, with dim⁡Vi=ni and dim⁡W=m. Then M(V1,…,Vk;W) is finite-dimensional, of dimension

    dim⁡M(V1,…,Vk;W)=(dim⁡W)∏i=1kdim⁡Vi=mn1n2⋯nk.
    (15.1.1)

    Explicitly, fix bases Bi of Vi with dual bases (φj(i)), and a basis (w1,…,wm) of W. For a tuple I=(i1,…,ik) and an index r, let EIr(x1,…,xk):=φi1(1)(x1)⋯φik(k)(xk)wr. The mn1⋯nk maps EIr form a basis of M(V1,…,Vk;W).

    Idea. Theorem 15.1.1 says a multilinear map is the same thing as a list of vectors of W, one per index tuple. So count the lists: there are n1⋯nk tuples and each entry needs m coordinates. The maps EIr are the maps whose list has a single wr in position I and zeros elsewhere, which is why they should be the basis.

    Proof. Each EIr is k-linear by the existence half of Theorem 15.1.1, being the map prescribed to take the value wr at the basis tuple (vi1(1),…,vik(k)) and 0 at every other basis tuple.

    Spanning. Let β∈M(V1,…,Vk;W). For each tuple I write its value on the corresponding basis tuple in the basis of W: β(vi1(1),…,vik(k))=∑r=1mcI,rwr, which is possible, and with unique coefficients, since (w1,…,wm) is a basis. The map ∑I,rcI,rEIr is k-linear and takes exactly these values on the basis tuples. By the uniqueness half of Theorem 15.1.1 it equals β.

    Independence. Suppose ∑I,rcI,rEIr=0, the zero map. Evaluate at a basis tuple indexed by J. By the displayed formula for EIr, the coefficient φi1(1)(vj1(1))⋯φik(k)(vjk(k)) is 1 for I=J and 0 otherwise, so the value is ∑rcJ,rwr=0. Since (wr) is independent, cJ,r=0 for every r. As J was arbitrary, every coefficient vanishes.

    Hence the EIr form a basis. There are n1n2⋯nk index tuples I and m choices of r, so the count is mn1⋯nk, which is Eq. 15.1.1. This proves the theorem.

    Aftermath. Two sanity checks. With k=1, Eq. 15.1.1 reads dim⁡L(V,W)=(dim⁡W)(dim⁡V), which is Theorem 4.1.4. With W=F and k=2, it reads dim⁡M(V1,V2;F)=n1n2, which is the count of n1×n2 matrices — and indeed Chapter 14 recorded a bilinear form on a single space by its Gram matrix (Definition 14.1.2). The ni enter as a product, once per slot, and that is the number to remember.

    Example (Counting bilinear maps)
    • (a) Find dim⁡M(F2,F3;F2).
    • (b) Find dim⁡M(F3,F3,F3;F), and the dimension of the subspace of alternating forms inside it when F=R.
    • (c) Write the bilinear map β:F2×F2→F2, β(x,y)=(x1y1, x1y2+x2y1), in the basis of Theorem 15.1.2 for the standard bases.

    Solution.

    • (a) dim⁡W⋅dim⁡V1⋅dim⁡V2=2⋅2⋅3=12.

    • (b) 1⋅3⋅3⋅3=27. The alternating ones form a subspace of dimension 1 by Corollary 7.4.4, spanned by the determinant. So alternation is a very strong condition: it cuts 27 down to 1.

    • (c) Here m=n1=n2=2, so there are 2⋅2⋅2=8 basis maps E(i,j)r, and E(i,j)r(x,y)=xiyjer. Evaluate β on the four basis pairs: β(e1,e1)=(1,0)=e1,β(e1,e2)=(0,1)=e2,β(e2,e1)=(0,1)=e2,β(e2,e2)=(0,0)=0. By the spanning argument, β=E(1,1)1+E(1,2)2+E(2,1)2, with the other five coefficients zero. Reading the formula back, β(x,y)=x1y1e1+x1y2e2+x2y1e2, which is the given map.

    Quick check. What does Eq. 15.1.1 give for M(V1,V2;W) when V2={0}? Does the answer make sense?

    Solution. It gives (dim⁡W)⋅(dim⁡V1)⋅0=0, so the space is {0}. That is right: a bilinear map must satisfy β(v,0)=0, and 0 is the only vector of V2, so the only bilinear map is the zero map. The degenerate case is worth checking because it is where a formula with a product behaves differently from one with a sum.

    15.1.5. The problem this chapter solves

    We now have a good supply of multilinear maps and we know how many there are. What we do not have is any way to work with them. Consider what Chapters 2 to 5 give a linear map T:V→W: a matrix, a kernel, an image, a rank, Rank–Nullity, a dual map, a determinant when V=W, eigenvalues, a Jordan form. A bilinear map β:V×W→Z has none of these. It has no matrix, because Definition 4.1.1 applies to linear maps. It has no kernel that is a subspace: the set where β vanishes contains (v,0) and (0,w) for all v,w but usually not their sum. It is not an element of L(V×W,Z), as the previous subsection insisted. Every fact we know about it has had to be proved by hand, one slot at a time.

    The wish is therefore easy to state. We want to replace multilinearity by linearity. Concretely, for two spaces V and W we want a single vector space — call it X for now — and a single bilinear map τ:V×W→X, so universal that every bilinear map out of V×W is τ followed by a linear map. If that works, then bilinear maps V×W→Z correspond to linear maps X→Z, and the entire toolkit of Chapters 2 to 5 applies to the latter.

    Before building anything, we can predict the size of X, and the prediction is a good reason to believe the object exists. Suppose such an X and τ existed, and suppose the correspondence “β on V×W ↔ linear map on X” is a bijection for every target Z. Take Z=F. Then Eq. 15.1.1 gives dim⁡M(V,W;F)=1⋅dim⁡V⋅dim⁡W, while Theorem 4.1.4 gives dim⁡L(X,F)=dim⁡X. A bijection that respects addition and scalars forces these to agree, so dim⁡X=(dim⁡V)(dim⁡W). The product of the dimensions, not the sum. This already rules out the naive guess X=V×W, whose dimension is dim⁡V+dim⁡W by Theorem 4.4.1, and it tells us what to aim for. The next section constructs X, calls it V⊗W, and proves that its dimension is exactly this product.

    One more remark before we go. The prediction used only the case Z=F, but the same count works for every Z: Eq. 15.1.1 gives dim⁡Z⋅dim⁡V⋅dim⁡W on one side and dim⁡Z⋅dim⁡X on the other, and the two agree precisely when dim⁡X=(dim⁡V)(dim⁡W). When the next section produces a basis of V⊗W indexed by pairs (i,j) of basis indices, that is the same count seen a second time, and the agreement is not a coincidence — it is the universal property, counted.

    15.1.6. Exercises

    A. Check your understanding

    Exercise (A1)
    • (a) Define what it means for β:V1×⋯×Vk→W to be k-linear, with every quantifier.
    • (b) State the difference between “β is bilinear” and “β is linear on the product space V×W”, and give a function that is one but not the other.
    • (c) Write out β(u+u′,v+v′) for a bilinear β. How many terms are there?
    • (d) State dim⁡M(V1,…,Vk;W) in terms of the dimensions of the spaces involved.
    • (e) True or false: every bilinear map β:V×W→Z satisfies β(v,0)=0. Justify your answer.
    • (f) What is a 1-linear map? What is a k-linear map with W=F called?

    Solution.

    • (a) It is k-linear if for every position i and every choice of fixed vj∈Vj with j≠i, the function x↦β(v1,…,x,…,vk) with x in position i is a linear map Vi→W (Definition 15.1.1). All spaces are over the same field.

    • (b) Bilinear means linear in each slot with the other frozen; linear on the product means linear when both slots move together. The multiplication β(a,b)=ab on F×F is bilinear but not linear on the product, since β(2⋅(1,1))=4≠2β(1,1). The sum σ(a,b)=a+b is linear on the product but not bilinear, since a↦a+1 is not linear.

    • (c) β(u,v)+β(u,v′)+β(u′,v)+β(u′,v′): four terms.

    • (d) (dim⁡W)∏i=1kdim⁡Vi (Eq. 15.1.1).

    • (e) True. Freeze v; the map y↦β(v,y) is linear, and a linear map sends 0 to 0 by Theorem 2.1.1.

    • (f) A 1-linear map is exactly a linear map. A k-linear map into F is a multilinear form (Definition 7.2.1).

    B. Practice

    Exercise (B1: Determine which are multilinear)

    Determine which of the following are multilinear maps. For those that are, say what k is; for those that are not, name the clause that fails and give a concrete witness. Justify your answer.

    • (a) β:Mn(F)×Mn(F)→Mn(F), β(A,B)=AB−BA.
    • (b) β:R2×R2→R, β(x,y)=x1y2−x2y1+1.
    • (c) β:Fn×Fn→Mn(F), β(x,y)=xy⊤.
    • (d) β:Mn(F)×Mn(F)→F, β(A,B)=det(AB), for n≥2.
    • (e) β:V∗×V∗×V×V→F, β(φ,ψ,u,v)=φ(u)ψ(v).

    Solution.

    • (a) Bilinear, k=2. This is the commutator [A,B] of Definition 8.5.1. Freeze B: then A↦AB−BA is a difference of two linear maps of A, hence linear (Theorem 2.4.1). Freezing A is the same computation.

    • (b) Not multilinear. Freeze y=0; then x↦1 is constant, so it sends 0 to 1 and the clause “is linear” fails at position 1. Removing the +1 leaves the signed area, which is bilinear.

    • (c) Bilinear, k=2. The (i,j) entry of xy⊤ is xiyj. Freeze y: each entry is a linear functional of x and the entries are the coordinates of the output in the basis of matrix units, so x↦xy⊤ is linear. Symmetrically in y. This map will reappear as the model of the tensor product of two coordinate spaces.

    • (d) Not multilinear for n≥2. By Theorem 7.5.4, β(A,B)=detAdetB. Freeze B=In; then A↦detA is not linear, since det(cA)=cndetA and n≥2. Concretely with n=2, det(2I2)=4≠2detI2=2. The failing clause is again “is linear”.

    • (e) 4-linear. Freeze three of the four arguments; in each case what remains is one of φ↦φ(u)⋅ψ(v), ψ↦ψ(v)⋅φ(u), u↦φ(u)⋅ψ(v), v↦ψ(v)⋅φ(u), each a fixed scalar times a linear functional, hence linear. Note that the four slots do not all lie in the same space, which Definition 15.1.1 allows and Definition 7.2.1 does not.

    Exercise (B2: Dimension counts)

    Compute the dimension of each space. The field is F throughout.

    • (a) M(F4,F5;F3).
    • (b) M(F2,F2,F2;F2).
    • (c) M(M2(F),F3;F).
    • (d) M(Fn;W) for dim⁡W=m, and the space L(Fn,W). Compare.

    Solution.

    • (a) 3⋅4⋅5=60 by Eq. 15.1.1.

    • (b) 2⋅2⋅2⋅2=16.

    • (c) dim⁡M2(F)=4, so 1⋅4⋅3=12.

    • (d) Both are mn. With k=1 the two spaces are equal, by Example (Seven functions of several vectors) (a), and Eq. 15.1.1 reduces to Theorem 4.1.4. The formula is consistent with what Chapter 2 already proved.

    Exercise (B3: Expanding in the basis)

    Let β:F2×F3→F2 be given by β(x,y)=(x1y1−2x2y3, x1y2+x2y1).

    • (a) Verify that β is bilinear.
    • (b) Compute the six values β(ei,fj), where (e1,e2) and (f1,f2,f3) are the standard bases.
    • (c) Write β in the basis {E(i,j)r} of Theorem 15.1.2, and say how many of the 12 coefficients are nonzero.

    Solution.

    • (a) Freeze y. Each output coordinate is a fixed linear combination of x1 and x2, hence a linear functional of x (Theorem 5.1.1), and a map into F2 whose coordinates are linear is linear. Freeze x: each output coordinate is a fixed linear combination of y1,y2,y3, and the same argument applies. So β is bilinear.

    • (b) Substituting the standard basis vectors: β(e1,f1)=(1,0),β(e1,f2)=(0,1),β(e1,f3)=(0,0),β(e2,f1)=(0,1),β(e2,f2)=(0,0),β(e2,f3)=(−2,0).

    • (c) Reading the coordinates off, c(1,1),1=1, c(1,2),2=1, c(2,1),2=1, and c(2,3),1=−2, all others zero. Hence β=E(1,1)1+E(1,2)2+E(2,1)2−2E(2,3)1, so 4 of the 2⋅2⋅3=12 coefficients are nonzero.

    C. Going deeper

    Exercise (C1: Bilinear forms on coordinate spaces are matrices)

    Let m,n≥1.

    • (a) Prove that for every bilinear β:Fm×Fn→F there is a unique A∈Mm×n(F) with β(x,y)=x⊤Ay for all x,y.
    • (b) Hence deduce that dim⁡M(Fm,Fn;F)=mn, and check that this agrees with Eq. 15.1.1.

    Hint for (a): the entries of A can only be the values of β on pairs of standard basis vectors.

    Solution.

    • (a) Existence. Put aij:=β(ei,fj), where (ei) and (fj) are the standard bases of Fm and Fn, and let A=(aij). For x=∑ixiei and y=∑jyjfj, expanding one slot at a time by Definition 15.1.1 gives β(x,y)=∑i,jxiyjβ(ei,fj)=∑i,jxiaijyj=x⊤Ay.

      Uniqueness. If x⊤Ay=x⊤A′y for all x,y, take x=ei and y=fj: the left side is aij and the right side is aij′. Hence A=A′.

    • (b) By (a) the map M(Fm,Fn;F)→Mm×n(F), β↦A, is a bijection, and it is linear because the entries β(ei,fj) depend linearly on β by the definition of the pointwise operations. So it is an isomorphism, and dim⁡M(Fm,Fn;F)=dim⁡Mm×n(F)=mn by Theorem 2.5.4. Eq. 15.1.1 gives 1⋅m⋅n=mn, the same value.
    Exercise (C2: Linear and bilinear at once)

    Let V,W,Z be vector spaces over F and let β:V×W→Z be a function.

    • (a) Prove that if β is both bilinear and linear as a map on the product space V×W, then β is the zero map.
    • (b) Give an example, with V=W=Z=F, of a nonzero bilinear map and a nonzero linear map on the product, and say which property each one fails.
    • (c) Does (a) still hold when V={0}? Explain what the statement says in that case.

    Solution.

    • (a) Let v∈V and w∈W. In the product space, (v,w)=(v,0)+(0,w). Since β is linear on the product, β(v,w)=β(v,0)+β(0,w). Since β is bilinear, freezing the first slot at v makes y↦β(v,y) linear, so β(v,0)=0 by Theorem 2.1.1; freezing the second slot at w gives β(0,w)=0 likewise. Therefore β(v,w)=0 for all v,w, that is, β=0.

    • (b) The product μ(a,b)=ab is bilinear and fails linearity on the product, since μ(2⋅(1,1))=4≠2μ(1,1). The sum σ(a,b)=a+b is linear on the product and fails bilinearity, since σ(0,1)=1≠0 while a bilinear map must vanish when a slot is 0.

    • (c) Yes, but it says nothing: if V={0} then v=0 always, and the only function {0}×W→Z that is bilinear is already the zero map, since β(0,w)=0. The content of (a) appears only when both V and W are nonzero and Z≠{0}.

    Exercise (C3: Counting over a finite field)

    Work over F2, the field with two elements.

    • (a) How many bilinear maps F22×F22→F2 are there? How many trilinear maps F22×F22×F22→F2?
    • (b) How many of the bilinear maps in (a) are symmetric, that is, satisfy β(x,y)=β(y,x) for all x,y? How many are alternating in the sense of Definition 7.2.2?
    • (c) Is every alternating bilinear form on F22 symmetric? Is every symmetric one alternating?

    Solution.

    • (a) By Eq. 15.1.1, dim⁡M(F22,F22;F2)=1⋅2⋅2=4. A vector space of dimension d over F2 has exactly 2d elements, since each of the d coordinates is 0 or 1. So there are 24=16 bilinear maps. For three slots the dimension is 23=8, giving 28=256 trilinear maps.

    • (b) By Exercise (C1: Bilinear forms on coordinate spaces are matrices) a bilinear form on F22 is x⊤Ay for a unique A∈M2(F2), and β is symmetric exactly when A=A⊤ (compare the values at (ei,ej) and (ej,ei)). A symmetric 2×2 matrix is determined by a11,a12,a22, so there are 23=8 symmetric ones. Alternating means β(x,x)=0 for all x, which forces a11=β(e1,e1)=0, a22=0, and then β(e1+e2,e1+e2)=a12+a21=0. Over F2 that says a21=a12, so A=(0aa0) and there are 2 alternating forms: the zero form and the signed area.

    • (c) Both alternating forms found in (b) have symmetric matrices, so yes, every alternating form here is symmetric — which is Theorem 14.3.3 in characteristic 2, where −1=1. The converse fails: the dot product β(x,y)=x1y1+x2y2 is symmetric, and β(e1,e1)=1≠0, so it is not alternating. Of the 8 symmetric forms only 2 are alternating.
