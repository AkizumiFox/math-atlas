    0.10  Groups and Permutations

    Several structures in this chapter have quietly behaved alike. The invertible n×n matrices, the nonzero elements of a field, and the bijections of a set can each be combined, have an element that does nothing, and can be undone. This short section gives that common structure a name, proves its basic rules once, and introduces the permutations that the determinant in Chapter 7 is built from. We keep it brief: groups are a language for us here, not a subject.

    0.10.1. Groups

    Look at four situations side by side. In GLn(F), the set of invertible matrices in Mn(F), we multiply matrices, In does nothing, and each A is undone by A−1 (Theorem 0.9.7). In a field F, we multiply nonzero elements, 1 does nothing, and each a is undone by a−1. The four rotations of a square about its center (by 0∘,90∘,180∘,270∘) can be performed one after another, the rotation by 0∘ does nothing, and each rotation is undone by rotating back. The bijections X→X of a set are composed, idX does nothing, and each is undone by its inverse function (Theorem 0.4.7). The objects differ completely, but the rules we use are the same three. So we give the pattern a name.

    A group is a set with one way of combining elements, in which combining is associative, some element does nothing, and every element can be undone.

    Definition 0.10.1 (Group)

    A group is a set G together with a binary operation G×G→G, (a,b)↦ab, such that:

    • (G1) (Associativity) (ab)c=a(bc) for all a,b,c∈G;
    • (G2) (Identity) there is an element e∈G with ea=ae=a for every a∈G;
    • (G3) (Inverses) for every a∈G there is b∈G with ab=ba=e, where e is the element of (G2).

    The group is abelian if moreover ab=ba for all a,b∈G.

    In words: the operation is a function on pairs, so the combination of two elements of G lies in G again; this “closure” is built into the phrase “binary operation G×G→G”. (G1) lets us drop brackets. (G2) asks for an element that changes nothing, from both sides. (G3) asks that each element can be undone, again from both sides, back to that same e. When the operation is addition we write a+b, 0, and −a instead of ab, e, and a−1; this notation is only used for abelian groups.

    Example (Groups)

    Check that each of the following is a group, and decide which are abelian: (Z,+); (F,+) and (F∖{0},⋅) for a field F; GLn(F) under matrix multiplication; the set Sn of bijections {1,…,n}→{1,…,n} under composition; and a one-element set {e} with ee=e.

    Solution. (Z,+): the sum of integers is an integer, addition is associative, 0 is an identity, and −a undoes a. It is abelian. (F,+) is a group for the same reasons, by the field axioms (Definition 0.7.1); it is abelian.

    (F∖{0},⋅): the product of two nonzero elements is nonzero by Theorem 0.7.1, so the operation lands in F∖{0}. Associativity and the identity 1≠0 come from the field axioms, and each a≠0 has an inverse a−1, which is nonzero since aa−1=1≠0. It is abelian.

    GLn(F): by Theorem 0.9.7 (part 3), a product of invertible matrices is invertible, so the operation lands in GLn(F). Associativity holds by Theorem 0.9.4, In is invertible and is an identity, and A−1∈GLn(F) undoes A by part 2. For n≥2 it is not abelian: for n=2, (1101)(1011)=(2111), while the product in the other order is (1112). (Over F2 read 2 as 0; the two products still differ.) For n≥3, put these blocks in the top-left corner and 1’s further down the diagonal. GL1(F) is just F∖{0}, and is abelian.

    Sn: a composition of bijections is a bijection (Theorem 0.4.3), composition is associative (Theorem 0.4.2), id is an identity, and each bijection has an inverse function (Theorem 0.4.7), which is again a bijection. We will see below that Sn is not abelian for n≥3.

    {e}: all three axioms reduce to ee=e. This trivial group is the degenerate case; it reappears as the smallest subgroup of every group.

    Now nonexamples, each a minimal change of an example. Replace addition on Z by multiplication. The operation still lands in Z, it is associative, and 1 is an identity. But (G3) fails: there is no integer b with 2b=1. So (Z,⋅) is not a group. Similarly, replace GLn(F) by all of Mn(F) under multiplication: (G1) and (G2) still hold with In, but the zero matrix has no inverse, so (G3) fails. Keep N under +: the identity 0 is there, but 1 has no inverse in N.

    Warning. The operation must land in the set. GLn(F) under matrix addition is not a group: In and −In are invertible, but In+(−In)=O is not, so addition is not even a binary operation on GLn(F). Before checking (G1)–(G3), check that combining two elements of the set gives an element of the set.

    The rules we proved separately for fields and for matrices follow from the axioms alone. It is worth proving them once:

    Theorem 0.10.1 (Basic properties of groups)

    Let G be a group and a,b,c∈G.

    1. The identity element of G is unique.
    2. The inverse of a is unique. We denote it by a−1.
    3. (a−1)−1=a and (ab)−1=b−1a−1.
    4. (Cancellation) If ab=ac, then b=c. If ba=ca, then b=c.

    Proof. For 1, suppose e and e′ both satisfy (G2). Then e=ee′, using that e′ is an identity, and ee′=e′, using that e is one. Hence e=e′.

    For 2, suppose b and b′ both satisfy ab=ba=e and ab′=b′a=e. By (G2) and (G1), b=be=b(ab′)=(ba)b′=eb′=b′.

    For 3, the equations aa−1=a−1a=e say that a is an inverse of a−1, so (a−1)−1=a by part 2. Next, by (G1), (ab)(b−1a−1)=a(bb−1)a−1=aea−1=aa−1=e, and similarly (b−1a−1)(ab)=b−1(a−1a)b=e. By part 2, (ab)−1=b−1a−1.

    For 4, suppose ab=ac. Multiplying on the left by a−1 and using (G1), b=(a−1a)b=a−1(ab)=a−1(ac)=(a−1a)c=c. The second statement follows by multiplying on the right by a−1. This proves the theorem.

    These are the arguments of Theorem 0.9.7 with matrices erased. That is the point of the definition: a proof that uses only (G1)–(G3) holds in every group at once.

    0.10.2. Subgroups

    After a structure comes the substructure. The even integers sit inside (Z,+) and form a group on their own, with the same operation.

    Definition 0.10.2 (Subgroup)

    Let G be a group. A subset H⊆G is a subgroup of G if e∈H, and ab∈H and a−1∈H for all a,b∈H.

    Then the operation of G restricts to a binary operation on H, and H is a group with it: (G1) holds in H because it holds in G, and (G2), (G3) hold because e and the inverses lie in H. In practice one checks a single condition:

    Theorem 0.10.2 (Subgroup test)

    Let G be a group and H⊆G. Then H is a subgroup of G if and only if H≠∅ and ab−1∈H for all a,b∈H.

    Proof. (⇒) If H is a subgroup, then e∈H, so H≠∅. For a,b∈H we have b−1∈H, and then ab−1∈H.

    (⇐) Suppose H≠∅ and ab−1∈H for all a,b∈H. Pick h∈H. Taking a=b=h gives e=hh−1∈H. For b∈H, taking a=e gives b−1=eb−1∈H. For a,b∈H, we now know b−1∈H, so ab=a(b−1)−1∈H by Theorem 0.10.1. Hence H is a subgroup. This proves the theorem.

    For example, 2Z={2k:k∈Z} is a subgroup of (Z,+). In additive notation the test reads “a−b∈H”, and 2k−2l=2(k−l)∈2Z, while 0∈2Z. By contrast N⊆Z is nonempty and closed under +, but 0−1=−1∉N: the test fails, because N lacks inverses. The set of odd integers fails more badly, since it does not contain 0. In GLn(F), the invertible diagonal matrices form a subgroup: In is one, and by Example (Some invertible matrices) the inverse of diag(d1,…,dn) is diag(d1−1,…,dn−1), so DE−1 is again diagonal with nonzero diagonal entries. Every group G has the subgroups {e} and G.

    0.10.3. Homomorphisms

    After objects come the maps between them that respect the structure.

    Definition 0.10.3 (Group homomorphism)

    Let G and H be groups. A function φ:G→H is a homomorphism if φ(ab)=φ(a)φ(b) for all a,b∈G. A bijective homomorphism is an isomorphism. The kernel of φ is kerφ={g∈G:φ(g)=eH}, where eH is the identity of H.

    The product ab on the left is taken in G, and φ(a)φ(b) on the right in H. For example, F∖{0}→GL2(F), a↦diag(a,1), is a homomorphism, since diag(ab,1)=diag(a,1)diag(b,1); its kernel is {1}. The map Z→Z/nZ, a↦[a], is a homomorphism of additive groups, because [a+b]=[a]+[b] is exactly how addition on Z/nZ was defined (Example (Addition modulo n is well defined)); its kernel is nZ. On the other hand, x↦x+1 from (R,+) to itself is not a homomorphism: writing φ(x)=x+1, we get φ(0+0)=1 but φ(0)+φ(0)=2.

    Theorem 0.10.3 (Basic properties of homomorphisms)

    Let φ:G→H be a homomorphism of groups. Then φ(eG)=eH, φ(a−1)=φ(a)−1 for every a∈G, and kerφ is a subgroup of G.

    Proof. Since φ(eG)φ(eG)=φ(eGeG)=φ(eG)=φ(eG)eH, cancellation (Theorem 0.10.1) gives φ(eG)=eH. Next, φ(a)φ(a−1)=φ(aa−1)=φ(eG)=eH, and similarly φ(a−1)φ(a)=eH, so φ(a−1)=φ(a)−1 by uniqueness of inverses. Finally, eG∈kerφ, and for a,b∈kerφ, φ(ab−1)=φ(a)φ(b)−1=eHeH−1=eH, so ab−1∈kerφ. By Theorem 0.10.2, kerφ is a subgroup. This proves the theorem.

    Two homomorphisms will matter later: the determinant GLn(F)→F∖{0} and the sign Sn→{1,−1}, both in Chapter 7. Linear maps in Chapter 2 are, among other things, homomorphisms of additive groups, and their kernels will be one of our main tools.

    0.10.4. Permutations

    A permutation of {1,…,n} is a bijection {1,…,n}→{1,…,n}, and Sn is the group of all of them, the symmetric group. It has n! elements: there are n choices for σ(1), then n−1 for σ(2), and so on.

    A permutation σ can be written in two-line notation, with σ(i) below i. A more compact notation lists what happens along a loop. For distinct i1,…,ik∈{1,…,n}, the cycle (i1 i2 ⋯ ik) is the permutation sending i1↦i2↦⋯↦ik↦i1 and fixing every other element. A cycle of length 2 is a transposition: (i j) swaps i and j. The same cycle can be written starting at any of its entries: (1 2 3)=(2 3 1)=(3 1 2), but (1 3 2) is different.

    The product στ in Sn means the composition σ∘τ: first apply τ, then σ. So products of cycles are read from right to left.

    Example (Computing with cycles)

    In S3, compute (1 3)(1 2) and (1 2)(1 3). In S5, write σ=(1234535124) (two-line notation) as a product of cycles.

    Solution. For (1 3)(1 2), follow each element through (1 2) first, then (1 3): 1↦2↦2, 2↦1↦3, 3↦3↦1. So (1 3)(1 2)=(1 2 3). For (1 2)(1 3): 1↦3↦3, 3↦1↦2, 2↦2↦1. So (1 2)(1 3)=(1 3 2). The two products differ, so S3 is not abelian; the same two transpositions show that Sn is not abelian for every n≥3.

    For σ, start at 1 and follow: 1↦3↦1, a loop (1 3). The smallest element not yet used is 2: 2↦5↦4↦2, a loop (2 5 4). Every element is now used, so σ=(1 3)(2 5 4). These two cycles move disjoint sets of elements, so they can be applied in either order.

    Warning. Mind the order. στ applies τ first, exactly as for functions, and as for matrices: (AB)x=A(Bx) applies B first. Reading a product of cycles from left to right gives the wrong answer, as the two different products (1 3)(1 2)≠(1 2)(1 3) above show.

    Quick check. Compute (1 2 3)(1 2) in S3.

    Solution. Apply (1 2) first: 1↦2↦3, 2↦1↦2, 3↦3↦1. So 1 and 3 are swapped and 2 is fixed: (1 2 3)(1 2)=(1 3).

    The example showed (1 2 3)=(1 3)(1 2): a 3-cycle is a product of transpositions. Every permutation is, and the proof is a model induction on n.

    Theorem 0.10.4 (Transpositions generate Sn)

    Let n≥2. Every permutation in Sn is a product of transpositions.

    Idea. Induction on n: what is the smaller object inside a permutation of n+1 elements? If σ fixes n+1, it is really a permutation of {1,…,n}. If not, one transposition repairs that: swap σ(n+1) back to n+1. The result fixes n+1, so the induction hypothesis applies, and we undo the swap.

    Proof. We use induction on n≥2 (Theorem 0.2.7). For n=2, S2={id,(1 2)}, and id=(1 2)(1 2).

    Suppose every permutation in Sn is a product of transpositions, and let σ∈Sn+1.

    Case 1. σ(n+1)=n+1. Since σ is injective, σ(i)≠n+1 for i≤n, so σ restricts to a function σ′:{1,…,n}→{1,…,n}. It is injective because σ is, and hence bijective by Theorem 0.4.9. By the induction hypothesis, σ′=τ1⋯τr with transpositions τj∈Sn. Regard each τj as a transposition in Sn+1 fixing n+1. Then τ1⋯τr agrees with σ′=σ on {1,…,n} and fixes n+1, as σ does. Hence σ=τ1⋯τr.

    Case 2. σ(n+1)=k≠n+1. Let τ=(k  n+1). Then (τσ)(n+1)=τ(k)=n+1, so by Case 1, τσ=τ1⋯τr for some transpositions τj. Since ττ=id, multiplying on the left by τ gives σ=ττ1⋯τr, a product of transpositions.

    This completes the induction, and proves the theorem.

    The product is not unique: (1 2 3)=(1 3)(1 2)=(1 2)(2 3), and one can always insert (1 2)(1 2)=id. What turns out to be unique is whether the number of transpositions is even or odd. That fact defines the sign of a permutation, which we do not define here; it is the subject of Chapter 7, where it builds the determinant.

    0.10.5. Exercises

    A. Check your understanding

    Exercise (A1)
    • (a) State the three axioms of a group.
    • (b) Is Z with the operation (a,b)↦a−b a group? Justify your answer.
    • (c) Determine whether the following statement is true: “in every group, (ab)−1=a−1b−1.” Justify your answer.
    • (d) Compute (1 3)(1 2 3) in S3.
    • (e) Explain why {A∈M2(R):A is not invertible} is not a subgroup of GL2(R).

    Solution.

    • (a) (G1) (ab)c=a(bc) for all a,b,c; (G2) there is e with ea=ae=a for all a; (G3) for every a there is b with ab=ba=e. The operation must be a binary operation G×G→G.
    • (b) No. Associativity fails: (1−1)−1=−1, but 1−(1−1)=1.
    • (c) False. By Theorem 0.10.1, (ab)−1=b−1a−1, and this can differ from a−1b−1. In S3 take a=(1 2) and b=(1 3), which are their own inverses. By Example (Computing with cycles), ab=(1 3 2), whose inverse is (1 2 3), while a−1b−1=ab=(1 3 2). The statement is true in abelian groups.
    • (d) Apply (1 2 3) first: 1↦2↦2, 2↦3↦1, 3↦1↦3. Hence (1 3)(1 2 3)=(1 2).
    • (e) It is not even a subset of GL2(R), since its elements are not invertible; for instance it does not contain the identity I2.

    B. Practice

    Exercise (B1: The table of S3)

    List the six elements of S3 in cycle notation and write out the table whose entry in row x and column y is xy. Hence find all elements x∈S3 with x2=id, and all x that commute with every element of S3.

    Solution. The elements are id,(1 2),(1 3),(2 3),(1 2 3),(1 3 2). Computing each product right to left, as in Example (Computing with cycles), the entry in row x, column y is xy:

    id id (12) (13) (23) (123) (132)
    (12) (12) id (132) (123) (23) (13)
    (13) (13) (123) id (132) (12) (23)

    (132) (132) (23) (12) (13) id (123)

    For example, the entry in row (1 2), column (2 3) is (1 2)(2 3): 1↦1↦2, 2↦3↦3, 3↦2↦1, which is (1 2 3).

    Reading the diagonal, x2=id exactly for x=id,(1 2),(1 3),(2 3). An element x commutes with every element exactly when row x equals column x. This holds for id. It fails for every other element: (1 2)(1 3)=(1 3 2)≠(1 2 3)=(1 3)(1 2) handles (1 2) and (1 3); (2 3)(1 2)=(1 3 2)≠(1 2 3)=(1 2)(2 3) handles (2 3); and (1 2 3)(1 2)=(1 3)≠(2 3)=(1 2)(1 2 3) handles (1 2 3) and, since (1 3 2)(1 2)=(2 3)≠(1 3)=(1 2)(1 3 2), also (1 3 2). Hence only id commutes with everything.

    Exercise (B2: Invertible upper triangular matrices)

    Let F be a field and T={(ab0d):a,b,d∈F, a≠0, d≠0}.

    • (a) Prove that T is a subgroup of GL2(F).
    • (b) For which fields F is T abelian? Justify your answer.

    Solution.

    • (a) Let X=(ab0d)∈T. Since a,d≠0, ad−b⋅0=ad≠0 by Theorem 0.7.1, so X is invertible by Theorem 0.9.8. Hence T⊆GL2(F), and T≠∅ since I2∈T. Now let Y=(a′b′0d′)∈T. By Theorem 0.9.8, Y−1=(a′d′)−1(d′−b′0a′)=(a′−1−b′(a′d′)−10d′−1). Therefore XY−1=(aa′−1−ab′(a′d′)−1+bd′−10dd′−1), whose (2,1)-entry is 0 and whose diagonal entries aa′−1, dd′−1 are nonzero by Theorem 0.7.1. So XY−1∈T, and T is a subgroup by Theorem 0.10.2.
    • (b) It depends on the field. Case 1: F has an element c with c≠0 and c≠1 (for example c=2 in R or F3). Let X=(1101) and Y=diag(1,c), both in T. Then XY=(1c0c) and YX=(110c), which differ in the (1,2)-entry since c≠1. So T is not abelian. Case 2: F={0,1}, that is, F=F2. Then a=d=1 is forced, so T={(1b01):b∈F2}, and (1b01)(1b′01)=(1b+b′01) is symmetric in b,b′. So T is abelian over F2, and over every other field it is not.
    Exercise (B3: The exponential is an isomorphism)

    Let R>0={x∈R:x>0}. Show that (R>0,⋅) is a group, and that exp:(R,+)→(R>0,⋅), x↦ex, is an isomorphism. What is its kernel? You may use the familiar facts ex+y=exey, ex>0, and that ln:R>0→R satisfies ln⁡(ex)=x and eln⁡y=y.

    Solution. A product of positive reals is positive, so multiplication is a binary operation on R>0. It is associative, 1∈R>0 is an identity, and for y>0 the inverse 1/y is positive. Hence (R>0,⋅) is a group.

    Since ex>0, exp maps R into R>0, and ex+y=exey says exactly that it is a homomorphism from (R,+) to (R>0,⋅). The function ln satisfies ln∘exp=idR and exp∘ln=idR>0, so exp is bijective by Theorem 0.4.7. Hence exp is an isomorphism. Its kernel is {x∈R:ex=1}={0}, since exp is injective and e0=1.

    C. Going deeper

    Exercise (C1: Every element its own inverse)
    • (a) Let G be a group in which g2=gg=e for every g∈G. Prove that G is abelian.
    • (b) Show that (M2(F2),+) is an example of such a group, written additively.

    Solution.

    • (a) Let a,b∈G. The hypothesis gg=e says that every g is its own inverse, by uniqueness of inverses (Theorem 0.10.1). Applying this to ab, a, and b, and using Theorem 0.10.1, ab=(ab)−1=b−1a−1=ba. Hence G is abelian.
    • (b) (M2(F2),+) is a group by Theorem 0.9.1: addition is associative, O is an identity, and −A is an inverse. In additive notation, “g2=e” reads A+A=O, and indeed (A+A)ij=aij+aij=(1+1)aij=0 in F2. (This group is abelian anyway, consistent with (a).)
    Exercise (C2: The order of a product of disjoint cycles)

    The order of σ∈Sn is the smallest integer m≥1 with σm=id, where σm is the product of m copies of σ. Two cycles are disjoint if no element appears in both.

    • (a) Let σ=(i1 ⋯ ik) be a k-cycle. Prove that σm=id if and only if k divides m. Deduce that σ has order k.
    • (b) Prove that disjoint cycles σ and τ commute, and deduce (στ)m=σmτm for all m≥1.
    • (c) Let σ be a k-cycle and τ an l-cycle, disjoint. Prove that στ has order lcm(k,l).
    • (d) Find the order of (1 2)(3 4 5)∈S5.

    Hint for (c): σm moves only elements that appear in σ.

    Solution.

    • (a) Index the entries of the cycle modulo k, so σ(ij)=ij+1 with ik+1=i1. By induction on m, σm(ij)=ij+m, indices taken modulo k, and σm fixes every element not in the cycle. Hence σm=id if and only if ij+m=ij for all j. Since i1,…,ik are distinct, this holds if and only if j+m≡j(modk), that is, k∣m. The smallest m≥1 with k∣m is k, so σ has order k.
    • (b) Let A and B be the disjoint sets of elements appearing in σ and τ. Note that σ maps A to A and fixes everything outside A, and τ does the same with B. Let i∈{1,…,n}. If i∈A, then i∉B and σ(i)∈A, so σ(i)∉B; hence στ(i)=σ(i)=τσ(i). The case i∈B is the same with the roles swapped. If i∉A∪B, both sides give i. Hence στ=τσ. Then (στ)m=σmτm follows by induction on m: (στ)m+1=σmτmστ=σmστmτ=σm+1τm+1, moving σ past τ one factor at a time, which is allowed because they commute.
    • (c) By (b), (στ)m=σmτm. We claim this is id if and only if σm=id and τm=id. One direction is clear. Conversely, suppose σmτm=id, and let i∈A. Then i∉B, so τm(i)=i by the hint, and σm(i)=σmτm(i)=i. Since σm also fixes every i∉A, σm=id, and then τm=σmτm=id as well. By (a), (στ)m=id if and only if k∣m and l∣m. The smallest such m≥1 is lcm(k,l), which is therefore the order of στ.
    • (d) (1 2) and (3 4 5) are disjoint cycles of lengths 2 and 3, so by (c) the order is lcm(2,3)=6.
