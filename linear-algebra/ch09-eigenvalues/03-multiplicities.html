    2. 9.3  Algebraic and Geometric Multiplicity

    Algebraic and Geometric Multiplicity

    An eigenvalue can be counted in two ways. It is a root of the characteristic polynomial, and a root has a multiplicity. It also has an eigenspace, and a subspace has a dimension. The two numbers need not agree, and the gap between them is exactly what can stop an operator from having a diagonal matrix. This section defines both counts, proves that the dimension never exceeds the root multiplicity, and shows that the root multiplicities package the trace and the determinant. The next section turns the comparison into a test for diagonalizability.

    9.3.1 Two ways to count an eigenvalue

    Compare two matrices over any field F: 2I2=(2002),J=(2102). Both are triangular with diagonal 2,2, so both have characteristic polynomial (x−2)2 and spectrum {2}. By the only measure we have so far, the eigenvalue data agree. Yet the eigenvectors are very different. For 2I2, every nonzero vector is an eigenvector and E2=F2. For J, the matrix J−2I=(0100) kills exactly the multiples of e1, so E2(J)=span(e1) is a line. The root 2 “counts twice” in both characteristic polynomials, but it supplies two independent eigenvectors for 2I2 and only one for J. Both numbers deserve names.

    The algebraic multiplicity counts an eigenvalue as a root; the geometric multiplicity counts the independent eigenvectors it supplies.

    Definition 9.3.1 (Algebraic Multiplicity)

    Let V be a finite-dimensional vector space over F with dim⁡V≥1, let T∈L(V) and λ∈F. The algebraic multiplicity of λ for T is aT(λ):=multλ(pT), the multiplicity of λ as a root of the characteristic polynomial (Definition 6.4.1). For A∈Mn(F), aA(λ):=multλ(pA).

    Definition 9.3.2 (Geometric Multiplicity)

    Let V be a finite-dimensional vector space over F, T∈L(V), and λ∈F. The geometric multiplicity of λ for T is gT(λ):=dim⁡Eλ(T)=dim⁡ker(T−λidV). For A∈Mn(F), gA(λ):=dim⁡Eλ(A)=n−rank(A−λIn).

    When T or A is clear from context we write simply a(λ) and g(λ).

    In words: aT(λ) is the largest m such that (x−λ)m divides pT. It is a statement about a polynomial and can be computed by factoring. gT(λ) is the dimension of the subspace of solutions of Tv=λv, including 0. It is the largest number of linearly independent eigenvectors for λ, not the number of eigenvectors, which is infinite over an infinite field. For matrices the second formula comes from Theorem 3.5.7 applied to A−λIn, and it is the one we compute with: find the rank of A−λI by elimination and subtract from n.

    Well-definedness. Both numbers are defined for every λ∈F, eigenvalue or not. By Theorem 9.2.1, λ is an eigenvalue if and only if pT(λ)=0, if and only if aT(λ)≥1; and by Definition 9.2.1, if and only if Eλ(T)≠{0}, that is, gT(λ)≥1. So for a scalar that is not an eigenvalue both multiplicities are 0, and for an eigenvalue both are at least 1. Neither depends on a basis: pT does not (Definition 7.10.2), and Eλ(T) is defined without one. If B is a basis of V, then aT(λ)=a[T]BB(λ) because pT=p[T]BB, and gT(λ)=g[T]BB(λ) because the coordinate map is an isomorphism from ker(T−λidV) onto nul([T]BB−λI) (Theorem 4.1.5 (a) and Corollary 4.1.3).

    Examples.

    • The hook. For 2I2: a(2)=2 and g(2)=2−rankO=2. For J: a(2)=2 and g(2)=2−rank(0100)=1.
    • A 1×1 matrix. For A=(c), pA=x−c, so a(c)=1, and A−cI=O1 has rank 0, so g(c)=1. This degenerate case already shows the pattern of the theorem below: the two counts can only differ when there is room, a repeated root.
    • Differentiation. On V=R[x]≤n, the matrix of D in the basis (1,x,…,xn) is strictly upper triangular, so pD=xn+1 and aD(0)=n+1. But E0(D) is the line of constant polynomials (the examples after Definition 9.2.2), so gD(0)=1. The gap can be as large as n.
    • A matrix from Chapter 7. For A=(201131102), Example (A 3×3 Characteristic Polynomial) found pA=(x−1)(x−3)2, so a(1)=1 and a(3)=2. The matrix A−3I=(−10110110−1) has a zero column, and its first two rows are independent while the third is minus the first, so its rank is 2 and g(3)=3−2=1. Similarly A−I=(101121101) has third row equal to the first and first two rows independent, so its rank is 2 and g(1)=1.

    Minimal change. Take the triangular matrices B=(201020001),B′=(211020001), which differ in one entry. Both have p=(x−2)2(x−1), so a(2)=2 for both: the algebraic multiplicity does not notice the change. But B−2I has nonzero rows (0,0,1) and (0,0,−1), rank 1, so gB(2)=2; while B′−2I has rows (0,1,1) and (0,0,−1), rank 2, so gB′(2)=1. One off-diagonal entry, invisible to p, removed an eigenvector.

    Why these definitions. The algebraic multiplicity is the natural count for a polynomial: with it, the roots of pT add up to deg⁡pT=dim⁡V whenever pT splits (Theorem 6.4.3), and the trace and determinant come out right (Theorem 9.3.3 below). The geometric multiplicity is the natural count for eigenvectors: it is the number of basis vectors we can take from Eλ(T) when we try to build a basis of eigenvectors. The names record where each number lives, in algebra (a polynomial) or in geometry (a subspace).

    Warning. The geometric multiplicity is not read off from pT. Two operators with the same characteristic polynomial can have different geometric multiplicities: 2I2 and J above, or B and B′. To find g(λ) you must compute rank(A−λI). Also, g(λ) is not “how many eigenvectors” λ has: over R, Eλ≠{0} always contains infinitely many eigenvectors.

    Quick check. Find a(0) and g(0) for N=(010000000)∈M3(F).

    Solution. N is triangular with zero diagonal, so pN=x3 and a(0)=3. The rank of N−0I=N is 1, so g(0)=3−1=2, with E0(N)=span(e1,e3).

    9.3.2 The geometric multiplicity never exceeds the algebraic

    In every example so far, g(λ)≤a(λ). That is always the case.

    Theorem 9.3.1 (Geometric Multiplicity Is at Most Algebraic Multiplicity)

    Let V be a finite-dimensional vector space over F with dim⁡V=n≥1, let T∈L(V), and let λ∈F be an eigenvalue of T. Then 1≤gT(λ)≤aT(λ).

    Idea. Start from the smallest subspace in sight, Eλ(T). Take a basis of it and extend it to a basis of V. In that basis, the first g columns of the matrix are λe1,…,λeg, so the matrix is block upper triangular with top-left block λIg. The block triangular determinant then factors (x−λ)g out of pT, and a root with a factor (x−λ)g has multiplicity at least g. The inequality can be strict because the other block may contribute further factors x−λ, as it does for J.

    Proof. Since λ is an eigenvalue, Eλ(T)≠{0}, so g=gT(λ)≥1. Let (v1,…,vg) be a basis of Eλ(T). By Theorem 1.6.5, it extends to a basis B=(v1,…,vg,w1,…,wn−g) of V.

    Case g=n. Then Tvi=λvi for every basis vector, so [T]BB=λIn by Definition 4.1.1, and pT=(x−λ)n by the triangular case of Definition 7.10.1. Hence aT(λ)=n=g.

    Case g<n. For i≤g, Tvi=λvi, so column i of [T]BB is λei. Hence [T]BB=(λIgBOD),xIn−[T]BB=((x−λ)Ig−BOxIn−g−D), for some B∈Mg×(n−g)(F) and D∈Mn−g(F). The second matrix is block upper triangular over F[x] with square diagonal blocks. By Theorem 7.8.4, which holds over the commutative ring F[x] (the remark after it), and Definition 7.10.2, pT=det((x−λ)Ig)det(xIn−g−D)=(x−λ)gpD, where det((x−λ)Ig)=(x−λ)g because the matrix is diagonal. So (x−λ)g∣pT. By Definition 6.4.1, aT(λ), the largest m with (x−λ)m∣pT, satisfies aT(λ)≥g. This proves the theorem.

    The inequality is strict exactly when λ is also a root of pD, the characteristic polynomial of the “rest” of the operator. For J, with B=(e1,e2), the block D is (2), and pD=x−2 contributes the second factor.

    A useful consequence: if a(λ)=1, then g(λ)=1. A simple root of pT always has a one-dimensional eigenspace, and so the only eigenvalues whose eigenspaces need checking are the repeated ones.

    Both multiplicities are properties of the operator, not of the basis, so they cannot distinguish similar matrices. That makes them tools for proving that two matrices are not similar.

    Proposition 9.3.2 (Similar Matrices Have the Same Multiplicities)

    Let A,B∈Mn(F) with A∼B, and let λ∈F. Then aA(λ)=aB(λ) and gA(λ)=gB(λ).

    Proof. Let B=P−1AP. By Theorem 7.10.3, pA=pB, so the algebraic multiplicities agree. Also B−λI=P−1AP−λP−1P=P−1(A−λI)P, so B−λI∼A−λI, and these have the same rank by Proposition 4.2.6 (a). Hence gB(λ)=n−rank(B−λI)=n−rank(A−λI)=gA(λ).

    For example, 2I2 and J have the same characteristic polynomial but g(2)=2 versus g(2)=1, so they are not similar. The same test shows B≁B′ in the minimal change above.

    Warning. A repeated eigenvalue does not force a shortage of eigenvectors, and equal eigenvalues do not force similarity. The identity I2 has the repeated eigenvalue 1, yet g(1)=a(1)=2 and its matrix is as simple as possible. In the other direction, I2 and (1101) have the same eigenvalues with the same algebraic multiplicities, and they are not similar. Even agreement of both multiplicities for every eigenvalue does not force similarity; Exercise (C2: Multiplicities do not determine similarity) gives two 4×4 matrices showing this.

    9.3.3 Multiplicities, trace, and determinant

    By Theorem 6.4.3, the algebraic multiplicities of the eigenvalues of T add up to at most deg⁡pT=dim⁡V, with equality exactly when pT splits over F. Over C this always happens (Corollary 6.5.5). When it does, pT is determined by the eigenvalues and their algebraic multiplicities, pT=(x−λ1)a(λ1)⋯(x−λk)a(λk), and two of its coefficients are familiar: by Theorem 7.10.2, the coefficient of xn−1 is −trT and the constant term is (−1)ndetT. Comparing the two descriptions expresses trace and determinant through eigenvalues.

    Theorem 9.3.3 (Trace and Determinant from Eigenvalues)

    Let V be a finite-dimensional vector space over F with dim⁡V=n≥1, and let T∈L(V). Suppose pT splits over F, and let λ1,…,λk be the distinct eigenvalues of T. Then a(λ1)+⋯+a(λk)=n,trT=∑i=1ka(λi)λi,detT=∏i=1kλia(λi). In words: listing each eigenvalue as often as its algebraic multiplicity, the trace is the sum of the list and the determinant is its product. In particular this holds for every operator on a nonzero finite-dimensional complex space, and for every A∈Mn(C).

    Idea. Rather than expanding a product of linear factors by hand, notice that the product is itself a characteristic polynomial: that of the diagonal matrix with the eigenvalues on its diagonal. Chapter 7 already knows the xn−1 coefficient and the constant term of any characteristic polynomial, so we read them off twice and compare.

    Proof. Since pT splits and is monic of degree n (Theorem 7.10.2), Definition 6.4.2 gives pT=(x−c1)⋯(x−cn) for some c1,…,cn∈F. For c,λ∈F, the polynomial x−c has multλ(x−c)=1 if c=λ and 0 otherwise, since λ is a root of x−c only when c=λ (Theorem 6.1.3). So by Theorem 6.4.2, multλ(pT)=∑jmultλ(x−cj) is the number of indices j with cj=λ. In particular the values occurring among c1,…,cn are exactly the roots of pT in F, which are λ1,…,λk by Theorem 9.2.1, and λi occurs exactly a(λi) times. Counting the n factors gives ∑ia(λi)=n, and c1+⋯+cn=∑ia(λi)λi,c1⋯cn=∏iλia(λi). Let C=diag(c1,…,cn). It is triangular, so pC=(x−c1)⋯(x−cn)=pT (the examples after Definition 7.10.1). Apply Theorem 7.10.2 to both C and T: the coefficient of xn−1 in this one polynomial is −trC=−(c1+⋯+cn) and also −trT; the constant term is (−1)ndetC=(−1)nc1⋯cn (Theorem 7.4.6) and also (−1)ndetT. Hence trT=c1+⋯+cn and detT=c1⋯cn, which are the displayed formulas. The complex case follows from Corollary 6.5.5.

    Examples.

    • For A=(201131102), with a(1)=1 and a(3)=2: trA=2+3+2=7=1+3+3, and detA=9=1⋅3⋅3.
    • For the real matrix (3−24−1) of Example (A Real Matrix with Non-Real Eigenvalues), p does not split over R, but it splits over C with roots 1±2i. The theorem over C gives (1+2i)+(1−2i)=2=trA and (1+2i)(1−2i)=1+4=5=detA. The trace and determinant are real, while the eigenvalues are not.
    • For a 2×2 matrix whose characteristic polynomial splits, the theorem says the eigenvalues λ,μ (listed with multiplicity) satisfy λ+μ=trA and λμ=detA. This is a quick way to guess eigenvalues: for (1232), we want two numbers with sum 3 and product −4, namely 4 and −1.

    Without splitting, the theorem says nothing. If pT does not split, the eigenvalues in F, counted with algebraic multiplicity, do not account for all of pT, and summing or multiplying them gives no information. For A=(3−24−1) over R there are no eigenvalues: the multiplicities add up to 0≠2, the empty sum 0 is not trA=2, and the empty product 1 is not detA=5. For the real rotation (0−110), with trace 0 and determinant 1, the empty sum and product happen to give the right values, but only by coincidence. For real matrices the remedy is to pass to C, where pA always splits, as in the second example above.

    9.3.4 Exercises

    A. Check your understanding

    Exercise (A1)
    • (a) Define the algebraic and the geometric multiplicity of λ∈F for A∈Mn(F).
    • (b) State the inequality between them for an eigenvalue λ, and name the tool its proof uses.
    • (c) True or false: if a(λ)=1, then g(λ)=1. Justify your answer.
    • (d) True or false: for every A∈Mn(C), the geometric multiplicities of the eigenvalues add up to n. Justify your answer.
    • (e) True or false: if A,B∈Mn(F) have the same characteristic polynomial, then gA(λ)=gB(λ) for every λ. Justify your answer.
    • (f) For A∈M3(C) with eigenvalues 2 (algebraic multiplicity 2) and −1, what are trA and detA?

    Solution.

    • (a) aA(λ)=multλ(pA), the largest m with (x−λ)m∣pA; gA(λ)=dim⁡Eλ(A)=n−rank(A−λI) (Definition 9.3.1, Definition 9.3.2).

    • (b) 1≤g(λ)≤a(λ) (Theorem 9.3.1). The proof extends a basis of Eλ to a basis of the space and uses the block triangular determinant (Theorem 7.8.4) over F[x].

    • (c) True. An eigenvalue has g(λ)≥1, and g(λ)≤a(λ)=1.

    • (d) False. For J=(2102), the only eigenvalue is 2, with g(2)=1≠2. (The algebraic multiplicities do add up to n over C.)

    • (e) False. 2I2 and J both have p=(x−2)2, but g(2)=2 and g(2)=1.

    • (f) By Theorem 9.3.3, listing eigenvalues with algebraic multiplicity as 2,2,−1: trA=3 and detA=−4.

    B. Practice

    Exercise (B1: Computing multiplicities)

    For each real matrix, find every eigenvalue together with its algebraic and geometric multiplicity.

    • (a) A1=(4−112).
    • (b) A2=(21101−1−1−11).
    • (c) A3=(211−10−1112), given that pA3=pA2.
    • (d) The matrix of the operator S(q)(x)=q(x+1) on R[x]≤2, in the basis (1,x,x2).

    Solution.

    • (a) trA1=6, detA1=8+1=9, so p=x2−6x+9=(x−3)2: the only eigenvalue is 3, with a(3)=2. A1−3I=(1−11−1) has rank 1, so g(3)=1.

    • (b) Expand det(xI−A2) along the first column: det(x−2−1−10x−1111x−1)=(x−2)[(x−1)2−1]+1⋅det(−1−1x−11). The first bracket is x2−2x=x(x−2) and the last determinant is −1+(x−1)=x−2, so pA2=(x−2)(x2−2x+1)=(x−1)2(x−2). Thus a(1)=2 and a(2)=1. By Theorem 9.3.1, g(2)=1. For λ=1, A2−I=(11100−1−1−10). Row 3 is −(row 1)−(row 2), and rows 1 and 2 are independent, so the rank is 2 and g(1)=1.

    • (c) Here a(1)=2 and a(2)=1, as for A2, so g(2)=1. Now A3−I=(111−1−1−1111) has all rows multiples of (1,1,1), so its rank is 1 and g(1)=2. By Proposition 9.3.2, A2 and A3 are not similar, although they have the same characteristic polynomial.

    • (d) S(1)=1, S(x)=1+x, S(x2)=1+2x+x2, so the matrix is (111012001) (as in Example (Characteristic Polynomials of Two Operators)). It is triangular, so p=(x−1)3 and a(1)=3. The matrix minus I is (011002000), of rank 2, so g(1)=1: the only polynomials with q(x+1)=q(x) in R[x]≤2 are the constants.

    Exercise (B2: A parameter that merges eigenvalues)

    For t∈R, let At=(t1−13). Find all t for which At has a real eigenvalue λ with g(λ)<a(λ).

    Solution. trAt=t+3 and detAt=3t+1, so p(x)=x2−(t+3)x+(3t+1). For a 2×2 matrix, g(λ)<a(λ) is possible only if a(λ)=2, because a(λ)=1 forces g(λ)=1 (Theorem 9.3.1). So p must have a repeated real root, which happens exactly when its discriminant vanishes: (t+3)2−4(3t+1)=t2−6t+5=(t−1)(t−5)=0. If t=1, then p=x2−4x+4=(x−2)2 and A1−2I=(−11−11), of rank 1, so g(2)=1<2=a(2). If t=5, then p=(x−4)2 and A5−4I=(11−1−1), of rank 1, so g(4)=1<2. Hence the answer is t∈{1,5}. (In both cases g=a was impossible anyway: g(λ)=2 would mean At−λI=O, but the off-diagonal entries of At are nonzero.)

    Exercise (B3: Eigenvalues from trace and determinant)
    • (a) Let A∈M3(R) have the eigenvalue 1+i (as a complex matrix) and detA=6. Find all eigenvalues of A over C, and trA.
    • (b) Let B∈M2(R) with trB=6 and detB=9. Show that spec(B)={3} with a(3)=2. Give one such B with g(3)=2 and one with g(3)=1.

    Solution.

    • (a) By Theorem 9.2.5, 1−i is also an eigenvalue. By Corollary 6.5.5, pA splits over C into three linear factors, and two of them are x−(1+i) and x−(1−i); let μ be the third root. By Theorem 9.3.3, 6=detA=(1+i)(1−i)μ=2μ, so μ=3. Hence the eigenvalues are 1+i,1−i,3, and trA=(1+i)+(1−i)+3=5.

    • (b) By Theorem 7.10.2, pB=x2−6x+9=(x−3)2. So spec(B)={3} and a(3)=2. For B=3I2, g(3)=2. For B=(4−112) of Exercise (B1: Computing multiplicities) (a), trB=6, detB=9, and g(3)=1.

    C. Going deeper

    Exercise (C1: Nilpotent matrices)

    Let A∈Mn(C), n≥1, be nilpotent (Ak=O for some k≥1).

    • (a) Prove that a(0)=n and g(0)=n−rankA.
    • (b) Deduce that g(0)=a(0) if and only if A=O.
    • (c) For N=(0100001000010000), check that N4=O and compute g(0). How large can a(0)−g(0) be for a nilpotent n×n matrix?

    Solution.

    • (a) By Exercise (C2: Nilpotent operators) (b), pA=xn, so a(0)=mult0(xn)=n. By Definition 9.3.2, g(0)=n−rank(A−0I)=n−rankA.

    • (b) By (a), g(0)=a(0) if and only if n−rankA=n, that is, rankA=0, that is, A=O (a matrix of rank 0 has no nonzero column).

    • (c) Ne1=0 and Nej=ej−1 for j≥2. So Njei=0 once j≥i, and N4ei=0 for i≤4; hence N4=O. The columns of N are 0,e1,e2,e3, so rankN=3 and g(0)=1, while a(0)=4. In general, a nilpotent A has 0∈spec(A) (Exercise (C2: Nilpotent operators) (a)), so g(0)≥1 and a(0)−g(0)≤n−1; the n×n analogue of N, with ones just above the diagonal, has rank n−1 and attains a(0)−g(0)=n−1.

    Exercise (C2: Multiplicities do not determine similarity)

    Let M1=(1100010000110001),M2=(1100011000100001)∈M4(R).

    • (a) Show that M1 and M2 have the same eigenvalues with the same algebraic and geometric multiplicities.
    • (b) Compute rank(M1−I)2 and rank(M2−I)2. Deduce that M1≁M2.
    • (c) Construct a matrix M∈M4(R) with spec(M)={2,5}, a(2)=3, g(2)=1, and a(5)=g(5)=1.

    Hint: for (b), if B=P−1AP, relate (B−I)2 to (A−I)2.

    Solution.

    • (a) Both matrices are upper triangular with diagonal 1,1,1,1, so both have p=(x−1)4, spectrum {1}, and a(1)=4. The matrix M1−I has columns 0,e1,0,e3, of rank 2; M2−I has columns 0,e1,e2,0, also of rank 2. So g(1)=4−2=2 for both.

    • (b) Let N1=M1−I, so N1e2=e1, N1e4=e3, and N1e1=N1e3=0. Then N12 kills every ej, so N12=O and rankN12=0. Let N2=M2−I, so N2e2=e1, N2e3=e2, and N2e1=N2e4=0. Then N22e3=e1≠0 and N22 kills e1,e2,e4, so N22=E13 has rank 1.

      Suppose M2=P−1M1P. With p(x)=(x−1)2, Proposition 4.2.6 (c) gives (M2−I)2=P−1(M1−I)2P, and then (a) of the same proposition gives equal ranks, 1=0. This contradiction shows M1≁M2. So eigenvalues together with both multiplicities do not determine a matrix up to similarity; Chapter 10 finds invariants that do.

    • (c) Take M=(2100021000200005). It is triangular, so pM=(x−2)3(x−5), a(2)=3, and a(5)=1, hence g(5)=1 by Theorem 9.3.1. The matrix M−2I has columns 0,e1,e2,3e4, which has rank 3, so g(2)=4−3=1.
