    3.3  Uniqueness of the Reduced Form

    Gauss–Jordan elimination involves choices: which nonzero entry to use as a pivot, and in what order to perform the operations. Different choices give different intermediate matrices, and different row echelon forms. The previous section claimed that they always end at the same reduced row echelon form. This matters more than it seems. Pivot columns, free variables, and later the rank of a matrix are all read off from the reduced form; if two people could reduce the same matrix to two different answers, none of these would be well defined. This section proves the claim.

    3.3.1. What row operations remember

    Row operations change the columns of a matrix. What do they keep? Take A=(121324023627)and its RREFR=(120100120000) over R (the computation is carried out in an example later in this section). The columns of R look nothing like those of A. But look at how the columns depend on each other. In R, column 2 is twice column 1, and column 4 is column 1 plus twice column 3. In A, with columns a1,…,a4, a2=(2,4,6)=2a1,a4=(3,2,7)=(1,2,3)+2(1,0,2)=a1+2a3. The same relations, with the same coefficients. This is no accident. A relation x1a1+⋯+xnan=0 among the columns says Ax=0 (Theorem 0.9.3), and row operations do not change the solutions of a homogeneous system.

    Lemma 3.3.1 (Row equivalent matrices have the same homogeneous solutions)

    Let A,B∈Mm×n(F) be row equivalent. Then for every x∈Fn, Ax=0 if and only if Bx=0.

    Proof. Let a sequence of elementary row operations turn A into B. By Lemma 3.2.1, the same sequence turns [A∣0] into [B∣0′], where 0′ is obtained from the zero column by row operations and so is again the zero column. Hence [A∣0] and [B∣0] are row equivalent, and by Theorem 3.2.2 (c) the systems Ax=0 and Bx=0 have the same solution set.

    Rewriting Ax as a combination of columns turns the lemma into the statement we observed.

    Lemma 3.3.2 (Row operations preserve column relations)

    Let A,B∈Mm×n(F) have columns a1,…,an and b1,…,bn, and suppose that Ax=0⇔Bx=0 for every x∈Fn. This holds, for instance, if A and B are row equivalent (Lemma 3.3.1). Then:

    • (a) for all x1,…,xn∈F: x1a1+⋯+xnan=0 if and only if x1b1+⋯+xnbn=0;
    • (b) for every index l and all scalars d1,…,dl−1: al=d1a1+⋯+dl−1al−1 if and only if bl=d1b1+⋯+dl−1bl−1;
    • (c) for every index l: al∈span(a1,…,al−1) if and only if bl∈span(b1,…,bl−1).

    Proof.

    • (a) By Theorem 0.9.3, x1a1+⋯+xnan=Ax and x1b1+⋯+xnbn=Bx, where x=(x1,…,xn). The hypothesis says Ax=0⇔Bx=0.

    • (b) The equation al=d1a1+⋯+dl−1al−1 holds if and only if d1a1+⋯+dl−1al−1+(−1)al+0al+1+⋯+0an=0. By (a), with these coefficients, this holds if and only if the same combination of the bj is 0, that is, bl=d1b1+⋯+dl−1bl−1.

    • (c) By Definition 1.3.2, al∈span(a1,…,al−1) means that the left side of (b) holds for some scalars d1,…,dl−1. By (b) this happens if and only if the right side holds for some scalars, which means bl∈span(b1,…,bl−1).

    Warning. Row operations preserve column relations, not columns or their span. For A=(1212) over R, the operation R2→R2−R1 gives (1200). The relation “column 2 =2⋅ column 1” holds in both. But every column of A lies on the line span((1,1)), and every column of the new matrix lies on the different line span((1,0)). So the span of the columns changed. To answer a question about the columns of A themselves, find the relations from the reduced form, and then use them on the columns of A.

    3.3.2. The columns of a reduced matrix

    In a matrix in RREF, the column relations can be read off at a glance: pivot columns are standard basis vectors, and a nonpivot column displays its own coefficients. We record this precisely, together with a description of the pivot columns that does not mention pivots at all.

    Lemma 3.3.3 (Columns of a matrix in RREF)

    Let R∈Mm×n(F) be in reduced row echelon form, with entries ril, columns u1,…,un, and pivot columns j1<⋯<jr.

    • (a) For each i=1,…,r, the pivot column uji is ei.
    • (b) If l is not a pivot column, then ul=∑i:ji<lrilei=∑i:ji<lriluji.
    • (c) Column l is a pivot column if and only if ul∉span(u1,…,ul−1).

    Proof.

    • (a) By (E3) the entry of uji in row i is 1, and by (E4) its other entries are 0.

    • (b) Let l be a nonpivot column, and look at the entry ril in each row i. If i>r, row i is zero by (E1), so ril=0. If i≤r and ji>l, then ril lies strictly before the leading entry of row i, so ril=0. The case ji=l does not occur, since l is not a pivot column. So the only possibly nonzero entries of ul are the ril with ji<l, which gives the first expression; the second follows from (a).

    • (c) If l is not a pivot column, (b) writes ul as a combination of the columns uji with ji<l, so ul∈span(u1,…,ul−1). Conversely, let l=ji be a pivot column. For each l′<ji, the entry ril′ lies before the leading entry of row i, so it is 0. Hence every vector of span(u1,…,ul−1), being a combination of vectors with i-th entry 0, has i-th entry 0. But ul=ei has i-th entry 1≠0, so ul∉span(u1,…,ul−1).

    Part (c) says: reading the columns from left to right, a column gets a pivot exactly when it is new, not a combination of the columns before it. That condition is about column relations only, and column relations survive row operations. This is the whole idea of the uniqueness proof.

    3.3.3. The uniqueness theorem

    We can now prove that the reduced form depends only on the homogeneous solutions, and hence not on the operations used to reach it.

    Theorem 3.3.4 (Uniqueness of the reduced row echelon form)

    Let R,R′∈Mm×n(F) be in reduced row echelon form, and suppose that Rx=0⇔R′x=0 for every x∈Fn. Then R=R′.

    Consequently, every matrix A∈Mm×n(F) is row equivalent to exactly one matrix in reduced row echelon form, called the RREF of A.

    Idea. A column dependence ∑jxjuj=0 is exactly a null vector x, so R and R′ have the same column relations. The pivot columns are exactly the columns that are not combinations of earlier columns (Lemma 3.3.3 (c)), so R and R′ have the same pivot columns. A pivot column is a standard basis vector in both. A nonpivot column of an RREF matrix is determined by how it is built from the pivot columns before it (Lemma 3.3.3 (b)), and that recipe is a column relation, so it is the same in both. Hence every column agrees.

    Proof. Let u1,…,un and u1′,…,un′ be the columns of R and R′, and ril the entries of R. By hypothesis, Lemma 3.3.2 applies to R and R′.

    Same pivot columns. For each l, by Lemma 3.3.2 (c), ul∈span(u1,…,ul−1) if and only if ul′∈span(u1′,…,ul−1′). By Lemma 3.3.3 (c) applied to R and to R′, column l is a pivot column of R if and only if it is a pivot column of R′. So both matrices have the same pivot columns j1<⋯<jr.

    Pivot columns agree. By Lemma 3.3.3 (a), uji=ei=uji′ for i=1,…,r.

    Same nonpivot columns. Let l be a nonpivot column. By Lemma 3.3.3 (b) for R, ul=∑i:ji<lriluji. This is an equation of the form in Lemma 3.3.2 (b), with coefficient ril on column ji and 0 on the other earlier columns. By that lemma, the same equation holds for R′: ul′=∑i:ji<lriluji′=∑i:ji<lrilei=ul, where the middle equality uses Lemma 3.3.3 (a) for R′, and the last uses Lemma 3.3.3 (b) for R.

    Hence ul=ul′ for every l, and R=R′.

    For the consequence, let A∈Mm×n(F). By Theorem 3.2.3, A is row equivalent to at least one matrix in RREF. Suppose A is row equivalent to R and to R′, both in RREF. Row equivalence is an equivalence relation (Theorem 3.2.2 (b)), so R is row equivalent to R′. By Lemma 3.3.1, Rx=0⇔R′x=0 for every x, and by the first part R=R′. This proves the theorem.

    Notice what the proof did not do: it never compared the two sequences of operations. A direct comparison of two runs of the algorithm would have to track every choice, and quickly becomes unmanageable. The proof instead found a description of the RREF, “pivots where a new column appears, and coefficients of the old columns elsewhere”, that refers only to the null space, which the operations cannot change.

    The theorem also gives a practical test: two matrices of the same size are row equivalent exactly when their RREFs are equal (you will write out the two-line proof in Exercise (B2: Row equivalence via the RREF)). For example, over R, (1224) and (2400) both reduce to (1200), by R2→R2−2R1 and by R1→12R1 respectively, so they are row equivalent. But (1326) reduces to (1300)≠(1200), so it is row equivalent to neither, even though all three matrices have the same pivot columns.

    Example (Two echelon forms, one reduced form)

    Let A=(121324023627) over R.

    • (a) Reduce A to a row echelon form in two ways: first using row 1 as the first pivot row, then starting with R1↔R2.
    • (b) Continue both to reduced row echelon form.
    • (c) Read the column relations of A off the RREF.

    Solution.

    • (a) First route: A→R2→R2−2R1(121300−2−43627)→R3→R3−3R1(121300−2−400−1−2)→R3→R3−12R2(121300−2−40000)=E1. Second route: A→R1↔R2(240212133627)→R2→R2−12R1(240200123627)→R3→R3−32R1(240200120024)→R3→R3−2R2(240200120000)=E2. Both E1 and E2 are in row echelon form, and E1≠E2. Both have pivot columns 1 and 3.
    • (b) From E1: E1→R2→−12R2(121300120000)→R1→R1−R2(120100120000). From E2: E2→R1→12R1(120100120000). The two routes end at the same matrix R, as Theorem 3.3.4 guarantees.
    • (c) By Lemma 3.3.3 (b), the nonpivot columns of R are u2=2u1 and u4=1⋅u1+2u3, reading the coefficients from the entries of each column. By Lemma 3.3.2 (b), the same relations hold for the columns of A: a2=2a1 and a4=a1+2a3. Check: 2(1,2,3)=(2,4,6) and (1,2,3)+2(1,0,2)=(3,2,7).

    Both echelon forms in the example had the same pivot columns, although they were different matrices. That is also true in general, and it is the practical version of the theorem.

    3.3.4. Pivot columns are well defined

    Corollary 3.3.5 (Pivot columns are well defined)

    Let A∈Mm×n(F) have columns a1,…,an. Define the pivot columns of A to be the pivot columns of the RREF of A.

    • (a) Column l is a pivot column of A if and only if al∉span(a1,…,al−1).
    • (b) If E is any matrix in row echelon form that is row equivalent to A, then the pivot columns of E are the pivot columns of A. In particular, every row echelon form of A has the same number of nonzero rows.

    Idea. Part (a) combines Lemma 3.3.3 (c) with the fact that column relations pass from the RREF back to A. For (b), finish the reduction of E: scale each pivot to 1 and clear the entries above the pivots. These operations never move a leading entry, so they produce a matrix in RREF with the same pivot columns as E, and by uniqueness it is the RREF of A.

    Proof. The RREF of A is well defined by Theorem 3.3.4; let u1,…,un be its columns.

    • (a) A and its RREF are row equivalent, so by Lemma 3.3.2 (c), al∈span(a1,…,al−1) if and only if ul∈span(u1,…,ul−1). By Lemma 3.3.3 (c), the latter fails exactly when l is a pivot column.

    • (b) Let E have entries ehl and pivot columns j1<⋯<js. First perform Ri→eiji−1Ri for i=1,…,s, which is legal since each pivot eiji is nonzero. Scaling a row by a nonzero scalar does not change which of its entries are zero (Theorem 0.7.1 (d), (f)), so the result is still in row echelon form with the same pivot columns, and now every pivot is 1. Next, for i=1,2,…,s in turn, and for each h<i, perform Rh→Rh−cRi, where c is the current entry of row h in column ji. Row i is zero in all columns before ji, so this changes row h only in columns ≥ji>jh. Hence the leading entry of row h is still a 1 in column jh, no zero row is touched, and the entries below every pivot stay 0. The operation makes the entry in position (h,ji) equal to 0, and it does not spoil the entries (h,ji′) with i′<i cleared earlier, because row i has a 0 in column ji′<ji. At the end, every pivot column is a standard basis vector, so the matrix is in RREF, with pivot columns j1,…,js.

    This matrix is row equivalent to E, hence to A (Theorem 3.2.2 (b)). By Theorem 3.3.4 it is the RREF of A. Therefore the pivot columns of E are those of A. Since the nonzero rows of E correspond one-to-one to its pivots, their number s is the number of pivot columns of A, whichever E we chose.

    In practice, (b) means we may stop at any row echelon form to find the pivot columns, and (a) means we can sometimes find them with no elimination at all. Part (a) also says that the pivot columns of A are exactly the columns kept when the list (a1,…,an) is sifted as in Theorem 1.5.4: a column is kept exactly when it is not in the span of the columns before it. The number of pivot columns is the first candidate for a measure of “how much a matrix contains”; later in this chapter it becomes the rank.

    Quick check. Without computing any row operations, find the pivot columns of A=(12012413) over R.

    Solution. Use Corollary 3.3.5 (a) column by column. a1=(1,2)≠0, so it is not in span()={0}: pivot. a2=(2,4)=2a1: not a pivot. a3=(0,1) is not a multiple of (1,2), and span(a1,a2)=span((1,2)): pivot. a4=(1,3)=a1+a3: not a pivot. The pivot columns are 1 and 3.

    Warning. Uniqueness is a property of the reduced form only. A matrix has many row echelon forms (Example (Two echelon forms, one reduced form) gave two), and it is only their pivot positions that agree. Also, two different matrices in RREF with the same pivot columns need not be row equivalent: (12) and (13) are both in RREF with pivot column 1, but they are different RREF matrices, so by Theorem 3.3.4 neither is row equivalent to the other.

    • (c) Determine whether the following statement is true: “if A and B are row equivalent and a3=a1−a2 for the columns of A, then b3=b1−b2 for the columns of B.” Justify your answer.
    • (d) Determine whether the following statement is true: “any two row echelon forms of the same matrix have the same number of zero rows.” Justify your answer.
    • (e) In the RREF of a matrix, what do the entries of a nonpivot column tell you about the original matrix?

    Solution.

    • (a) If R,R′∈Mm×n(F) are in RREF and Rx=0⇔R′x=0 for all x∈Fn, then R=R′. Hence every matrix is row equivalent to exactly one matrix in RREF.
    • (b) False. (1212) and (1200) are row equivalent, but their columns span span((1,1)) and span((1,0)), which are different lines in R2.
    • (c) True, by Lemma 3.3.2 (b) with l=3, d1=1, d2=−1.
    • (d) True. By Corollary 3.3.5 (b), every row echelon form of an m×n matrix A has exactly as many nonzero rows as A has pivot columns, so the number of zero rows is m minus that number.
    • (e) If column l is not a pivot column, its entries ril (for the pivot rows i with ji<l) are the coefficients expressing column l of the original matrix as a combination of its pivot columns: al=∑ji<lrilaji.

    B. Practice

    Exercise (B1: Column relations)

    Let A=(1−10212−21701−1151) over R. Find the RREF of A, naming each operation. Hence find the pivot columns of A, and express each nonpivot column of A as a linear combination of the pivot columns before it. Check your answer on the columns of A.

    Solution. A→R2→R2−2R1(1−10210013−21−1151)→R3→R3−R1(1−10210013−200130)→R3→R3−R2(1−10210013−200002) →R3→12R3(1−10210013−200001)→R1→R1−R3(1−10200013−200001)→R2→R2+2R3(1−10200013000001). The pivot columns are 1, 3 and 5. By Lemma 3.3.3 (b), in the RREF column 2 is −1 times column 1, and column 4 is 2 times column 1 plus 3 times column 3. By Lemma 3.3.2 (b), the columns of A satisfy a2=−a1,a4=2a1+3a3. Check: −(1,2,1)=(−1,−2,−1)=a2, and 2(1,2,1)+3(0,1,1)=(2,7,5)=a4.

    Exercise (B2: Row equivalence via the RREF)

    Prove that two matrices A,B∈Mm×n(F) are row equivalent if and only if they have the same RREF.

    Solution. (⇒) Suppose A and B are row equivalent, and let R be the RREF of B. Then A is row equivalent to B, and B to R, so A is row equivalent to R by transitivity (Theorem 3.2.2 (b)). By the uniqueness in Theorem 3.3.4, R is the RREF of A.

    (⇐) Suppose both have the RREF R. Then A is row equivalent to R, and by symmetry R is row equivalent to B (Theorem 3.2.2 (b)). By transitivity A is row equivalent to B.

    Exercise (B3: Row equivalent or not?)

    Determine whether the matrices in each pair are row equivalent over R. Justify your answer.

    • (a) P=(123257) and Q=(112347).
    • (b) P=(111123012) and Q=(10−1012112).

    Solution. By Exercise (B2: Row equivalence via the RREF), two matrices of the same size are row equivalent exactly when their RREFs are equal. So we compute both RREFs.

    • (a) Row reduce both: P→R2→R2−2R1(123011)→R1→R1−2R2(101011),Q→R2→R2−3R1(112011)→R1→R1−R2(101011). The RREFs are equal, so P and Q are row equivalent.

    • (b) P→R2→R2−R1(111012012)→R1→R1−R2(10−1012012)→R3→R3−R2(10−1012000).

      Q→R3→R3−R1(10−1012013)→R3→R3−R2(10−1012001)→R1→R1+R3(100012001)→R2→R2−2R3I3.

      The RREFs differ (one has a zero row, the other is I3), so P and Q are not row equivalent. Consistently with Corollary 3.3.5, P has pivot columns 1, 2 while Q has 1, 2, 3.

    C. Going deeper

    Exercise (C1: Counting reduced forms)
    • (a) List, by pivot columns, all 2×3 matrices over F2 in reduced row echelon form, and show that there are exactly 15 of them.
    • (b) Deduce that M2×3(F2), which has 64 elements, splits into exactly 15 classes of row equivalent matrices.
    • (c) Show that over a field with q elements there are exactly 2q2+2q+3 such matrices.

    Solution. We count over a field F with q elements, sorting by the list of pivot columns. In a matrix in RREF, a pivot column is forced (it is ei), an entry before a leading entry or in a zero row is forced to be 0, and every other entry, one lying in a nonpivot column to the right of its row’s pivot, is free.

    • (a) With q=2, writing ∗ for a free entry:
      • no pivots: (000000), 1 matrix;
      • pivot column 1 only: (1∗∗000), 4 matrices;
      • pivot column 2 only: (01∗000), 2 matrices;
      • pivot column 3 only: (001000), 1 matrix;
      • pivot columns 1, 2: (10∗01∗), 4 matrices;
      • pivot columns 1, 3: (1∗0001), 2 matrices;
      • pivot columns 2, 3: (010001), 1 matrix.
      A 2×3 matrix has at most two pivots, so these are all the cases. The total is 1+4+2+1+4+2+1=15.
    • (b) Row equivalence is an equivalence relation (Theorem 3.2.2 (b)), so M2×3(F2) is partitioned into equivalence classes (Theorem 0.5.2). By Theorem 3.3.4, each class contains exactly one matrix in RREF: at least one by Theorem 3.2.3, and at most one since two RREF matrices in the same class would be row equivalent, hence equal. So the classes correspond one-to-one to the 15 matrices of (a).
    • (c) The same list, with each free entry taking q values, gives 1+q2+q+1+q2+q+1=2q2+2q+3. For q=2 this is 8+4+3=15, as in (a).
    Exercise (C2: Deleting a column)

    Let A∈Mm×n(F) with n≥2, and let R be its RREF.

    • (a) Let A′ and R′ be obtained from A and R by deleting the last column. Prove that R′ is the RREF of A′.
    • (b) Show by an example that the corresponding statement for deleting the first column is false.

    Solution.

    • (a) Let a sequence of row operations turn A into R. By Lemma 3.2.1, the same sequence turns A′ into R′, so A′ is row equivalent to R′. By Theorem 3.3.4 it suffices to show that R′ is in RREF. Let j1<⋯<jr be the pivot columns of R. If jr<n, then deleting column n does not change any leading entry or any pivot column, and the zero rows of R stay zero, so (E1)–(E4) still hold. If jr=n, then row r of R is zero except for its pivot in column n, so in R′ rows r,…,m are zero and rows 1,…,r−1 keep their leading entries in columns j1<⋯<jr−1 and their pivot columns. Again (E1)–(E4) hold, with r−1 pivots. Hence R′ is in RREF, and it is the RREF of A′.
    • (b) Let A=(1101) over R. Then A→R1→R1−R2I2, so its RREF is I2, and deleting the first column of I2 gives (01). But deleting the first column of A gives (11), whose RREF is (10), via R2→R2−R1. These differ. The pivot of a later column depends on the columns before it, so removing an early column can move pivots.
