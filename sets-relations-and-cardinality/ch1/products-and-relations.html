1.4  Ordered Pairs, Products and Relations

Sections 1.2 and 1.3 built sets and combined them: a set is fixed by its elements, and ∪, ∩, ∖ are ∨, ∧, ∧¬ read through membership. None of this can yet say “the point (1,2) of the plane”, “3 is less than 5”, or “y is the square of x”. Each of these is about two objects in a given order, and a set forgets order. This section adds one new kind of object, the ordered pair (with its longer versions, the n-tuples), and then uses it twice: to build the product A×B of two sets, and to say what a relation between two sets is. The next section needs exactly this much: a function will be given by a relation of a special kind, its graph, together with a declared target set.

1.4.1. Order matters: ordered pairs

A set remembers which objects are its elements and nothing else. By extensionality (Definition 1.2.1), {1,2}={2,1}, since both sets have the elements 1 and 2; and {1,1}={1}, since both have the element 1 and nothing else. For a set that is exactly right. For a point of the plane it is exactly wrong. The point (1,2) lies one unit to the right of the vertical axis and two units above the horizontal one; the point (2,1) lies elsewhere. And the point (1,1) on the diagonal is a perfectly good point, with the same number in both places.

So we need an object built from two objects a and b that remembers which came first, and that still has two places when a=b. What we need to know about such an object is one fact: when two of them are equal.

An ordered pair is equal to another exactly when they agree in the first place and in the second place.

Definition 1.4.1 (Ordered pair)

For any objects a and b there is an object (a,b), the ordered pair of a and b; we call a its first coordinate and b its second coordinate. Ordered pairs have the characteristic property: for all a,b,c,d, (a,b)=(c,d)⟺a=c and b=d.

In words: to decide whether two pairs are equal, compare first coordinates with first coordinates and second with second; nothing else matters, and both comparisons must succeed. The direction (⇐) is nothing new: equal inputs give equal pairs, as for any construction (=E, Logic and Proof, Definition 5.7.1). The direction (⇒) is the content. It says that from the pair we can read off its coordinates, each in its place.

We do not say here what the object (a,b) is. Besides the characteristic property, we use one working convention: pairs and n-tuples are a different kind of object from numbers, just as sets are (Section 1.2), so a pair is not a number; and tuples of different lengths are different kinds of object, so a triple is not a pair. Nothing else about pairs is used in this chapter. Number Systems: From N to R, Chapter 1 shows that a pair with this property can be built from sets alone, so that nothing new has to be assumed. Until then, the existence of pairs with this property is taken as given, alongside the working rules (W1)–(W6) of Section 1.2.

A convention about parentheses. The symbol (a,b) now has two meanings. For real numbers a<b it is also the open interval {x∈R:a<x<b}. The book keeps both, and context decides, as it does in every analysis text. In “(0,1) contains 12” it is an interval. In “the point (0,1) lies on the unit circle” it is a pair. Where both readings are near each other, the text says which is meant. This convention is stated once, here.

Example (Solving an equation between pairs)

Find all real numbers x and y with (x+y,x−y)=(3,1). Then decide whether (1,2)=(2,1) and whether (1,1)=(1,1).

Solution. Uniqueness. By the characteristic property, (x+y,x−y)=(3,1) holds if and only if x+y=3andx−y=1. Adding the two equations gives 2x=4, so x=2; subtracting them gives 2y=2, so y=1. Existence. Conversely, x=2 and y=1 give (x+y,x−y)=(3,1). So there is exactly one solution, x=2, y=1.

The pairs (1,2) and (2,1) are not equal. If they were, the characteristic property would give 1=2 for the first coordinates. So (1,2)≠(2,1), by ¬I. The same test on (1,1) and (1,1) passes in both places, so they are equal; and (1,1) has two places, although both hold the same number.

The first part is typical. One equation between pairs is two equations between coordinates, and this is how pairs are used: an equation of pairs is split by the characteristic property, and the coordinates are compared one at a time.

The solution also has a shape worth naming. “Exactly one solution” was two claims, proved separately: any solution must be (2,1), and (2,1) is a solution. Claims of this kind come with every “the” in a definition, so the shape gets a box.

Example (Method: existence and uniqueness)

Template. “There is exactly one x with P(x)” is two claims (Logic and Proof, Definition 5.8.1, Logic and Proof, Proposition 5.8.1). For existence, name a candidate x0 and check P(x0), or obtain one from a given “there exists”. For uniqueness, take x and x′ with P(x) and P(x′), two names about which nothing else is assumed, and prove x=x′; or show that every x with P(x) equals x0.

When to use it. Whenever a definition says “the”: the coordinates of a pair, the value f(x), the empty set (Proposition 1.2.3), an inverse.

The usual failure. Proving only one half: a uniqueness proof with no candidate, or a candidate never shown to be the only one. Also checking P(x0) twice and calling it uniqueness, and naming “the” object before either half is proved (entry (N14) of Logic and Proof, Example (What is not allowed)).

Quick check. Is there exactly one real x with (x2,x3)=(4,−8)? Is there exactly one with (x2,x)=(4,3)?

Solution. Yes for the first: x3=−8 forces x=−2 (uniqueness), and (−2)2=4 (existence). No for the second: x=3 is forced, but 32=9≠4, so there is no such x at all. Uniqueness held and existence failed.

Nonexample by minimal change. Replace the parentheses by braces. The set {1,2} has the same two numbers as the pair (1,2), but the characteristic property fails for sets: {1,2}={2,1}, and yet 1≠2. What survives is membership: 1 and 2 are both in {1,2}. What is lost is order, the one thing the pair was made to keep.

Why this definition. Only (⇒) carries content. Without it, the pair could forget its coordinates, as {1,2} forgets which number came first. The direction (⇐) could be dropped from the definition without loss: =E already gives it for (a,b), as for any construction. It is stated so that the property reads as a single test for equality of pairs.

Longer lists. The same idea gives ordered triples (a,b,c), and more generally ordered n-tuples (x1,…,xn) for n∈N, n≥2. Like pairs, n-tuples are taken as given, and the n-tuples with all coordinates in a set form a set, by the working rule (W5) of Section 1.2. Two n-tuples are equal if and only if they agree in every place: (x1,…,xn)=(y1,…,yn) means xk=yk for every k∈{1,…,n}. A triple is a new kind of object, not a pair whose first coordinate is a pair (by the convention stated after Definition 1.4.1). The pairs ((1,2),3) and (1,(2,3)) carry the same three numbers in the same order, and it is tempting to call both “the triple (1,2,3)”; that is an identification made by convention, and exercise A1 asks whether the two pairs are equal.

Quick check. For which real numbers t is (t2,t)=(1,−1)? For which is {t2,t}={1,−1}?

Solution. The pair equation holds if and only if t2=1 and t=−1, so exactly for t=−1. The set equation holds for t=−1 too, since {1,−1}={1,−1}. It holds for no other t: the element −1 of the right side must be t2 or t, and t2≥0, so t=−1. Here the sets agree exactly where the pairs do, but that is luck. The pair equation (t,1)=(1,t) holds only for t=1, while the set equation {t,1}={1,t} holds for every t.

1.4.2. Cartesian products

With pairs in hand, the plane is the set of all pairs of real numbers. More generally, from any two sets we can collect all pairs whose first coordinate comes from the first set and whose second comes from the second. Taking such a collection is the working rule (W5) of Section 1.2: it is a set.

Definition 1.4.2 (Cartesian product)

Let A and B be sets. Their Cartesian product is the set A×B:={(a,b):a∈A, b∈B} of all ordered pairs with first coordinate in A and second coordinate in B. Written out, an object p is an element of A×B if and only if ∃a∈A ∃b∈B  p=(a,b). For a set X we write X2:=X×X, and, for n∈N with n≥2, Xn is the set of all n-tuples (x1,…,xn) with every xk∈X.

In words: an element of A×B is a pair, and there exist coordinates, one in A and one in B, from which it is made. The membership condition hides two existential quantifiers, so using it means naming the coordinates, by ∃E (Logic and Proof, Proposition 6.1.1), and then matching them against any other naming by the characteristic property of pairs. That two-step move is the basic move for products; (∗) below packages it.

For a pair the condition simplifies, and we use the simpler form constantly: (∗)(x,y)∈A×B⟺x∈A and y∈B. Here is why. If x∈A and y∈B, then x and y themselves are coordinates of the required kind, and (x,y)∈A×B by ∃I. Conversely, let (x,y)∈A×B. Then there are a∈A and b∈B with (x,y)=(a,b) [∃E], and the characteristic property (Definition 1.4.1) gives x=a and y=b. So x∈A and y∈B. The characteristic property is used exactly once, in the direction (⇒); without it, (x,y) might equal (a,b) with the coordinates swapped or lost, and nothing could be concluded.

We write (∗) for this equivalence in the rest of the section. It is the reason a product is easy to work with: membership of a pair in a product is checked one coordinate at a time.

The membership condition says that an element of A×B is made from some pair of coordinates. Can it be made from two different ones? The method of Example (Method: existence and uniqueness) answers this, and the answer is what lets us speak of “the first coordinate” of an element of a product.

Example (The coordinates of an element of a product)

Let p∈A×B. Show that there is exactly one a and exactly one b such that a∈A, b∈B and p=(a,b).

Idea (Scratch work). Existence should come straight from the definition, since membership in A×B is an existence statement. For uniqueness, take two namings of p and ask what connects them. Only p itself does, so the two pairs are equal, and an equation between pairs is exactly what Definition 1.4.1 splits. As givens and goal:

Givens Goal
p∈A×B some a∈A, b∈B with p=(a,b); any two such agree
p=(a,b), a∈A, b∈B (∃E twice, Definition 1.4.2) existence: done
p=(a,b) and p=(a′,b′) a=a′, b=b′: the gap is (a,b)=(a′,b′) (=E), then Definition 1.4.1

The last row is the gap. Once (a,b)=(a′,b′) is written down, the characteristic property closes it in one step.

Solution. Existence. By Definition 1.4.2 there are a∈A and b∈B with p=(a,b). Uniqueness. If also p=(a′,b′) with a′∈A, b′∈B, then (a,b)=p=(a′,b′), so a=a′ and b=b′ by the characteristic property (Definition 1.4.1).

This licenses “the first coordinate of p”, and so the assignment p↦ its first coordinate, which the next section will call a function.

Quick check. Which half of the solution used Definition 1.4.2, and which used Definition 1.4.1?

Solution. Existence used Definition 1.4.2: membership in the product hands over the coordinates. Uniqueness used Definition 1.4.1: the characteristic property matches two namings of the same pair.

Set-builders with a pair pattern. We write {(x,y)∈A×B:P(x,y)} for {p∈A×B:there are x,y with p=(x,y) and P(x,y)}, a set-builder in the sense of Definition 1.2.3. By (∗) and the characteristic property, (x,y) belongs to it if and only if x∈A, y∈B and P(x,y). The notation {(a,b):a∈A, b∈B} in Definition 1.4.2 is different: it names no ambient set, so it is not a set-builder. It is notation for the set that (W5) provides, and the displayed membership condition is its definition.

Example (Products, small and large)

  • (a) Let a,b,c be three different objects, none of them a number. List {1,2}×{a,b,c} and {a,b,c}×{1,2}.

  • (b) Describe R2 and [0,1]×[0,1] as sets of points of the plane.

  • (c) What is {1,2}×∅?

Solution.

  • (a) Each of the 2 first coordinates is paired with each of the 3 second coordinates: {1,2}×{a,b,c}={(1,a),(1,b),(1,c),(2,a),(2,b),(2,c)}, six pairs, all different by the characteristic property, since 1≠2 and a,b,c are different. Swapping the factors gives the six pairs (a,1),(a,2),(b,1),(b,2),(c,1),(c,2). No pair of the first list is in the second: every pair in the first list has a number as its first coordinate, and every pair in the second list has one of a,b,c there, none of which is a number; so by the characteristic property no pair of one list equals a pair of the other.

  • (b) R2=R×R is the set of all pairs (x,y) of real numbers: the plane, with x the horizontal and y the vertical coordinate. By (∗), (x,y)∈[0,1]×[0,1] if and only if 0≤x≤1 and 0≤y≤1: the closed unit square, with its four sides.

  • (c) It is empty. An element p would be (a,b) with b∈∅, and ∅ has no elements. So {1,2}×∅ has no elements, and a set with no elements is ∅ (Proposition 1.2.3).

Part (c) is the degenerate case, and it matters: a product is empty as soon as one factor is. The general statement is part of the next proposition.

Quick check. List {0,1}×{0,1,2}. Is (1,1)∈{1}×∅?

Solution. {0,1}×{0,1,2}={(0,0),(0,1),(0,2),(1,0),(1,1),(1,2)}, six pairs. And (1,1)∉{1}×∅: by (∗) it would need 1∈∅. In fact {1}×∅ has no elements at all, as in part (c) of the example.

Warning. The product is not commutative: A×B and B×A are in general different sets. For A={1} and B={2}, A×B={(1,2)} and B×A={(2,1)}, and (1,2)≠(2,1) by Example (Solving an equation between pairs). The two products have “the same size”, but they do not have the same elements. (They are equal when A=B, and when one of the sets is empty. Exercise C2 finds exactly when even the inclusion A×B⊆B×A holds.)

1.4.3. Products and the set operations

Section 1.3 showed that ∪, ∩, and ∖ obey the laws of ∨, ∧, and ∧¬. The product interacts with them just as simply, one factor at a time. We use these laws for regions of the plane (exercise B1) and for functions out of the empty set (Section 1.5), so we state them all.

Proposition 1.4.1 (Products and Set Operations)

For all sets A, B, C: A×(B∪C)=(A×B)∪(A×C),A×(B∩C)=(A×B)∩(A×C),A×(B∖C)=(A×B)∖(A×C),A×∅=∅, and the mirror-image laws, with the varying factor on the left: (B∪C)×A=(B×A)∪(C×A),(B∩C)×A=(B×A)∩(C×A),(B∖C)×A=(B×A)∖(C×A),∅×A=∅.

Idea. As in Example (Method: element-chasing), we take an element of one side and unwind; here every element is a pair, so its coordinates are named first, by ∃E, and membership is then tested one coordinate at a time, by (∗). The first coordinate lies in A on both sides; the second lies in B∪C on one side and in “B or C” on the other, which is the same condition by Definition 1.3.1. Each law is a law of Section 1.3 in the second coordinate, with the first coordinate carried along unchanged.

Proof. The ∪ law. We prove two inclusions and conclude by Proposition 1.2.1.

(⊆) Let p∈A×(B∪C). By Definition 1.4.2 there are a∈A and d∈B∪C with p=(a,d) [F1, Proposition 6.1.1]. By Definition 1.3.1, d∈B or d∈C, and we argue by cases. If d∈B, then p=(a,d)∈A×B by (∗), so p∈(A×B)∪(A×C). If d∈C, then likewise p∈A×C⊆(A×B)∪(A×C). In either case p∈(A×B)∪(A×C).

(⊇) Let p∈(A×B)∪(A×C). Then p∈A×B or p∈A×C. If p∈A×B, there are a∈A and b∈B with p=(a,b) [∃E]; since b∈B⊆B∪C, (∗) gives p∈A×(B∪C). If p∈A×C, the same argument with C in place of B gives p∈A×(B∪C).

The ∩ law. Let p∈A×(B∩C), so p=(a,d) with a∈A and d∈B∩C. Then d∈B and d∈C, and (∗) gives p∈A×B and p∈A×C. Conversely, let p∈(A×B)∩(A×C). Since p∈A×B, p=(a,b) with a∈A and b∈B. Since also (a,b)=p∈A×C, (∗) gives b∈C. So b∈B∩C, and p=(a,b)∈A×(B∩C).

The ∖ law. Let p∈A×(B∖C), so p=(a,d) with a∈A, d∈B, and d∉C. Then p∈A×B by (∗). If p were in A×C, then (∗) would give d∈C, which is false; so p∉A×C, and p∈(A×B)∖(A×C). Conversely, let p∈(A×B)∖(A×C). Then p=(a,b) with a∈A and b∈B, and p∉A×C. If b were in C, then (∗) would give p=(a,b)∈A×C, which is false; so b∉C. Hence b∈B∖C and p∈A×(B∖C).

The ∅ law. An element of A×∅ would be a pair (a,b) with b∈∅, and there is no such b. So A×∅ has no elements, and it equals ∅ by Proposition 1.2.3.

The mirror-image laws. The same four arguments, with the roles of the two coordinates exchanged throughout, prove them: the varying set now sits in the first coordinate, and (∗) is applied to it there. This proves the proposition.

The proofs of the ∖ law do not use excluded middle: both “∉” conclusions are reached by assuming membership and deriving a contradiction, which is ¬I. Only the first law was written with every ∃E marked; from here on, “p=(a,b) with a∈A and b∈B” is understood to name fresh coordinates.

A proof about products usually runs like the one above: take an element, write it as a pair with named coordinates, and work coordinatewise. Here is the pattern on concrete sets.

Example (Two rectangles)

Show that ([0,2]×[0,1])∩([1,3]×[0,2])=[1,2]×[0,1].

Solution. Draw the two rectangles first: the first is 2 wide and 1 high, with its lower left corner at the origin; the second is 2 wide and 2 high, with its lower left corner at (1,0). They overlap in the rectangle over [1,2] of height 1. Now the proof, by two inclusions.

(⊆) Let p be in the intersection. Since p∈[0,2]×[0,1], p=(x,y) with 0≤x≤2 and 0≤y≤1. Since also (x,y)=p∈[1,3]×[0,2], (∗) gives 1≤x≤3 and 0≤y≤2. Together, 1≤x≤2 and 0≤y≤1, so p=(x,y)∈[1,2]×[0,1] by (∗).

(⊇) Let p∈[1,2]×[0,1], so p=(x,y) with 1≤x≤2 and 0≤y≤1. Then 0≤x≤2, so p∈[0,2]×[0,1]; and 1≤x≤3, 0≤y≤2, so p∈[1,3]×[0,2]. Hence p is in the intersection.

By Proposition 1.2.1, the two sets are equal. The picture found the answer; the element-chase proved it.

The degenerate law of the proposition deserves a second look, because it is easy to misuse.

Remark. Combining the two ∅ laws with one more step gives the full description of an empty product: A×B=∅ if and only if A=∅ or B=∅. The direction (⇐) is the pair of ∅ laws. For (⇒), suppose A×B=∅. If A has an element a and B has an element b, then (a,b)∈A×B=∅, which is impossible. So it is not the case that both sets have an element; by excluded middle (Logic and Proof, Proposition 2.5.3) applied to “A has an element”, either A has none, and then A=∅ by Proposition 1.2.3, or A has one, and then B has none, so B=∅.

Warning. “A×B=∅, so A=∅” misses a case. The product {1,2}×∅ is empty, and {1,2} is not. The correct conclusion is the disjunction “A=∅ or B=∅” of the remark, and an argument that continues from it must treat both cases. Dropping one is the missing case of the catalogue in Logic and Proof, Chapter 8, entry (N7): a ∨E with one of its boxes left out.

1.4.4. Relations

“Is less than”, “divides”, “is the square of”, “lies on the unit circle with”: each of these connects an object of one set with an object of another, or of the same set. Each can be described by a rule, a formula, or a sentence. But two different descriptions can pick out exactly the same connections: “x<y” and “y−x>0” are different sentences about real numbers, and they hold for exactly the same pairs (x,y). In mathematics we want these to count as the same relation.

The way to make them the same is to forget the description and keep what it picks out: the set of pairs (x,y) for which it holds. Two descriptions that pick out the same pairs then give the same set, by extensionality.

A relation is the set of pairs it relates.

Definition 1.4.3 (Relation)

Let A and B be sets. A relation from A to B is a subset R⊆A×B. For a∈A and b∈B we write aRb, read “a is R-related to b”, to mean (a,b)∈R. A relation on A is a relation from A to A, that is, a subset of A2.

The domain of R is the set of first coordinates that occur, {a∈A:∃b∈B  aRb}, and its range is the set of second coordinates that occur, {b∈B:∃a∈A  aRb}. Turning every pair of R around gives a relation from B to A, the inverse relation R−1:={(b,a)∈B×A:(a,b)∈R}.

In words: a relation is a set, namely a set of pairs whose coordinates come from the two given sets. The notation aRb is only a way of writing “(a,b)∈R” that reads like “a<b”. The domain collects the elements of A that are related to at least one element of B; the range collects those of B that something is related to. The inverse relation turns each pair around: bR−1a exactly when aRb.

Two relations are equal exactly when they relate the same pairs, since relations are sets (Definition 1.2.1). So the relation “x<y” on R and the relation “y−x>0” on R are one relation, as we wanted. That is the whole reason for the definition: a relation is determined by what it relates, not by how it is described.

Example (Relations as sets of pairs)

Write each relation as a set, and find its domain and range.

  • (a) The relation < on {1,2,3}.

  • (b) Divisibility on {1,…,6}: aDb when a∣b.

  • (c) The unit circle, as a relation on R.

  • (d) The graph of squaring, as a relation on R.

  • (e) The two extreme relations from A to B: ∅ and A×B.

Solution.

  • (a) The pairs (a,b) of elements of {1,2,3} with a<b are L:={(1,2),(1,3),(2,3)}, three of the nine elements of {1,2,3}2. Its domain is {1,2}, since nothing in the set is larger than 3; its range is {2,3}, since nothing is smaller than 1.

  • (b) Write a∣b when b=ak for some integer k. For each first coordinate a, the second coordinates b∈{1,…,6} with a∣b are the multiples of a up to 6:

    a the b∈{1,…,6} with a∣b
    1 1,2,3,4,5,6
    2 2,4,6
    3 3,6
    4 4
    5 5
    6 6

    So D has 6+3+2+1+1+1=14 elements, the pairs (a,b) read off the rows. Its domain and range are both all of {1,…,6}, because every a divides itself: (a,a)∈D.

  • (c) The unit circle is S:={(x,y)∈R2:x2+y2=1}, a relation on R; for instance 0S1, 0S(−1), and 1S0. Its domain is [−1,1]. If xSy, then x2=1−y2≤1, so −1≤x≤1. Conversely, for −1≤x≤1 the number 1−x2 is nonnegative and so has a square root y=1−x2, which satisfies x2+y2=1. By the symmetry of the equation, the range is [−1,1] too.

  • (d) The graph of squaring is Q:={(x,y)∈R2:y=x2}. Its domain is all of R: every x is related to x2. Its range is [0,∞): a square is nonnegative, and every y≥0 is the square of y.

  • (e) Both are subsets of A×B, so both are relations. The empty relation ∅ relates nothing, and its domain and range are empty. The full relation A×B relates everything to everything. If A and B both have elements, its domain is A and its range is B.

The circle and the graph of squaring look alike, both being curves in the plane, but they differ in a way that the next section makes precise. In Q every x is related to exactly one y. In S the number 0 is related to two numbers, 1 and −1, and the number 2 to none. A relation of the first kind will be the graph of a function.

Quick check. Write the inverse relation L−1 of part (a) as a set. Which familiar relation on {1,2,3} is it?

Solution. Turning each pair of L around gives L−1={(2,1),(3,1),(3,2)}: the pairs (b,a) with b>a. So L−1 is the relation > on {1,2,3}. Its domain {2,3} is the range of L, and its range {1,2} is the domain of L.

Nonexample by minimal change. The set {(1,2),(2,3),3} looks like the relation “is one less than” on {1,2,3}, with one pair damaged. It is not a relation on {1,2,3}: the element 3 is a number, not a pair (the convention after Definition 1.4.1), so the set is not a subset of {1,2,3}2. Remove the 3, or replace it by the pair (3,4) and enlarge the second set to {1,2,3,4}, and it becomes a relation. The clause that failed is “R⊆A×B”: every element of a relation must be a pair with coordinates in the right sets.

Why this definition. A relation could be defined as a rule, a sentence, or a formula. Each of those raises the question of when two rules are “the same”, and that question has no good answer: “x<y” and “y−x>0” are different sentences. The definition as a set answers it by extensionality. The price is small: a relation may be any set of pairs whatever, such as {(1,3),(2,2)} on {1,2,3}, and the definition never asks for a rule that produces it. That is a gain, not a loss: in analysis we meet relations and functions that no formula describes.

Warning. A relation “from A to B” has its direction built in: R⊆A×B, and the first coordinate comes from A. The relation L of part (a) contains (1,2) and not (2,1). Reading a relation backwards, “since 1L2, also 2L1”, treats it as a symmetric relation; relations with that property, and other properties such as transitivity, are studied in Chapter 4. Relating b to a is the job of the inverse relation R−1, a different set.

This definition is all the next section needs. The graph of a function from X to Y will be a relation from X to Y in which every element of X is related to exactly one element of Y; the function is that graph together with the declared codomain Y. The graph Q qualifies and the circle S does not. The properties that make a relation an order or an equivalence (reflexive, symmetric, antisymmetric, transitive) are the subject of Chapter 4.

1.4.5. Exercises

A. Check your understanding

Exercise (A1)
  • (a) Define A×B in symbols, with its membership condition written out using quantifiers.
  • (b) Is ((1,2),3)=(1,(2,3))? Justify your answer.
  • (c) Write the inverse of the relation < on {1,2,3} as a set of pairs.
  • (d) Is ∅ a relation on every set A? Justify your answer.

Solution.

  • (a) A×B={(a,b):a∈A, b∈B}; that is, p∈A×B if and only if ∃a∈A ∃b∈B  p=(a,b) (Definition 1.4.2).

  • (b) No. Both are ordered pairs, so by the characteristic property (Definition 1.4.1) they are equal if and only if their first coordinates are equal and their second coordinates are equal. The first coordinates are the pair (1,2) and the number 1. A pair is not a number, by the working convention stated after Definition 1.4.1 (Number Systems: From N to R, Chapter 1, which builds both from sets, bears it out). So the first coordinates differ, and the pairs are not equal. Calling both “the triple (1,2,3)” is an identification made by convention, not an equality.

  • (c) {(2,1),(3,1),(3,2)}, which is the relation > on {1,2,3}.

  • (d) Yes. A relation on A is a subset of A×A, and ∅⊆A×A: the condition “x∈∅→x∈A×A” holds for every x, because its hypothesis is false (Logic and Proof, Proposition 2.1.2, Definition 1.2.2).

B. Practice

Exercise (B1: An L-shaped region)

Let E:=([0,1]×[0,2])∪([1,2]×[0,1]). Describe E as a region of the plane. Then use Proposition 1.4.1 to write E as ([0,2]×[0,1])∪(P×Q) for intervals P and Q, and prove the equality.

Solution. The first rectangle is 1 wide and 2 high, standing on the origin; the second is 1 wide and 1 high, standing on [1,2]. Together they form an “L”: a bottom strip [0,2]×[0,1] of width 2, with a square [0,1]×[1,2] on top of its left half. So we expect P=[0,1] and Q=[1,2].

Now the proof. Since [0,2]=[0,1]∪[1,2], the first law of Proposition 1.4.1 gives [0,1]×[0,2]=([0,1]×[0,1])∪([0,1]×[1,2]), and the mirror-image ∪ law gives [0,2]×[0,1]=([0,1]×[0,1])∪([1,2]×[0,1]). Substituting the first equation into the definition of E and regrouping the unions (∪ is commutative and associative by Theorem 1.3.1), E=([0,1]×[0,1])∪([0,1]×[1,2])∪([1,2]×[0,1])=([0,2]×[0,1])∪([0,1]×[1,2]), where the second line uses the mirror-image equation. So P=[0,1] and Q=[1,2]. (The equality [0,2]=[0,1]∪[1,2] is an order fact: 0≤x≤2 holds exactly when 0≤x≤1 or 1≤x≤2.)

Exercise (B2: The intersection law, written with two pairs)

Here is a proof of the inclusion (⊇) of A×(B∩C)=(A×B)∩(A×C) that works from the definition of the product and the characteristic property directly, without the shortcut (∗). Its last sentence is blank. Name the move, then complete it.

Let p∈(A×B)∩(A×C). Since p∈A×B, there are a∈A and b∈B with p=(a,b). Since p∈A×C, there are a′∈A and c∈C with p=(a′,c); the names a′ and c are new, because nothing says that this second pair of coordinates is the first one again. Hence (a,b)=(a′,c). ―

Solution. The move is the second half of the section’s move, the characteristic property of pairs (Definition 1.4.1) in the direction (⇒). An equation between pairs splits into equations between coordinates.

The completed last sentence: By the characteristic property, a=a′ and b=c; so b∈B and b=c∈C, hence b∈B∩C, and p=(a,b)∈A×(B∩C).

The names a′ and c had to be fresh (a second ∃E may not reuse the names of the first), and the characteristic property is what shows, afterwards, that the two namings name the same coordinates. The proof of Proposition 1.4.1 took the same step through (∗), which packages exactly this use of the characteristic property.

Exercise (B3: Two products crossed)

Prove that (A×B)∩(B×A)=(A∩B)×(A∩B) for all sets A and B.

Solution. We prove two inclusions and conclude by Proposition 1.2.1.

(⊆) Let p∈(A×B)∩(B×A). Since p∈A×B, p=(x,y) with x∈A and y∈B. Since also (x,y)=p∈B×A, (∗) gives x∈B and y∈A. So x∈A∩B and y∈A∩B, and p=(x,y)∈(A∩B)×(A∩B) by (∗).

(⊇) Let p∈(A∩B)×(A∩B), so p=(x,y) with x,y∈A∩B. Then x∈A and y∈B, so p∈A×B; and x∈B and y∈A, so p∈B×A. Hence p∈(A×B)∩(B×A).

Exercise (B4: Prove or disprove)

Prove each true statement by the method of Example (Method: existence and uniqueness), or the section’s element arguments, and refute each false one with a concrete counterexample.

  • (a) For all real a and b there is exactly one pair (x,y) of real numbers with (3x−y,x+2y)=(a,b).
  • (b) For every real a there is exactly one pair (x,y) of real numbers with (x2,y)=(a,0).
  • (c) For all sets A, B, C: if A×B=A×C, then B=C.
  • (d) For all sets A, B, C such that A has an element: if A×B=A×C, then B=C.
  • (e) There is exactly one set E with E×E=∅.

Solution.

  • (a) True. Uniqueness. Let (x,y) be a solution. By the characteristic property (Definition 1.4.1), 3x−y=a and x+2y=b. The first equation gives y=3x−a, and then x+2(3x−a)=b, so 7x=2a+b. Hence x=(2a+b)/7 and y=3x−a=(3b−a)/7. Existence. For these values, 3⋅2a+b7−3b−a7=7a7=a,2a+b7+2⋅3b−a7=7b7=b, so (3x−y,x+2y)=(a,b).

  • (b) False. For a=1, both (1,0) and (−1,0) qualify, since 12=(−1)2=1, and they are different pairs because 1≠−1. (For a=−1 there is no pair at all; one failing a is enough.)

  • (c) False. Take A=∅, B={1}, C={2}. Both products are ∅ by Proposition 1.4.1, so A×B=A×C, but B≠C.

  • (d) True. Let a be an element of A, and suppose A×B=A×C. For b∈B, (a,b)∈A×B=A×C by (∗), so b∈C by (∗) again. Hence B⊆C, and the other inclusion is the same argument with B and C exchanged. So B=C by Proposition 1.2.1. Part (c) shows where the element a was needed.

  • (e) True. Existence. ∅×∅=∅, by the ∅ law of Proposition 1.4.1. Uniqueness. Let E×E=∅. If e∈E, then (e,e)∈E×E=∅ by (∗), which is impossible; so E has no elements, and E=∅ by Proposition 1.2.3.

C. Going deeper

Exercise (C1: The square of a union)
  • (a) Determine whether (A∪B)×(A∪B)=(A×A)∪(B×B) for all sets A and B. Justify your answer.
  • (b) Prove the inclusion (A×A)∪(B×B)⊆(A∪B)×(A∪B).
  • (c) Prove, from Proposition 1.4.1, that (A∪B)×(A∪B)=(A×A)∪(A×B)∪(B×A)∪(B×B).

Solution.

  • (a) No. Take A={1} and B={2}. Then (1,2)∈{1,2}×{1,2}=(A∪B)×(A∪B). But (A×A)∪(B×B)={(1,1),(2,2)}, and (1,2) is neither (1,1) nor (2,2), since in each case the second (or first) coordinates differ. So the two sets are different.

  • (b) Let p∈(A×A)∪(B×B). If p∈A×A, then p=(x,y) with x,y∈A; so x,y∈A∪B, and p∈(A∪B)×(A∪B) by (∗). If p∈B×B, the same argument with B in place of A applies. In either case p∈(A∪B)×(A∪B).

  • (c) The mirror-image ∪ law, with A∪B as the fixed factor on the right, gives (A∪B)×(A∪B)=(A×(A∪B))∪(B×(A∪B)). The first ∪ law, applied to each of the two products, gives A×(A∪B)=(A×A)∪(A×B),B×(A∪B)=(B×A)∪(B×B). Substituting, and using that ∪ is associative (Theorem 1.3.1), so that no brackets are needed, gives the formula. Part (a)’s counterexample is the term A×B at work: (1,2)∈A×B.

Exercise (C2: When one inclusion forces equality)

Let A and B be sets. Prove that A×B⊆B×A if and only if A=B or A=∅ or B=∅.

Solution (Hint 1). For (⇒), the empty cases are easy, so assume both sets have elements. To show A⊆B, you need to test an element a∈A; put it into a pair that is sure to lie in A×B.

Solution (Hint 2). Fix b0∈B. For a∈A, the pair (a,b0) lies in A×B.

Solution. (⇐) If A=B, then A×B=B×A, and in particular A×B⊆B×A. If A=∅, then A×B=∅ by Proposition 1.4.1, and ∅ is a subset of every set. If B=∅, likewise A×B=A×∅=∅.

(⇒) Suppose A×B⊆B×A. By excluded middle (Logic and Proof, Proposition 2.5.3), each of A and B either has an element or has none, and a set with no elements is ∅ (Proposition 1.2.3). If A=∅ or B=∅, we are done. In the remaining case both have elements: fix a0∈A and b0∈B (∃E twice, with fresh names).

A⊆B. Let a∈A. Then (a,b0)∈A×B by (∗), so (a,b0)∈B×A by the hypothesis. By (∗) again, a∈B (and b0∈A).

B⊆A. Let b∈B. Then (a0,b)∈A×B⊆B×A, and (∗) gives b∈A (and a0∈B).

By Proposition 1.2.1, A=B. This proves the equivalence.

Both witnesses are needed. With B=∅ there is no b0, and indeed then A×B⊆B×A holds for every A, including A≠B: the inclusion {1}×∅⊆∅×{1} is ∅⊆∅.

Marking scheme. (10 points) - 2: (⇐): all three cases, including that an empty factor makes A×B empty and hence a subset of anything. - 2: (⇒): splits off the empty cases and, in the remaining case, names witnesses a0∈A and b0∈B. - 2: A⊆B, through a pair (a,b0) with an arbitrary a∈A. - 2: B⊆A, through a pair (a0,b) with an arbitrary b∈B. - 2: uses the characteristic property (directly or through (∗)) to read the coordinates off a pair of B×A, and concludes A=B by two inclusions.

Fatal errors (0 for the step): testing inclusion on particular elements only (entry (N1) of Logic and Proof, Chapter 8’s catalogue); using b0 without having shown that B has an element; concluding A=B from A×B=B×A “by canceling” without an element argument. A proof of (⇒) by contraposition (assume A≠B and both nonempty, and exhibit a pair of A×B outside B×A) earns full marks if it finds the pair: 2 points for the witnesses and 4 for the pair and the check that it is outside B×A, in place of the two inclusions.
