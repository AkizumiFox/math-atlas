5.1  Chains and Zorn’s Lemma

Section 3.4 proved that injections both ways give a bijection, and left open whether, for any two sets, at least one injection exists. Section 4.3 ended with a question about partially ordered sets: if every chain has an upper bound, must there be a maximal element? One principle answers both questions. This section states it, Zorn’s lemma, which answers the second question; explains why this volume does not prove it; and turns it into a method of proof, the maximality template, with two first uses. Section 5.2 uses the template to answer the first question.

5.1.1. Matching two sets, one pair at a time

Let A and B be sets, and suppose we want an injection from one of them into the other, in either direction. A natural plan is to match elements in pairs. Pick a0∈A and b0∈B and pair them. Then pick a1∈A∖{a0} and b1∈B∖{b0} and pair those. Continue until one side is used up. If A runs out first, every element of A has a partner, different elements have different partners, and the pairs form the graph of an injection A→B. If B runs out first, the same pairs read backwards form an injection B→A.

For finite sets the plan works, because each step uses one more element of each side, and a finite set is used up after as many steps as it has elements (Section 2.5). Take A={1,2,3} and B={x,y}. Pair 1 with x, then 2 with y. Now B is used up, and reading the pairs backwards gives x↦1, y↦2, an injection B→A.

For A=B=R the plan breaks down. Suppose we have made one step for each natural number. The elements of A used so far are a0,a1,a2,…, the image of the function n↦an on N, so they form a countable set (Proposition 3.1.4). But R is uncountable (Theorem 3.3.4), so A is not used up; neither is B. The instruction “continue until one side is used up” has no last step, and the words “and so on” stand in for a step that is never stated: (N13) of Logic and Proof, Example (What is not allowed), “an ‘and so on’ needs its step”. (The infinitely many unnamed choices of an and bn are a second problem, the one Section 3.2 met.)

Still, the attempt gets two things right, and they are the thesis of this section:

Every unfinished matching can be enlarged by one more pair, and a growing family of matchings, put together, is again a matching.

The first half is plain: if neither side is used up, an unused a and an unused b make one more pair. The rest of the section makes “growing family” exact and supplies a principle that turns these two facts into a finished matching. We return to the matching in Section 5.2.

5.1.2. Chains

Look at the matchings the plan produces, each a set of pairs. Of any two of them, one was built from the other by adding pairs, so one is a subset of the other: under ⊆, any two are comparable. That is what “growing family” means, and it makes sense in any partially ordered set.

Definition 5.1.1 (Chain)

Let (X,⪯) be a partially ordered set. A subset C⊆X is a chain if any two elements of C are comparable: for all x,y∈C, x⪯y or y⪯x.

So a chain is a subset on which ⪯ is total (Definition 4.3.1); in a totally ordered set, every subset is a chain.

Examples.

  • In (N,∣), the set {1,2,4,8,…}={2n:n∈N} is a chain: for m≤n, 2n=2n−m⋅2m, so 2m∣2n. The set {2,3} is not, since 2∤3 and 3∤2.
  • In (P({1,2,3}),⊆), the set {∅,{2},{2,3}} is a chain.
  • Degenerate cases: ∅ is a chain, vacuously, and so is every one-element set {x}, by (PO1).

Quick check. Decide: (a) Is {{1},{1,2},{3}} a chain in (P({1,2,3}),⊆)? (b) Is {0,1,5,25} a chain in (N,∣)? (c) Is {3,6,0}? (d) In (R,≤), which subsets are chains?

Solution.

  • (a) No: {1,2}⊈{3} and {3}⊈{1,2}.

  • (b) Yes. 1 divides every natural number, 25=5⋅5, and every natural number a divides 0=0⋅a; so any two of the four are comparable.

  • (c) Yes: 6=2⋅3, and 3∣0, 6∣0.

  • (d) All of them, since ≤ is total on R.

Why do chains matter for the matching? Take two pairs from the union of a growing family of matchings. Each pair comes from some matching of the family, and the two matchings are comparable, so both pairs lie in the larger of the two. Any condition that speaks about two pairs at a time can then be checked inside one matching. The same works for any finite number of elements, and that is the content of the next lemma.

The lemma speaks about a set of sets ordered by ⊆. That is always a partially ordered set: each member of a set of sets S is a subset of ⋃S, and ⊆ is a partial order on P(⋃S) (Example (Inclusion is a partial order, rarely total)), which stays one when restricted to the subset S, since (PO1)–(PO3) are statements about all elements.

Lemma 5.1.1 (Finitely Many Members of a Chain)
  • (a) Let C be a chain in a partially ordered set (X,⪯), let n≥1 and x1,…,xn∈C. Then some xk satisfies xj⪯xk for j=1,…,n.
  • (b) Let S be a set of sets, partially ordered by ⊆, and C⊆S a chain. Then C⊆⋃C for every C∈C; and if n≥1 and z1,…,zn∈⋃C, then some single C∈C contains all of z1,…,zn.

Proof. (a) By induction on n (Theorem 2.2.1 with n0=1). For n=1, take k=1: x1⪯x1 by (PO1). For the step, let x1,…,xn+1∈C, and by the induction hypothesis let xk with k≤n be above x1,…,xn. Since C is a chain, xn+1⪯xk or xk⪯xn+1. In the first case xk is above all n+1 elements. In the second, xn+1 is: xj⪯xk⪯xn+1 gives xj⪯xn+1 by (PO3) for j≤n, and xn+1⪯xn+1 by (PO1).

(b) The first claim is the definition of the union. For the second, induct on n (Theorem 2.2.1 with n0=1). For n=1: z1∈⋃C means that z1∈C for some C∈C, and one use of ∃E (Logic and Proof, Definition 5.6.1) names such a C. For the step, by the induction hypothesis some C′∈C contains z1,…,zn, and one use of ∃E gives C″∈C with zn+1∈C″. Since C is a chain, C′⊆C″ or C″⊆C′, and the larger of the two contains all of z1,…,zn+1.

Each step of the induction in (b) makes one use of ∃E, so no choice is involved. Writing “use ∃E n times” instead would be the “and so on” that (N13) flags; the induction is what supplies its step.

Quick check.

  • (a) Is there a chain of subsets of N, none of whose members contains both 0 and 1, whose union contains both? (b) Is there such a family of subsets that is not a chain?

Solution.

  • (a) No. If 0 and 1 lie in the union of a chain, then by Lemma 5.1.1 (b) with n=2 some member contains both.

  • (b) Yes: {{0},{1}} has union {0,1}, and neither member contains both. This is exactly what “chain” rules out.

5.1.3. Zorn’s lemma

Return to the question of Section 4.3: in a partially ordered set in which every chain has an upper bound, is there a maximal element? A naive attempt: start at any p0. If p0 is not maximal, there is p1≻p0; if p1 is not maximal, there is p2≻p1; and so on. The pn form a chain, which has an upper bound u; if u is not maximal, continue above u, and so on. Each single step is legitimate. But the chain p0≺p1≺⋯ may have an upper bound that is again not maximal, the next chain may too, and “continue past every such bound” is neither a finite process nor one indexed by N. It is (N13) once more: the “and so on” has no step. Instead of a proof, there is a principle, stated as its own result.

Theorem 5.1.2 (Zorn’s Lemma)

Let (P,⪯) be a non-empty partially ordered set in which every non-empty chain has an upper bound in P. Then P has a maximal element.

We do not prove Theorem 5.1.2. It cannot be proved from the rules of logic and the working rules for sets of Chapter 1 alone: it is equivalent to the axiom of choice (Axiom 3.2.1), which, as Section 3.2 records, can be neither proved nor refuted from the other axioms. One half of the equivalence, that Zorn’s lemma implies the axiom of choice, is the first application below (Theorem 5.1.3). The other half, which builds a maximal element from a choice function, is proved in Axiomatic Set Theory, Chapter 4, together with the other equivalents. As with the axiom, we use the lemma openly and cite it at each use. Zorn (1935) put the principle in this form, which suits algebra, where the objects to be built are sets ordered by inclusion.

Why each hypothesis is needed. Each of three small examples breaks one hypothesis and has no maximal element.

  • (N,≤) is non-empty and total, and has no maximal element, since n<n+1. The chain hypothesis fails: the chain N has no upper bound in N.
  • The empty partially ordered set satisfies the chain hypothesis vacuously, since it has no non-empty chain, and it has no maximal element. “Non-empty” is needed.
  • The set of finite subsets of N, ordered by ⊆, is non-empty, as ∅ belongs to it, and has no maximal element. For finite F, N is not a subset of F, since a subset of a finite set is finite (Proposition 2.5.6) and N is infinite (Example (Hilbert’s Hotel)); for m∈N∖F, the set F∪{m} is finite (Proposition 2.5.5) and strictly larger. By the contrapositive of Zorn’s lemma, some non-empty chain has no upper bound in this set, and here one is visible: {{0,1,…,n−1}:n∈N}, that is, ∅,{0},{0,1},…. An upper bound would be a finite set containing every natural number, hence containing N, which is impossible.

Warning. Maximal, not greatest, and not unique. Zorn’s lemma produces a maximal element, by no formula, and says nothing about how many there are. By Proposition 4.3.2 a greatest element would be maximal, but the converse fails (Example (Maximal elements that are not greatest)). In the applications below there are usually many maximal objects and no greatest one; a proof that treats “the” maximal element as unique, or as above everything, has gone wrong.

Quick check. Let P={{1},{2},{1,3}}, ordered by ⊆. List the chains with at least two elements; check that every non-empty chain has an upper bound in P; name the maximal elements.

Solution. The only comparable pair of different elements is {1}⊆{1,3}, so the only chain with at least two elements is {{1},{1,3}}, with upper bound {1,3}. A one-element chain {p} has the upper bound p. The maximal elements are {2} and {1,3}: two of them, as the warning says, and no greatest element.

Remark (Every chain, or every non-empty chain). Some books ask for an upper bound of every chain, the empty one included. An upper bound of ∅ is any element of P (Definition 4.3.2), so that form contains “P≠∅” as a special case. The two forms say the same thing.

5.1.4. The maximality template

Zorn’s lemma is almost always used in one pattern. Its first use proves the half of the equivalence with the axiom of choice that this volume can prove.

Theorem 5.1.3 (Zorn’s Lemma Gives Choice)

Assume Theorem 5.1.2. Let I be a set and (Ai)i∈I a family of non-empty sets. Then there is a function c:I→⋃i∈IAi with c(i)∈Ai for every i∈I.

This is the conclusion of Axiom 3.2.1, so the axiom follows from Zorn’s lemma.

Idea (Scratch work). A choice function can be built one index at a time, like the matching of the first subsection. Call a set of pairs (i,x) with x∈Ai, at most one pair for each i, a partial choice function: it is a graph (Definition 1.5.1) defined on part of I. Order these by ⊆: the larger of two comparable ones agrees with the smaller and is defined at more indices. Write U:=⋃i∈IAi.

Givens Goal
Ai≠∅ for each i∈I c:I→U with c(i)∈Ai for all i
P: the G⊆I×U with (C1) (i,x)∈G⇒x∈Ai and (C2) (i,x),(i,y)∈G⇒x=y; order ⊆ Zorn’s hypotheses: P≠∅, and each non-empty chain has an upper bound in P
∅∈P; for a chain C, try ⋃C: (C1) and (C2) mention at most two pairs (Lemma 5.1.1) a maximal M∈P is defined at every i∈I
M maximal; suppose i0 is missed M∪{(i0,x0)}∈P, strictly larger: a contradiction

The last row is a proof by contradiction (Example (Method: choosing direct, contrapositive or contradiction)): a missed index gives a larger partial object. Choosing x0∈Ai0 is one use of ∃E, which Section 3.2 showed is always allowed; Zorn’s lemma does the infinitely many.

Proof. Let U and P be as in the table. Then P⊆P(I×U) is a set, partially ordered by ⊆.

P is non-empty: ∅ satisfies (C1) and (C2) vacuously.

Chains have upper bounds: let C⊆P be a non-empty chain and H:=⋃C⊆I×U. If (i,x)∈H, it lies in some G∈C, so x∈Ai by (C1) for G. If (i,x),(i,y)∈H, some G∈C contains both (Lemma 5.1.1 (b) with n=2), so x=y by (C2) for G. So H∈P, and G⊆H for every G∈C: H is an upper bound of C in P.

Zorn: by Theorem 5.1.2, P has a maximal element M.

M is defined everywhere: suppose some i0∈I has no pair (i0,x)∈M. Since Ai0≠∅, take x0∈Ai0, and let M′:=M∪{(i0,x0)}. Then M′⊆I×U, since i0∈I and x0∈Ai0⊆U; M′ satisfies (C1), and it satisfies (C2), because the only pair of M′ with first coordinate i0 is (i0,x0). So M′∈P, M⊆M′, and M≠M′, as (i0,x0)∉M; this contradicts the maximality of M. Hence for every i∈I there is a pair (i,x)∈M, and by (C2) exactly one. By Definition 1.5.1, M is the graph of a function c:I→U, and c(i)∈Ai by (C1).

If I=∅, then P={∅}, and the proof produces the empty function, which is correct. Of the proof’s four steps, only the last is about choice functions; the first three run the same way in every use of the lemma, and that is worth recording.

Example (Method: the maximality template)

Template. To show that a complete object exists: (1) partial objects: let P be the set of partial objects, of which the complete ones are the finished case, ordered by ⊆ (extension); check P≠∅, usually with the empty or the given starting object. (2) chains: for a non-empty chain C⊆P, show ⋃C∈P; each defining condition mentions finitely many elements, which lie in one member (Lemma 5.1.1). (3) Zorn: P has a maximal element M (Theorem 5.1.2). (4) complete: suppose M is not complete; use the missing piece to build a strictly larger partial object, a contradiction.

When to use it. The object can be built piece by piece, each condition on it checks finitely many pieces at a time, and the pieces cannot be listed.

The usual failure. The union of a chain is not a partial object, because a condition mentions infinitely many pieces (“finite”, “countable”); step (4) builds an object that is not strictly larger, or not in P; and treating M as the greatest or the only complete object.

The second use runs the template with a shorter plan.

Example (A set of representatives)

Let ∼ be an equivalence relation on a set X. Show that there is a set S⊆X that meets every equivalence class in exactly one element.

Idea (Scratch work). By the method of Example (Method: the maximality template). A partial object should be a set that meets each class at most once, so that the complete ones meet each class exactly once. “At most once” reads: s∼t implies s=t, a condition on two elements at a time, so step (2) works. For step (4), a class [x] that is missed gives the larger set S∪{x}, and no choice is needed, since x is already in hand.

Solution. Let P be the set of S⊆X such that for all s,t∈S, s∼t implies s=t; order it by ⊆. Then ∅∈P. For a non-empty chain C⊆P, any two elements s,t of ⋃C lie in one member (Lemma 5.1.1 (b)), so s∼t gives s=t: ⋃C∈P, an upper bound of C. By Theorem 5.1.2, take a maximal M∈P.

Suppose some class [x] (Definition 4.2.2) contains no element of M. Then x∉M, since x∈[x] by (Eq1). And M∪{x}∈P: let s,t∈M∪{x} with s∼t. If both lie in M, then s=t. If s=x and t∈M, then t∼x by (Eq2), so t∈[x]∩M, which is impossible; the case t=x, s∈M is the same with the letters exchanged; and if s=t=x, there is nothing to show. So M⊊M∪{x} in P, contradicting maximality. Hence M meets every class, and by the condition defining P in at most one element: S:=M works.

The axiom of choice gives the same set in one line, by choosing one element from each class; the template’s advantage shows when the pieces interact, as in Section 5.2. On R, the relation x∼y⟺x−y∈Q is an equivalence relation (Section 4.2, after Example (The reals modulo the integers)). A set of representatives for it inside [0,1] is a set of real numbers that Measure and Integration, Chapter 1 shows has no length, and no formula for one is known.

Quick check. Let X=Z and m∼n⟺m−n is even. Describe the partial objects of Example (A set of representatives) that have two elements, and the maximal ones.

Solution. They are the sets {e,o} with e even and o odd: two even or two odd integers are related, since their difference is even, so a partial object holds at most one of each parity. Conversely, {e,o} is a partial object: with e=2a and o=2b+1, e−o=2(a−b−1)+1 is odd, hence not even (no integer is both, Theorem 1.1.2), so e≁o. These are exactly the maximal elements, since any third integer has the parity of e or of o (every integer is even or odd, Theorem 1.1.2), and ∅ and the one-element sets are not maximal, since each lies strictly inside some {e,o}. There are many maximal elements, such as {0,1} and {4,−7}, and no greatest one.

Warning. Check that the union is a partial object. Here is an almost-correct proof that N has a maximal finite subset. “Let P be the set of finite subsets of N, ordered by ⊆. A chain has its union as an upper bound. By Zorn’s lemma, P has a maximal element.” The conclusion is false, by the third example after Theorem 5.1.2. The failing line is the second: the union is an upper bound in P(N), but it need not be finite, so it need not lie in P. “Finite” is a condition on all the elements at once, and Lemma 5.1.1 handles only finitely many.

Section 5.2 applies the template twice more, first to the matching that opened this section.

5.1.5. Exercises

A. Check your understanding

Exercise (A1)

These questions are about the proof of Theorem 5.1.3.

  • (a) Where is “Ai≠∅” used, and which step fails without it?
  • (b) Why does the chain step need Lemma 5.1.1 only for n=2?
  • (c) Run the proof on I={1,2}, A1={0}, A2={5,6}: list P, name its maximal elements, and decide whether P has a greatest element.
  • (d) Which of the two hypotheses of Theorem 5.1.2 does the empty partially ordered set satisfy?

Solution.

  • (a) In the last step: x0∈Ai0 exists only because Ai0≠∅. Without it, M could miss i0 and still be maximal, and indeed no choice function exists if some Ai is empty.

  • (b) Condition (C1) mentions one pair and (C2) mentions two; no condition defining P mentions more.

  • (c) U={0,5,6}, and P={∅,{(1,0)},{(2,5)},{(2,6)},{(1,0),(2,5)},{(1,0),(2,6)}}. The maximal elements are the last two, each the graph of a choice function. There is no greatest element: the two maximal elements are incomparable, and a greatest element would be maximal (Proposition 4.3.2 (a)), so it would be one of them and contain the other.

  • (d) The chain hypothesis, vacuously; not non-emptiness.

B. Practice

Exercise (B1: Maximal chains)

Let (X,⪯) be a partially ordered set and C0⊆X a chain. Prove that there is a chain C⊇C0 that is maximal: no chain contains C properly.

Solution (Hint). The partial objects are the chains containing C0.

Solution. Let P be the set of chains C⊆X with C0⊆C, ordered by ⊆; then C0∈P. Let K⊆P be a non-empty chain and H:=⋃K. Then H⊇C0, since K has a member and each member contains C0. Any x,y∈H lie in one member K∈K (Lemma 5.1.1 (b)), which is a chain, so x and y are comparable. So H∈P, and it is an upper bound of K. By Theorem 5.1.2, P has a maximal element C. If a chain D⊋C existed, then D⊇C0, so D∈P and C⊊D, contradicting maximality. So C is a maximal chain containing C0.

Exercise (B2: Name the move, then complete it)

Here is the frame of a proof that for every set F of non-empty sets there is a subfamily D⊆F of pairwise disjoint sets such that every member of F meets some member of D.

Let P be the set of subfamilies E⊆F whose members are pairwise disjoint (E∩E′=∅ for E≠E′ in E), ordered by ⊆. Then ∅∈P. For a non-empty chain of such subfamilies, two members E≠E′ of its union lie in one subfamily of the chain, so E∩E′=∅; the union lies in P and is an upper bound. By Zorn’s lemma, P has a maximal element D.

⋮

… Hence every member of F meets some member of D.

Name the move, then complete it.

Solution. The move is step (4) of Example (Method: the maximality template): a missing piece gives a strictly larger partial object. Suppose F∈F meets no member of D. Then F∉D: otherwise F would meet itself, as F∩F=F≠∅. And D∪{F} is pairwise disjoint, since F∩D=∅ for every D∈D by assumption. So D⊊D∪{F}∈P, against the maximality of D. The check F∉D is what makes the new family strictly larger, the failure the method box warns about. Hence every member of F meets some member of D.

Exercise (B3: A small poset of partial injections)

Let A={1,2} and B={b}. List the relations G⊆A×B in which each element of A and each element of B occurs in at most one pair, ordered by ⊆. Name the maximal elements. For each, is every element of A paired? Every element of B?

Solution. They are ∅, {(1,b)} and {(2,b)}; the only other subset of A×B, {(1,b),(2,b)}, fails because b occurs twice. The maximal elements are {(1,b)} and {(2,b)}. Neither pairs every element of A; each pairs every element of B, and read backwards it is an injection B→A. (Section 5.2 shows that this always happens: a maximal partial injection uses up one side.)

Exercise (B4: Prove or disprove)

Prove each true statement and refute each false one.

  • (a) If every chain of a non-empty partially ordered set P has an upper bound in P, then P has a greatest element.
  • (b) Every non-empty finite partially ordered set has a maximal element.
  • (c) The set of subsets of N that contain no two consecutive numbers, ordered by ⊆, has a greatest element.
  • (d) If P is a non-empty partially ordered set in which every non-empty chain has an upper bound, then every p∈P lies below some maximal element of P.
  • (e) The set of countable subsets of R, ordered by ⊆, has a maximal element.

Hint for (d): apply Zorn’s lemma to the elements above p.

Solution.

  • (a) False. Take P={{1},{2}} under ⊆. Its chains are ∅, {{1}} and {{2}}, each with an upper bound in P. But P has no greatest element, since {1} and {2} are incomparable.

  • (b) True. Let P be non-empty and finite, and let C be a non-empty chain of P. Then C is finite (Proposition 2.5.6); list it as x1,…,xn with n≥1. By Lemma 5.1.1 (a), one xk is above all of them, an upper bound of C in P. By Theorem 5.1.2, P has a maximal element. (Section 4.3, Exercise R4 proves this without Zorn’s lemma, by induction.)

  • (c) False. The set E of even numbers and the set O of odd numbers both contain no two consecutive numbers. A greatest element G would contain E and O, so 0,1∈G, which are consecutive. (In fact E and O are both maximal: adding any n∉E to E puts n and n+1 in it (n is odd by Theorem 1.1.2, so n+1 is even), and adding any n∉O to O does the same. So Zorn’s lemma, if applied here, gives a maximal element, never a greatest one, as the warning after Theorem 5.1.2 says.)

  • (d) True. Let p∈P, and let Q:={q∈P:p⪯q}, ordered by ⪯; then p∈Q. A non-empty chain K of Q is a chain of P, so it has an upper bound u∈P; for any c∈K, p⪯c⪯u, so u∈Q by (PO3). By Theorem 5.1.2, Q has a maximal element m, and p⪯m. If m≺q for some q∈P, then p⪯q by (PO3), so q∈Q, against the maximality of m in Q. So m is maximal in P.

  • (e) False. Let C⊆R be countable. Then C≠R, since R is uncountable (Theorem 3.3.4); for x∈R∖C, the set C∪{x} is countable (Proposition 3.1.5) and strictly larger. So no countable set is maximal. (By the contrapositive of Zorn’s lemma, some non-empty chain of countable sets has no countable upper bound; the answer does not need one.)

C. Going deeper

Exercise (C1: Find the error)

Claim: every chain C0 of a partially ordered set X lies in a maximal chain.

“Proof”: Let P be the set of chains containing C0, ordered by ⊆; then C0∈P. Let K be a non-empty chain in P. Every K∈K is a subset of ⋃K, so ⋃K is an upper bound of K. By Zorn’s lemma, P has a maximal element C. A chain containing C contains C0, so it lies in P; hence C is a maximal chain.

Is the conclusion true? Does the argument prove it?

Solution. The conclusion is true: it is Exercise B1.

The argument does not prove it. It never checks that ⋃K is a chain, that is, that it lies in P; the upper bound in Theorem 5.1.2 must belong to P. The step’s general form, “the union of a chain of partial objects lies in P”, is false: among the finite subsets of N, the chain {{0,…,n−1}:n∈N} has union N, which is not finite (the warning before these exercises). Here the conclusion of the step happens to be true, which is exactly why it must be proved, not assumed. The repair is the chain step of B1: two elements of ⋃K lie in one member K∈K (Lemma 5.1.1 (b)), which is a chain, so they are comparable.

Marking scheme. (10 points) - 2: the conclusion is true, with B1 cited. - 3: the missing check named: ⋃K∈P. - 3: a counterexample to the general inference “the union of a chain of partial objects lies in P” (in any partially ordered set), with the remark that here the step’s conclusion is true but unproved. - 2: the repair via Lemma 5.1.1. Fatal errors (0 for the step): calling the conclusion false; “repairing” the proof by assuming that a union of chains is always a chain.

Exercise (C2: Exit check: when no choice is needed)
  • (a) Let ∼ be an equivalence relation on N. Without Zorn’s lemma or the axiom of choice, give a set S meeting every class exactly once, and prove that it does.
  • (b) Do the same for an equivalence relation on a set X with an injection j:X→N.
  • (c) Which ingredient of Example (A set of representatives) does your answer to (a) make unnecessary, and why?

Solution (Hint 1). Each class is a non-empty set of natural numbers. Which element of it can be named without choosing?

Solution.

  • (a) Let S:={mx:x∈N}, where mx is the least element of [x]. It exists by Theorem 2.1.3, since [x]⊆N contains x and so is non-empty, and it is unique (Proposition 4.3.1), so the rule names one value. Every class is met: mx∈[x]∩S. At most once: let mx,my∈S lie in the same class [z]. Then mx∈[x]∩[z], so [x]=[z], and likewise [y]=[z], since different classes are disjoint (Theorem 4.2.1). So [x]=[y], these classes have the same least element, and mx=my. Hence S meets each class [x] in mx and nowhere else.

  • (b) For x∈X, the set j([x])⊆N is non-empty, so it has a least element kx (Theorem 2.1.3), and since j is injective exactly one sx∈[x] has j(sx)=kx. Let S:={sx:x∈X}. The argument of (a) applies word for word, with sx for mx: equal classes give equal kx, hence equal sx.

  • (c) Zorn’s lemma, that is, the whole argument with P, chains and a maximal M: a rule names each representative, so nothing needs to be chosen (Example (Method: name the choice)).

Marking scheme. (10 points) - 3: (a) each class has a well-defined representative (well-ordering, and the rule names one value). - 3: (a) every class met, and met at most once (justified). - 2: (b) the least value of j, and injectivity naming one element. - 2: (c) Zorn’s lemma named as the unnecessary ingredient, because a rule names each representative. Fatal errors (0 for the step): “choose an element of each class” in (a) or (b), which is the axiom of choice.
