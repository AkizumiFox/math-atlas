# 03 深度編碼（A／R）——草稿，待作者確認

先前的對話使用「A／R 深度編碼」標記每個節點**教完時**的目標深度，例如 `A2/R3`。但這套編碼**沒有任何檔案定義它**：`kw` 專案用的是另一套 `L1|L2|L3`（`kw/kwlib/graph/schema.py`）。下面的定義是我從用法推回來的草稿，請作者改寫或確認。

## A：抽象層級（abstraction）

| 級 | 意思 | 例 |
|---|---|---|
| A0 | 具體對象與計算，不談結構 | 解一個 3×3 線性系統 |
| A1 | 在具體空間裡的定義與定理 | ℝ 上的連續、$\mathbb{R}^n$ 的子空間 |
| A2 | 公理化：從公理推出，對一切模型成立 | 抽象向量空間、度量空間、群 |
| A3 | 結構之間的關係：泛性質、函子 | 範疇、張量積的泛性質、同調 |

## R：嚴謹與推理層級（rigour）

| 級 | 意思 | 對應的習題級別（第一份報告 §9） |
|---|---|---|
| R0 | 會檢查定義、會計算 | L1 |
| R1 | 能讀懂並複述標準證明 | L1 |
| R2 | 能自己寫出標準證明 | L2 |
| R3 | 能處理量詞順序、反例與病態情形 | L3 |

## 與 kw 的 L1–L3 的對照（提案）

| kw | 大致對應 |
|---|---|
| L1 computational | A0–A1、R0–R1 |
| L2 proof | R2–R3 |
| L3 abstract | A2–A3 |

A／R 是兩個獨立的軸，kw 把它們壓成一個軸。若要讓 math-atlas 和 kw 共用同一個 registry，需要決定 kw 的節點 `concept@L2` 對到哪一個 (A, R)。

## 使用處

- `registry/statements.yaml` 每個節點的最後兩欄。
- 概念頁依 A–R 平面排列同一概念的各個版本。
- 習題分級與 mastery 判定（之後由學習平台使用）。
