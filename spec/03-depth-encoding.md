## 1. 定義

能力狀態：

```
state(node) = (A, R),   A ∈ {A0, A1, A2, A3},   R ∈ {R0, R1, R2, R3}
```

先備需求：

```
requires(node) = (A, R [, assessed])
```

滿足關係：

```
satisfies(s, r)  ⟺  s.A ≥ r.A  ∧  s.R ≥ r.R
```

`assessed` MUST NOT 參與此比較。

## 2. Abstraction 軸

衡量學習者能在多抽象的物件上運作。理論基礎為 Tall 的三世界（embodied／symbolic／formal）。

### A0 — 具體數值與座標（provisional）

能在具體數值、具體向量與具體函數上運作。物件對他而言就是一串數字或一條可畫出的曲線。

can-do

- 能對給定的具體數字做運算並得到數值答案。
- 能在二維或三維中畫出向量與函數，並讀出幾何意義。
- 無法在未指定維度或未指定係數的情形下推理。

示範題

1. 給定 $\mathbf{u} = (1, 2)$ 與 $\mathbf{v} = (3, -1)$，求 $\mathbf{u} \cdot \mathbf{v}$ 並說明其幾何意義。
2. 畫出 $f(x) = x^2 - 2x$ 的圖形並標出極小值位置。

### A1 — 符號化的 ℝⁿ 與矩陣運算

能在一般的 $\mathbb{R}^n$ 與一般大小的矩陣上運作，使用符號而非具體數值，但物件仍限於座標與矩陣。

can-do

- 能以符號處理任意維度的向量與矩陣，並正確使用維度相容性。
- 能操作 $\mathbf{A}^{\top}\mathbf{A}$、$\mathbf{A}^{-1}$、跡、行列式等運算而不需具體代入。
- 仍將向量理解為座標元組，將線性映射理解為矩陣。

示範題

1. 設 $\mathbf{A}$ 為 $m \times n$ 實矩陣。說明 $\mathbf{A}^{\top}\mathbf{A}$ 的大小，並說明它為何必為對稱。
2. 設 $\mathbf{X}$ 為滿秩的 $n \times p$ 矩陣。寫出最小平方解 $\hat{\boldsymbol{\beta}}$ 的公式，並說明公式中的反矩陣為何存在。

### A2 — 一般公理化結構

能在以公理定義的結構上運作，物件不再需要座標表示。

can-do

- 能在一般向量空間中論證，不預設基底或座標。
- 能區分線性映射與其矩陣表示，並理解基底變換的角色。
- 能使用群、環、體、度量空間等公理化定義進行推理。
- 能在未給定具體實例的情形下，僅由公理推出性質。

示範題

1. 設 $V$ 為有限維向量空間，$T : V \to V$ 為線性映射。不選取基底，證明 $T$ 為單射的充要條件是 $T$ 為滿射。
2. 說明「對稱矩陣可正交對角化」這個陳述，在不指定基底的語言中對應到什麼命題。

### A3 — 高階抽象（provisional）

能以泛性質、函子或範疇層次的語言思考。

can-do

- 能以泛性質刻劃物件，而非以構造刻劃。
- 能辨識不同結構之間的函子式對應。
- 能在「所有滿足某性質的物件」這個層次上論證。

示範題

1. 以泛性質敘述張量積的定義，並說明此定義為何唯一確定該物件至同構。
2. 說明對偶空間的構造在什麼意義下是一個反變函子。

註：pilot 語料（最佳化、機器學習、經濟、物理、離散數學）中 A3 觀測為 0。math-atlas 的 AL4.7（範疇）與 AL4.11（同調）預期是 A3 的主要來源，待其標註後複審。

### 與記號的對應

粗體依型別決定（見 spec/02）：A1 的物件（座標向量與矩陣）加粗，A2 的物件（抽象空間的元素）不加粗。字形因此直接標示讀者正在哪一層抽象上運作。

## 3. Rigor 軸

衡量學習者對論證的處理能力。等級定義與主題無關。理論基礎為 MATH taxonomy 與 Mejía-Ramos 等人的證明理解模型（local 對應 R1，holistic 對應 R2 與 R3）。

### R0 — 能計算

能套用既定程序得到正確結果，不需要理解程序為何成立。

can-do

- 能依步驟執行演算法並得到正確答案。
- 能辨識何時該套用哪個程序。
- 無法說明程序成立的理由，也無法判斷程序失效的條件。

示範題

1. 對給定的 $3 \times 3$ 對稱矩陣求其特徵值與一組正交特徵向量。
2. 對給定的凸二次函數以梯度下降執行三步迭代，寫出每步的數值。

### R1 — 能讀懂證明

能追蹤既有證明的邏輯鏈，並說明每一步的理由。對應 Mejía-Ramos 模型的 local 類別。

can-do

- 能說明證明中每個名詞的意義。
- 能指出某一步是由哪些前提推出，以及用到哪個定理。
- 能辨識證明的邏輯結構，例如反證、歸納或分情況討論。
- 能指出若某個假設被移除，證明會在哪一步斷裂。

示範題

1. 給定 Cauchy–Schwarz 不等式的一個證明。指出該證明在哪一步用到了內積的正定性，並說明若只假設半正定會發生什麼。
2. 給定「有限維空間中線性映射為單射則為滿射」的證明。指出該證明何處用到有限維假設。

### R2 — 能寫證明

能獨立產生標準論證，並把既有方法遷移到相近命題。對應 Mejía-Ramos 模型的 general method 與 holistic 類別。

can-do

- 能對難度相當的新命題產生完整且正確的證明。
- 能辨識某個證明所使用的一般方法，並將其套用到結構相似的命題。
- 能自行選擇證明策略，而非依賴被告知的策略。

示範題

1. 證明：若 $\mathbf{A}$ 為實對稱矩陣，則其相異特徵值所對應的特徵向量彼此正交。
2. 證明：凸函數的局部極小值必為全域極小值。

### R3 — 能處理量詞、反例與病態情形（provisional）

能處理含多重量詞的論證，能構造反例，能辨識並處理不成立的邊界情形。

can-do

- 能正確處理量詞的順序，並說明交換量詞順序後命題如何改變。
- 能在命題不成立時構造反例，而非僅指出證明失敗。
- 能辨識哪些假設是必要的，並說明移除後會出現什麼病態情形。
- 能區分逐點與一致兩種性質的差異。

示範題

1. 給出一個逐點收斂但不一致收斂的函數列，並說明此差異在量詞順序上如何體現。
2. 舉出一個連續函數及其定義域，使函數有界卻取不到最大值，並說明它違反了哪個假設。

已知風險：R2 與 R3 的示範題目前分屬不同主題，難以排除「主題差異被當成嚴謹度差異」的雙重計數。複審時應在同一主題下各寫一題 R2 與 R3（例如凸性：R2 證明 Jensen 不等式；R3 說明凸函數在開集內連續、在邊界可能不連續，並構造反例）。

## 4. 需求側標記 assessed（選填）

`assessed ∈ {yes, no}`：此先備是否在課程或本冊的評量中被直接考到。

- 與 R 無關：它問的是「有沒有考」，不是「要多深」。
- 名目變數，MUST NOT 排序，MUST NOT 參與滿足關係。
- 信度以 Fleiss' kappa 另外報告。

## 5. 標註程序與信度

1. 標註者對每個（課程或章，節點）配對獨立給出 (A, R)，選填 assessed。
2. 不涵蓋的節點標為 n/a，MUST 與「涵蓋但要求極低」區分。
3. 標註依據限於公開課綱、指定教科書的目錄與序言，以及作業或考題（若公開）。MUST 記錄依據來源。
4. 標註完成前，標註者之間 MUST NOT 討論個別課程。

### 5.1 信度統計

- 主係數：Gwet's AC2，有序加權。
- 併列報告：Krippendorff's ordinal alpha。
- A 與 R MUST 分開報告，各附 bootstrap 95% 信賴區間，並呈現邊際分布。
- 門檻：AC2 ≥ 0.667 進入下一輪；目標 0.800。此門檻 MUST 於標註開始前寫入協定。

### 5.2 半級的解禁條件

v1.0 前 MUST NOT 引入半級。日後提案新增半級時，MUST 提出以下證據：

- 現有相鄰類別的 Andrich thresholds 有序；
- 相鄰 threshold 間距大於 1.4 logits；
- 擬新增的每個半級在既有標註中有至少 10 次觀測。

### 5.3 provisional 等級的複審

A0、A3、R3 在累積至少 10 次觀測後複審。若擴充後的語料仍無法達到，MAY 提案移除或合併。

### 5.4 正交性檢核

若 A 與 R 的 Spearman 相關超過 0.8，MUST 在下一版提案中檢討是否合併為單一深度軸。此檢核 MUST 於每次主版本發佈前重跑。

**前提條件：** 檢核僅在語料同時包含以下四類課程時具效力。缺任一類時，結果 MUST NOT 作為合併維度的依據。

| 類型 | 定義 | 目標格 |
|---|---|---|
| applied | 以計算與應用為主，物件為座標與矩陣 | A1·R0 |
| pure-theory | 以嚴格論證為主，物件為公理化結構 | A2·R2 以上 |
| concrete-rigorous | 論證嚴格，但物件保持具體 | A1·R2 |
| abstract-computational | 使用抽象結構，但僅作計算、不證明 | A2·R0 |

## 6. 在 math-atlas 中的語意

同一組 (A, R) 在地圖上有兩個位置，意義不同：

- **節點上**：該章或陳述「教到」的程度，記為 taught。
- **邊上**：下游「需要」上游的程度，記為 required。

lint 規則：

1. s 邊 MUST 滿足 `required ≤ taught(source)`，逐軸比較。
2. b 邊的 `required.R` MUST ≤ R1。借用的意思是讀者只需讀懂並套用陳述，不需重現證明；若下游需要 R2 以上，該邊應為 s。
3. b 邊的陳述 MUST 能以讀者當下記號作用域內的語彙完整寫出（見 spec/02）。

本檔示範題中的 LaTeX 為直接字形，只供閱讀；書稿中一律改用 spec/02 的語意巨集。

### 6.1 實作狀態（`atlas.py check`）

| 規則 | 層級 | 做法 |
|---|---|---|
| 1 | 陳述層 | `statements.yaml` 的 uses 邊若標了需要的 A／R，與被用陳述節點上的 A／R 逐軸比較 |
| 2 | 陳述層 | borrows 邊若標了需要的 A／R，R 必須 ≤ R1 |
| 3 | 章層級（代理） | b 邊可宣告 `scope`：寫出被借用陳述所需語彙的章。每個 scope 章都必須在借用章的 s 祖先閉包裡（或就是借用章本身）。未宣告的 b 邊列在 `generated/diff.md`。真正的記號作用域 lint 要讀記號表，排在引擎需求（spec/05 第 6 項） |

### 6.2 R1 讀者的必讀集（2026-10-09）

s 祖先閉包是「要讀懂每一個證明」的讀者的必讀量。R1 讀者（例如數值方向）只需要讀懂並套用定理，他讀一章時只讀定義與陳述，不讀證明，因此不必跟著那一章的證明依賴往回走。

- **定義**：目標章引用到的定義所在的章，加上目標章借用的定理在陳述中用到的定義所在的章；對每個納入的章，再加上它的定義與陳述所引用的定義（遞移）。
- **不改邊型別**：章層級的 s 邊照舊是「證明依賴」。R1 必讀集是另一個並列的量，由 `import_la.py` 的 `vocab` 邊（`all`、`stmt` 兩種）算出，列在 `generated/report.md`。不必為了降低數值方向的必讀量，把大量計算邊改成 b。
- **目前是下界**：只看得到書稿明寫的 crossref。定義裡直接使用前面的語彙、卻沒有引用（例如直接寫「矩陣」）的情形看不到。要變成精確值，需要引擎強制定義引用它用到的定義（spec/05 第 10 項）。
- 例（2026-10-09 的數值，現值見 report.md）：NLA.24 的 s 閉包是 27 章，R1 下界是 14 章。改用 b 分流 NLA.24 自己的邊，s 閉包仍是 27 章，因為 MA.16、LA3.11 等定義所在的章本身就以 s 依賴譜理論與行列式。
