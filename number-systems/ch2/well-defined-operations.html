2.2  Well-Definedness, and the Arithmetic of the Integers

Section 2.1 built Z as the set of classes of ∼ on N×N, and gave each integer a normal form (Proposition 2.1.2). The integers cannot yet be added. Every operation on classes will be defined by a formula on representatives, and Sets, Relations, and Cardinality, Section 4.2 showed what can go wrong: a formula that gives two answers for one class (Sets, Relations, and Cardinality, Example (A rule on classes that is not a function)). This section proves, once and for all, the lemma that says when such a formula defines a function. It then uses the lemma for the sum, product and negative of integers, and finds a copy of N inside Z.

2.2.1. Definitions through representatives

In Sets, Relations, and Cardinality, Section 4.2 the addition of Z/n was defined by [a]+[b]:=[a+b], and Sets, Relations, and Cardinality, Proposition 4.2.5 checked that the right side depends only on the classes, not on the integers a and b used to name them. In Sets, Relations, and Cardinality, Example (A rule on classes that is not a function) the same kind of formula, [a]6↦[a]4, gave one class two values, and so defined no function.

The same situation will recur throughout this volume: for Z in this section, for Q in Section 2.4, and for R later in this volume. Each time, a set is a quotient X/∼, and something is defined on it by a formula on elements of X. Rather than repeat the argument of Sets, Relations, and Cardinality, Proposition 4.2.5 for every formula, we separate it into two parts: a general lemma, proved here once, which turns a check on representatives into a function on classes; and the check itself, which is different for each formula and is all that remains to do each time.

A rule “[x]↦ something computed from x” is called well defined when representatives of the same class always give the same result. The lemma below says that being well defined is enough, in three settings: a map from one quotient to another, a binary operation on a quotient, and a property of classes.

2.2.2. The lemma

A rule on classes is a function as soon as equivalent inputs give equivalent outputs.

Theorem 2.2.1 (Functions on Classes)

Let ∼ be an equivalence relation on a set X, and ≈ an equivalence relation on a set Y. Classes are taken for ∼ in X and for ≈ in Y.

  • (a) Let f:X→Y be a function such that, for all x,x′∈X, x∼x′ implies f(x)≈f(x′). Then there is exactly one function F:X/∼→Y/≈ with F([x])=[f(x)] for every x∈X.
  • (b) Let g:X×X→X be a function such that, for all x,x′,y,y′∈X, x∼x′⟹g(x,y)∼g(x′,y),y∼y′⟹g(x,y)∼g(x,y′). Then there is exactly one function G:(X/∼)×(X/∼)→X/∼ with G([x],[y])=[g(x,y)] for all x,y∈X.
  • (c) Let S⊆X be such that, for all x,x′∈X, x∼x′ and x∈S imply x′∈S. Let S¯:={[x]:x∈S}⊆X/∼. Then, for every x∈X, [x]∈S¯ if and only if x∈S.

In words: (a) says that a map on elements that respects the two relations passes to a map on classes; (b) says that a binary operation that respects ∼ in each argument separately passes to an operation on classes; (c) says that a property that respects ∼ can be asked of a class, and the answer is the answer for any of its representatives. Clause (a) will give the negative of an integer, (b) its sum and product, and (c) the positive integers in Section 2.3.

Idea. A function is a graph with exactly one output for each input (Sets, Relations, and Cardinality, Definition 1.5.1). The obvious graph is the set of all pairs ([x],[f(x)]). It has at least one output for each class, because every class is some [x]. The only danger is two outputs for one class, coming from two representatives x and x′ of it; Sets, Relations, and Cardinality, Theorem 4.2.1 (b) turns “same class” into x∼x′, the hypothesis turns that into f(x)≈f(x′), and Sets, Relations, and Cardinality, Theorem 4.2.1 (b) turns it back into “same output”. For (b) the same plan works, once the two one-argument hypotheses are chained into one statement about both arguments by transitivity.

Proof. (a) Let GF:={(C,D)∈(X/∼)×(Y/≈):C=[x] and D=[f(x)] for some x∈X}, a set by specification (Sets, Relations, and Cardinality, Definition 1.2.3). We check the two clauses of Sets, Relations, and Cardinality, Definition 1.5.1. (Fn1): every C∈X/∼ is [x] for some x∈X (Sets, Relations, and Cardinality, Definition 4.2.4), and then (C,[f(x)])∈GF. (Fn2): suppose (C,D)∈GF and (C,D′)∈GF, say C=[x], D=[f(x)], and C=[x′], D′=[f(x′)]. Then [x]=[x′], so x∼x′ by Sets, Relations, and Cardinality, Theorem 4.2.1 (b). By the hypothesis, f(x)≈f(x′), so [f(x)]=[f(x′)] by Sets, Relations, and Cardinality, Theorem 4.2.1 (b), that is, D=D′. So F, the function with graph GF and codomain Y/≈, is a function X/∼→Y/≈, and F([x])=[f(x)] because ([x],[f(x)])∈GF.

For uniqueness, let F′:X/∼→Y/≈ also satisfy F′([x])=[f(x)] for every x. Every C∈X/∼ is some [x], and then F′(C)=[f(x)]=F(C). The two functions have the same domain and codomain, so F′=F by Sets, Relations, and Cardinality, Proposition 1.5.1.

(b) First, for all x,x′,y,y′∈X with x∼x′ and y∼y′, g(x,y)∼g(x′,y)andg(x′,y)∼g(x′,y′), by the first hypothesis (with y fixed) and the second (with x′ fixed). By transitivity, (Eq3) of Sets, Relations, and Cardinality, Definition 4.2.1, g(x,y)∼g(x′,y′).

Now let GG be the set of (P,E)∈((X/∼)×(X/∼))×(X/∼) such that P=([x],[y]) and E=[g(x,y)] for some x,y∈X, a set by specification. (Fn1): an element of (X/∼)×(X/∼) is a pair (C,D) of classes (Sets, Relations, and Cardinality, Definition 1.4.2), and C=[x], D=[y] for some x,y∈X (Sets, Relations, and Cardinality, Definition 4.2.4); then ((C,D),[g(x,y)])∈GG. (Fn2): suppose (P,E) and (P,E′) lie in GG, with P=([x],[y]), E=[g(x,y)], and P=([x′],[y′]), E′=[g(x′,y′)]. From ([x],[y])=([x′],[y′]) the characteristic property of pairs (Sets, Relations, and Cardinality, Definition 1.4.1) gives [x]=[x′] and [y]=[y′], so x∼x′ and y∼y′ by Sets, Relations, and Cardinality, Theorem 4.2.1 (b). By the first paragraph, g(x,y)∼g(x′,y′), so E=E′ by Sets, Relations, and Cardinality, Theorem 4.2.1 (b). So GG, with codomain X/∼, defines a function G with G([x],[y])=[g(x,y)]. Uniqueness is as in (a), by Sets, Relations, and Cardinality, Proposition 1.5.1.

(c) (⇐) If x∈S, then [x]∈S¯ by the definition of S¯. (⇒) If [x]∈S¯, then [x]=[x′] for some x′∈S. By Sets, Relations, and Cardinality, Theorem 4.2.1 (b), x∼x′, so x′∼x by (Eq2). The hypothesis, applied to x′∼x and x′∈S, gives x∈S.

This proves the theorem.

The functions F and G are said to be induced by f and g. In practice we write the conclusion of (a) as “the rule [x]↦[f(x)] is well defined”, and of (b) as “the operation [x]∗[y]:=[g(x,y)] is well defined”, and the work is always the check of the hypotheses.

Remark. Each hypothesis has a job. Without the hypothesis of (c) the conclusion fails. On N×N with the relation ∼ of Definition 2.1.1, let S:={(a,b):0<a}. Then (1,1)∈S, so [(1,1)]∈S¯; and [(0,0)]=[(1,1)], so [(0,0)]∈S¯, while (0,0)∉S. Membership in S¯ does not tell us whether a particular representative lies in S. The hypotheses of (a) and (b) are needed in the same way, and the examples below show them failing.

2.2.3. Sum, product and negative of integers

To guess the formulas, borrow the school picture once more. If (a,b) records “a−b” and (c,d) records “c−d”, then school algebra gives (a−b)+(c−d)=(a+c)−(b+d),(a−b)(c−d)=(ac+bd)−(ad+bc),−(a−b)=b−a. These identities are a heuristic: they come from the school integers, which this chapter does not assume, and they are used only to find the definition. Each right side is again a difference of two natural numbers, so it can be recorded as a pair.

Definition 2.2.1 (Sum, Product and Negative of Integers)

For all (a,b),(c,d)∈N×N, let +[(c,d)]:=[(a+c, b+d)],[(a,b)]⋅[(c,d)]:=[(ac+bd, ad+bc)],−[(a,b)]:=[(b,a)]. The sum +:Z×Z→Z and product ⋅:Z×Z→Z are the functions that Theorem 2.2.1 (b), with X=N×N and the equivalence relation ∼ of Proposition 2.1.1, induces from the maps g+, g⋅:(N×N)×(N×N)→N×N given by the pairs on the right; the negative −:Z→Z is the function that Theorem 2.2.1 (a) induces from (a,b)↦(b,a). We also write xy for x⋅y.

In words: to add integers, add representatives coordinatewise; to multiply, use the cross formula; to negate, swap the coordinates. All the arithmetic on the right happens in N, where it is always possible. The definition is legitimate only if the hypotheses of Theorem 2.2.1 hold for the three maps on pairs; the next proposition checks them, and until then the three formulas are rules, not yet functions.

The move used in the proof is the one this chapter is built on.

Check on representatives, one argument at a time. To show that [x]∗[y]:=[g(x,y)] is well defined, change x to an equivalent x′ with y fixed, then change y to an equivalent y′ with x′ fixed. Each change is a computation at the level below, in N here; Theorem 2.2.1 (b) joins the two by transitivity.

Proposition 2.2.2 (The Operations on Integers Are Well Defined)

The maps g+ and g⋅ of Definition 2.2.1 satisfy the hypotheses of Theorem 2.2.1 (b), and the map (a,b)↦(b,a) satisfies those of Theorem 2.2.1 (a), with ∼ on both sides. Hence the sum, product and negative of Definition 2.2.1 are well-defined functions.

Idea. Each hypothesis is an equation in N to be derived from another. The given equation is the cross-sum equation for (a,b)∼(a′,b′); the target is the cross-sum equation for the two outputs. For the sum, adding c+d to both sides of the given equation and rearranging is enough. For the product, the target has c and d in every term, so we multiply the given equation by c, and separately by d, and add the results; the rest is rearranging. Both formulas are unchanged when the two input pairs are swapped, so the second argument costs nothing.

Before reading on: why may we change one argument at a time, rather than both at once?

Proof. Let (a,b),(a′,b′),(c,d)∈N×N with (a,b)∼(a′,b′), that is,

a+b′=b+a′.
(2.2.1)

All rearrangements below use Theorem 1.5.3: commutativity and associativity of +, commutativity of ⋅, and distributivity.

Sum, first argument. We need (a+c,b+d)∼(a′+c,b′+d), that is, (a+c)+(b′+d)=(b+d)+(a′+c). The left side is (a+b′)+(c+d), which by Eq. 2.2.1 equals (b+a′)+(c+d), and that is the right side rearranged.

Product, first argument. We need (ac+bd, ad+bc)∼(a′c+b′d, a′d+b′c), that is, the cross-sum equation

(ac+bd)+(a′d+b′c)=(ad+bc)+(a′c+b′d).
(2.2.2)

Multiply both sides of Eq. 2.2.1 by c and use distributivity: ac+b′c=bc+a′c. Multiply both sides of Eq. 2.2.1, read from right to left, by d: bd+a′d=ad+b′d. Adding these two equations, (ac+b′c)+(bd+a′d)=(bc+a′c)+(ad+b′d). The left side rearranges to the left side of Eq. 2.2.2, and the right side to its right side. This proves Eq. 2.2.2.

Second arguments. By commutativity in N, g+((a,b),(c,d))=(a+c,b+d)=(c+a,d+b)=g+((c,d),(a,b)), and likewise g⋅((a,b),(c,d))=(ac+bd, ad+bc)=(ca+db, cb+da)=g⋅((c,d),(a,b)). So if (c,d)∼(c′,d′), then, by the first-argument case applied with the roles of the two pairs exchanged, g((a,b),(c,d))=g((c,d),(a,b))∼g((c′,d′),(a,b))=g((a,b),(c′,d′)) for g=g+ and g=g⋅. This is the second hypothesis of Theorem 2.2.1 (b).

Negative. The pair (b,a) is related to (b′,a′) when b+a′=a+b′, and that is Eq. 2.2.1 read from right to left. This is the hypothesis of Theorem 2.2.1 (a).

By Theorem 2.2.1 (b) and (a), the three rules define functions Z×Z→Z, Z×Z→Z and Z→Z, as claimed.

The answer to the prompt is the first paragraph of the proof of Theorem 2.2.1 (b): two one-argument changes, g(x,y)∼g(x′,y) and g(x′,y)∼g(x′,y′), are joined by transitivity of ∼. Changing both at once is also possible, but the computation then mixes four equations in eight unknowns; one argument at a time keeps each computation to a single hypothesis.

2.2.4. Rules that fail

Every check happens in the hypotheses of the lemma. Here they fail, next to a rule where they hold.

Example (The first coordinate is not a function of the class)
  • (a) Does the rule [(a,b)]↦a define a function Z→N?
  • (b) Does the rule [(a,b)]↦[(a+1,b)] define a function Z→Z?
  • (c) A student argues: “Each integer x has a pair with least first coordinate, by Theorem 1.6.2 applied to the non-empty set of first coordinates of the pairs in x; call that least first coordinate h(x). Then h is a function Z→N, since each x determines its own least first coordinate. So [(a,b)]↦a is a function, namely h, with h([(a,b)])=a for every (a,b).” Find the error.

Solution.

  • (a) No. (0,2)∼(1,3), since 0+3=2+1, so [(0,2)]=[(1,3)] by Sets, Relations, and Cardinality, Theorem 4.2.1 (b). Read with the representative (0,2), the rule gives 0; read with (1,3), it gives 1. One input gets two values, and (Fn2) of Sets, Relations, and Cardinality, Definition 1.5.1 fails. The hypothesis of Theorem 2.2.1 (a), with f(a,b):=a and equality on N as ≈ (so that f(x)≈f(x′) means f(x)=f(x′)), fails at x=(0,2), x′=(1,3).

  • (b) Yes. Let (a,b)∼(a′,b′), so a+b′=b+a′. Then (a+1)+b′=(a+b′)+1=(b+a′)+1=b+(a′+1) by Theorem 1.5.3 (b), (c), which is (a+1,b)∼(a′+1,b′). By Theorem 2.2.1 (a), the rule is a function. In fact it is x↦x+[(1,0)], since [(a,b)]+[(1,0)]=[(a+1,b+0)]=[(a+1,b)].

  • (c) The conclusion is false, by (a), so some step fails. The function h is fine: the least first coordinate is computed from the set x alone. The failing step is the last clause, “h([(a,b)])=a for every (a,b)”. It holds only when (a,b) happens to be the pair with least first coordinate. The argument chose a particular representative to define h, and then used an arbitrary one. Counterexample to the step: x=[(1,3)]=[(0,2)] contains (0,2), so h(x)=0, while the representative (1,3) has first coordinate 1.

Warning. A formula that looks right need not be well defined. “[(a,b)]⋅[(c,d)]:=[(ac,bd)], like the sum” is not a definition: (1,0)∼(2,1), since 1+1=0+2, but with (c,d)=(1,2) the outputs are (1⋅1,0⋅2)=(1,0) and (2⋅1,1⋅2)=(2,2), and (1,0)≁(2,2), since 1+2≠0+2. And well defined is necessary, not sufficient. The rule [(a,b)]∗[(c,d)]:=[(ad+bc, ac+bd)] is well defined, since it is the negative of the product; but it gives [(0,1)]∗[(0,1)]=[(0+0,0+1)]=[(0,1)], so the “square” of the class of (0,1) is that class itself, not [(1,0)]. Well-definedness says that a rule is a function; whether it is the right function is a separate question.

2.2.5. The natural numbers inside the integers

The integers were built to contain the natural numbers and more. They do not literally contain them: the natural number 0 is the empty set (Definition 1.5.1 (c)), while every integer is a non-empty class (Sets, Relations, and Cardinality, Theorem 4.2.1 (a)), so 0∉Z. What Z contains is a copy of N, the classes in normal form [(n,0)], and the copy has the same arithmetic.

Proposition 2.2.3 (The Natural Numbers Embed in the Integers)

Let ι:N→Z, ι(n):=[(n,0)].

  • (a) ι is injective, and for all m,n∈N, ι(m+n)=ι(m)+ι(n),ι(mn)=ι(m)ι(n).
  • (b) For every x∈Z, x+ι(0)=x and ι(1)⋅x=x. For every (a,b)∈N×N, [(a,b)]=ι(a)+(−ι(b)).
  • (c) Z=ι(N)∪{−ι(n):n∈N}.

Idea. The identities in (a) and (b) are computations with the formulas of Definition 2.2.1 in which at least one operand is some ι(n)=[(n,0)], and its zero second coordinate makes most terms vanish. Injectivity and (c) are the two halves of Proposition 2.1.2: (b) of it says that different natural numbers give different classes, and (a) says that every class is in normal form.

Proof. (a) If ι(m)=ι(n), then [(m,0)]=[(n,0)], so m=n by Proposition 2.1.2 (b); hence ι is injective (Sets, Relations, and Cardinality, Definition 1.5.3). By Definition 2.2.1, ι(m)+ι(n)=[(m+n, 0+0)]=[(m+n,0)]=ι(m+n), since 0+0=0 (Definition 1.5.1 (a)), and ι(m)ι(n)=[(mn+0⋅0, m⋅0+0⋅n)]=[(mn,0)]=ι(mn), since m⋅0=0 (Definition 1.5.1 (b)), 0⋅n=0 (Theorem 1.5.3 (e)) and k+0=k.

(b) Let x=[(a,b)]. Then x+ι(0)=[(a+0,b+0)]=[(a,b)]=x, and ι(1)⋅x=[(1⋅a+0⋅b, 1⋅b+0⋅a)]=[(a,b)]=x, by Theorem 1.5.3 (e) (1⋅n=n, 0⋅n=0) and n+0=n. Finally, −ι(b)=−[(b,0)]=[(0,b)], so ι(a)+(−ι(b))=[(a+0, 0+b)]=[(a,b)], using 0+b=b (Theorem 1.5.3 (a)).

(c) (⊇) Both sets on the right consist of integers. (⊆) Let x∈Z. By Proposition 2.1.2 (a), x=[(k,0)] or x=[(0,k)] for some k∈N. In the first case x=ι(k). In the second, x=[(0,k)]=−[(k,0)]=−ι(k) by Definition 2.2.1. So x lies in the right side.

Identification. From now on we write n for ι(n) and regard N as a subset of Z. This is a convenient abuse of notation, and (a) makes it honest: because ι is injective, different natural numbers stay different; because ι preserves + and ⋅, a sum or product of natural numbers is the same whether computed in N or in Z. One could rebuild Z so that it contains N literally, by putting each n in place of ι(n), but nothing later needs it. The order of N is matched to an order on Z in Section 2.3.

With this convention, (b) reads [(a,b)]=a+(−b): the pair (a,b) records the difference it was meant to record. The notation a−b is defined in Section 2.3, where x−y:=x+(−y) is set up in every ring at once. Clause (c) reads Z=N∪{−n:n∈N}, which is word for word the definition of the integers in Sets, Relations, and Cardinality, Section 2.1. There it was a definition inside the familiar real numbers; here it is a theorem about a set built from ω. The positive integers keep the definition of Sets, Relations, and Cardinality, Section 2.1, Z>0:={n∈N:n≠0}, which mentions only N, and so is now a subset of Z. In particular 5+x=3 has the solution x=[(0,2)]=−2 in Z, since [(5,0)]+[(0,2)]=[(5,2)]=[(3,0)] by Proposition 2.1.2 (a).

Quick check. Compute [(2,5)]⋅[(4,1)] from Definition 2.2.1, and write the two factors and the product as n or −n with n∈N.

Solution. [(2,5)]⋅[(4,1)]=[(2⋅4+5⋅1, 2⋅1+5⋅4)]=[(13,22)]. By Proposition 2.1.2 (a): 5=2+3, so [(2,5)]=[(0,3)]=−3; 4=1+3, so [(4,1)]=[(3,0)]=3; and 22=13+9, so [(13,22)]=[(0,9)]=−9. So the product of −3 and 3 is −9, as school predicts; here it is a computation in N, not a rule of signs.

The integers now have a sum, a product and a negative, each a function on classes, and they contain a copy of N with its arithmetic. Section 2.3 checks that these operations obey the usual laws, by reducing each law to a law of N, and defines the order.

2.2.6. Exercises

A. Check your understanding

Exercise (A1)

These questions are about the proof of Proposition 2.2.2.

  • (a) Which hypothesis of Theorem 2.2.1 (b) does the computation leading to Eq. 2.2.2 verify?
  • (b) Run that computation with (a,b)=(1,3), (a′,b′)=(4,6) and (c,d)=(2,0): check that (a,b)∼(a′,b′), compute both outputs, and check that they are equivalent.
  • (c) Where in the proof are the laws of arithmetic in N used?
  • (d) Give the idea of the proof in two sentences.

Solution.

  • (a) The first: for all x,x′,y, x∼x′ implies g⋅(x,y)∼g⋅(x′,y), with x=(a,b), x′=(a′,b′), y=(c,d).

  • (b) 1+6=7=3+4, so (1,3)∼(4,6). The outputs are (ac+bd, ad+bc)=(2+0, 0+6)=(2,6),(a′c+b′d, a′d+b′c)=(8+0, 0+12)=(8,12), and 2+12=14=6+8, so they are equivalent. The two intermediate equations are ac+b′c=bc+a′c, here 2+12=6+8, and bd+a′d=ad+b′d, here 0=0, since d=0. Both outputs are representatives of −4, and indeed (−2)⋅2=−4.

  • (c) In every rearrangement: commutativity and associativity of + (to regroup the four-term sums), distributivity (to multiply Eq. 2.2.1 by c and by d), and commutativity of ⋅ and + (in the second-argument step, to see that both formulas are symmetric in the two input pairs).

  • (d) A change of representative in one argument is an equation in N, and multiplying it by c and by d and adding gives exactly the cross-sum equation for the two products. The second argument follows by symmetry of the formula, and transitivity (inside Theorem 2.2.1 (b)) combines the two changes.

B. Practice

Exercise (B1: Two rules that pass the check)

Prove that each rule defines a function Z→Z, and identify it in terms of the operations of Definition 2.2.1.

  • (a) [(a,b)]↦[(b,a)].
  • (b) [(a,b)]↦[(a+b, a+b)].

Solution.

  • (a) Let (a,b)∼(a′,b′), that is, a+b′=b+a′. The target (b,a)∼(b′,a′) is b+a′=a+b′, the same equation read from right to left. By Theorem 2.2.1 (a), the rule is a function. It is the negative x↦−x of Definition 2.2.1.

  • (b) Every output is the zero class: (a+b,a+b)∼(0,0), since (a+b)+0=(a+b)+0. So for (a,b)∼(a′,b′) the outputs (a+b,a+b) and (a′+b′,a′+b′) are both related to (0,0), hence to each other by (Eq2) and (Eq3) of Proposition 2.1.1, and Theorem 2.2.1 (a) applies. The function is the constant map x↦0, where 0=ι(0)=[(0,0)]. In terms of Definition 2.2.1 it is x↦x+(−x), since [(a,b)]+[(b,a)]=[(a+b, b+a)]=[(a+b, a+b)] by Theorem 1.5.3 (b).

Exercise (B2: Determine which)

Determine which of the following rules define a function. Justify your answer.

  • (a) Z→N, [(a,b)]↦a+b.
  • (b) Z→Z, [(a,b)]↦[(2a,2b)].
  • (c) Z→Z, [(a,b)]↦[(a2,b2)], where n2:=n⋅n.

Solution.

  • (a) No. [(0,0)]=[(1,1)], since 0+1=0+1, but the rule gives 0+0=0 for the first representative and 1+1=2 for the second.

  • (b) Yes. If a+b′=b+a′, then by distributivity (Theorem 1.5.3 (d)) 2a+2b′=2(a+b′)=2(b+a′)=2b+2a′, which is (2a,2b)∼(2a′,2b′); Theorem 2.2.1 (a) applies. The function is x↦x+x: [(a,b)]+[(a,b)]=[(a+a,b+b)], and 2n=(1+1)n=n+n by 1+1=2 (Definition 1.5.1 (c)) and Theorem 1.5.3 (d), (e).

  • (c) No. [(0,1)]=[(1,2)], since 0+2=1+1. The rule gives [(0,1)] for the first representative and [(1,4)] for the second, and (0,1)≁(1,4), since 0+4=4≠2=1+1.

C. Going deeper

Exercise (C1: Properties of classes, and an operation that half works)
  • (a) Prove Theorem 2.2.1 (c), and give an example, different from the one in the remark after the theorem, of a subset S⊆N×N for which its conclusion fails for ∼ of Definition 2.1.1.
  • (b) Give an example of an equivalence relation ∼ on N and a function g:N×N→N such that the first hypothesis of Theorem 2.2.1 (b) holds and the second fails. Check each property, and show that no function G as in the conclusion of (b) exists for your example.

Solution.

  • (a) Proof. Let x∈X. If x∈S, then [x]∈S¯ by the definition of S¯. Conversely, if [x]∈S¯, there is x′∈S with [x]=[x′]; then x∼x′ (Sets, Relations, and Cardinality, Theorem 4.2.1 (b)), so x′∼x by symmetry, and the hypothesis on S, applied to x′∼x and x′∈S, gives x∈S.

    Example. Let S:={(a,b)∈N×N:a=0}. Then (0,0)∈S, so [(0,0)]∈S¯; and [(1,1)]=[(0,0)], so [(1,1)]∈S¯, but (1,1)∉S. The hypothesis fails at (0,0)∼(1,1). Any example must contain a pair of S and an equivalent pair outside S, since that is exactly the negation of the hypothesis.

  • (b) Example. On N, let x∼y mean “x=0 if and only if y=0”. This is an equivalence relation: it says that x and y have the same value under the function sending 0 to 0 and every other number to 1, so it is an equivalence relation by Sets, Relations, and Cardinality, Example (The fibers of a function). Its two classes are {0} and N∖{0}. Let g(x,y):={xif y=1,0if y≠1. First hypothesis holds. Let x∼x′ and y∈N. If y=1, then g(x,y)=x∼x′=g(x′,y). If y≠1, both values are 0, and 0∼0.

Second hypothesis fails. 1∼2, since neither is 0; but g(5,1)=5 and g(5,2)=0, and 5≁0.

No induced G. If G([x],[y])=[g(x,y)] held for all x,y, then, since [1]=[2], we would get [5]=[g(5,1)]=G([5],[1])=G([5],[2])=[g(5,2)]=[0], and [5]≠[0] because 5≁0.

What any example must have. (i) ∼ is not equality: some class has two elements y∼y′ with y≠y′, else the second hypothesis holds trivially. (ii) ∼ has at least two classes, else every two outputs are related and both hypotheses hold. (iii) For some x and some y∼y′, the values g(x,y) and g(x,y′) lie in different classes, while for every y, changing x within its class never moves g(x,y) out of its class. A different answer can be checked against (i)–(iii).

Exercise (C2: One at a time or both at once)

Let ∼ be an equivalence relation on X and g:X×X→X a function. Prove that the hypotheses of Theorem 2.2.1 (b) hold if and only if, for all x,x′,y,y′∈X, x∼x′ and y∼y′⟹g(x,y)∼g(x′,y′). Name the property of ∼ that each direction uses.

Solution. (⇒) Let x∼x′ and y∼y′. The first hypothesis, with y fixed, gives g(x,y)∼g(x′,y); the second, with x′ fixed, gives g(x′,y)∼g(x′,y′). By transitivity (Eq3), g(x,y)∼g(x′,y′). This direction is the first paragraph of the proof of Theorem 2.2.1 (b).

(⇐) Let x∼x′ and y∈X. By reflexivity (Eq1), y∼y, so the displayed condition with y′=y gives g(x,y)∼g(x′,y): the first hypothesis. Likewise x∼x and y∼y′ give g(x,y)∼g(x,y′): the second.

So the two forms are interchangeable. The one-at-a-time form is the one to check, because each check involves a single hypothesis x∼x′; the both-at-once form is the one the proof of the lemma uses.
