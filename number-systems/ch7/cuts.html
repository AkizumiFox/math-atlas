7.1  Cuts

This section opens Chapter 7, which is optional: nothing outside the chapter depends on it, and the volume’s main line ended with Chapter 6. Chapter 5 built a real number as a class of Cauchy sequences of rationals, and Chapter 6 proved that any two complete ordered fields are linked by exactly one order-preserving field isomorphism. Here we begin a second construction, Dedekind’s, in which a real number is a single set of rationals: the set of all rationals below it. This section defines these sets, called cuts, tests the definition on the rationals and on the gap that Section 2.6 found, and proves two lemmas on which the rest of the chapter rests. The inside and the outside of a cut are separated, and one can walk up through a cut in steps of any fixed size until one steps out.

Throughout the chapter, lower-case Latin letters such as p,q,r,s stand for rationals and m,n,k for natural numbers; Section 7.6, which brings back the field of Chapter 5, says where that changes. Nothing about real numbers is assumed: they are what is being built.

7.1.1. The set below the gap

Section 2.6 proved that the set A:={x∈Q:x2<2} is non-empty and bounded above in Q, and has no supremum in Q (Theorem 2.6.2 (a)). Its rational upper bounds crowd down toward a place where Q has no element. Chapter 5 filled that place with a new object, a class of sequences. Dedekind noticed that something already present in Q describes the place exactly: the set of rationals that lie below it.

That set is not quite A. The set A contains −1, since (−1)2=1<2, but not −2, since (−2)2=4>2; it is a window of rationals around 0, not “everything below” anything. Adding the non-positive rationals repairs this. Let σ:={p∈Q:p≤0 or p2<2}. This set has the same upper bounds in Q as A. It contains A, so every upper bound of σ bounds A. Conversely, let u be an upper bound of A; since 1∈A, u≥1>0, and every element p of σ outside A has p≤0<u. The conditions (S1) and (S2) of a supremum mention only the set of upper bounds (Sets, Relations, and Cardinality, Definition 4.3.5), so σ, like A, has no supremum in Q; this is the argument of Theorem 2.6.2 (b).

So no rational sits at the top of σ, yet σ itself is a perfectly good set of rationals. Dedekind’s move is to take the set as the number. The rest of the chapter makes this precise: it says which sets of rationals qualify, orders them, adds and multiplies them, and proves that they form a complete ordered field.

7.1.2. Dedekind cuts

Which subsets of Q should count as “the set of rationals below a number”? Three features of σ suggest the answer. It is neither empty nor all of Q: a number should have rationals below it and rationals above it. With any rational it contains every smaller one. And it has no largest element, as Example (The cut of the gap) below shows. The third feature is the least obvious, and the paragraph “Why this definition” after the examples explains it.

A real number is the set of rationals below it.

Definition 7.1.1 (Dedekind Cut)

A subset α⊆Q is a cut (or Dedekind cut) if

  • (C1) α≠∅ and α≠Q;
  • (C2) for every p∈α and every q∈Q with q<p, q∈α;
  • (C3) α has no largest element: for every p∈α there exists p′∈α with p′>p.

The set of all cuts is RD:={α∈P(Q):α satisfies (C1), (C2) and (C3)}, a subset of the power set P(Q) (Sets, Relations, and Cardinality, Definition 1.3.2).

In symbols, with bounded quantifiers, (C1)∃p∈Q (p∈α) ∧ ∃q∈Q (q∉α),(C2)∀p∈α ∀q∈Q (q<p⇒q∈α),(C3)∀p∈α ∃p′∈α (p′>p).

In words, clause by clause. (C1) says that the cut is a proper, non-empty part of Q: some rational is in it and some rational is not. (C2) says that the cut is closed downward: whatever rational it contains, it contains every smaller one too. (C3) says that it has no top: above each of its elements it has another. The letters α,β,γ,δ are reserved for cuts in this chapter.

Well-definedness. The collection RD is a set: it is carved out of the set P(Q) by a condition, which (Z6) of Axiom 1.1.1 allows, and P(Q) exists by (Z5). A real number in the sense of this chapter is therefore literally an element of P(Q), a subset of Q.

Negations. We shall often show that a set is not a cut, so the three negations are worth writing out once. By Logic and Proof, Proposition 6.2.3 and Logic and Proof, Proposition 6.2.2, a subset α⊆Q fails

  • (C1) if α=∅ or α=Q;
  • (C2) if ∃p∈α ∃q∈Q (q<p∧q∉α): some element has a smaller rational missing;
  • (C3) if ∃p∈α ∀p′∈α (p′≤p): α has a largest element.

In the last line, “not p′>p” became p′≤p by trichotomy in Q (Proposition 2.3.5 (i)).

The first examples are the rationals themselves. For a rational q, the rationals below q form a cut, and this is how the old numbers will sit among the new ones.

Definition 7.1.2 (Rational Cut)

For q∈Q, let Dq:={r∈Q:r<q}. It is a cut (checked below), the rational cut of q. A cut α is rational if α=Dq for some q∈Q.

Dq is a cut. (C1): q−1∈Dq, since q−(q−1)=1>0 (Proposition 2.3.5 (e), as 1≠0 in the field Q, Theorem 2.5.1), so q−1<q by Proposition 2.3.5 (a); and q∉Dq, since q<q fails by (O1). (C2): if p∈Dq and r<p, then r<p<q, so r<q by (O2), and r∈Dq. (C3): if r∈Dq, the midpoint (r+q)/2 satisfies r<(r+q)/2<q (Section 2.5, “Between two rationals”), so it lies in Dq and is larger than r.

The letter D is for Dedekind.

Example (The cut of the gap)

Show that σ={p∈Q:p≤0 or p2<2} is a cut.

Solution. (C1): 0∈σ, since 0≤0. And 2∉σ: 2>0, and 22=4>2.

(C2): let p∈σ and q∈Q with q<p. If q≤0, then q∈σ. Otherwise 0<q<p. Then p>0, so p≤0 fails and p2<2. Since 0≤q<p, Proposition 2.3.5 (g) gives q2<p2, so q2<2 by (O2), and q∈σ.

(C3): let p∈σ. If p≤0, then 1∈σ (as 12=1<2) and 1>0≥p. If p>0, then p2<2. Put d:=2−p2,h:=d2p+2. Here d>0, and d<2 because p2>0 (Proposition 2.3.5 (e)); also 2p+2>2, since p>0. So 0<h<1 (Proposition 2.5.2 (a) for h>0; d<2p+2 for h<1). From 0<h<1, h2<h by Proposition 2.3.5 (c). Hence (p+h)2=p2+2ph+h2<p2+2ph+h<p2+h(2p+2)=p2+d=2, where the second inequality adds h>0 (O3). So p+h∈σ, and p+h>p.

The step size h depends on p: the closer p2 is to 2, the smaller d and so h. That is unavoidable, since a fixed step would jump out of σ from points near the top. Section 7.5 proves that σ is not a rational cut, σ≠Dq for every q∈Q, and Exercise C1 below asks for a direct proof. So σ is a genuinely new number: the cut that will square to 2.

Quick check. Which of the following subsets of Q are cuts? For each that is not, name a condition that fails.

  • (a) {p∈Q:p<0 or p2<4};
  • (b) {p∈Q:p2<2};
  • (c) {p∈Q:p3<5};
  • (d) ∅.

Solution.

  • (a) It is a cut, because it equals D2. If p<0, then p<2. If p≥0 and p2<4=22, then p<2 by Proposition 2.3.5 (g). Conversely, if p<2, either p<0, or 0≤p<2 and then p2<4 by (g).

  • (b) Not a cut: (C2) fails. The set contains 1, and −2<1, but (−2)2=4>2, so −2 is missing.

  • (c) A cut. Call the set E. Cubes are monotone on non-negatives: for 0≤q<p, p3−q3=(p−q)(p2+pq+q2), where p−q>0 and p2+pq+q2≥p2>0 (Proposition 2.3.5 (e), with pq,q2≥0); so p3−q3>0 by (O4). (C1): 0∈E, and 2∉E, as 23=8>5. (C2): let q<p∈E. If q≤0, then q3≤0<5 (q3=q⋅q2, a non-positive times a non-negative). If q>0, then 0<q<p and q3<p3<5. (C3): let p∈E. If p≤0, then 1∈E is larger. If p>0, put d:=5−p3 and h:=d/(3p2+3p+5). Then 0<d<5<3p2+3p+5, so 0<h<1, hence h3<h2<h by Proposition 2.3.5 (c), and (p+h)3=p3+3p2h+3ph2+h3<p3+h(3p2+3p+1)<p3+d=5. So p+h∈E and p+h>p.

  • (d) Not a cut: (C1) fails, since ∅ has no element.

Why this definition. Each clause excludes something that would spoil the arithmetic to come.

  • Without (C1), ∅ and Q would be numbers, below and above every rational. Section 7.3 adds cuts as sets, and Q+D0=Q=Q+D1 there would make cancellation fail.
  • Without (C2), {p:p2<2} of the Quick check would be a number. It contains 1 but not the smaller rational −2, so it is not the set of all rationals below anything.
  • Without (C3), each rational q would be represented twice, by Dq and by {r∈Q:r≤q}. The next example shows that this is more than untidy: the sum of sets cannot tell the two apart.
Example (Two candidates for one rational) Optional: nothing later depends on this.

Let E1:={r∈Q:r≤1}. Show that E1 satisfies (C1) and (C2) but not (C3), and that, with the sum of sets X+Y:={x+y:x∈X, y∈Y} of Sets, Relations, and Cardinality, Section 1.7 (Sets, Relations, and Cardinality, Example (Reflections, scalings and sums as images)), E1+D1=D2=D1+D1,although E1≠D1.

Solution. The conditions. (C1): 0∈E1 and 2∉E1. (C2): q<p≤1 gives q<1. (C3) fails: 1∈E1, and every p′∈E1 has p′≤1, so 1 is a largest element. And E1≠D1, since 1∈E1∖D1.

E1+D1=D2. (⊆): if a≤1 and b<1, then a+b<2 by Proposition 2.3.5 (b). (⊇): if s<2, then s=1+(s−1) with 1∈E1 and s−1<1, so s−1∈D1.

D1+D1=D2. (⊆): a<1 and b<1 give a+b<2, by (b) again. (⊇): if s<2, then s=s/2+s/2, and multiplying s<2 by 1/2>0 (Proposition 2.3.5 (c)) gives s/2<1, so s/2∈D1.

So if E1 were admitted as a number, the equation ξ+D1=D2 would have two solutions, E1 and D1, and addition could not be canceled, so the numbers could not form a group under addition.

Condition (C3) chooses between the two sets {r∈Q:r<1} and {r∈Q:r≤1} that describe “the rationals up to 1”: it keeps the one that leaves 1 out.

Warning. A cut is a set of rationals, not a rational. “σ<2” compares a set with a number and means nothing yet. Section 7.2 orders cuts, so that σ<D2 acquires a meaning, and Section 7.5 shows that D2 plays the part of the rational 2 among the cuts. Until then, every comparison in this chapter is between rationals, or between sets by inclusion.

7.1.3. Inside and outside

The defining conditions speak about the inside of a cut. The first lemma says what they imply about the outside: everything outside lies above everything inside.

Lemma 7.1.1 (Separation)

Let α be a cut, p∈α and q∈Q∖α. Then p<q. Consequently the complement Q∖α is closed upward: if q∉α and q′∈Q with q′>q, then q′∉α.

Proof. Suppose p<q fails. By trichotomy (Proposition 2.3.5 (i)), q≤p. If q=p, then q∈α; if q<p, then q∈α by (C2). Either way q∈α, against q∉α. So p<q.

For the consequence, let q∉α and q′>q, and suppose q′∈α. The first part, with q′ in the role of p, gives q′<q, which together with q<q′ contradicts (O1). So q′∉α.

So a cut and its complement split Q into a lower piece and an upper piece, every element of the lower below every element of the upper. In particular every rational outside a cut is an upper bound of it. Together with (C3), this gives the picture to keep in mind, and one of the chapter’s named moves:

A cut is a downset with an open top.

Inside is closed downward, outside is closed upward, everything inside lies below everything outside, and the inside has no largest element. The outside may have a least element: the complement of Dq is {r∈Q:r≥q}, with least element q. Most “is it a cut?” checks in this chapter are this sentence, read clause by clause.

The second result locates a rational relative to a cut by comparing two sets. It is the bridge between a rational q and its cut Dq.

Proposition 7.1.2 (Where a Rational Lies)

Let α be a cut and q∈Q. Then

  • (a) q∈α if and only if Dq⊊α;
  • (b) q∉α if and only if α⊆Dq.

Idea. If q is in α, closure downward brings everything below q along, and q itself is the extra element. If q is outside, separation puts all of α below q. The two converses come from the same two facts.

Proof.

  • (a) (⇒) Let q∈α. For r∈Dq, r<q, so r∈α by (C2); thus Dq⊆α. The inclusion is proper, because q∈α and q∉Dq (as q<q fails, (O1)). (⇐) Let Dq⊊α. Then some r∈α has r∉Dq, that is, r<q fails, so q≤r (Proposition 2.3.5 (i)). If q=r, then q∈α; if q<r, then q∈α by (C2).

  • (b) (⇒) Let q∉α. For r∈α, Lemma 7.1.1 gives r<q, so r∈Dq; thus α⊆Dq. (⇐) Let α⊆Dq. Since q∉Dq, also q∉α.

Since every rational is either in α or not, exactly one of Dq⊊α and α⊆Dq holds. Section 7.2 rewrites (a) as q∈α⟺Dq<α, once inclusion has become the order on cuts.

7.1.4. Walking up through a cut

Many proofs in this chapter need two rationals, one inside a cut and one outside, that are close together: within a prescribed rational distance ε>0. Separation says that the inside lies below the outside, but not that the two come close. They do, and the reason is a walk: start inside, climb in steps of ε, and stop at the first step that leaves the cut.

Lemma 7.1.3 (The Step Lemma)

Let α be a cut, a∈α, and ε∈Q with ε>0. Then there is n∈N with a+nε∈αanda+(n+1)ε∉α.

Idea. Picture the rungs a,a+ε,a+2ε,…. The bottom rung a is inside. Some rung is outside: pick any rational b outside α; the rationals are Archimedean, so finitely many steps of size ε climb past b, and everything above b is outside by separation. Among the rungs outside there is a lowest one, because a non-empty set of natural numbers has a least element. It is not the bottom rung, so the rung just below it exists and is inside. The n found depends on α, a and ε.

Proof. By (C1), there is b∈Q with b∉α. By Theorem 2.5.3, applied to the rational (b−a)/ε, there is m∈N with (b−a)/ε<m. Multiplying by ε>0 (Proposition 2.3.5 (c)) gives b−a<mε, so b<a+mε by (O3). Since b∉α, Lemma 7.1.1 gives a+mε∉α.

Let K:={k∈N:a+kε∉α}. Then m∈K, so K is a non-empty set of integers, and 0 is a lower bound of it. By Proposition 2.3.6, K has a least element k0. Since a+0⋅ε=a∈α, 0∉K, so k0≠0 and k0>0. By discreteness (Theorem 2.3.4 (c)), k0≥1. Put n:=k0−1. Then n≥0 by (O3), so n∈N (Theorem 2.3.4 (b)). Since n<k0 and k0 is least in K, n∉K, that is, a+nε∈α. And a+(n+1)ε=a+k0ε∉α, since k0∈K. This proves the lemma.

Since n≥0 and ε>0, the point p:=a+nε found by the lemma satisfies p≥a. So the lemma hands over a pair p∈α, p+ε∉α: a point inside and a point outside, exactly ε apart, with the inside point as high as we like above a given element. This is another of the chapter’s named moves.

Walk up by ε: from a point inside a cut, add ε until you leave; the last step inside and the first step outside are ε apart.

It drives the hardest “⊇” halves to come: the additive inverse in Section 7.3 and, in its multiplicative form of Section 7.4, the multiplicative inverse in Section 7.4 and the square of σ in Section 7.5. Note what it needs from Q: the Archimedean property, to know that the walk leaves the cut at all, and least elements and discreteness of the integers, to find the first step out and the step before it.

Here is one walk, through σ from a=1 in steps of ε=1/10. The rungs 1,11/10,12/10,… are positive, so a rung r lies in σ exactly when r2<2. Now (14/10)2=196/100<2, because 196<200, and the lower positive rungs have smaller squares (Proposition 2.3.5 (g)), so the rungs for k=0,…,4 are inside. But (15/10)2=225/100>2. So the least k with 1+k/10∉σ is k0=5, the n of the lemma is 4, and the pair is 7/5∈σ, 3/2∉σ.

Quick check. Continue the walk with a finer step: start at a=7/5∈σ and take ε=1/100. Which pair p∈σ, p+ε∉σ does the lemma give?

Solution. The rungs are 140/100,141/100,142/100,…. Since 1412=19881<20000, (141/100)2<2, so 141/100∈σ. Since 1422=20164>20000, 142/100∉σ. So k0=2, n=1, and the pair is p=141/100, p+ε=142/100=71/50.

Each walk traps the top of σ between two rationals ε apart, and a smaller ε traps it more tightly. No walk ever lands on the top, since σ has none.

7.1.5. Exercises

A. Check your understanding

Exercise (A1)
  • (a) State (C1)–(C3) for a subset α⊆Q, and write the negation of (C3) in symbols.
  • (b) For each set, name every condition among (C1)–(C3) that fails: (i) {p∈Q:p≤3}; (ii) {p∈Q:p>0}; (iii) {p∈Q:p2≤0}; (iv) {p∈Q:p<p+1}.
  • (c) Let q,r∈Q. Is Dq∪Dr a cut? Is Dq∩Dr? Identify each.

Solution.

  • (a) (C1) α≠∅ and α≠Q; (C2) for every p∈α and every q∈Q with q<p, q∈α; (C3) for every p∈α there is p′∈α with p′>p. The negation of (C3) is ∃p∈α ∀p′∈α (p′≤p): α has a largest element.

  • (b)
    • (i) Only (C3) fails: 3 is a largest element. (C1) holds (0 in, 4 out) and (C2) holds (q<p≤3 gives q<3). (ii) Only (C2) fails: 1 is in, and 0<1 is not. (C1) holds (1 in, 0 out), and (C3) holds (p+1>p>0). (iii) The set is {0}, since p≠0 gives p2>0 (Proposition 2.3.5 (e)). (C2) fails (−1<0, −1 missing) and (C3) fails (0 is largest); (C1) holds. (iv) The set is Q, since 0<1 gives p<p+1 for every p (O3). (C1) fails; (C2) and (C3) hold.

  • (c) Both are cuts. If q≤r, then Dq⊆Dr (s<q≤r gives s<r), so Dq∪Dr=Dr and Dq∩Dr=Dq; if r≤q, the roles swap. So Dq∪Dr=Dmax(q,r) and Dq∩Dr=Dmin(q,r), rational cuts by Definition 7.1.2.

B. Practice

Exercise (B1)

Prove that {p∈Q:3p<2} is a cut, and that it equals D2/3.

Solution. For p∈Q, 3p<2 implies p<2/3, by multiplying with 1/3>0 (Proposition 2.5.2 (a), Proposition 2.3.5 (c)); and p<2/3 implies 3p<2, by multiplying with 3>0. So the set is {p∈Q:p<2/3}=D2/3, and it is a cut because every rational cut is one (Definition 7.1.2, with the check after it).

Exercise (B2)

Prove that {p∈Q:p<0 or p2<3} is a cut. For (C3), give an explicit larger element.

Solution. Call the set β. (C1): 0∈β, since 02=0<3; and 2∉β, since 2≥0 and 22=4>3.

(C2): let q<p∈β. If q<0, then q∈β. Otherwise 0≤q<p, so p>0, p<0 fails, and p2<3. By Proposition 2.3.5 (g), q2<p2<3, so q∈β.

(C3): let p∈β. If p<0, then 0∈β and 0>p. If p≥0, then p2<3. Put d:=3−p2,h:=d2p+4. Then 0<d≤3<4≤2p+4, so 0<h<1 and h2<h (Proposition 2.3.5 (c)). Hence (p+h)2=p2+2ph+h2<p2+h(2p+1)<p2+h(2p+4)=p2+d=3, so p+h∈β and p+h>p. (The denominator is chosen to exceed d, so that h<1, and to be at least 2p+1; any such denominator works.)

C. Going deeper

Exercise (C1: The cut of the gap is not rational)

Prove directly from the definitions that σ≠Dq for every q∈Q.

Solution (Hint 1). If σ=Dq, where would q itself sit relative to σ? What does that say about q and q2?

Solution (Hint 2). You will reach q>0 and q2≥2. If q2>2, look for a smaller positive rational whose square still exceeds 2; Section 2.6 has one.

Solution. Suppose σ=Dq for some q∈Q. Since q∉Dq, q∉σ: so q≤0 fails, and q2<2 fails. That is, q>0 and q2≥2.

Case q2=2. Impossible, by Theorem 2.6.1.

Case q2>2. Let q′:=(q2+2)/(2q), the rational t(q) of Section 2.6. It is positive, as a quotient of positives (Proposition 2.5.2 (a), (O4)). By the identities Eq. 2.6.1, q−q′=q2−22q>0,q′2−2=(q2−2)24q2>0, the first a quotient of positives, the second because q2−2≠0 (Proposition 2.3.5 (e)). So q′<q, that is, q′∈Dq=σ. But q′>0 and q′2>2, so q′∉σ. This contradiction shows that σ≠Dq.

Marking scheme. (10 points) - 3: from q∉Dq=σ, derives both q>0 and q2≥2. - 2: excludes q2=2, citing that no rational squares to 2. - 3: for q2>2, exhibits a rational q′ with 0<q′<q and q′2>2, with both inequalities verified (any such q′ earns the points). - 2: concludes: q′ lies in Dq but not in σ. Fatal errors (0 for the step): “q=2” or any use of a square root of 2 as a number; a candidate q′ whose square is not checked to exceed 2.
