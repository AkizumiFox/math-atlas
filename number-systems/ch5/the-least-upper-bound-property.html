5.5  Least Upper Bounds

Section 5.4 made R an Archimedean ordered field with Q dense in it. Analysis on the Real Line, Chapter 1 starts from a property of sets: every non-empty set of real numbers that is bounded above has a least upper bound. In Q it fails (Theorem 3.3.2). This section names the property for an arbitrary ordered field and proves that the constructed R has it. The proof halves intervals with rational ends. Their right ends form a Cauchy sequence of rationals, which is a real number by definition, and that number is the least upper bound. The sequence form of completeness, that every Cauchy sequence of reals converges, is proved from this one in Analysis on the Real Line, Chapter 4.

Throughout, F is an ordered field (Definition 2.4.1). Its order ≤ is a total order (Proposition 4.1.2 (a)), so the words “upper bound”, “bounded above” and “supremum” of Sets and Functions, Section 5.3 apply to subsets of F (Sets and Functions, Definition 5.3.2, Sets and Functions, Definition 5.3.5). When F=R, we keep the identification of Section 5.4, writing q for κ(q).

5.5.1. Complete ordered fields

Section 3.3 found a gap in Q without any sequence: the set A={x∈Q:x2<2} is non-empty and bounded above in Q, and among its rational upper bounds there is no least one (Theorem 3.3.2). The upper bounds crowd down toward a place where Q has no element. A field without such gaps is one in which every set that could have a least upper bound does have one.

Every non-empty set that is bounded above has a least upper bound.

Definition 5.5.1 (Complete Ordered Field)

An ordered field F is complete if every non-empty subset A⊆F that is bounded above in (F,≤) (Sets and Functions, Definition 5.3.2) has a supremum in F (Sets and Functions, Definition 5.3.5). In symbols, writing ub(u) for ∀a∈A  a≤u, ∀A⊆F  ((A≠∅∧∃u∈F ub(u))⇒∃s∈F (ub(s)∧∀u∈F (ub(u)⇒s≤u))). An ordered field in which every Cauchy sequence (Definition 4.5.1) converges is called Cauchy-complete.

In words: the hypothesis asks for a set with at least one element and at least one upper bound in F; the conclusion asks for an element s of F that is an upper bound, clause (S1), and lies below every upper bound, clause (S2). The supremum need not belong to A.

Well-definedness. A set has at most one supremum, since a supremum is a least element of the set of upper bounds (Sets and Functions, Section 5.3, the remark after Sets and Functions, Definition 5.3.5, by Sets and Functions, Proposition 5.3.1). So “the supremum of A”, written supA, names one element when it exists.

Examples.

The negative elements. In every ordered field, A:={x∈F:x<0} has supremum 0. It is non-empty (−1∈A). The element 0 is an upper bound. If an upper bound b had b<0, then b<b/2<0 (Proposition 4.1.2 (b)), so b/2∈A lies above b, which is impossible. So every upper bound b satisfies b≥0, and supA=0∉A. No completeness was needed: some sets have suprema in every ordered field.

The rationals. Q is not complete: Theorem 3.3.2 exhibits a non-empty subset bounded above with no supremum in Q.

The constructed reals. R is complete; this is the main theorem of the section.

↺Second readingA degenerate case, and non-examples by minimal change

A singleton. sup{a}=a, in every ordered field, since a greatest element is the supremum (the same remark of Sets and Functions, Section 5.3). This degenerate case matters below: a set may be bounded above by its own element.

Drop “non-empty”: the empty set is bounded above by every element of F, so its upper bounds are all of F, and F has no least element (x−1<x). Drop “bounded above”: F itself has no upper bound (x<x+1), so no supremum. With either clause removed, no ordered field at all would be complete.

Why this definition. It asks about suprema, not maxima: the set of negative elements has no greatest element in any ordered field, since x<x/2<0 for x<0, and asking for maxima would make no field complete. It asks about sets, not sequences, the form Analysis on the Real Line, Chapter 1 takes as its axiom. “Complete” alone always means this property; the sequence property is “Cauchy-complete”.

Warning. The supremum of a set is an upper bound not necessarily in the set, and “complete” is not “every non-empty bounded set has a largest element”: the set of negative elements above has supremum 0 and no largest element. A proof that ends “so supA∈A” needs a reason, such as A being finite.

So Q is not complete. The rest of the section proves that R is.

5.5.2. Powers of two in an ordered field

The bisection below halves an interval at each step, so after k steps its length is the first length divided by 2k. We need 2k to grow at least as fast as k+1, here in Q; the induction is the one for 10k in Section 5.1.

Lemma 5.5.1 (A Lower Bound for Powers of Two)

Let F be an ordered field, and let (2⋅1F)k be the power in F of Definition 4.2.1 (b). Then (2⋅1F)k≥(k+1)⋅1Ffor every k∈N. In particular (2⋅1F)k≥1F>0.

Idea. Induction on k. Multiplying by 2 doubles the right side, (k+1)+(k+1), and doubling gains at least 1, which is all the step needs.

Proof. We use Logic and Proof, Axiom 4.2.1, read on N through Corollary 1.4.3 (b), for P(k): (2⋅1F)k≥(k+1)⋅1F.

Base P(0). (2⋅1F)0=1F by Definition 4.2.1 (b), and (0+1)⋅1F=1⋅1F=0⋅1F+1F=1F by (a) of that definition, since 0+1=1 (Definition 1.2.1 (c)). Equality holds.

Step. Assume P(k), and let y:=(k+1)⋅1F. By Definition 4.2.1 (a) and Definition 1.2.1 (c), 2⋅1F=1⋅1F+1F=1F+1F, which is positive (Proposition 4.1.2 (b)). By Definition 4.2.1 (b), P(k), and Proposition 2.4.3 (c) (or equality, if P(k) holds with equality), (2⋅1F)k+1=(2⋅1F)k(2⋅1F)≥y(1F+1F)=y+y, the last step by distributivity (F9) and (F7). Since k+1≥1 (Theorem 1.3.2 (d)), Proposition 4.2.1 (b) gives y≥1F, so y+y≥y+1F (Proposition 2.4.3 (b)). Finally y+1F=((k+1)+1)⋅1F by Definition 4.2.1 (a). Hence (2⋅1F)k+1≥((k+1)+1)⋅1F, which is P(k+1).

The last sentence of the lemma follows, since (k+1)⋅1F≥1F>0 (Proposition 4.2.1 (b), as k+1≥1).

From here on, 2k means (2⋅1F)k. By Proposition 4.2.1 (c) it equals (2k)⋅1F, the multiple of 1F by the natural number 2k, so the two readings agree; the proofs below use only the power in F and the lemma. Since 2k>0, the quotient D/2k is defined for every D∈F.

5.5.3. Bisection with rational ends

Section 3.3 found the gap of Q by improving each rational candidate. In R we trap the candidate instead. Start with a rational that is an upper bound of A and one that is not, and halve: keep the half whose right end is still an upper bound and whose left end is still not. The ends stay rational, and the intervals shrink, so the right ends form a Cauchy sequence of rationals: by definition, a real number. Before reading on: which two properties of that number are needed, and which end of the intervals gives each?

Theorem 5.5.2 (The Constructed Reals Form a Complete Ordered Field)

The set R of Definition 5.2.1, with the operations of Definition 5.2.2 and the order of Definition 5.3.2, is a complete ordered field. The map κ:Q→R of Definition 5.4.1 is injective, preserves +, ⋅ and <, and has dense image: between any two real numbers x<y there is κ(q) with q∈Q.

Idea (Scratch work). A real number is a class of members of C, so the supremum should arrive as the class of a Cauchy sequence of rationals. The bisection supplies two: right ends uk, each an upper bound of A, and left ends lk, none an upper bound, with the gap halved at each step. The invariants are proved by induction, finding the claim for k inside the claim for k+1 (Sets and Functions, Example (Method: finding P(n) inside P(n+1))).

Givens Goal
A⊆R non-empty, bounded above s∈R with (S1) and (S2)
a real number is a class [(uk)], (uk)∈C rationals uk, upper bounds, and lk, not upper bounds, closing in
a step rule on the midpoint; induction keeps (I1)–(I3), uk−lk=D/2k (uk),(lk)∈C, (lk)∼(uk): s:=[(uk)]=[(lk)]
s<a∈A: a rational q between; q−uk eventually ≥δ some uk<a, against (I1): (S1)
b<s, b an upper bound: a rational q between; lk−q eventually ≥δ some lk>b, against (I2): (S2)

Both clauses of the supremum are proved by contradiction, and each spends one invariant.

Proof. R is an ordered field by Theorem 5.3.3. Let A⊆R be non-empty and bounded above.

Step 1: rational ends. Fix a0∈A and an upper bound M of A. By Theorem 5.4.3, fix l0,u0∈Q with a0−1<l0<a0 and M<u0<M+1. Then l0 is not an upper bound, since a0∈A and a0>l0; u0 is one, since a≤M<u0 for every a∈A; and D:=u0−l0∈Q>0, since l0<a0≤M<u0. Each of these is one object, fixed once.

Step 2: the bisection. Define g:N×(Q×Q)→Q×Q by g(k,(l,u)):={(l,c)if c is an upper bound of A,(c,u)otherwise,c:=l+u2∈Q. For each input exactly one case applies, so g is a function, given by a rule. By Sets and Functions, Theorem 3.3.1 (read on N through Corollary 1.4.3 (b)), with X=Q×Q and starting value (l0,u0), there is exactly one sequence k↦(lk,uk) with (lk+1,uk+1)=g(k,(lk,uk)) for every k.

We prove by induction on k that, for every k∈N:

  • (I1) uk is an upper bound of A;
  • (I2) lk is not an upper bound of A;
  • (I3) uk−lk=D/2k, in Q.

The base is Step 1, with D/20=D/1=D. Suppose (I1)–(I3) hold for k, and let c:=(lk+uk)/2. Then c−lk=uk−c=(uk−lk)/2=D/(2k⋅2)=D/2k+1, by field arithmetic in Q (Lemma 4.1.1 (b)) and Definition 4.2.1 (b). If c is an upper bound, then (lk+1,uk+1)=(lk,c): the right end c is an upper bound, the left end lk is not, by (I2), and c−lk=D/2k+1. Otherwise (lk+1,uk+1)=(c,uk): the left end c is not an upper bound, the right end uk is, by (I1), and uk−c=D/2k+1. This proves (I1)–(I3) for k+1.

By (I3), uk−lk=D/2k>0, so lk<c<uk (Proposition 4.1.2 (b)); in either case lk≤lk+1 and uk+1≤uk. By induction on i, lk≤lk+i and uk+i≤uk for every i∈N, and every j≥k is k+i for some i (Proposition 1.3.1 (a)). So for j≥k, lk≤lj<uj≤uk, and therefore

0≤uk−uj≤D2k,0≤lj−lk≤D2k(j≥k).
(5.5.1)

Step 3: a real number. Let ε∈Q>0. By Theorem 3.2.3 there is n∈N with D/ε<n. Let k≥n. By Lemma 5.5.1 with F=Q and Proposition 4.2.1 (b), 2k≥k+1>n>D/ε>0, so 1/2k<ε/D (Proposition 3.2.2 (b)), and multiplying by D>0 (Proposition 2.4.3 (c)) gives D/2k<ε. So (D/2k)k is null in Q. For j,k≥n, say j≥k, Eq. 5.5.1 gives |uj−uk|=uk−uj≤D/2k<ε (Proposition 4.1.3 (b), Definition 4.1.1); so (uk)∈C. Then (lk)=(uk−D/2k)k∈C (Theorem 4.5.3 (a), (b)), and (uk−lk)k=(D/2k)k is null, so (uk)∼(lk) (Definition 5.1.2). Let s:=[(uk)]; then s=[(lk)] (Sets and Functions, Theorem 5.2.1 (b)).

Step 4: (S1). Let a∈A, and suppose s<a. By Theorem 5.4.3, fix q∈Q with s<q<a. By Definition 5.2.2, q−s=[(q−uk)k], and q−s∈P (Definition 5.3.2); so (q−uk)k is positive, since every representative of an element of P is (Proposition 5.3.1). Fix δ∈Q>0 and N∈N with q−uk≥δ for every k≥N. Then uN≤q−δ<q, so uN<q<a (Theorem 5.4.1 (b)), and a≤uN fails, against (I1). So s<a is false, and a≤s by (O1). Hence s is an upper bound of A.

Step 5: (S2). Let b be an upper bound of A, and suppose b<s. Fix q∈Q with b<q<s. Now read s through the left ends: s−q=[(lk−q)k]∈P, so, as in Step 4, there are δ∈Q>0 and N∈N with lk−q≥δ for every k≥N; in particular lN>q>b. By (I2), lN is not an upper bound: some a∈A has a≰lN (Logic and Proof, Proposition 6.2.3), that is, a>lN by totality (Proposition 4.1.2 (a)). Then a>lN>b, against b being an upper bound. So b<s is false, and s≤b by (O1).

By (S1) and (S2), s=supA (Sets and Functions, Definition 5.3.5). Since A was an arbitrary non-empty subset bounded above, R is complete. The statements about κ are Theorem 5.4.1 (a), (b) (injectivity is part of (b)) and Theorem 5.4.3.

The answer to the prompt: (S1) is read off the right ends and spends (I1); (S2) is read off the left ends and spends (I2); (lk)∼(uk) is what lets one number be read both ways. Archimedes enters twice, never as an assumption: the Archimedean property of Q (Chapter 3) makes D/2k small in Step 3, and density of Q in R, which came from the Archimedean property of R, supplies the rationals of Steps 1, 4 and 5. One more consequence: for j≥k, uj≤uk and lj≥lk, so Lemma 5.3.4 gives lk≤s≤uk for every k. The number s lies in every interval of the bisection.

Remark. Steps 2–5 use only that l0 and u0 are rational, that l0 is not an upper bound of A and that u0 is one (which forces D>0); Step 1 merely shows that such a pair exists. So the bisection may start from any such pair.

Example (Method: bisect and keep the invariant)

Template. (1) Start with two points on opposite sides of a test (here: not an upper bound, an upper bound). (2) Define the step by a rule that applies the test to the midpoint and keeps one end on each side; the recursion theorem then builds the sequence with no choice. (3) Prove the invariants and the length D/2k by induction. (4) Make D/2k small, by Archimedes, to get Cauchy sequences. (5) Spend one invariant on each half of the conclusion.

When to use it. The point you want is the boundary between two kinds of points, and one test decides the kind of each point.

The usual failure. A step that “takes some point of A above the midpoint” with no rule. A starting left end that may itself be an upper bound (l0=a0 for A={a0}). Asserting 1/2k→0 without Archimedes.

Quick check. Run Step 2 on A:={q∈Q:q2<2}, viewed as a subset of R, from l0=0, u0=2 (0 is not an upper bound, as 1∈A; 2 is one). List (lk,uk) for k=0,1,2,3. This start was not obtained by Step 1; by the remark after the proof, it is allowed.

Solution. (l0,u0)=(0,2). Two tests decide the midpoints. An element c>0 with c2≥2 is an upper bound of A: if some q∈A had q>c, then q2>c2≥2 (Proposition 2.4.3 (g)), against q2<2. An element exceeded by some member of A is not an upper bound; we use the member 7/5, which is in A because (7/5)2=49/25<2.

  • k=0→1: c=1; 7/5∈A and 7/5>1, so 1 is not an upper bound: (l1,u1)=(1,2).
  • k=1→2: c=3/2; (3/2)2=9/4≥2, so 3/2 is an upper bound: (l2,u2)=(1,3/2).
  • k=2→3: c=5/4; 7/5∈A and 7/5>5/4, so 5/4 is not an upper bound: (l3,u3)=(5/4,3/2).

So the pairs are (0,2), (1,2), (1,3/2), (5/4,3/2), and u3−l3=1/4=D/23 with D=2, as (I3) says.

The bisection names supA as a class. For this set a second name is already known: Section 5.4 built a real number whose square is 2 from the Newton sequence. The next example shows that the two names agree.

Example (Bisection Finds the Square Root of Two)

Let A and (lk,uk) be as in the Quick check, and let r be the class of the Newton sequence (Example (The Class of the Newton Sequence)). Show that a rational c≥0 is an upper bound of A if and only if c≥r. Deduce that lk<r≤uk for every k, and that [(uk)]=r.

Solution. Recall r>0 and r2=2 (Example (The Class of the Newton Sequence)).

(⇐) Let c≥r, and suppose some q∈A has q>c. Then q>r>0, so q2>r2=2 (Proposition 2.4.3 (g) in R), against q2<2. So c is an upper bound.

(⇒) Let 0≤c<r. By Theorem 5.4.3 there is q∈Q with c<q<r. Then 0<q<r gives q2<r2=2, so q∈A, and q>c: c is not an upper bound.

Every end is ≥0: l0=0, the left ends never decrease, and uk>lk. So (I1) and (I2) read r≤uk and lk<r.

By Steps 3–5 of the proof of Theorem 5.5.2, which apply to this start by the remark after the proof, [(uk)]=supA. And r=supA: it is an upper bound, by the (⇐) argument with c replaced by r; and if t<r, density gives q∈Q with max{t,0}<q<r, so q∈A and q>t, and t is not an upper bound. A set has at most one supremum, so [(uk)]=r.

So the bisection and the Newton sequence, two unrelated Cauchy sequences of rationals, name one real number, as the truncations did in Section 5.1.

The proof of Theorem 5.5.2 built two infinite sequences of rationals and chose nothing. The last example says what choosing would have meant.

Example (Picking Representatives Is a Use of Choice)

A proof about a sequence (xk) in R says: “for each k, pick a representative a(k)∈xk.” What does that ask for? Does the proof of Theorem 5.5.2 make such picks?

Solution. Each xk is a class, a non-empty subset of C (Sets and Functions, Definition 5.2.2). The family (xk)k∈N is a family of non-empty sets indexed by N, and “pick a(k)∈xk for each k” asks for a function c:N→C with c(k)∈xk for every k: a choice function for the family. Its existence, with no rule given, is what Sets and Functions, Axiom 6.1.1 provides. Fixing one object would give one representative of one xk; it cannot give infinitely many in one step.

The proof of Theorem 5.5.2 fixes finitely many objects, one at a time: a0, M, l0, u0; in Step 3, for the given ε, one n; and in Steps 4 and 5 one q, δ, N (and in Step 5 one a∈A). Each is fixed once and is ordinary logic. The infinitely many ends lk, uk are not picked: the recursion theorem defines them from a rule, which applies a test, “is c an upper bound?”, to a point it has already computed. So Sets and Functions, Axiom 6.1.1 is not used. A proof that needs infinitely many objects must name the rule that gives them, or say that the axiom of choice is used and where (Sets and Functions, Example (Method: name the choice)).

5.5.5. Exercises

A. Check your understanding

Exercise (A1)

These questions are about the proof of Theorem 5.5.2 and the definition of a complete ordered field.

  • (a) Where in the proof is (I1) used, and where (I2)?
  • (b) Why must l0 not be an upper bound, and why might a0 itself be one?
  • (c) Where does the proof use that Q is Archimedean, and where that R is?
  • (d) State the idea of the proof in two sentences.
  • (e) Write “F is complete” in symbols, and form its negation.

Solution.

  • (a) (I1) is used in Step 4, for (S1): a rational q between s and a larger a∈A would put some right end uN below a. (I2) is used in Step 5, for (S2): a left end lN above a supposed smaller upper bound b yields an element of A above b. Both are carried by the induction of Step 2, which is what keeps them true.

  • (b) The left end must not be an upper bound, and a0 might be one: for A={a0}, the element a0 is an upper bound (even the supremum), and (I2) would fail at k=0. Any l0<a0 is safe, since a0∈A lies above it, so it is never an upper bound.

  • (c) That Q is Archimedean: in Step 3, to make D/2k smaller than ε (Theorem 3.2.3). That R is: through density (Theorem 5.4.3, proved from Theorem 5.4.2), which supplies the rationals of Steps 1, 4 and 5.

  • (d) Halve an interval with rational ends by a rule that keeps the right end an upper bound and the left end not one; the ends form two equivalent Cauchy sequences of rationals, hence one real number s. A rational between s and a larger element of A would undercut a right end, and one between a smaller upper bound and s would be overtaken by a left end.

  • (e) With ub(u) for ∀a∈A a≤u, “complete” is the display in Definition 5.5.1. Its negation (Logic and Proof, Proposition 6.2.1, Logic and Proof, Proposition 6.2.3, Logic and Proof, Proposition 6.2.2, Logic and Proof, Proposition 2.5.5 (d), and ¬(x≤y) as y<x by (O1)): ∃A⊆F (A≠∅∧∃u∈F ub(u)∧∀s∈F(∃a∈A s<a ∨ ∃u∈F (ub(u)∧u<s))). Some non-empty set bounded above defeats every candidate s, by an element above it or an upper bound below it.

B. Practice

Exercise (B1)

Prove that every non-empty subset A⊆R that is bounded below has an infimum in R (Sets and Functions, Definition 5.3.5), and that infA=−sup(−A), where −A:={−a:a∈A}.

Solution. Let b be a lower bound of A. The set −A is non-empty, and −b is an upper bound of it: for a∈A, b≤a gives −a≤−b (Proposition 2.4.3 (a)). By Theorem 5.5.2, s:=sup(−A) exists.

We show that −s is the infimum of A. Lower bound: for a∈A, −a∈−A, so −a≤s and −s≤a. Greatest: let c be a lower bound of A. As for b, −c is an upper bound of −A, so s≤−c by (S2), that is, c≤−s. Hence infA=−s=−sup(−A).

Exercise (B2)

Let A:={1−1/(n+1):n∈N}⊆R. Prove that supA=1, and decide whether 1∈A.

Solution. Upper bound. 1/(n+1)>0 (Proposition 3.2.2 (a)), so 1−1/(n+1)<1 for every n.

Least. Let b<1. Then 1−b∈R>0, and Proposition 4.2.3 in R (Theorem 5.4.2) gives N∈Z>0 with 1/N<1−b. With n:=N, the element 1−1/(N+1) of A satisfies 1/(N+1)<1/N<1−b, so 1−1/(N+1)>b, and b is not an upper bound. By (O1), every upper bound u satisfies u≥1.

So supA=1, and 1∉A, since every element of A is <1. The supremum exists here without Theorem 5.5.2: we exhibited it.

Exercise (B3: Prove or disprove)

Let A⊆R be non-empty and bounded above, and let (lk,uk) and s be as in the proof of Theorem 5.5.2, from any rational start allowed by the remark after the proof. Prove each true statement and refute each false one with a counterexample.

  • (a) a≤uk for every a∈A and every k∈N.
  • (b) s∈A.
  • (c) If A has a largest element m, then s=m.
  • (d) Some lk lies in A.
  • (e) If the step rule is changed to “(c,u) if c∈A, and (l,c) otherwise”, the new s is still supA.

Solution.

  • (a) True. This is (I1): uk is an upper bound of A.

  • (b) False. For A={x∈R:x<0}, s=supA=0∉A (the example of the negative elements after Definition 5.5.1).

  • (c) True. A greatest element is the supremum (Sets and Functions, Section 5.3, the remark after Sets and Functions, Definition 5.3.5), so m=supA, and s=supA by the theorem’s proof; a set has at most one supremum, so s=m.

  • (d) False. For A={0}, (I2) says that lk is not an upper bound of {0}, that is, lk<0; so lk∉A for every k.

  • (e) False. The changed rule still halves the interval and keeps lk+1,uk+1 between lk and uk, so Steps 2 and 3 still give a real number s=[(uk)]. Take A={0,1}, with the start l0=−1/2, u0=3/2, one that Step 1 allows for a0=0, M=1 (−1<−1/2<0, 1<3/2<2). The midpoint c=1/2 is not in A, so (l1,u1)=(−1/2,1/2). From then on every end lies in [l1,u1], so uk≤1/2 for every k≥1, and the new s≤1/2<1=supA (Lemma 5.3.4). The test must be the invariant itself.

C. Going deeper

Exercise (C1: Exit check: bisection on a dyadic grid)

Let A⊆R be non-empty and bounded above. For k∈N, let Uk:={m∈Z:m/2k is an upper bound of A}.

  • (a) Show that Uk has a least element mk.
  • (b) Let uk:=mk/2k. Show that uk+1≤uk and that uk−1/2k is not an upper bound of A; deduce that uk−1/2k<uj≤uk for j≥k.
  • (c) Show that (uk)∈C, and that s:=[(uk)] is the supremum of A. Name the lines that use an Archimedean property, and of which field.

Solution (Hint 1). Least elements of sets of integers (Chapter 2), and integer parts in R.

Solution (Hint 2). For (a): fix a0∈A and an upper bound M, and look at the integer parts of 2kM and 2ka0.

Solution. Integer parts exist in R by Proposition 4.2.4 with F=R, which is Archimedean (Theorem 5.4.2).

  • (a) Fix a0∈A and an upper bound M. Let p be the integer part of 2kM. Then 2kM<p+1, so M<(p+1)/2k (multiply by 1/2k>0), and (p+1)/2k bounds A: p+1∈Uk, and Uk≠∅. If m∈Uk, then m/2k≥a0, so m≥2ka0≥p′, where p′ is the integer part of 2ka0; thus p′≤m in Z (Theorem 5.4.1 (b)), and p′ is a lower bound of Uk. By Proposition 2.4.4, Uk has a least element mk.

  • (b) 2mk/2k+1=mk/2k=uk bounds A, so 2mk∈Uk+1 and mk+1≤2mk, that is, uk+1≤uk. Since mk is least, mk−1∉Uk: (mk−1)/2k=uk−1/2k is not an upper bound. For j≥k: uj≤uk by induction (Logic and Proof, Axiom 4.2.1; every j≥k is k+i, Proposition 1.3.1 (a)). And uj>uk−1/2k, since otherwise uk−1/2k≥uj would be an upper bound.

  • (c) By (b), |uj−uk|=uk−uj<1/2k for j≥k, and (1/2k)k is null in Q, as in Step 3 of the proof of Theorem 5.5.2 (Archimedes in Q). So (uk)∈C. With lk:=uk−1/2k∈Q: (lk)∈C and (lk)∼(uk), lk is not an upper bound and uk is one. Steps 4 and 5 of the proof used nothing else, so they apply word for word, and s=supA.

Archimedean lines: the integer parts in (a), for R; 1/2k→0 in (c), for Q; and the rationals q of Steps 4 and 5, reused in (c), come from density (Theorem 5.4.3), that is, from the Archimedean property of R.

Marking scheme. (10 points) - 2: (a), Uk non-empty and bounded below, each with a reason. - 2: (b), uk+1≤uk, and “uk−1/2k is not an upper bound” from leastness. - 2: (uk)∈C, with the Archimedean property of Q named (and that of R for the integer parts in (a)). - 2: (S1), from (I1) and the fact that s is the class (or limit) of the uk. - 2: (S2), through (lk)∼(uk). Fatal errors (0 for the step): “choose an upper bound m/2k” with no least element (no rule); s∈A asserted.

Exercise (C2: The rationals are not complete, by bisection)

Run the bisection of Step 2 inside F=Q, on A:={q∈Q:q2<2}, with “upper bound” meaning upper bound in Q, (l0,u0)=(0,2) and D=2.

  • (a) Explain why (I1)–(I3) and Step 3 hold in Q, so that (uk) is Cauchy in Q.
  • (b) Prove: if A had a supremum s in Q, then uk→s in Q.
  • (c) Prove that (uk) has no limit in Q. (Show lk2<2≤uk2.)
  • (d) Conclude that A has no supremum in Q. Why is “(uk) is Cauchy with no rational limit” not enough on its own for this?

Solution (Hint 1). For (b), compare s with uk and with lk, using (I1), (I2), (S1) and (S2). For (c), the left ends are below some element of A.

Solution (Hint 2). For uk2≥2 in (c): suppose uk2<2, and look for a rational h with 0<h≤1 and (uk+h)2<2.

Solution.

  • (a) 1∈A as 12<2, so 0 is not an upper bound, and 2 bounds A, as q>2≥0 gives q2>4 (Proposition 2.4.3 (g)). By the remark after the proof, this start is allowed. Steps 2 and 3 use only rational arithmetic, Lemma 5.5.1 and Theorem 3.2.3, so (I1)–(I3) hold, (D/2k) is null in Q, and (uk) is Cauchy in Q. Steps 4 and 5 need R: the rational between s and a presupposes s.

  • (b) Suppose s=supA in Q. Each uk is an upper bound (I1), so s≤uk by (S2). Each lk is not an upper bound (I2), so some a∈A has lk<a≤s. Hence 0≤uk−s<uk−lk=D/2k for every k. By the squeeze, Proposition 4.4.4 (c), with lower sequence 0 and the null upper sequence (D/2k), uk−s→0, so uk→s (Proposition 4.3.3).

  • (c) Left ends. lk≥l0=0, since the left ends are non-decreasing (Step 2). By (I2) some a∈A has a>lk≥0, so lk2<a2<2 (Proposition 2.4.3 (g)).

    Right ends. uk>lk≥0. Suppose uk2<2, and let h:=min{1,(2−uk2)/(2(2uk+1))}, a positive rational (2uk+1>0). Since h≤1, h2≤h, and (uk+h)2=uk2+2ukh+h2≤uk2+(2uk+1)h≤uk2+2−uk22<2. So uk+h∈A and uk+h>uk, against (I1). Hence uk2≥2.

    No limit. Suppose uk→L∈Q. Then lk=uk−D/2k→L (Theorem 4.4.3 (b)), and by the product law (c), uk2→L2 and lk2→L2. By Proposition 4.4.4 (b), uk2≥2 gives L2≥2, and lk2<2 gives L2≤2. So L2=2, against Theorem 3.3.1.

  • (d) By (b) and (c), a supremum s∈Q would be a rational limit of (uk), and there is none. So A has no supremum in Q: Q is not complete. A Cauchy sequence with no rational limit shows only that Q is not Cauchy-complete; part (b) is the link between the two properties, and it uses the invariants of the bisection. Section 3.3 proved the same conclusion (Theorem 3.3.2 (a)) directly, by improving each rational candidate; here a sequence finds the gap.

Marking scheme. (10 points) - 2: (a), with the Archimedean property of Q cited (Step 3), and Steps 4–5 located as needing s∈R and density. - 3: (b), the two invariants used to get lk<s≤uk, and the squeeze. - 3: (c), both bounds lk2<2≤uk2 justified (the second by a rational h), then the limit laws and Theorem 3.3.1. - 2: (d), the conclusion, with the difference between “not Cauchy-complete” and “not complete” stated. Fatal errors (0 for the step): using 2 as a rational or as a real number in (b)–(d); concluding (d) from (c) alone.

R. Review

Exercise (R1)

Let F be an ordered field, (an) a sequence in F, and L∈F with L>0 and an→L. Prove that an≥L/2 for every sufficiently large n.

Solution. By Definition 4.3.2 with ε:=L/2∈F>0 (Proposition 4.1.2 (b)), there is N with |an−L|<L/2 for every n≥N. For such n, Proposition 4.1.3 (d) gives −L/2<an−L, so an>L−L/2=L/2; in particular an≥L/2.

This is the second half of Lemma 4.4.2. It is also the shape of Theorem 4.5.4, in the case where the limit is known: a sequence with a positive limit is eventually above a fixed positive element, which is what “positive” meant for Cauchy sequences in Section 5.3.

Exercise (R2)

On X:=Z×Z>0, let (p,q)∼(p′,q′) mean pq′=p′q. Show that the condition “p≥q” on a pair gives a well-defined property of classes: if (p,q)∼(p′,q′), then p≥q if and only if p′≥q′. Then show that “p≥2” does not give a well-defined property of classes.

Solution. These are the classes of Definition 3.1.1, and the move is representatives, then independence: a property stated on a representative is a property of the class only if equivalent representatives agree. By Theorem 2.2.1 (c), with S:={(p,q)∈X:p≥q}, it suffices to check one direction (the relation is symmetric).

Let pq′=p′q with q,q′>0, and suppose p≥q. Multiplying by q′>0 (Proposition 2.4.3 (c), or equality), pq′≥qq′, that is, p′q≥q′q. If p′<q′, then p′q<q′q by Proposition 2.4.3 (c), since q>0, a contradiction by (O1). So p′≥q′. In Q, the property says [(p,q)]≥1, by the comparison formula of Theorem 3.2.1 (a).

“p≥2” is not well defined: (1,2)∼(2,4), since 1⋅4=2⋅2, but 1≱2 while 2≥2. One class, two verdicts: the hypothesis of Theorem 2.2.1 (c) fails. (The test “p≥1” would pass, but only because for an integer it says p>0 (Theorem 2.4.2 (c)), the positivity test of Definition 3.2.1.)

Exercise (R3)

Prove that R is uncountable. For s∈{0,1}N, consider the rationals Sk(s):=∑i=0k2si3i+1(k∈N), and show that s↦[(Sk(s))k] is an injection {0,1}N→R.

Solution. (i) The sums. The powers 3i are those of Definition 4.2.1 in Q, with 3i+1=3i⋅3. The sum is defined by Sets and Functions, Theorem 3.3.1 with X=Q: S0(s):=2s0/3 and Sk+1(s):=Sk(s)+2sk+1/3k+2.

(ii) A tail bound. For m≥k,

0≤Sm(s)−Sk(s)≤13k+1−13m+1.
(5.5.2)

By Logic and Proof, Axiom 4.2.1 on m−k (base P(0), m=k: 0≤0≤0): passing from m to m+1 adds 2sm+1/3m+2, which lies between 0 and 2/3m+2, and −1/3m+1+2/3m+2=−3/3m+2+2/3m+2=−1/3m+2.

So |Sm(s)−Sk(s)|<1/3k+1 for m≥k. Also 3k+1≥2k+1≥(k+2)⋅1: the first by induction (30=20, and 3i+1=3i⋅3≥2i⋅2 by Proposition 4.1.2 (d), with 2i>0), the second by Lemma 5.5.1 with F=Q. So 1/3k+1<1/(k+1). Given ε∈Q>0, Corollary 3.2.4 gives N∈Z>0 with 1/n<ε for n≥N; for m,k≥N, say m≥k, |Sm(s)−Sk(s)|<1/(k+1)<ε. So (Sk(s))k∈C.

(iii) Different sequences give different classes. Let s≠t. The set {i∈N:si≠ti} is non-empty and bounded below by 0, so it has a least element j (Proposition 2.4.4). Say sj=1 and tj=0. Since si=ti for i<j, induction gives Sj−1(s)=Sj−1(t) when j≥1, so Sj(s)−Sj(t)=2/3j+1 (also when j=0). For k≥j, by Eq. 5.5.2 applied to s and to t, Sk(s)−Sk(t)=23j+1+(Sk(s)−Sj(s))−(Sk(t)−Sj(t))≥23j+1+0−13j+1=13j+1. So S(s)−S(t) is eventually ≥δ:=1/3j+1∈Q>0: it is positive (Definition 5.3.1), so [S(t)]<[S(s)] (Definition 5.3.2, Definition 5.2.2), and in particular [S(s)]≠[S(t)]. The map Φ:s↦[(Sk(s))k] is injective.

(iv) Uncountable. If R were countable, there would be an injection g:R→N (Sets and Functions, Theorem 4.2.2, (i) ⇒ (ii)). Then g∘Φ:{0,1}N→N would be injective (Sets and Functions, Theorem 2.2.1 (a)), so {0,1}N would be countable ((ii) ⇒ (i)), against Sets and Functions, Theorem 4.3.1.

The method is that of Sets and Functions, Chapter 4: an injection from a set known to be uncountable. (The route through Sets and Functions, Proposition 6.1.3 is not taken: its (⇐) direction uses choice.)

Exercise (R4)

Let x∈R. Prove that there is a strictly increasing sequence (qk) of rationals with qk→x in R.

Solution. The tool is Sets and Functions, Theorem 3.3.1 with a step given by a rule, on the set X:={q∈Q:q<x}. Integer parts (Proposition 4.2.4 with F=R, Archimedean by Theorem 5.4.2; unique) supply the rule.

Start. Let p be the integer part of x, and q0:=p−1. Then q0<p≤x, so q0∈X.

Step. For k∈N and q∈X, let L:=max{q,x−1/(k+1)}, a real number with L<x. Let n be the integer part of 2/(x−L), plus 1: a positive integer (with r the integer part, 0<2/(x−L)<r+1 gives r+1>0, so r≥0 and n=r+1≥1) with n>2/(x−L), so 2/n<x−L (Proposition 3.2.2 (b)). Let m be the integer part of nx, and put g(k,q):=(m−1)/n. From m≤nx<m+1, dividing by n, L<x−2n<m−1n≤x−1n<x. So g(k,q)∈X, and g:N×X→X is a function: each step is a formula, made unambiguous by the uniqueness of integer parts. By Sets and Functions, Theorem 3.3.1 there is exactly one sequence with qk+1=g(k,qk).

Properties. By the display, qk+1>L≥qk, so the sequence is strictly increasing; and x−1/(k+1)≤L<qk+1<x, so |qk+1−x|<1/(k+1). Given ε∈R>0, Proposition 4.2.3 in R (Theorem 5.4.2) gives N∈Z>0 with 1/N<ε; for k≥N+1, |qk−x|<1/k≤1/N<ε (Proposition 4.1.2 (c)). So qk→x.

Why the look-alikes fail. The terms of a representative of x converge to x (Exercise (B3, used later: Put the proof in order)) but need not increase. The approximants mk/(k+1) of Exercise (B2, used later) are ≤x but not always strictly increasing (for x=0 they are all 0). Density (Theorem 5.4.3) only says that a rational exists; it is not a rule in the data (k,q), so it cannot serve as a recursion step. And “at each step take some rational between L and x” makes one pick for each k with no rule, an unflagged use of Sets and Functions, Axiom 6.1.1 (compare Example (Picking Representatives Is a Use of Choice)).
