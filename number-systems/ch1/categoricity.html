1.7  All Peano Systems Are Alike

Section 1.4 proved that (ω,0,S) is a Peano system (Theorem 1.4.2, Definition 1.4.2), and Sections 1.5 and 1.6 built +, ⋅ and < on it. One question is left. Sets, Relations, and Cardinality, Chapter 2 worked with a set N inside the familiar real numbers, and this chapter has built a quite different set ω out of ∅. In what sense are they the same? This section answers: any two Peano systems are copies of each other, by exactly one matching, which also carries +, ⋅ and < across. Then it says what the later chapters may take from Logic and Proof, Chapter 4, and Sets, Relations, and Cardinality, Chapter 2 when they write N for ω.

1.7.1. Two Peano systems, and what “alike” should mean

Here is a second Peano system, inside ω itself: (ω∖{0},1,S), the natural numbers from 1 on, with the same successor. Exercise C1 of Section 1.4 asked you to check it; the check is three lines.

  • S maps ω∖{0} into itself, since S(n)≠0 by Theorem 1.4.2 (P3).
  • (P3) holds with e=1: if S(n)=1=S(0), then n=0 by (P4) of Theorem 1.4.2, and 0∉ω∖{0}. (P4) holds because S is injective on all of ω.
  • (P5) holds: if A⊆ω∖{0} contains 1 and is closed under S, then {0}∪A contains 0 and is closed under S (as S(0)=1∈A), so it is ω by Theorem 1.3.3 (a), and A=ω∖{0}.

Its starting point is 1, not ∅, yet it counts the same way: n↦S(n) pairs 0,1,2,… with 1,2,3,…, sends start to start, and turns one step into one step.

That is the right meaning of “alike”. For Peano systems (M,e,s) and (M′,e′,s′), call a bijection ψ:M→M′ an isomorphism if ψ(e)=e′andψ(s(x))=s′(ψ(x))  for every x∈M. In words: ψ renames the elements, sends the starting point to the starting point, and it does not matter whether we first step and then rename, or first rename and then step.

Warning. Being equinumerous is not enough. The bijection τ:ω→ω that exchanges 1 and 2 and fixes every other number satisfies τ(0)=0, but τ(S(0))=τ(1)=2, while S(τ(0))=S(0)=1. So τ is a bijection from a Peano system to itself that is not an isomorphism: it does not respect the successor. Categoricity, below, is a statement about isomorphisms, and it says much more than “same size”.

1.7.2. The categoricity theorem

The theorem says that every Peano system is an isomorphic copy of ω, and so any two are copies of each other, in only one way.

Theorem 1.7.1 (Categoricity of the Peano Axioms)

Let (M,e,s) be a Peano system.

  • (a) There is exactly one function φ:ω→M with φ(0)=e and φ(S(n))=s(φ(n)) for every n∈ω.
  • (b) This φ is a bijection.
  • (c) For any two Peano systems (M,e,s) and (M′,e′,s′) there is exactly one bijection ψ:M→M′ with ψ(e)=e′ and ψ(s(x))=s′(ψ(x)) for every x∈M.

Try it first (ten minutes): given a Peano system (M,e,s), which map ω→M would you build, with which theorem, and how would you show that it is onto?

Idea. The attempt meets three obstacles, one for each part.

① Which map. It is forced: 0 must go to e, then 1 to s(e), then 2 to s(s(e)), and so on. But “and so on” is not a definition. Theorem 1.5.1 turns it into one, with X=M, starting value e and step x↦s(x); it gives existence and uniqueness at once.

② Onto. We know nothing about the elements of M one by one, so we cannot show “each x∈M is s(…s(e))” directly. What we have is (P5) for M, which speaks about subsets. So look at the image of φ: it contains e and is closed under s, and (P5) does the rest.

③ One-to-one. Prove “φ(m)=φ(n)⇒m=n” by induction on n. If m is fixed before the induction, the hypothesis at n speaks about that one m, while the step needs it at the predecessor of m. So “for every m” goes inside the property. The base and the step then use (P3) and (P4) for M: a successor is never e, and equal successors have equal predecessors.

For (c), compose: go back from M to ω along φ−1, then forward to M′ along φ′.

Before reading on: which axiom of M gives surjectivity, and which give injectivity?

Proof. (a) Let g:ω×M→M be g(n,x):=s(x); its graph {((n,x),y)∈(ω×M)×M:y=s(x)} is a set by (Z6) inside the product of Proposition 1.2.2, and each (n,x) has exactly one partner s(x) because s is a function. By Theorem 1.5.1 with X=M and a=e, there is exactly one φ:ω→M with φ(0)=e and φ(S(n))=g(n,φ(n))=s(φ(n)) for every n∈ω.

(b), onto. Let B:=φ(ω)⊆M, the image of ω under φ (Sets, Relations, and Cardinality, Definition 1.7.1). Then e=φ(0)∈B. If x∈B, say x=φ(n) with n∈ω, then S(n)∈ω by Theorem 1.4.2 (P2), and s(x)=s(φ(n))=φ(S(n))∈B. So B contains e and is closed under s, and (P5) for M gives B=M. Hence φ is surjective (Sets, Relations, and Cardinality, Definition 1.5.4).

(b), one-to-one. Let Q(n) be “for every m∈ω, if φ(m)=φ(n), then m=n”. We prove Q(n) for every n∈ω by Theorem 1.3.3 (b).

Base case. Let m∈ω with φ(m)=φ(0)=e. Suppose m≠0. Then m=S(k) for some k∈ω (Lemma 1.4.1 (d)), and φ(m)=s(φ(k))≠e by (P3) for M, a contradiction. So m=0.

Inductive step. Let n∈ω with Q(n), and let m∈ω with φ(m)=φ(S(n))=s(φ(n)). If m=0, then s(φ(n))=φ(0)=e, against (P3) for M. So m≠0, and m=S(k) for some k∈ω (Lemma 1.4.1 (d)). Then s(φ(k))=φ(m)=s(φ(n)), so φ(k)=φ(n) by (P4) for M, and k=n by Q(n), applied to k in the place of m. Hence m=S(k)=S(n), which is Q(S(n)).

So φ is injective (Sets, Relations, and Cardinality, Definition 1.5.3), and with the first half it is a bijection (Sets, Relations, and Cardinality, Definition 1.5.5).

(c) Let φ:ω→M and φ′:ω→M′ be the maps of (a) for the two systems; both are bijections by (b). By Sets, Relations, and Cardinality, Theorem 1.6.4, φ has an inverse φ−1:M→ω, and we set ψ:=φ′∘φ−1 (Sets, Relations, and Cardinality, Definition 1.5.2). The two equations φ∘φ−1=idM and φ−1∘φ=idω of Sets, Relations, and Cardinality, Definition 1.6.2 also say that φ is an inverse of φ−1, so φ−1 is a bijection by Sets, Relations, and Cardinality, Theorem 1.6.4. Hence ψ is a bijection as a composite of bijections (Sets, Relations, and Cardinality, Theorem 1.5.4 (c)).

ψ has the two properties. Since φ(0)=e, we have φ−1(e)=0, so ψ(e)=φ′(0)=e′. Let x∈M and n:=φ−1(x), so x=φ(n). Then s(x)=φ(S(n)), so φ−1(s(x))=S(n), and ψ(s(x))=φ′(S(n))=s′(φ′(n))=s′(ψ(x)).

Uniqueness. Let χ:M→M′ be any function with χ(e)=e′ and χ(s(x))=s′(χ(x)) for every x∈M. Then χ∘φ:ω→M′ satisfies (χ∘φ)(0)=χ(e)=e′ and (χ∘φ)(S(n))=χ(s(φ(n)))=s′((χ∘φ)(n)) for every n∈ω. By the uniqueness in (a), for the system M′, χ∘φ=φ′. So for every x∈M, χ(x)=χ(φ(φ−1(x)))=φ′(φ−1(x))=ψ(x), and χ=ψ by Sets, Relations, and Cardinality, Proposition 1.5.1. This proves the theorem.

The proof is the third named move of the chapter, build by recursion, compare by induction: the map out of ω came from the recursion theorem, and every fact about it (onto, one-to-one) came from an induction or from (P5). The uniqueness in (c) is stronger than stated: no function at all, bijective or not, other than ψ respects e and s.

Each axiom of M has a job in (b), and the structures of Example (Each axiom is needed) show each job failing. These are not Peano systems, so the theorem does not apply to them. But for each of them Theorem 1.5.1, with X=M, a=e and g(n,x)=s(x) exactly as in the proof of (a), still gives exactly one φ:ω→M with φ(0)=e and φ(S(n))=s(φ(n)).

  • In structure (i), M={0} with s(0)=0, which fails (P3) only, φ is the constant map 0, not injective: φ(1)=s(φ(0))=0=φ(0).
  • In structure (ii), M={0,1} with s(0)=s(1)=1, which fails (P4) only, φ(1)=φ(2)=1, again not injective.
  • In the natural numbers beside a two-sided chain, structure (iii), which fails (P5) only, φ is n↦(n,0) (remark below), which is injective by Theorem 1.2.1, but not onto, as the remark below shows.

Remark. What induction buys. In structure (iii) of Example (Each axiom is needed), the natural numbers beside a two-sided chain (a copy of ω next to a copy of Z), M=ω×3 with e=(0,0), the map φ still exists, by Theorem 1.5.1 as above. It is φ(n)=(n,0), by the uniqueness half of Theorem 1.5.1: n↦(n,0) sends 0 to e and satisfies the recursion, as s(n,0)=(S(n),0). Its image ω×{0} misses (0,1), so φ is not onto. Exercise C2 asks the reverse question: is there a map M→ω that respects the two structures?

Quick check. For the Peano system (ω∖{0},1,S) of the first subsection, what is the map φ of Theorem 1.7.1 (a)? What is φ(3)?

Solution. φ(n)=S(n)=n+1. Indeed n↦S(n) maps ω into ω∖{0} by (P3), sends 0 to S(0)=1, and satisfies S(S(n))=S(φ(n)); by the uniqueness in (a), it is φ. So φ(3)=S(3)=4. Step by step: φ(0)=1, φ(1)=S(1)=2, φ(2)=3, φ(3)=4.

1.7.3. Arithmetic and order travel along the isomorphism

An isomorphism matches e and s. Addition and multiplication on ω were built from 0 and S alone, by recursion (Definition 1.5.1), and < can be described by + (Proposition 1.6.3 (a)). So we expect the matching to carry them across, as long as the other system has operations defined by the same equations.

Proposition 1.7.2 (Isomorphisms Preserve Arithmetic and Order)

Let (M,e,s) be a Peano system, and let ⊕,⊗:M×M→M be functions such that, for all x,y∈M, x⊕e=x,x⊕s(y)=s(x⊕y),x⊗e=e,x⊗s(y)=(x⊗y)⊕x. Let φ:ω→M be the bijection of Theorem 1.7.1. Then for all m,n∈ω:

  • (a) φ(m+n)=φ(m)⊕φ(n);
  • (b) φ(mn)=φ(m)⊗φ(n);
  • (c) m<n if and only if φ(n)=φ(m)⊕z for some z∈M with z≠e.

Idea. For (a) and (b), fix m and induct on n, the variable the recursions run on: each side obeys the same two equations, the base from 0 and the step from S, and φ turns one set of equations into the other. For (c), translate Proposition 1.6.3 (a), “m<n iff n=m+j with j≠0”, through (a), using that φ is a bijection with φ(0)=e.

Proof. (a) Fix m∈ω; we induct on n (Theorem 1.3.3 (b)). Base case: φ(m+0)=φ(m)=φ(m)⊕e=φ(m)⊕φ(0), by Definition 1.5.1 (a) and the first equation for ⊕. Step: if φ(m+n)=φ(m)⊕φ(n), then φ(m+S(n))=φ(S(m+n))=s(φ(m+n))=s(φ(m)⊕φ(n))=φ(m)⊕s(φ(n))=φ(m)⊕φ(S(n)), by Definition 1.5.1 (a), the equation of φ, the hypothesis, the second equation for ⊕, and the equation of φ again.

(b) Fix m∈ω and induct on n. Base case: φ(m⋅0)=φ(0)=e=φ(m)⊗e=φ(m)⊗φ(0), by Definition 1.5.1 (b) and the first equation for ⊗. Step: if φ(mn)=φ(m)⊗φ(n), then φ(m⋅S(n))=φ(mn+m)=φ(mn)⊕φ(m)=(φ(m)⊗φ(n))⊕φ(m)=φ(m)⊗s(φ(n))=φ(m)⊗φ(S(n)), by Definition 1.5.1 (b), part (a) just proved, the hypothesis, the second equation for ⊗, and the equation of φ.

(c) By Proposition 1.6.3 (a), m<n if and only if n=m+j for some j∈ω with j≠0.

(⇒) Let n=m+j with j≠0. By (a), φ(n)=φ(m)⊕φ(j). Put z:=φ(j). Since φ is injective (Theorem 1.7.1 (b)), j≠0 gives z≠φ(0)=e.

(⇐) Let z∈M with z≠e and φ(n)=φ(m)⊕z. Since φ is onto (Theorem 1.7.1 (b)), z=φ(j) for some j∈ω, and j≠0 because φ(0)=e≠z. By (a), φ(n)=φ(m)⊕φ(j)=φ(m+j), so n=m+j by injectivity. Hence m<n. This proves the proposition.

So once a Peano system carries an addition and a multiplication obeying the recursive equations, φ is an isomorphism for them too, and the order defined from ⊕ as in (c) is carried along as well. Nothing about ⊕ and ⊗ was assumed beyond the four equations.

1.7.4. Identifying the two sets of natural numbers

Now apply all this to the set N of Sets, Relations, and Cardinality, Chapter 2. Two different things are true, and it matters which one the later chapters lean on. One is a statement about Sets, Relations, and Cardinality, Chapter 2’s N, a subset of the familiar real numbers: it is a Peano system, so it is a copy of ω. The other is a statement about ω alone: the principles Logic and Proof, Chapter 4, and Sets, Relations, and Cardinality, Chapter 2 assumed or proved for N are theorems about ω, proved from the axioms (Z1)–(Z7).

Corollary 1.7.3 (ω Is the Natural Numbers)
  • (a) About Sets, Relations, and Cardinality, Chapter 2’s N. Let N⊆R be the set of natural numbers as Sets, Relations, and Cardinality, Section 2.1 describes it, with (( )0), (NS) and Logic and Proof, Axiom 4.2.1. With e:=0 and s(n):=n+1, it is a Peano system. There is exactly one bijection φ:ω→N with φ(0)=0 and φ(S(n))=φ(n)+1 for every n∈ω. For all m,n∈ω it satisfies φ(m+n)=φ(m)+φ(n),φ(mn)=φ(m)φ(n), and m<n if and only if φ(m)<φ(n); and it sends each numeral of ω to the natural number of the same name.
  • (b) About ω, proved from (Z1)–(Z7). The statements of Logic and Proof, Axiom 4.2.1 and Sets, Relations, and Cardinality, Theorem 2.3.1, read with N:=ω and n+1:=S(n), are Theorem 1.3.3 (b) and Theorem 1.5.1. Induction started at a base b∈ω (the form of Sets, Relations, and Cardinality, Theorem 2.2.1 with base n0=b) is Proposition 1.6.3 (g).
  • (c) Each clause of Sets, Relations, and Cardinality, Lemma 2.1.1 holds on ω, with n−m, for m≤n, read as the unique j∈ω with n=m+j of Proposition 1.6.3 (a).

Idea. For (a), check (P3)–(P5) for Sets, Relations, and Cardinality, Chapter 2’s N with the tools of Sets, Relations, and Cardinality, Section 2.1, and the equations of Proposition 1.7.2 with school arithmetic; then Theorem 1.7.1 and that proposition do the rest. Parts (b) and (c) are a matter of reading statements side by side and pointing to the label that proves each one on ω.

Before reading on: which clause do the later chapters actually use, when they build Z, Q and R?

Proof. (a) The map s sends N into N by (NS). (P3): for n∈N, n≥0 by Sets, Relations, and Cardinality, Lemma 2.1.1 (a), so n+1≥1>0 and n+1≠0. (P4): m+1=n+1 gives m=n, by subtracting 1 in R. (P5): a subset of N that contains 0 and is closed under n↦n+1 is N; this is the set form of Logic and Proof, Axiom 4.2.1, the remark at the start of Sets, Relations, and Cardinality, Section 2.1. So (N,0,s) is a Peano system (Definition 1.4.2), and Theorem 1.7.1 (a), (b) give exactly one φ as stated, and it is a bijection.

For the operations, take ⊕ and ⊗ to be the addition and multiplication of N; they are functions N×N→N by Sets, Relations, and Cardinality, Lemma 2.1.1 (b). The four equations of Proposition 1.7.2 read x+0=x, x+(y+1)=(x+y)+1, x⋅0=0 and x(y+1)=xy+x, which hold in R. That proposition gives φ(m+n)=φ(m)+φ(n) and φ(mn)=φ(m)φ(n).

For the order we first show: for x,y∈N, x<y if and only if y=x+z for some z∈N with z≠0. If x<y, then z:=y−x∈N by Sets, Relations, and Cardinality, Lemma 2.1.1 (d), and z≠0 since y≠x. Conversely, z≠0 gives z≥1>0 by Sets, Relations, and Cardinality, Lemma 2.1.1 (a), so y=x+z>x. Now Proposition 1.7.2 (c), with e=0, says that m<n if and only if φ(n)=φ(m)+z for some z∈N with z≠0, that is, if and only if φ(m)<φ(n).

Finally, φ(0)=0, and each numeral of ω is the successor of the one before (Definition 1.5.1 (c)), so φ(1)=φ(S(0))=0+1=1, φ(2)=φ(S(1))=1+1=2, and so on, one step for each numeral written.

(b) By the two equations of Definition 1.5.1 (a), n+1=n+S(0)=S(n+0)=S(n) for every n∈ω (Section 1.5, “the successor is plus one”). With N:=ω, the statement of Logic and Proof, Axiom 4.2.1 becomes Theorem 1.3.3 (b), and the statement of Sets, Relations, and Cardinality, Theorem 2.3.1 is word for word Theorem 1.5.1. Induction from a base b∈ω is Proposition 1.6.3 (g).

(c) We take the clauses of Sets, Relations, and Cardinality, Lemma 2.1.1 in turn, for m,n∈ω.

    • (a) “n≥0; if n≠0, then n≥1” is Theorem 1.6.1 (d).
    • (b) “m+n∈ω and mn∈ω” holds because + and ⋅ are functions ω×ω→ω (Definition 1.5.1).
    • (c) If n≠0, then 1≤n by Theorem 1.6.1 (d), so n=1+j for exactly one j∈ω by Proposition 1.6.3 (a); this j is n−1, and it lies in ω.
    • (d) If m≤n, then n−m∈ω by Proposition 1.6.3 (a).
    • (e) No k∈ω has n<k<S(n), by Theorem 1.6.1 (b). For the second form, let m<n. By trichotomy (Theorem 1.6.1 (a)), S(m)<n, S(m)=n or n<S(m). The last gives n≤m by Theorem 1.6.1 (b), and then n≤m<n gives n<n by transitivity, which (a) of that theorem rules out. So m+1=S(m)≤n.

This proves the corollary.

Clause (a) is the honest sense in which “ω is N”: the two are copies of each other by a unique isomorphism, which also matches +, ⋅ and <. But (a) is a theorem about Sets, Relations, and Cardinality, Chapter 2’s N, and its proof used the school arithmetic of R (in (P3), (P4), the four equations, the step describing < by +, and the numerals). The answer to the prompt is therefore (b), with (c): when a later chapter applies induction or recursion to ω, it uses a theorem proved here from the axioms for sets, and nothing about the school real numbers enters.

Warning. The isomorphism carries 0, successor, +, ⋅ and <, and nothing else. In ω, 0∈5 and 2⊆3 are true, because natural numbers here are sets (Example (The first natural numbers as sets)). In Sets, Relations, and Cardinality, Chapter 2’s picture numbers are not sets, and “0∈5” has no meaning there. Such statements are facts about one particular construction, and no theorem of the later chapters asks them.

1.7.5. How later chapters cite Logic and Proof, Chapter 4, and Sets, Relations, and Cardinality, Chapter 2

In the rest of this volume, N means ω, with the 0, +, ⋅ and < of this chapter. The later chapters build Z, Q and finally R from it, and they cite results of Logic and Proof, Chapter 4, and Sets, Relations, and Cardinality, Chapters 2 and 3 about N. This subsection says how such a citation is to be read, so that the construction of R never rests on the school R it is meant to replace.

The proofs in Sets, Relations, and Cardinality, Chapters 2 and 3 use the arithmetic of the real numbers freely: Sets, Relations, and Cardinality, Chapter 2’s “What you need” paragraph takes the arithmetic and order of R as school facts, Sets, Relations, and Cardinality, Section 2.1 says so for itself in “the rule for this section”, and Sets, Relations, and Cardinality, Chapter 3’s proofs do the same (Sets, Relations, and Cardinality, Theorem 3.4.1, for example, uses 1−b). So they do not rest only on (( )0), (NS), Logic and Proof, Axiom 4.2.1, Sets, Relations, and Cardinality, Theorem 2.3.1 and Sets, Relations, and Cardinality, Lemma 2.1.1, and “they hold unchanged on ω” would be false. What is true is a dictionary: each fact about N those proofs use has a counterpart proved on ω here.

With the dictionary, the results of Sets, Relations, and Cardinality, Chapters 2 and 3 that later chapters cite fall into three groups.

  • (i) Results that run on ω through the dictionary. Part (b) of Sets, Relations, and Cardinality, Corollary 3.2.7 is not in this group and is not checked on ω here: Sets, Relations, and Cardinality, Chapter 3 treats its list A1,…,Ak as a family in the everyday sense of Sets, Relations, and Cardinality, Definition 1.3.3, with no set holding it, and Section 1.2 left such families to the axiom of Replacement. The parts that need Z (Sets, Relations, and Cardinality, Proposition 2.3.4 (d) for an integer base, and the general index of Sets, Relations, and Cardinality, Definition 2.3.1, which uses Sets, Relations, and Cardinality, Proposition 2.1.2) are not part of the pattern.

Finally, the axiom of choice. Apart from Sets, Relations, and Cardinality, Chapter 2’s N⊆R and its school operations, which Corollary 1.7.3 (a) takes as given, every set in Sections 1.1–1.7 is produced by one of (Z1)–(Z7). Every function is produced by Theorem 1.5.1, by (Z6) applied to a graph described by a property (as g was in the proof of Theorem 1.7.1 (a)), or by Sets, Relations, and Cardinality, Chapter 1’s inverses and composites of such functions. Nothing is chosen from infinitely many sets, and Sets, Relations, and Cardinality, Axiom 3.3.1 is used nowhere in this chapter; it is mentioned only to say where it lives.

So everything that Logic and Proof, Chapter 4, and Sets, Relations, and Cardinality, Chapter 2 assumed about N (that 0 is a natural number, that n+1 is one whenever n is, induction, recursion, and the arithmetic of Sets, Relations, and Cardinality, Lemma 2.1.1) is now proved, from seven axioms about sets. The set-theory volume returns to those axioms and adds the rest of the system. Chapter 2 builds Z and Q from ω by the same kind of construction as here: pairs, and classes of pairs.

1.7.6. Exercises

A. Check your understanding

Exercise (A1)

These questions are about the proof of Theorem 1.7.1.

  • (a) Where in the proof is (P5) for M used, and where are (P3) and (P4) for M used?
  • (b) Where is (P4) for ω used? (It is not visible in the proof itself.)
  • (c) Run φ of part (a) for the system (ω∖{0},1,S) on 0, 1 and 2, from the two equations alone.
  • (d) State the idea of the proof of (a) and (b) in two sentences.

Solution.

  • (a) (P5) for M is used once, for surjectivity: the image φ(ω) contains e and is closed under s, so it is M. (P3) for M is used for injectivity, in the base case (φ(S(k))=s(φ(k))≠e, so only m=0 has φ(m)=e) and at the start of the inductive step (to exclude m=0). (P4) for M is used in the inductive step, to pass from s(φ(k))=s(φ(n)) to φ(k)=φ(n).

  • (b) Inside part (a), through Theorem 1.5.1: its proof extends a partial solution by one new pair at S(n), and (P4) for ω makes S(n) the successor of n only, so the equation at S(n) asks for g(n,h(n)) and nothing else.

  • (c) φ(0)=1; φ(1)=φ(S(0))=S(φ(0))=S(1)=2; φ(2)=φ(S(1))=S(2)=3.

  • (d) The map is forced at 0 and at each successor, so the recursion theorem builds it and makes it unique. It is onto because its image contains e and is closed under s, so (P5) for M applies; it is one-to-one by an induction whose base and step are (P3) and (P4) for M.

B. Practice

Exercise (B1: The even numbers)

Let E:={2n:n∈ω}, with e:=0 and s(x):=x+2 for x∈E. Show that (E,0,s) is a Peano system, and that the map φ of Theorem 1.7.1 is φ(n)=2n.

Solution. E is a set by (Z6) inside ω: it is {x∈ω:x=2n for some n∈ω}. By Definition 1.5.1 (b), 2⋅S(n)=2n+2 for every n∈ω. So s maps E into E: s(2n)=2n+2=2⋅S(n)∈E.

(P3): 2n+2=2n+S(1)=S(2n+1) by Definition 1.5.1 (a), and a successor is never 0 (Theorem 1.4.2 (P3)). (P4): if x+2=y+2, then x=y by Proposition 1.6.3 (b). (P5): let A⊆E with 0∈A and x+2∈A for every x∈A. Let B:={n∈ω:2n∈A}. Then 0∈B, since 2⋅0=0∈A; and if n∈B, then 2⋅S(n)=2n+2∈A, so S(n)∈B. By Theorem 1.3.3 (a), B=ω, so every 2n lies in A, and A=E.

The map n↦2n from ω to E sends 0 to 2⋅0=0=e, and 2⋅S(n)=2n+2=s(2n). By the uniqueness in Theorem 1.7.1 (a), it is φ. In particular, by (b) of that theorem, n↦2n is a bijection ω→E.

Exercise (B2: The identification at work)

Let φ:ω→N be the bijection of Corollary 1.7.3 (a).

  • (a) Compute φ(3) step by step from the two equations of φ.
  • (b) Compute φ(2⋅3) in two ways: from (a) of the corollary, and by unwinding 2⋅3 in ω to a numeral first.

Solution.

  • (a) Using φ(0)=0 and φ(S(n))=φ(n)+1, with 3=S(2), 2=S(1), 1=S(0) (Definition 1.5.1 (c)): φ(3)=φ(2)+1=(φ(1)+1)+1=((0+1)+1)+1=3.

  • (b) By the corollary, φ(2⋅3)=φ(2)φ(3)=2⋅3=6 in N, where φ(2)=2 as in (a). In ω, 2⋅3=2⋅2+2=(2⋅1+2)+2=((2⋅0+2)+2)+2=6, by Definition 1.5.1 (b) three times and then 2⋅0=0, 0+2=2, 2+2=4, 4+2=6 from the equations for +. Then φ(6)=6 by six steps as in (a). The two answers agree, as the corollary says they must.

C. Going deeper

Exercise (C1: Writing out categoricity)

Without looking at the text, prove part (b) of Theorem 1.7.1: for a Peano system (M,e,s), the map φ:ω→M with φ(0)=e and φ(S(n))=s(φ(n)) is a bijection.

Solution (Hint 1). For surjectivity, use (P5) for M on a set built from φ. For injectivity, induct on n; decide first where “for every m” goes.

Solution (Hint 2). The induction for injectivity starts: “Let Q(n) be: for every m∈ω, φ(m)=φ(n) implies m=n.”

Solution. Onto. The image B:=φ(ω) (Sets, Relations, and Cardinality, Definition 1.7.1) contains e=φ(0), and x=φ(n)∈B gives s(x)=φ(S(n))∈B. By (P5) for M, B=M.

One-to-one. By Theorem 1.3.3 (b) we prove, for every n, Q(n): “for every m∈ω, φ(m)=φ(n) implies m=n”. For Q(0), let φ(m)=e; an m≠0 is S(k) (Lemma 1.4.1 (d)), with φ(m)=s(φ(k))≠e by (P3) for M; so m=0. For the step, assume Q(n) and φ(m)=s(φ(n)). Then m≠0, as e is not a value of s (P3 for M); so m=S(k), and s(φ(k))=s(φ(n)) gives φ(k)=φ(n) by (P4) for M, hence k=n by Q(n) used at k, and m=S(n). So φ is injective, and a bijection.

Marking scheme. (10 points) - 3: surjectivity: shows the image of φ contains e and is closed under s, and cites (P5) for M. - 2: sets up an induction (on either variable, or by least counterexample) whose hypothesis is strong enough to use at the predecessor, e.g. Q(n) with “for every m” inside, or the difference j≠0 fixed and induction on m. - 2: base case, via m=S(k) for m≠0 and (P3) for M. - 3: inductive step, using (P3) for M to get m≠0, (P4) for M to cancel s, and the induction hypothesis at the predecessor k. Fatal errors (0 for the part concerned): an induction whose hypothesis is then applied at a value it does not cover (typically: m fixed outside Q, then used at k); using injectivity of φ to prove injectivity; using (P3), (P4) or (P5) for ω where the axiom for M is needed. A proof of injectivity by Theorem 1.6.2 (a least n with some m≠n, φ(m)=φ(n)) earns the same 7 points, mapped to base, step and hypothesis in the same way. So does the fixed-difference route (reducing to φ(m+j)≠φ(m) for j≠0 by Theorem 1.6.1 (a) and Proposition 1.6.3 (a), and inducting on m): its base uses (P3) for M, its step (P4) for M and the hypothesis at m, and the points are mapped in the same way.

Exercise (C2: Without induction, no recursion)

Let (M,e,s) be structure (iii) of Example (Each axiom is needed), the natural numbers beside a two-sided chain: M=ω×3, e=(0,0), s(n,0)=(S(n),0), s(n,1)=(S(n),1), s(0,2)=(0,1) and s(S(k),2)=(k,2). Show that there is no function f:M→ω with f(e)=0 and f(s(x))=S(f(x)) for every x∈M. Which Peano axiom, missing in M, is responsible?

Solution. Suppose such an f exists. For every k∈ω, s(S(k),2)=(k,2), so f((k,2))=S(f((S(k),2))). Let T:={f((k,2)):k∈ω}⊆ω, a set by (Z6) inside ω; it is non-empty, since it contains f((0,2)). By Theorem 1.6.2, T has a least element t=f((k0,2)). But u:=f((S(k0),2))∈T, and t=S(u), so u∈S(u)=t, that is, u<t (Definition 1.6.1). This contradicts the leastness of t, since t≤u and u<t would give u<u (Theorem 1.6.1 (a)). So no such f exists. (The condition f(e)=0 was not even used: no map at all turns s into S.)

M satisfies (P3) and (P4) and fails only (P5) (Example (Each axiom is needed)). So (P5) is what makes the recursion theorem possible: the downward chain (0,2),(1,2),(2,2),…, each element the successor of the next, would need values in ω that decrease forever.

R. Review

Exercise (R1)

Prove that ω is infinite.

Solution. We read Sets, Relations, and Cardinality, Definition 3.1.3 and Sets, Relations, and Cardinality, Theorem 3.1.9 on ω, through the dictionary of this section (group (i)). Consider S with codomain ω∖{0}; its values lie there by Theorem 1.4.2 (P3). It is injective by (P4) of that theorem, and onto ω∖{0} by Lemma 1.4.1 (d): every n≠0 is S(k) for some k∈ω. So it is a bijection ω→ω∖{0}. The set ω∖{0} is a proper subset of ω, since 0∈ω and 0∉ω∖{0}. By Sets, Relations, and Cardinality, Theorem 3.1.9, a finite set is not equinumerous with any proper subset; so ω is not finite, that is, it is infinite (Sets, Relations, and Cardinality, Definition 3.1.3). This is the Quick check after Sets, Relations, and Cardinality, Example (Hilbert’s Hotel) (every guest moves up one room), built from (P3) and (P4).

Exercise (R2)

Show that the successor function S:ω→ω has a left inverse and no right inverse. Write a left inverse down explicitly. Is it the only one?

Solution. No right inverse. A function with a right inverse is surjective (Sets, Relations, and Cardinality, Proposition 1.6.2), and S is not: 0 is not a value, by Theorem 1.4.2 (P3).

A left inverse. Let L:ω→ω have the graph G:={(n,k)∈ω×ω:(n=0 and k=0) or n=S(k)}, a set by (Z6). Each n∈ω has exactly one partner. If n=0, the partner k=0 works, and no k has 0=S(k), by (P3). If n≠0, then n=S(k) for some k (Lemma 1.4.1 (d)), and only one, by (P4). So L is a function (Sets, Relations, and Cardinality, Definition 1.5.1) with L(0)=0 and L(S(k))=k. Hence L(S(n))=n for every n∈ω, that is, L∘S=idω: L is a left inverse of S (Sets, Relations, and Cardinality, Definition 1.6.1 (a)). This matches Sets, Relations, and Cardinality, Theorem 1.6.1: S is injective and ω≠∅.

Not unique. The value of a left inverse at 0 is never used, since 0 is not of the form S(n); setting L′(0):=5 and L′(S(k)):=k gives another left inverse.

Exercise (R3)

Let M={0,1}, e=0 and s(0)=s(1)=1. Show that there is no function f:M→ω with f(0)=0 and f(s(x))=S(f(x)) for every x∈M. Which of the Peano axioms play the part, for definitions on ω, that a theorem about reading formulas plays for definitions on formulas?

Solution. Suppose f exists. Taking x=1, f(1)=f(s(1))=S(f(1)). But no n∈ω has n=S(n): n∈S(n) (Definition 1.3.1), so n=S(n) would give n∈n, against Lemma 1.4.1 (c). So no such f exists. (Taking x=0 instead gives f(1)=S(0)=1, so the two equations at the input 1 also contradict each other.)

The trouble is that 1 is built in two ways, as s(0) and as s(1), and the two ways ask for different values. In Logic and Proof, Chapter 4, Logic and Proof, Theorem 4.3.4 defines functions on formulas, and what makes it work is Logic and Proof, Theorem 4.3.3: each compound formula is built from its parts in exactly one way. On ω the same job is done by (P3) and (P4): 0 is not a successor, so its value is not asked for twice, and a successor is the successor of exactly one number, so the equation at S(n) asks for one thing. The structure M fails (P4), since s(0)=s(1), though it satisfies (P5).

Exercise (R4)

For n∈ω, compute ⋃S(n) and ⋃n. Then find a set x with ⋃S(x)≠x.

Solution. A formula for every set. For any set x, ⋃S(x)=⋃(x∪{x})=⋃x∪x: an element of a member of x∪{x} is an element of a member of x, or an element of x itself.

For n∈ω. The tool is transitivity. By Lemma 1.4.1 (a), n is transitive, so every element of a member of n is a member of n, that is, ⋃n⊆n. Hence ⋃S(n)=⋃n∪n=n. For ⋃n itself: ⋃0=⋃∅=∅=0; and if n≠0, then n=S(k) (Lemma 1.4.1 (d)), and ⋃n=⋃S(k)=k by what we just proved. So ⋃ undoes the successor: it is the “predecessor” on ω, with 0 sent to 0.

A set where it fails. Let x:={1}={{∅}}. Then ⋃x=1={∅}, and ⋃S(x)={∅}∪{{∅}}={0,1}=2. This is not x: 0=∅∈2, but ∅∉x, since the only element of x is {∅}≠∅.

Why the identity alone is not enough. The look-alike tool is the identity ⋃S(x)=⋃x∪x, which holds for every set. On its own it does not give x: it gives ⋃S(x)=x exactly when ⋃x⊆x, that is, when x is transitive (Definition 1.4.1), and {1}, which is not transitive, is a witness that this can fail. Nor is an induction on n a route that avoids transitivity: its step ⋃S(S(n))=⋃S(n)∪S(n)=n∪S(n)=S(n) proves ⋃S(n)=n, which is equivalent to transitivity of n, so it proves Lemma 1.4.1 (a) again along the way.
