1.1  Peano’s Axioms and Induction

Sets and Functions, Chapter 3 took the natural numbers as a subset N of the familiar real numbers, and borrowed the arithmetic of R whenever it was convenient. This volume builds the integers, the rationals and the real numbers. If we started from the N inside R, the real numbers would rest on the real numbers. So we need N on its own. We make one assumption: there is a set with a start and a step that obey three rules. This section shows that each rule is needed, proves induction in the form we use, and proves that every natural number except 0 has exactly one predecessor.

1.1.1. What counting needs

Two descriptions of N come to mind at once, and neither will do.

The first is N={0,1,2,3,…}. It names four elements and then writes three dots, and the dots carry all the content. They say “keep going one at a time, and nothing else”, and to say what that means is exactly the job of a definition of N.

The second is more careful: N is the smallest subset of R that contains 0 and is closed under x↦x+1. A smallest such subset exists, by Sets and Functions, Proposition 1.3.2 with start 0 and step x↦x+1, and the set form of Logic and Proof, Axiom 4.2.1 shows that it is the N of Sets and Functions. Either way the description needs R. Since R is where this volume is going, it cannot be where N comes from.

So we describe N by what counting has to do, not by where its elements live. Counting needs

  • (P1) a start: an element where counting begins;
  • (P2) a step: a rule sending each element to a next element of the same set.

That is a set M, an element e∈M, and a function s:M→M. A start and a step are not enough, and here are three ways they fail to count. In each picture an arrow goes from x to s(x).

A loop. Let M:={p,q,r}, start at p, and step p↦q↦r↦p.

Counting comes back to its start: three steps after p we are at p again, as on a clock.

A merge. Let M:={p,q,r} again, start at p, and step p↦q↦r↦q.

Counting never returns to p, but two different elements, p and r, step to the same q. After r the count repeats q, and runs in a circle from there.

An extra row. Take the counting numbers, and beside them a second copy with its own step, which the start never reaches. Every element still has one next element, no two elements step to the same one, and nothing steps back to the start. Yet starting at the start and stepping, we never meet the second copy. Counting cannot see those elements, and a description of the natural numbers must exclude them.

Each failure is ruled out by one clause: the step never returns to the start; the step never sends two elements to the same one; and nothing is there that steps from the start cannot reach. The last clause needs care, since “reached by steps” is the three dots again. The way around it is the one Sets and Functions, Proposition 1.3.2 takes: speak of subsets. A subset that contains the start and is closed under the step contains everything the steps reach. If the only such subset is the whole set, nothing is left over.

A Peano system is a set with a start and a step, where the step is one-to-one, never returns to the start, and reaches everything.

Definition 1.1.1 (Peano system)

A Peano system (M,e,s) consists of a set M, an element e∈M, and a function s:M→M, such that:

  • (P3) s(x)≠e for every x∈M;
  • (P4) s is injective;
  • (P5) every subset A⊆M with e∈A and s(x)∈A for every x∈A is equal to M.

In words: (P1) and (P2) are built into the data, since e∈M and s maps M into M. (P3) says the step never leads back to the start. (P4) says two different elements never step to the same element. (P5) is induction for M: a subset that contains the start and is closed under the step is everything, so every element of M is reached from e by steps. We write (M,e,s) and not (N,e,s), so that the letter never suggests N. The notation (M,e,s) lists the three pieces of data; it is not a set built from them (if one object is wanted, take the pair ((M,e),s) of Sets and Functions, Definition 1.4.1).

The merge breaks (P4), since s(p)=q=s(r) with p≠r. The extra row breaks (P5): the first copy contains the start, is closed under the step, and is not everything. The loop is the subject of the first Quick check.

Quick check. For the loop (M={p,q,r}, e=p, s(p)=q, s(q)=r, s(r)=p), which of (P3), (P4), (P5) fail?

Solution. Only (P3): s(r)=p=e. (P4) holds, since the three values s(p)=q, s(q)=r, s(r)=p are different. (P5) holds: a subset containing p and closed under s contains s(p)=q, then s(q)=r, so it is M.

1.1.2. The one assumption

The natural numbers are to be a Peano system. That is the whole of what we assume about them.

Axiom 1.1.1 (The Natural Numbers)

There is a Peano system.

We fix one Peano system for the rest of the volume and write it (N,0,S). Its elements are the natural numbers, 0 is zero, and S(n) is the successor of n. Spelled out, N is a set, 0∈N, S:N→N is a function, and:

  • (P3) S(n)≠0 for every n∈N;
  • (P4) S(m)=S(n) implies m=n;
  • (P5) every A⊆N that contains 0 and is closed under S is N.

Why believe the assumption? If the school real numbers are trusted, the N of Sets and Functions, with start 0 and step x↦x+1, is a Peano system; Section 1.4 checks this. And Axiomatic Set Theory, Chapter 1 builds a Peano system from sets alone, assuming nothing about numbers; Section 1.5 describes how. Which Peano system we fix does not matter: Section 1.4 proves that any two are copies of each other, matched by exactly one bijection that sends start to start and step to step.

From here on, every fact about N is proved from Axiom 1.1.1. We do not borrow the order, the subtraction or the arithmetic of R. Addition and multiplication are not defined yet; Section 1.2 defines them. Even the numeral 1 is not available until then, and the element after 0 is written S(0).

Why these three clauses and no others? Each one does work that the other two cannot do: for each clause there is a structure satisfying the other two and failing it.

Example (Each axiom is needed)

Show that each of the following structures (M,e,s), with s:M→M, satisfies two of (P3), (P4), (P5) and fails the third.

  • (i) M:={0}, e:=0, s(0):=0.
  • (ii) M:={0,S(0)}, e:=0, s(0):=S(0), s(S(0)):=S(0).
  • (iii) (Two copies of N.) Let a≠b be two objects, M:=N×{a,b}, e:=(0,a), and s(n,t):=(S(n),t) for n∈N and t∈{a,b}.

Solution.

  • (i) Fails (P3): s(0)=0=e. (P4) holds: M has one element, so two inputs with equal outputs are equal. (P5) holds: a subset of {0} containing e=0 is {0}.

  • (ii) Here 0≠S(0) by (P3) for N, so M has two elements. Fails (P4): s(0)=s(S(0)) with 0≠S(0). (P3) holds: both values are S(0)≠0=e. (P5) holds: if A⊆M has 0 as an element and is closed under s, then s(0)=S(0)∈A, so A=M.

  • (iii) First, s is a function M→M. Each element of M is (n,t) for some n∈N and t∈{a,b} (Sets and Functions, Definition 1.4.2), and for exactly one such pair (Sets and Functions, Definition 1.4.1), so the formula names one value; and (S(n),t)∈M, since S maps N into N.

(P3) holds. If s(n,t)=(0,a), then (S(n),t)=(0,a) gives S(n)=0 (Sets and Functions, Definition 1.4.1), against (P3) for N.

(P4) holds. If s(n,t)=s(n′,t′), then (S(n),t)=(S(n′),t′) gives t=t′ and S(n)=S(n′), so n=n′ by (P4) for N. Hence (n,t)=(n′,t′).

(P5) fails. Let A:=N×{a}. It contains e=(0,a), and it is closed under s, since s(n,a)=(S(n),a)∈A. But (0,b)∈M is not in A, because its second coordinate is b≠a. So A≠M.

The picture shows (iii), with an arrow from each element to its image under s.

This is the extra row of the start of the section. The element (0,b) has no arrow coming in, and it is not e. The top row is a copy of N, and so is the bottom row; but the bottom row cannot be reached from e. (P3) and (P4) cannot prevent this, and (P5) is the clause that says “nothing else”.

(P5) speaks of every subset of M, and that is what lets it exclude every kind of extra row. A first-order induction schema speaks only of subsets defined by formulas, and Logic and Proof, Section 7.6 showed (Logic and Proof, Example (A Model of Arithmetic with an Infinite Number)) that the sentences true in N also hold in a structure with an element beyond every numeral; its closing remark promised the comparison made here. Exercise C2 builds an extra row in which, unlike (0,b) above, every element has an arrow coming in.

1.1.3. Induction in the form we use

(P5) is induction, stated about subsets of a Peano system. For N we record it in the two forms the rest of the volume cites: a set form, and a form about properties.

Theorem 1.1.2 (Induction on N)
  • (a) (Set form.) Let A⊆N. If 0∈A, and S(n)∈A for every n∈A, then A=N.
  • (b) (Property form.) Let P(n) be a property of natural numbers, possibly with other variables as parameters. If P(0) holds and, for every n∈N, P(n) implies P(S(n)), then P(n) holds for every n∈N.

Proof. (a) This is (P5) of Definition 1.1.1 for the Peano system (N,0,S) of Axiom 1.1.1.

(b) Let A:={n∈N:P(n)} (Sets and Functions, Definition 1.2.3). Then 0∈A, because P(0) holds. Let n∈A. Then P(n), so P(S(n)) by hypothesis, and S(n)∈N because S maps N into N; hence S(n)∈A. By (a), A=N, which says that P(n) holds for every n∈N.

Compare part (b) with the principle of induction, Logic and Proof, Axiom 4.2.1. Read with S(n) in place of n+1, the two statements are the same, and Section 1.2 shows that n+1=S(n) once addition is defined. The difference lies in their status. In Logic and Proof, Chapter 4, induction was taken on trust, for an N that came with the school arithmetic attached. Here (P5) is part of the one assumption, and arithmetic is not assumed at all: Section 1.2 builds it, and proves its laws by this theorem.

Warning. Both halves of the hypothesis are needed. The set N∖{0} is closed under S, by (P3), and it is not N. The set {0} contains 0 and is not closed under S, since S(0)≠0.

Quick check. Let P(n) be “n=0”. Does the base case hold? Does the step hold? What does Theorem 1.1.2 (b) conclude?

Solution. The base case holds: P(0) says 0=0. The step fails at n=0: P(0) holds, while P(S(0)) says S(0)=0, which is false by (P3). So the theorem concludes nothing, and indeed P fails at S(0).

1.1.4. Every natural number except 0 has one predecessor

Sets and Functions used that n−1∈N for every natural number n≠0 (Sets and Functions, Lemma 3.1.1 (c)), with the subtraction done in R. Our N has no subtraction. Yet Sections 1.2–1.4 split, again and again, into the cases “n=0” and “n=S(k) for some k”. For that we need every n≠0 to be a successor, and of exactly one k. The fact holds in every Peano system, and the proof is no harder there; Exercises B3 and C2 use it in that generality.

Proposition 1.1.3 (Predecessors in a Peano System)

Let (M,e,s) be a Peano system.

  • (a) For every x∈M with x≠e there is exactly one y∈M with s(y)=x.
  • (b) s(x)≠x for every x∈M.

Idea (Scratch work). For (a), “at most one” is (P4): if s(y)=x=s(y′), then y=y′. “At least one” is the real question. Of the three clauses, only (P5) can prove that every element of M has a given property, and (P5) speaks of subsets. So we must choose a subset A of M and show A=M. That choice is the new point. Inside an abstract M nothing can be computed: there is no subtraction that would produce y from x.

The first candidate is the set of values of s, {z∈M:z=s(y) for some y∈M}. It fails at the start, since e is not a value, by (P3). The cure is the shape of Sets and Functions, Lemma 3.1.1 (c): carry “z=e or …”.

Givens Goal
(M,e,s) a Peano system; x∈M, x≠e some y∈M with s(y)=x
A:={z∈M:z=e or z=s(y) for some y∈M} A=M; then x∈A and x≠e give y
(P5) for A e∈A; and z∈A⇒s(z)∈A, since s(z) is a value of s

The step never uses z∈A, as in Sets and Functions, Example (An induction that ignores its hypothesis).

Idea. Both parts apply (P5) to a subset chosen for the purpose: (a) to e together with the values of s, and (b) to the set where s(x)≠x. In (b), unlike (a), the step uses its hypothesis, through (P4).

Proof. (a) Let x∈M with x≠e. At most one: if s(y)=x and s(y′)=x, then y=y′ by (P4). At least one: let A:={z∈M:z=e or z=s(y) for some y∈M} (Sets and Functions, Definition 1.2.3). Then e∈A, by the first alternative. Let z∈A. Then s(z)∈M is the value of s at z, so s(z)∈A, by the second alternative with y:=z. By (P5), A=M. Hence x∈A; since x≠e, the second alternative holds, and x=s(y) for some y∈M.

(b) Let A′:={x∈M:s(x)≠x}. Then e∈A′, since s(e)≠e by (P3). Let x∈A′, so that s(x)≠x. If s(s(x))=s(x), then (P4), applied to the inputs s(x) and x, gives s(x)=x, a contradiction. So s(s(x))≠s(x), that is, s(x)∈A′. By (P5), A′=M. This proves the proposition.

For N, part (a) says that every natural number n≠0 is S(k) for exactly one k∈N; this k is the predecessor of n. Part (b) says that no natural number is its own successor.

The two proofs make the same move with one difference. In (a) the closure step proves s(z)∈A outright, whatever z is; in (b) it needs x∈A′, and (P4) turns the hypothesis s(x)≠x into the conclusion s(s(x))≠s(x). The move has a name.

Example (Method: induction through a closed subset)

Template. (1) Name A:={x∈M:P(x)}. (2) Show e∈A. (3) Take x∈A and show s(x)∈A, using P(x) if needed. (4) Conclude A=M by (P5). If P fails at e, carry “x=e or P(x)” (the shape of Sets and Functions, Lemma 3.1.1 (c)).

When to use it. A statement about every element of a Peano system whose elements are not known one by one: an abstract (M,e,s), the image of a map out of N, a set of pairs.

The usual failure. A property false at e. Closure checked only for elements of a special form (x=s(y)), forgetting e. (P5) applied to a set that is not a subset of M.

On N the method is Theorem 1.1.2 (b), and Sets and Functions, Example (Method: finding P(n) inside P(n+1)) still finds P(n) inside P(S(n)) in the step; the box adds the choice of the set.

Quick check. In structure (ii) of Example (Each axiom is needed), which element has two predecessors, and which conclusions of Proposition 1.1.3 fail?

Solution. The element S(0): s(0)=S(0)=s(S(0)). So “exactly one” in (a) fails at x=S(0), because (P4) fails; and (b) fails at x=S(0), since s(S(0))=S(0).

Quick check. Does the loop (e=p, s(p)=q, s(q)=r, s(r)=p) satisfy the conclusion of Proposition 1.1.3 (a)? What does the answer say about a converse?

Solution. Yes. Every element, e included, has exactly one element stepping to it: r to p, p to q, q to r. Yet the loop is not a Peano system, since it fails (P3). So the conclusion of (a) does not give back the axioms; Exercise C2 shows that it does not even together with (P3) and (P4).

The next section uses each of (P3), (P4) and (P5) to prove that a function on N can be defined by recursion, and then defines addition and multiplication.

1.1.5. Exercises

A. Check your understanding

Exercise (A1)
  • (a) For each of the three structures in Example (Each axiom is needed), which of (P3), (P4), (P5) fails?
  • (b) In the proof of Proposition 1.1.3 (a), which axiom gives at least one y, and which gives at most one?
  • (c) Is N∖{0} closed under S? Is it N? Which hypothesis of Theorem 1.1.2 (a) fails for it?
  • (d) True or false: in a Peano system (M,e,s), the function s is a bijection M→M.

Solution.

  • (a)
    • (i) fails (P3); (ii) fails (P4); (iii) fails (P5). Each satisfies the other two (Example (Each axiom is needed)).

  • (b) At least one comes from (P5), applied to the set A of elements that are e or a value of s. At most one is (P4).

  • (c) Yes: for n∈N∖{0}, S(n)∈N and S(n)≠0 by (P3). No: 0∈N is not in it. The hypothesis that fails is 0∈A.

  • (d) False. The function s is injective, by (P4), but not surjective: e is not a value of s, by (P3) (Sets and Functions, Definition 2.2.2).

B. Practice

Exercise (B1: Put the proof in order)

Let (M,e,s) be a Peano system. The following lines contain a proof that s(s(x))≠x for every x∈M, shuffled, together with two lines that do not belong. Write the six correct lines in an order that makes a proof, say which other orders are also admissible, and say why each of the other two lines fails.

  • (i) Let x∈A; we show s(x)∈A.

  • (ii) Let A:={x∈M:s(s(x))≠x}.

  • (iii) Then s(s(x))=x by (P4), contradicting x∈A.

  • (iv) e∈A, since s(s(e)) is a value of s, so it is not e, by (P3).

  • (v) Suppose s(s(s(x)))=s(x).

  • (vi) So s(s(s(x)))≠s(x), that is, s(x)∈A; by (P5), A=M.

  • (vii) Since s is a bijection, write x=s(y) and apply the hypothesis to y.

  • (viii) Since s(s(e))≠e, and every element is reached from e by steps, s(s(x))≠x for every x.

Solution. An admissible order is (ii), (iv), (i), (v), (iii), (vi):

Let A:={x∈M:s(s(x))≠x}. Then e∈A, since s(s(e)) is a value of s, so it is not e, by (P3). Let x∈A; we show s(x)∈A. Suppose s(s(s(x)))=s(x). Then s(s(x))=x by (P4), contradicting x∈A. So s(s(s(x)))≠s(x), that is, s(x)∈A; by (P5), A=M.

Line (ii) comes first, since every other line mentions A. Lines (i), (v), (iii), (vi) come in that order: (i) opens the closure step, (v) opens a supposition, (iii) applies (P4) to the inputs s(s(x)) and x and reaches a contradiction, and (vi) closes the supposition and applies (P5), which needs both e∈A and the closure step. So (iv) may stand right after (ii) or right after (i), before the supposition (v) opens; it must come before (vi), which uses it. Stating the base case first, as above, is the convention.

Line (vii) cites a false fact: s is not surjective, since e is not a value, by (P3). Citing an unavailable “fact” is (N9) of Logic and Proof, Example (What is not allowed). Line (viii) is an “and so on” with nothing behind it: “every element is reached from e by steps” is (P5) only if the step from x to s(x) is proved, and line (viii) never proves it. That is (N13).

Exercise (B2: Two steps at a time)

Let d:=S∘S:N→N (Sets and Functions, Definition 2.1.2), so that d(n)=S(S(n)). Show that (N,0,d) satisfies (P3) and (P4) of Definition 1.1.1, and that it does not satisfy (P5).

Hint: look at the set N∖{S(0)}.

Solution. (P3): for n∈N, d(n)=S(S(n))≠0 by (P3) for N, applied to S(n)∈N.

(P4): if d(m)=d(n), then S(S(m))=S(S(n)), so S(m)=S(n) by (P4) for N, and then m=n by (P4) again. (Equivalently: d is a composite of two injections, so it is injective by Sets and Functions, Theorem 2.2.1 (a).)

(P5) fails. Let A:=N∖{S(0)}. It contains 0, since 0≠S(0) by (P3). It is closed under d: let n∈A; then d(n)∈N, and d(n)≠S(0), because S(S(n))=S(0) would give S(n)=0 by (P4), against (P3). But A≠N, since S(0)∈N and S(0)∉A. So a subset of N with 0 as an element and closed under d need not be all of N. The step d skips S(0), and starting from 0 it meets only 0, S(S(0)), S(S(S(S(0)))), …: every second number.

Exercise (B3: Prove or disprove)

Let (M,e,s) be a Peano system. Prove or disprove each statement.

  • (a) If A⊆M contains s(e) and is closed under s, then A∪{e}=M.
  • (b) If A⊆M is non-empty and closed under s, then A=M.
  • (c) Every x≠e in M is s(y) for some y∈M with y≠x.
  • (d) If f:M→M satisfies f(e)=e and f(s(x))=s(f(x)) for every x∈M, then f=idM.
  • (e) Every x∈M is e or s(s(y)) for some y∈M.

Solution.

  • (a) True. The set A∪{e} is a subset of M containing e. It is closed under s: for x=e, s(e)∈A by hypothesis; for x∈A, s(x)∈A by closure. By (P5), A∪{e}=M.

  • (b) False. Let A:=M∖{e}. It contains s(e), since s(e)≠e by (P3), so it is non-empty. It is closed under s, since no value of s is e, by (P3). It misses e, so A≠M.

  • (c) True. Let x≠e. By Proposition 1.1.3 (a) there is y∈M with s(y)=x. If y=x, then s(x)=x, against Proposition 1.1.3 (b). So y≠x.

  • (d) True, by Example (Method: induction through a closed subset). Let A:={x∈M:f(x)=x}. Then e∈A, since f(e)=e. If x∈A, then f(s(x))=s(f(x))=s(x), so s(x)∈A. By (P5), A=M. So f and idM have the same domain, the same codomain and the same value at every x∈M, and f=idM by Sets and Functions, Proposition 2.1.1.

  • (e) False. Take x:=s(e). It is not e, by (P3). If s(e)=s(s(y)) for some y∈M, then e=s(y) by (P4), against (P3). So s(e) is neither e nor of the form s(s(y)).

C. Going deeper

Exercise (C1: A Peano system with a different start)

Give an example of a Peano system (M,e,s) with M⊆N and e≠0. Check every clause of Definition 1.1.1.

Solution. Any correct answer has: a set M⊆N; an element e∈M with e≠0; a function s:M→M, so that every value lies in M; and the three clauses (P3), (P4), (P5) for these data.

Take M:=N∖{0}, e:=S(0), and s(n):=S(n) for n∈M.

  • The data. S(0)∈M, since S(0)∈N and S(0)≠0 by (P3) for N. For n∈M, S(n)∈N since S maps N into N, and S(n)≠0 by (P3) for N, so S(n)∈M. So s:M→M is a function, since S is one and its values on M lie in M (Sets and Functions, Definition 2.1.1).
  • (P3). If s(n)=S(0) for some n∈M, then S(n)=S(0), so n=0 by (P4) for N; but 0∉M.
  • (P4). If S(m)=S(n) with m,n∈M, then m=n by (P4) for N.
  • (P5). Let A⊆M with S(0)∈A and S(n)∈A for every n∈A. The set A′:=A∪{0}⊆N contains 0 and is closed under S: S(0)∈A⊆A′; and for n∈A, S(n)∈A⊆A′. By Theorem 1.1.2 (a), A′=N. Every n∈M lies in A′ and is not 0, so n∈A. Hence A=M.

Other answers can be checked against the four properties at the start. For instance, M:=N∖{0,S(0)}, e:=S(S(0)), s(n):=S(n) also works, by the same argument with {0,S(0)} added in (P5).

Exercise (C2: Every element but one is a successor, used later)

Let a,b,c be three different objects, M:=N×{a,b,c}, e:=(0,a), and, for n,k∈N, s(n,a):=(S(n),a),s(n,b):=(S(n),b),s(0,c):=(0,b),s(S(k),c):=(k,c).

  • (a) Explain why s is a function M→M.
  • (b) Show that (M,e,s) satisfies (P3) and (P4).
  • (c) Show that every x∈M with x≠e is a value of s.
  • (d) Show that (M,e,s) fails (P5).
  • (e) Which conclusions of Proposition 1.1.3 hold in (M,e,s)?

Solution (Hint 1). For (a), apply Proposition 1.1.3 (a) to N.

Solution (Hint 2). For (d), try the set N×{a}.

Solution.

  • (a) Each element of M is (n,t) for some n∈N and t∈{a,b,c} (Sets and Functions, Definition 1.4.2), and for exactly one such pair (Sets and Functions, Definition 1.4.1). For t=a and t=b, one formula applies and names one value. For t=c, the first coordinate is 0 or S(k) for some k∈N, by Proposition 1.1.3 (a) for N; never both, by (P3) for N; and the k is unique. So exactly one line of the definition applies to each element, and it names one value. The values lie in M, since S(n),0,k∈N.

  • (b) Sort the values by their second coordinates (Sets and Functions, Definition 1.4.1): second coordinate a:s(n,a)=(S(n),a),second coordinate b:s(n,b)=(S(n),b)  and  s(0,c)=(0,b),second coordinate c:s(S(k),c)=(k,c).

    (P3) holds. A value equal to e=(0,a) would have second coordinate a, so it would be (S(n),a) with S(n)=0, against (P3) for N.

    (P4) holds. Suppose s(x)=s(x′). The two values have the same second coordinate, so they come from the same row of the display. In the first row, (S(n),a)=(S(n′),a) gives n=n′ by (P4) for N. In the third row, (k,c)=(k′,c) gives k=k′, so S(k)=S(k′). In the second row, (S(n),b)≠(0,b) because S(n)≠0; so either both values are of the form (S(n),b), and n=n′ as before, or both are (0,b), and both inputs are (0,c). In every case x=x′.

  • (c) Let x=(m,t)≠e. If t=a, then m≠0, so m=S(n) for some n (Proposition 1.1.3 (a) for N), and x=s(n,a). If t=b, then x=(0,b)=s(0,c), or m=S(n) and x=s(n,b). If t=c, then x=(m,c)=s(S(m),c).

  • (d) The set N×{a} contains e, is closed under s, since s(n,a)=(S(n),a), and misses (0,b), since b≠a. So it is a subset of M containing e, closed under s, and not equal to M.

  • (e) Both. Part (a) of Proposition 1.1.3 holds: a predecessor exists by (c), and it is unique by (P4), proved in (b). Part (b) holds: (S(n),a)≠(n,a) and (S(n),b)≠(n,b), since S(n)≠n in N (Proposition 1.1.3 (b)); s(0,c)=(0,b)≠(0,c), since b≠c; and s(S(k),c)=(k,c)≠(S(k),c), since k≠S(k). So neither conclusion of the proposition gives back (P5), even together with (P3) and (P4).

The picture to keep in mind: the elements with second coordinate a form a copy of N, starting at e. The elements with second coordinates b and c form one chain running forever in both directions. Read (n,b) as “n” and (k,c) as “−(k+1)”: the step moves one place to the right everywhere, with (0,c), playing −1, stepping to (0,b), playing 0. Every element of the chain has an arrow coming in, and none of it is reached from e.
