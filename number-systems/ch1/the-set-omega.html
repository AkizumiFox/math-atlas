1.3  Successors, Inductive Sets and the Natural Numbers

Logic and Proof, Chapter 4 described the natural numbers as what we reach from 0 by adding 1, again and again, and nothing else; induction (Logic and Proof, Axiom 4.2.1) was the precise form of “nothing else”. In this chapter every object is a set, so we need a set to play 0 and an operation on sets to play “add 1”. This section chooses both, adds the one axiom that lets the repetition be completed into a set, and proves induction as a theorem about the set it produces.

1.3.1. Going one step further

The empty set is the only set we can name without first having another one, so it will be 0. For “add one” we want an operation that, started from ∅, keeps producing new sets, never returning to one already met. Putting a set inside itself as an element does that, as we shall see.

The successor of a set adds the set itself as an element.

Definition 1.3.1 (Successor of a set)

For every set x, the successor of x is the set S(x):=x∪{x}.

In words: the elements of S(x) are the elements of x, together with x itself. So, for every set y, y∈S(x)⟺y∈x  or  y=x. The set S(x) exists and is unique: {x} is the set {x,x} of Pairing (Z3), and x∪{x}=⋃{x,{x}} comes from Union (Z4), both by Proposition 1.1.2 (b), (c). Two facts are visible at once. First, x∈S(x) for every x. Second, x⊆S(x): the successor keeps every old element and adds x itself, which is a new element whenever x∉x. The next section proves n∉n for every natural number n.

The letter is an upright S. Sets, Relations, and Cardinality, Chapter 1 used an italic S for a set in Sets, Relations, and Cardinality, Proposition 1.2.2, and we are about to use that proposition with this operation as its step; the two letters never stand for the same thing.

Start from ∅ and apply S repeatedly.

Example (The first natural numbers as sets)

Define 0:=∅,1:=S(0),2:=S(1),3:=S(2),4:=S(3). Write each of 1,2,3,4 as a set of the earlier numerals, and then using only ∅ and braces. Check that 0,1,2,3 are four different sets.

Solution. Each step adds the previous set as a new element: 1=∅∪{0}={0}={∅},2=1∪{1}={0,1}={∅,{∅}},3=2∪{2}={0,1,2}={∅,{∅},{∅,{∅}}},4=3∪{3}={0,1,2,3}={∅,{∅},{∅,{∅}},{∅,{∅},{∅,{∅}}}}. Written with ∅ and braces only, 4 already needs eight pairs of braces and eight copies of ∅, which is why the numerals are worth having.

The four sets differ, by Extensionality (Z1): two sets are equal only if they have the same elements, so it is enough to find an element of one that is not an element of the other. The set 0 has no elements, while 1, 2 and 3 all have the element 0; so 0 differs from each of them. Next, 1∈2 and 1∈3, but 1∉1: the only element of 1={0} is 0, and 1≠0. So 1 differs from 2 and from 3. Finally 2∈3, but 2∉2: the elements of 2 are 0 and 1, and 2 differs from both, as just shown. So 2≠3.

Each number is the set of the numbers before it: 3={0,1,2}, and 0=∅ because nothing comes before 0. The picture draws a set as a box and its elements as the boxes directly inside it.

The box for 3 holds three boxes, which are copies of the boxes for 0, 1 and 2. In general a natural number n will turn out to be the set of the natural numbers less than n, so that n={0,1,…,n−1} for n≠0. That is a theorem, proved later in this chapter once the order on the natural numbers is defined. For now the pattern is only something we have seen in the first five cases.

From here to the end of the chapter, the numerals 0,1,2,3,… name these sets. They are not real numbers; where the chapter compares the two pictures, it says so.

Other choices of “add one” are possible. The rule x↦{x} also starts a list of different sets, ∅,{∅},{{∅}},…. With an axiom of infinity stated for that rule, it too would give a set satisfying Peano’s axioms, but not by the proofs of the next section. What it loses is the pattern above: under it, the set playing 3 has one element, not three, and it does not contain the sets playing 0 and 1. The next section’s proofs rest on that pattern, and one of its results fails outright: under x↦{x} the set playing 2 is {{∅}}, which is the pair (∅,∅) of Definition 1.2.1, while the next section shows that no pair is a natural number in our sense. The choice x∪{x} makes the order of the numbers into membership, which the chapter uses repeatedly.

Warning. The successor is defined for every set, not only for numerals, and its result need not look like a number. For x={1}={{∅}}, the successor is S(x)={1,{1}}. It does not contain 0, while every numeral after 0 computed above does. A statement about S(x) that holds for the numerals may fail for other sets; this is why the results below are stated for elements of one particular set.

1.3.2. Inductive sets and the axiom of infinity

We want a set whose elements are exactly 0,1,2,…. The dots are the problem: Pairing and Union make each numeral, one at a time, and no axiom so far collects them all. The way out is to describe the property such a set must have, ask for a set with that property, and then cut it down to size.

An inductive set contains 0 and never runs out of successors.

Definition 1.3.2 (Inductive set)

A set I is inductive if ∅∈I and, for every x∈I, also S(x)∈I.

In words: the first clause gives the set a starting point, and the second says it is closed under the successor, so that applying S never leads out of it. In symbols, with bounded quantifiers, ∅∈I ∧ ∀x∈I  S(x)∈I.

The word “inductive” has another use in the analysis volume of this series, for subsets of the real numbers that contain the number 0 and are closed under x↦x+1. The shape is the same, but here the starting point is the set ∅, the step is S, and there is no ambient set of real numbers.

An inductive set contains all the numerals: 0=∅ by the first clause, then 1=S(0) by the second, then 2=S(1), and so on, one application of the second clause per numeral. So an inductive set cannot be finite in any naive sense, and nothing we have so far produces one.

Non-examples by minimal change come cheaply. The set 4={0,1,2,3} contains ∅ and the successors of 0, 1 and 2; only the last successor is missing, since S(3)=4∉4: the set 4 has the element 3, and none of 0,1,2,3 does (0 has no elements, and the elements of 1, 2 and 3 are among 0,1,2, each different from 3 by Example (The first natural numbers as sets)). And {1,2,3,…}, if we had it, would be closed under S but would miss the starting point. Both clauses do work.

Quick check. Is {∅} inductive? Is {0,1,2}?

Solution. Neither. {∅} contains ∅, but S(∅)={∅}=1 is not an element of {∅}: its only element is ∅=0, and 1≠0 because 0∈1. So the closure clause fails at x=∅.

{0,1,2} contains 0 and the successors of 0 and 1, but S(2)=3 is not among 0,1,2: the set 3 has the element 2, and none of 0,1,2 does (0 has no elements, the only element of 1 is 0, and the elements of 2 are 0 and 1, both different from 2 by Example (The first natural numbers as sets)). So the closure clause fails at x=2.

Axioms (Z1)–(Z6) of Axiom 1.1.1 produce each numeral separately, never all of them at once. That they cannot do better, that is, that no inductive set can be shown to exist from (Z1)–(Z6), is a theorem of set theory proper; we state it without proof, and nothing in this book depends on it. So the existence of an inductive set has to be assumed.

Axiom 1.3.1 (Axiom of Infinity)

(Z7) There is an inductive set.

Everything else the chapter builds, the natural numbers and their arithmetic included, comes from the inductive set of (Z7) by the six axioms of Axiom 1.1.1.

The axiom provides some inductive set and says nothing else about it. It may contain sets other than 0,1,2,…. We cannot simply call it “the set of natural numbers”; we have to carve that set out of it.

1.3.3. The least inductive set

An inductive set contains the numerals, and perhaps more. To remove anything extra, keep only what lies in every inductive set: whatever a set must contain merely by being inductive.

The natural numbers are what every inductive set is forced to contain.

There is one obstacle. Separation (Z6) can only cut a set out of a set already given, so we need an ambient set for the natural numbers; and the smallest-closed-set construction of Sets, Relations, and Cardinality, Chapter 1 (Sets, Relations, and Cardinality, Proposition 1.2.2) intersects a set of subsets, but the inductive sets are not handed to us as the elements of any set. So we fix one inductive set I and look only at the inductive subsets of I, which do form a set, by Power set and Separation; the theorem below shows that the choice of I does not matter.

Definition 1.3.3 (The set of natural numbers)

Fix an inductive set I, which exists by (Z7). Define ω:={x∈I:x∈J for every inductive set J⊆I}. The elements of ω are the natural numbers.

In words: a natural number is an element of the fixed inductive set I that survives every attempt to shrink I to a smaller inductive set.

The set ω exists by Separation (Z6), with ambient set I, once the condition is a property in the sense of (Z6): a formula of Logic and Proof, Chapter 5’s first-order language with ∈ and = (Logic and Proof, Definition 5.2.2), with I as a parameter. The condition is “for every J, if J⊆I and J is inductive, then x∈J”, and, since J⊆I abbreviates ∀y(y∈J→y∈I) as in (Z5) (Sets, Relations, and Cardinality, Definition 1.1.2), the only part not yet written in that language is “J is inductive”. Written out with no abbreviations it is ∃e(e∈J∧∀y¬(y∈e))∧∀u(u∈J→∃z(z∈J∧∀w(w∈z↔(w∈u∨w=u)))). The first line says that J has an element with no elements, which is ∅∈J, because ∅ is the only set with no elements (Proposition 1.1.2 (a)). The second says that for each u∈J some element z of J has exactly the elements of u∪{u}, which is S(u)∈J by (Z1).

Here is what “least” means, and why the choice of I is harmless.

Theorem 1.3.2 (The Least Inductive Set)
  • (a) ω is inductive.
  • (b) ω⊆J for every inductive set J, whether or not J⊆I.
  • (c) ω is the only set with properties (a) and (b). In particular, ω does not depend on the inductive set I fixed in Definition 1.3.3.

Idea. Part (a) is Sets, Relations, and Cardinality, Chapter 1’s smallest closed set, with I as the ambient set, ∅ as the starting element and S as the step: the closed subsets of I are exactly its inductive subsets, and ω is their intersection. For (b), an inductive J need not lie inside I, so we cut it down to ω∩J, which does; then the definition of ω applies. Part (c) is two inclusions, each an instance of (b).

Proof. (a) Apply Sets, Relations, and Cardinality, Proposition 1.2.2 with X:=I, the single starting element ∅, which lies in I because I is inductive, and the single step x↦S(x), which turns elements of I into elements of I for the same reason. A subset J⊆I is closed in the sense of that proposition exactly when ∅∈J and S(x)∈J for every x∈J, that is, when J is inductive. So the set of closed subsets is S:={J∈P(I):J is inductive}, a set by Power set (Z5) and Separation (Z6); it is non-empty, since I∈S. Its intersection ⋂S, formed inside I as in Proposition 1.1.2 (c), is {x∈I:x∈J for every J∈S}, which is ω. By Sets, Relations, and Cardinality, Proposition 1.2.2, ⋂S is closed; that is, ω is inductive.

(b) Let J be an inductive set. The set ω∩J exists by (Z6) (Proposition 1.1.2 (c)), and ω∩J⊆ω⊆I. It is inductive: ∅∈ω by (a) and ∅∈J because J is inductive; and if x∈ω∩J, then S(x)∈ω by (a) and S(x)∈J because J is inductive. So ω∩J is an inductive subset of I, and by Definition 1.3.3 every element of ω lies in it. Hence ω⊆ω∩J⊆J.

(c) Let W be a set that is inductive and is contained in every inductive set. Then W⊆ω, because ω is inductive by (a); and ω⊆W by (b), because W is inductive. So W=ω by Sets, Relations, and Cardinality, Proposition 1.1.1. Now let I′ be another inductive set, and let ω′ be the set that Definition 1.3.3 produces from I′. The proofs of (a) and (b) used nothing about I except that it is inductive, so they apply to ω′ as well: ω′ is inductive and is contained in every inductive set. By what we just proved, ω′=ω. This proves the theorem.

So ω is the least inductive set: it is inductive, and it lies inside every inductive set. From now on we forget I. The numerals 0,1,2,3,4 of Example (The first natural numbers as sets) are natural numbers, since ω is inductive and contains each of them by the argument given after Definition 1.3.2.

Warning. “An inductive set is the set of natural numbers” is false in general. Theorem 1.3.2 gives ω⊆J for an inductive J, and nothing more. The set-theory volume of this series, using the axiom of Replacement (not part of this chapter), builds the inductive set ω∪{ω,S(ω),S(S(ω)),…}; it contains ω itself as an element, and the next section shows that ω∉ω. Axiom (Z7) does not say that its I is not a set of this kind. What distinguishes ω among inductive sets is “least”, and every argument about natural numbers must go through ω, not through an arbitrary inductive set.

1.3.4. Induction on the natural numbers

Leastness has an immediate consequence. To show that every natural number belongs to some set A, it is enough to show that A is inductive, since then ω⊆A.

Theorem 1.3.3 (Induction on ω)
  • (a) (Set form.) Let A⊆ω. If 0∈A, and S(n)∈A for every n∈A, then A=ω.
  • (b) (Property form.) Let P(n) be a property, that is, a formula of the first-order language with ∈ and =, possibly with other variables as parameters. If P(0) holds and, for every n∈ω, P(n) implies P(S(n)), then P(n) holds for every n∈ω.

Proof. (a) The hypotheses say that A is inductive. By Theorem 1.3.2 (b), ω⊆A. With A⊆ω, Sets, Relations, and Cardinality, Proposition 1.1.1 gives A=ω.

(b) Let A:={n∈ω:P(n)}, a set by (Z6). Then 0∈A, because 0∈ω by Theorem 1.3.2 (a) and P(0) holds. Let n∈A. Then n∈ω and P(n), so P(S(n)) by hypothesis, and S(n)∈ω because ω is inductive; hence S(n)∈A. By (a), A=ω, which says that P(n) holds for every n∈ω.

Compare part (b) with the principle of induction, Logic and Proof, Axiom 4.2.1. Read with ω in place of N, and with S(n) in place of n+1, the two statements are the same; and once addition is defined, later in this chapter, n+1 will be S(n). The difference lies in their status. In Logic and Proof, Chapter 4, induction was an axiom, a basic property of N taken on trust. Here it is a theorem, proved from the seven axioms (Z1)–(Z7) about sets, and the proof is three lines long because all the work went into the definition of ω: the natural numbers were defined as what every inductive set contains, and induction says exactly that.

The proof of (b) is the model for the inductions in the rest of this chapter.

Show the set is inductive. To prove P(n) for every n∈ω, form {n∈ω:P(n)} and show that it has 0 as an element and is closed under S.

Here is the move once, on a statement about the shape of natural numbers: every n∈ω is 0, or is 1, or has 1 as an element. Let A:={n∈ω:n=0 or n=1 or 1∈n}, a set by (Z6). Then 0∈A by the first alternative. Let n∈A; there are three cases. If n=0, then S(n)=1, which satisfies the second alternative. If n=1, then S(n)=2={0,1}, which has 1 as an element. If 1∈n, then 1∈n⊆S(n). In every case S(n)∈A, since also S(n)∈ω because ω is inductive (Theorem 1.3.2 (a)). By Theorem 1.3.3 (a), A=ω.

Two features of this small proof recur. The property carried along is a disjunction, because “1∈n” alone is false at n=0 and n=1, and an induction can only carry a property that holds at the start. And the step is a case split along the disjunction, with one case for each alternative; dropping a case would be the error (N7) of Logic and Proof, Example (What is not allowed).

Quick check. In the proof just given, which case of the step produces the first natural number that satisfies the third alternative “1∈n”, and which number is it?

Solution. The case n=1. It produces S(1)=2={0,1}, which has 1 as an element. Neither 0 nor 1 has 1 as an element (0 has no elements, and the only element of 1 is 0≠1), so 2 is the first. From then on the third case passes “1∈n” to S(n), because n⊆S(n).

The next section uses the move five times in a row, to show that ω satisfies Peano’s axioms.

1.3.5. Exercises

A. Check your understanding

Exercise (A1)
  • (a) List the elements of 3 and of 4 as sets of numerals.
  • (b) Is 2⊆3? Is 2∈3?
  • (c) True or false, with a reason: every inductive set has 5:=S(4) as an element.
  • (d) Write “J is not inductive” in symbols, with the negation moved inward until it stands only in front of a membership statement.

Solution.

  • (a) 3={0,1,2} and 4={0,1,2,3}, by Example (The first natural numbers as sets).

  • (b) Both are true. The elements of 2 are 0 and 1, and both are elements of 3={0,1,2}; so 2⊆3 (Sets, Relations, and Cardinality, Definition 1.1.2). And 2 is itself one of the listed elements of 3, so 2∈3. A set can be both an element and a subset of another set; for numerals this will turn out to be the rule, not an accident.

  • (c) True. Let J be inductive. Then 0=∅∈J by the first clause of Definition 1.3.2, and the second clause applied five times gives 1,2,3,4,5∈J, each being the successor of the one before.

  • (d) “J is inductive” is ∅∈J∧∀x∈J  S(x)∈J. Its negation is ¬(∅∈J∧∀x∈J  S(x)∈J), which by De Morgan’s law Logic and Proof, Proposition 2.5.5 (d) and (c) is equivalent to ¬(∅∈J)∨¬∀x∈J  S(x)∈J, and by Logic and Proof, Proposition 6.2.3 (a), the bounded form of Logic and Proof, Proposition 6.2.1, to ∅∉J ∨ ∃x∈J  S(x)∉J. In words: J lacks the starting point, or some element of J has its successor outside J.

B. Practice

Exercise (B1: Intersections and differences)

Let J and K be inductive sets. Prove that J∩K is inductive. Is J∖{∅} inductive? Justify your answer, and say which clause of the definition holds and which fails.

Solution. The set J∩K exists by (Z6) (Proposition 1.1.2 (c)). It contains ∅, since ∅∈J and ∅∈K. If x∈J∩K, then S(x)∈J because J is inductive and x∈J, and S(x)∈K likewise; so S(x)∈J∩K. Hence J∩K is inductive.

The set J∖{∅} is not inductive: it does not contain ∅, so the first clause fails. The second clause holds: if x∈J∖{∅}, then S(x)∈J, and S(x)≠∅ because x∈S(x); so S(x)∈J∖{∅}. This is a non-example by minimal change: removing one element breaks exactly one clause.

Exercise (B2: Zero or a successor)

Prove that every n∈ω is ∅ or is S(k) for some k∈ω, by showing that the set A:={n∈ω:n=∅ or n=S(k) for some k∈ω} is inductive.

Solution. The set A exists by (Z6), and A⊆ω. It contains 0=∅ by the first alternative. Let n∈A. Then n∈ω, so S(n)∈ω because ω is inductive (Theorem 1.3.2 (a)), and S(n) satisfies the second alternative with k:=n∈ω. So S(n)∈A. By Theorem 1.3.3 (a), A=ω, which is the claim.

The step never used the hypothesis that n satisfies one of the alternatives, only that n∈ω. That is legitimate: the step’s conclusion was reached outright, and induction still does the work of saying that every natural number is reached from 0 by successors.

C. Going deeper

Exercise (C1: Two steps back)
  • (a) Prove that every n∈ω is 0, or is 1, or is S(S(k)) for some k∈ω.
  • (b) Let I be an arbitrary inductive set. Running the argument of (a) on {x∈I:x=0 or x=1 or x=S(S(k)) for some k∈I}, what does it prove about the elements of I, and what does it not prove?

Solution.

  • (a) Let A:={n∈ω:n=0 or n=1 or n=S(S(k)) for some k∈ω}, a set by (Z6). Then 0∈A by the first alternative. Let n∈A; we show S(n)∈A, in three cases along the disjunction. If n=0, then S(n)=1, the second alternative. If n=1, then S(n)=S(S(0)), the third alternative with k:=0∈ω. If n=S(S(k)) with k∈ω, then S(n)=S(S(S(k))), the third alternative with S(k) in place of k, and S(k)∈ω because ω is inductive. In each case S(n)∈ω, so S(n)∈A. By Theorem 1.3.3 (a), A=ω.

  • (b) Call the set AI. The same three cases show that AI has 0 as an element and is closed under S, so AI is inductive; by Theorem 1.3.2 (b), ω⊆AI. That says only that every natural number is 0, 1 or S(S(k)) for some k∈I, which is weaker than (a), whose k lies in ω. It does not say that every element of I is 0, 1 or S(S(k)) for some k∈I. The set form of induction concludes A=ω only because A⊆ω was given; for AI⊆I the most we get is ω⊆AI⊆I, and the elements of I outside ω, if any, are not reached. Induction proves statements about ω, not about arbitrary inductive sets.
