1.2  The Recursion Theorem; Addition and Multiplication

The natural numbers now have a zero, a successor map and induction (Theorem 1.1.2), and nothing else: no addition, no multiplication. Sets and Functions, Section 3.3 had the same need and met it with Sets and Functions, Theorem 3.3.1, a theorem that turns two equations into a function. Its proof built partial solutions on the sets {0,…,n} and compared them using the order of the real numbers. The natural numbers of Axiom 1.1.1 have no order yet; the order is defined in the next section, from the addition of this one. So this section proves the recursion theorem by a construction that needs no order at all: it takes the smallest set of pairs that the two equations force, and shows that this set is the graph of a function. Then it defines addition and multiplication as school does, and proves the laws of arithmetic by one move and its consequences.

1.2.1. Recursion on ℕ

A starting value and a rule for the next value determine exactly one function on N.

Theorem 1.2.1 (Recursion Theorem on N)

Let X be a set, let a∈X, and let g:N×X→X be a function. Then there is exactly one function f:N→X such that f(0)=aandf(S(n))=g(n,f(n))  for every n∈N.

This is the statement of Sets and Functions, Theorem 3.3.1, with N the Peano system of Axiom 1.1.1 and S(n) in place of n+1. The set N×X is the Cartesian product of Sets and Functions, Definition 1.4.2. As before, a is the starting value and g turns the stage n and the current value into the next value; the conclusion has an existence half and a uniqueness half.

Idea (Scratch work). Uniqueness will be an induction: two solutions agree at 0, and the second equation passes agreement from n to S(n). Existence is the hard half. “Define f by the two equations” names f on both sides of the second one, so it is not yet a definition. A definition must produce an object, and the object a function is made of is its graph (Sets and Functions, Definition 2.1.1). So ask what the graph must contain. It must contain the pair (0,a). Whenever it contains a pair (n,x), meaning f(n)=x, it must also contain (S(n),g(n,x)).

That is a description of a closed set: in N×X, take the starting element (0,a) and the step (n,x)↦(S(n),g(n,x)), which maps N×X into itself because g takes its values in X. By Sets and Functions, Proposition 1.3.2 there is a smallest closed subset; call it R. It contains exactly what the equations force and nothing more. The question is whether R is a graph: does each n have exactly one partner x with (n,x)∈R?

Givens Goal
R is the smallest closed subset of N×X each n has exactly one x with (n,x)∈R
induction on n base: the only pair at 0 is (0,a); step: the only pair at S(n) is (S(n),g(n,xn)), where xn is the partner of n
an extra pair (n,y)∈R R∖{(n,y)} is still closed, against “smallest”

The last row is the gap the proof closes. A smallest closed set has no spare elements: if one pair could be removed without breaking closure, the smaller set would be closed, and R would lie inside it. Removing a pair is safe only if no step produces it from a pair that stays. That is where (P3) and (P4) enter.

Before reading on: where is each of them used?

Proof. Step 1 (uniqueness). Let f,f′:N→X both satisfy the two equations, and let P(n) be “f(n)=f′(n)”. P(0) holds, since f(0)=a=f′(0). If P(n) holds, then f(S(n))=g(n,f(n))=g(n,f′(n))=f′(S(n)), so P(S(n)) holds. By Theorem 1.1.2 (b), P(n) holds for every n∈N. The two functions have the same domain and codomain, so f=f′ by Sets and Functions, Proposition 2.1.1.

Step 2 (the set of pairs). Call a subset C⊆N×X closed if (0,a)∈C and (S(n),g(n,x))∈C for every (n,x)∈C. The step sends N×X into itself, since S(n)∈N and g(n,x)∈X. By Sets and Functions, Proposition 1.3.2 there is a closed set R⊆N×X that lies inside every closed set.

Step 3.

Claim. For every n∈N there is exactly one x∈X with (n,x)∈R.

Proof of Claim. We use Theorem 1.1.2 (b) on n.

Base case. (0,a)∈R, since R is closed. Suppose (0,b)∈R with b≠a, and let R′:=R∖{(0,b)}. Then (0,a)∈R′, because (0,a)≠(0,b) (Sets and Functions, Definition 1.4.1). Let (m,x)∈R′. Then (m,x)∈R, so (S(m),g(m,x))∈R; and this pair is not (0,b), because S(m)≠0 by (P3). So it lies in R′, and R′ is closed. Hence R⊆R′, which is false, since (0,b)∈R and (0,b)∉R′. So a is the only partner of 0.

Inductive step. Let n∈N, and suppose n has exactly one partner xn in R. Since (n,xn)∈R and R is closed, (S(n),g(n,xn))∈R. Suppose (S(n),y)∈R with y≠g(n,xn), and let R′:=R∖{(S(n),y)}. Then (0,a)∈R′, because S(n)≠0 by (P3). Let (m,x)∈R′; then (S(m),g(m,x))∈R. If this pair were (S(n),y), then S(m)=S(n), so m=n by (P4); then (n,x)∈R, so x=xn by the induction hypothesis; and then y=g(m,x)=g(n,xn), against the choice of y. So (S(m),g(m,x))∈R′, and R′ is closed. As in the base case, R⊆R′ is false. So g(n,xn) is the only partner of S(n), which proves the claim.

Step 4 (the function). R is a subset of N×X in which each n∈N has exactly one partner, so f:=(R,X) is a function N→X by Sets and Functions, Definition 2.1.1, and f(n) is the partner of n. Since (0,a)∈R, f(0)=a. For n∈N, (n,f(n))∈R, so closure gives (S(n),g(n,f(n)))∈R, that is, f(S(n))=g(n,f(n)). This proves existence, and with Step 1, the theorem.

Each Peano axiom has a visible job in the proof. (P3) appears in the base case of Step 3, where no step can produce a pair with first coordinate 0, and again in its inductive step, where it keeps (0,a) in R′. (P4) appears in the inductive step: a pair that steps to first coordinate S(n) has first coordinate n, where the induction hypothesis applies. (P5) enters through Theorem 1.1.2, in Steps 1 and 3. No choice is made: R is the one smallest closed set, and each partner is the only one. From now on a definition “f(0):=a, f(S(n)):=g(n,f(n))” on N is legitimate whenever a∈X and g:N×X→X is a function, and f is defined by recursion.

Quick check. For X=N, a=0 and g(n,x)=S(S(x)), which pairs of R have first coordinate 0, 1 or 2? (Here 1, 2, 3, 4 stand for S(0), S(1), S(2), S(3).)

Solution. (0,0), since R contains the starting pair; then (1,2), since g(0,0)=S(S(0))=2; then (2,4), since g(1,2)=S(S(2))=4. There are no others with these first coordinates, by the claim of Step 3.

Quick check. In the inductive step of the claim, why does R′:=R∖{(S(n),y)} still contain (0,a)? Which axiom is used?

Solution. (P3): S(n)≠0, so the removed pair has a different first coordinate from (0,a) and is not (0,a) (Sets and Functions, Definition 1.4.1).

Warning. The hypothesis that g takes its values in X cannot be dropped. Let X={0}, a=0, and g(n,x):=S(0) for n∈N, x∈X, so that g maps N×X into N but not into X. Any f:N→X with the two equations would need f(S(0))=g(0,f(0))=S(0), and S(0)∉X since S(0)≠0 by (P3); so no such f exists. The proof breaks at Step 2: this step does not map N×X into itself, so Sets and Functions, Proposition 1.3.2 does not apply.

1.2.2. Addition and multiplication

With the theorem, addition is the old school definition made official. To add n to m, start at m and take n successor steps: m+0 is m, and m+S(n) is one step further than m+n. Multiplication is repeated addition in the same way.

Adding n to m is taking n successor steps from m.

Definition 1.2.1 (Addition and Multiplication on N)
  • (a) For each m∈N, let Am:N→N be the function given by Theorem 1.2.1 with X=N, a=m and g(n,x)=S(x). The sum of m and n is m+n:=Am(n). Thus, for all m,n∈N, m+0=m,m+S(n)=S(m+n).
  • (b) For each m∈N, let Mm:N→N be the function given by Theorem 1.2.1 with X=N, a=0 and g(n,x)=x+m. The product of m and n is m⋅n:=Mm(n), also written mn. Thus, for all m,n∈N, m⋅0=0,m⋅S(n)=m⋅n+m.
  • (c) The numerals are 1:=S(0), 2:=S(1), 3:=S(2), and so on. For every n∈N, n+1=S(n); in particular 1+1=2 and k+2=(k+1)+1 for every k∈N.

In words: (a) and (b) are the two clauses we would write for a school definition, and the theorem guarantees that they define exactly one function Am, respectively Mm, for each m. Multiplication binds more tightly than addition, so m⋅n+m is (m⋅n)+m.

Well-definedness. Each g maps N×N into N: S(x)∈N because S maps N into N, and x+m=Ax(m)∈N because Ax maps into N. So (b) uses (a), and (a) uses nothing but the successor. The sum is then a function N×N→N, with graph {((m,n),k)∈(N×N)×N:k=Am(n)} (Sets and Functions, Definition 1.2.3): each (m,n) gets exactly one k, because each Am exists and is unique. Likewise for the product.

The successor is “plus one”. Proof of the last sentence of (c): for every n∈N, n+1=n+S(0)=S(n+0)=S(n), by (c) and the two equations of (a). From now on we write n+1 for S(n) whenever n∈N; the defining equations then read as in school: m+0=m,m+(n+1)=(m+n)+1,m⋅0=0,m⋅(n+1)=m⋅n+m. Two small computations are used repeatedly later: 1+1=S(1)=2, and, for every k∈N, k+2=k+S(1)=S(k+1)=(k+1)+1.

A non-example by minimal change: keep a=m in (a), but replace g(n,x)=S(x) by g(n,x)=S(n), which ignores the current value. This g is still a function N×N→N, so Theorem 1.2.1 gives exactly one f:N→N with f(0)=m and f(S(n))=S(n). The first equation m+0=m still holds for this “sum”, but the second, m+S(n)=S(m+n), fails: with m=2, f(1)=S(0)=1, while S(f(0))=S(2)=3. So it would give 2+1=1, and it is not addition.

The defining equations immediately give the two Peano facts in the “plus one” notation.

Corollary 1.2.2 (Successor Cancellation)

For all k,l∈N: if k+1=l+1, then k=l; and k+1≠0.

Proof. By (c) of Definition 1.2.1, k+1=S(k) and l+1=S(l). So the first claim is (P4) for N, and the second is (P3) (Axiom 1.1.1).

Quick check. Compute 2+2 and 2⋅2 from the defining equations alone.

Solution. By (a) of Definition 1.2.1, three times, 2+2=S(2+1)=S(S(2+0))=S(S(2))=S(3)=4. By (b), twice and then at 0, 2⋅2=2⋅1+2=(2⋅0+2)+2=(0+2)+2, and 0+2=S(0+1)=S(S(0+0))=S(S(0))=2. So 2⋅2=2+2=4.

1.2.3. The laws of arithmetic

Every law of arithmetic that Sets and Functions, Chapter 3 took from the real numbers must now be proved, and the only tools are the four defining equations and induction. The equations are lopsided: they say what happens when the second argument goes up by one, and nothing about the first. So in every induction in the proof of Theorem 1.2.3 we fix all variables but one and induct on the variable that the recursion runs on, the second argument of + or ⋅.

Idea (Scratch work). Take the first law that school arithmetic uses without a thought: 0+n=n. The defining equations do not give it. They give m+0=m, with the 0 in the second place, and 0+n has its 0 in the first. Which variable to induct on? The equations speak about 0 and successors in the second place, and in 0+n that place is held by n. So induct on n: then the base case is a defining equation, and the step can open 0+(n+1) with the other one.

Givens Goal
m+0=m and m+(n+1)=(m+n)+1 for all m,n 0+n=n for every n∈N
0+0=0: the first equation with m=0 base closed; step: 0+(n+1)=n+1
IH: 0+n=n 0+(n+1)=(0+n)+1=n+1: closed

The second equation, with m=0, opens the term at n+1; the hypothesis applies to the inner 0+n; nothing is left to do. Had we tried to induct with 0 and n in the other roles, there would be no equation to open the term with.

The scratch work proves the first half of (a) in the theorem below; the rest of the theorem is proved the same way.

Theorem 1.2.3 (Laws of Arithmetic on N)

For all k,m,n∈N:

  • (a) 0+n=n, and (m+1)+n=(m+n)+1;
  • (b) m+n=n+m;
  • (c) (k+m)+n=k+(m+n);
  • (d) m(n+k)=mn+mk and (n+k)m=nm+km;
  • (e) 0⋅n=0, (m+1)⋅n=mn+n, and n⋅1=1⋅n=n;
  • (f) mn=nm;
  • (g) (km)n=k(mn).

The move of the scratch work is worth naming, because the identities of this section are proved with it.

Example (Method: fix the others, induct on the recursion variable)

Template. (1) Find the variable the definition is a recursion on: the second argument of + and ⋅, the exponent of a power un (Sets and Functions, Section 3.3; on N in the next section). (2) Fix the other variables. (3) Induct on it: the base is the defining equation at 0; the step opens the term at n+1 by the other equation, applies the hypothesis inside, and closes up. (4) If the variable sits where no equation applies (a first argument), first prove the lemma that moves it.

When to use it. Identities between terms built by recursion: laws of + and ⋅, of powers, of sums.

The usual failure. Inducting on a first argument (the warning after the proof); citing a law not yet proved, such as commutativity before (a).

Idea. Every clause except the second half of (d) and the last part of (e), which follow from earlier clauses directly, is proved by Example (Method: fix the others, induct on the recursion variable), in an order where each uses only earlier ones. Commutativity (b) needs both halves of (a), which move a successor out of the first argument, where no defining equation reaches.

Proof. Each induction is Theorem 1.1.2 (b), applied to the property stated in the clause, with the other variables fixed. “Def” refers to the equations of Definition 1.2.1, “IH” to the induction hypothesis.

(a) The first half, 0+n=n, is the scratch work above: the base is Def with m=0, and the step is 0+(n+1)=(0+n)+1=n+1, by Def and IH. For the second half, fix m∈N and induct on n. Base case: (m+1)+0=m+1=(m+0)+1, by Def twice. Inductive step: if (m+1)+n=(m+n)+1, then (m+1)+(n+1)=((m+1)+n)+1=((m+n)+1)+1=(m+(n+1))+1, by Def, IH, and Def read from right to left inside the outer +1.

(c) We prove associativity of addition in full. Fix k,m∈N, and let P(n) be “(k+m)+n=k+(m+n)”. Base case: by the first equation of (a) of Definition 1.2.1, applied twice, (k+m)+0=k+m=k+(m+0). Inductive step: suppose P(n). Then (k+m)+(n+1)=((k+m)+n)+1=(k+(m+n))+1=k+((m+n)+1)=k+(m+(n+1)), where the first equality is Def with first argument k+m, the second is P(n), the third is Def with first argument k and second argument m+n, and the fourth is Def with first argument m. So P(n+1) holds, and by Theorem 1.1.2 (b), P(n) holds for every n∈N.

(b), (d)–(g) follow by the same move, in the order of the table in the fold below.

↺Second readingProofs of (b) and (d)–(g)

“Def” refers to the equations of Definition 1.2.1, “IH” to the induction hypothesis. The second half of (d) and the last part of (e) are derived from earlier clauses without induction; for the first half of (d) the variable is k, the recursion variable of m(n+k).

The other clauses follow the same pattern; the table gives, for each, the property inducted on, the base case, the step, and the earlier clauses used. They are proved in the order of the table, so each row uses only (a), (c) and rows above it.

The laws (a)–(g) are the rules of school arithmetic, now proved from Axiom 1.1.1. The next section defines the order from addition and proves its properties with these laws.

Warning. Do not assume 0+n=n. It is clause (a) of Theorem 1.2.3, proved by induction; the defining equation is n+0=n. For the same reason, inducting on m in m+n=n+m gets stuck: the step would need (m+1)+n, and the definition says nothing about a sum whose first argument is a successor until (a) is proved.

The order of the table is forced by the lopsided definition. Commutativity, which lets us move a successor from the second place to the first, comes only after the two facts in (a) that move it by hand; once it is available, (e) and (f) follow the same way for multiplication.

Quick check. Which variable would you induct on to prove m(n+k)=mn+mk, and which earlier law lets the step close?

Solution. On k, the second argument of n+k and of mk, where the recursion runs; m and n are fixed. The step is m(n+(k+1))=m((n+k)+1)=m(n+k)+m=(mn+mk)+m=mn+(mk+m)=mn+m(k+1), by Def of +, Def of ⋅, IH, associativity (c), and Def of ⋅ again. Law (c) is the one that lets the step close.

1.2.4. Exercises

A. Check your understanding

Exercise (A1)
  • (a) In the proof of Theorem 1.2.1, where are (P3) and (P4) used?
  • (b) Why does the uniqueness half need only an induction, while existence needs the set R?
  • (c) Name the move, and the variable, for proving 0⋅n=0.
  • (d) State the idea of the existence proof in two sentences.

Solution.

  • (a) (P3) is used in the base case of the claim of Step 3: no step produces a pair with first coordinate 0, since S(m)≠0, so a second pair (0,b) could be removed without breaking closure. It is used again in the inductive step, where S(n)≠0 keeps (0,a) in R′. (P4) is used in the inductive step: a pair that steps to first coordinate S(n) has first coordinate n, where the induction hypothesis applies.

  • (b) Uniqueness compares two functions that are given, value by value, and comparing values at n+1 through the values at n is exactly an induction on n. Existence asks for a function that is not given; induction proves statements and builds nothing. So existence needs an object first, the set R, and induction then proves a statement about it (the claim of Step 3).

  • (c) Fix the others, induct on the recursion variable (Example (Method: fix the others, induct on the recursion variable)). There are no others to fix; the recursion variable of 0⋅n is n. Base: 0⋅0=0 by Def. Step: 0⋅(n+1)=0⋅n+0=0+0=0, by Def, the hypothesis, and Def.

  • (d) The smallest set of pairs closed under the two equations exists. Each n has exactly one partner in it, because a second partner could be removed without breaking closure, so the set is the graph of the required function.

B. Practice

Exercise (B1: Small products)

Compute 3⋅2 and 2⋅3 from the defining equations of Definition 1.2.1 alone, without using Theorem 1.2.3. Here 5:=S(4) and 6:=S(5).

Solution. For 3⋅2, by (b) twice and then at 0: 3⋅2=3⋅1+3=(3⋅0+3)+3=(0+3)+3. By (a), 0+3=S(0+2)=S(S(0+1))=S(S(S(0+0)))=S(S(S(0)))=3. Then 3+3=S(3+2)=S(S(3+1))=S(S(S(3+0)))=S(S(S(3)))=6. So 3⋅2=6.

For 2⋅3, by (b), 2⋅3=2⋅2+2, and 2⋅2=4 by the Quick check above. Then 4+2=S(4+1)=S(S(4+0))=S(S(4))=6. So 2⋅3=6=3⋅2, as (f) of Theorem 1.2.3 predicts; but the two computations took different routes, and neither used a law.

Exercise (B2: Distributivity, last step blank)

Here is the proof of m(n+k)=mn+mk for all m,n,k∈N, with the last step left blank. Name the move, then complete it.

Fix m,n∈N and induct on k. Base case: m(n+0)=mn=mn+0=mn+m⋅0. Inductive step: suppose m(n+k)=mn+mk. Then m(n+(k+1))=m((n+k)+1)=m(n+k)+m=(mn+mk)+m=―.

Justify each equality you add.

Solution. The move is fix the others, induct on the recursion variable (Example (Method: fix the others, induct on the recursion variable)): in m(n+k) the recursion of + runs on k, so m and n are fixed and the induction is on k.

The completion is (mn+mk)+m=mn+(mk+m)=mn+m(k+1), where the first equality is associativity, (c) of Theorem 1.2.3, and the second is the defining equation m(k+1)=mk+m of Definition 1.2.1 (b), read from right to left. This is the statement for k+1, so by Theorem 1.1.2 (b) it holds for every k∈N. (This is clause (d) of Theorem 1.2.3, already proved; the exercise practices the move.)

Exercise (B3: Prove or disprove)

Prove each true statement and refute each false one with a counterexample. All letters stand for natural numbers, and you may use Theorem 1.2.3.

  • (a) If m+n=0, then m=n=0.
  • (b) If mn=m, then n=1.
  • (c) m⋅(n+1)=m⋅n+n.
  • (d) If m+n=m, then n=0.
  • (e) If n⋅n=n, then n=0.

Solution.

  • (a) True. Suppose n≠0. Then n=S(k)=k+1 for some k∈N (Proposition 1.1.3 (a), and (c) of Definition 1.2.1), and m+n=m+(k+1)=(m+k)+1≠0 by Def and Corollary 1.2.2. So m+n=0 forces n=0, and then m=m+0=0.

  • (b) False. Take m=n=0: 0⋅0=0=m, but n=0≠1, since 1=S(0)≠0 by (P3).

  • (c) False. This is a look-alike of the defining equation m⋅(n+1)=m⋅n+m of Definition 1.2.1 (b), whose last term is m, not n. Take m=0, n=1: the left side is 0⋅2=0 by law (e), and the right side is 0⋅1+1=0+1=1, and 1≠0.

  • (d) True. Induct on m for the property “for every n, if m+n=m, then n=0”. Base: 0+n=n by law (a), so 0+n=0 gives n=0. Step: suppose the property for m, and let (m+1)+n=m+1. By law (a), (m+1)+n=(m+n)+1, so (m+n)+1=m+1, and Corollary 1.2.2 gives m+n=m. By the hypothesis, n=0.

  • (e) False. Take n=1: 1⋅1=1⋅0+1=0+1=1, by Def and law (a), but 1≠0.

C. Going deeper

Exercise (C1: Exit check: addition is commutative)

From the two defining equations of addition, m+0=m and m+(n+1)=(m+n)+1, and Theorem 1.1.2 alone, prove that m+n=n+m for all m,n∈N. Prove every auxiliary fact you need.

Solution (Hint 1). The definition says what happens when the second argument is 0 or a successor. To use it on n+m, you need to know the same for the first argument: prove two lemmas first.

Solution (Hint 2). Start with the first lemma, 0+n=n, by induction on n; the base is the first equation with m=0. Then find the second lemma, about (m+1)+n, yourself.

Solution. All inductions are by Theorem 1.1.2 (b).

Lemma 1: 0+n=n for every n. Induct on n. Base: 0+0=0, by the first equation. Step: if 0+n=n, then 0+(n+1)=(0+n)+1=n+1, by the second equation and the hypothesis.

Lemma 2: (m+1)+n=(m+n)+1 for all m,n. Fix m and induct on n. Base: (m+1)+0=m+1=(m+0)+1, by the first equation twice. Step: if (m+1)+n=(m+n)+1, then (m+1)+(n+1)=((m+1)+n)+1=((m+n)+1)+1=(m+(n+1))+1, by the second equation, the hypothesis, and the second equation read from right to left inside the outer +1.

Main induction. Fix m and induct on n for “m+n=n+m”. Base: m+0=m=0+m, by the first equation and Lemma 1. Step: if m+n=n+m, then m+(n+1)=(m+n)+1=(n+m)+1=(n+1)+m, by the second equation, the hypothesis, and Lemma 2 (with n in the role of m and m in the role of n), read from right to left. Hence m+n=n+m for all m,n∈N.

Marking scheme. (10 points) - 2: proves 0+n=n by induction on n, from the first equation (base) and the second (step). - 3: proves, by an induction with the other variable fixed, a lemma that moves a successor out of the first argument (the book’s (m+1)+n=(m+n)+1, or 1+n=n+1 together with associativity of addition), base and step both justified. - 2: in the main induction, the base case m+0=0+m, using the first lemma. - 2: in the main induction, the step, using the second equation, the hypothesis and that lemma. - 1: names the variable inducted on in each induction and fixes the other. Fatal errors (0 for the step): citing commutativity, or any law of Theorem 1.2.3, without proving it from the two equations; treating 0+n=n as if it were a defining equation. A second route inducts on m in the main induction with n fixed; it needs the same two lemmas, and its base and step map to the same 2 + 2 points. A third route proves associativity and 1+n=n+1 (each by induction on n, from the equations and 0+n=n) and then closes the step as m+(n+1)=(m+n)+1=(n+m)+1=n+(m+1)=n+(1+m)=(n+1)+m; those two lemmas together earn the 3 points.

Exercise (C2: Associativity of multiplication, last half blank)

Prove that (km)n=k(mn) for all k,m,n∈N. The first half is given; name the move, then complete it.

Fix k,m∈N and induct on n. Base case: (km)⋅0=0=k⋅0=k(m⋅0). Inductive step: ―

You may use (a)–(f) of Theorem 1.2.3. If you read the fold after its proof, the last row of the table compresses this step into one line; write it out without looking, and give the reason for each equality.

Solution. The move is fix the others, induct on the recursion variable: in (km)n and k(mn) the variable n is the second argument of the outer and the inner product, where the recursion runs, so k and m are fixed.

Inductive step. Suppose (km)n=k(mn). Then (km)(n+1)=(km)n+km=k(mn)+km=k(mn+m)=k(m(n+1)), where the first equality is the defining equation of Definition 1.2.1 (b) with first factor km, the second is the induction hypothesis, the third is (d) of Theorem 1.2.3 read from right to left (k(x+y)=kx+ky with x=mn, y=m), and the fourth is the defining equation with first factor m. By Theorem 1.1.2 (b), (km)n=k(mn) for every n, and k,m were arbitrary.

The base case used the defining equation x⋅0=0 three times, with x=km, x=k and x=m. Commutativity (f) is not needed for this route; a proof that first rewrites km as mk would need it.

Exercise (C3: Doubling)

Show that there is exactly one function D:N→N with D(0)=0 and D(n+1)=(D(n)+1)+1 for every n∈N, and prove that D(n)=n+n for every n∈N.

Solution. Existence and uniqueness. The function g:N×N→N, g(n,x):=S(S(x))=(x+1)+1, maps into N since S maps N into N. By Theorem 1.2.1 with X=N and a=0, there is exactly one D:N→N with D(0)=0 and D(n+1)=g(n,D(n))=(D(n)+1)+1. (Its graph is the set R of the proof for these data, which contains (1,2) and (2,4) by the first Quick check after Theorem 1.2.1; so D(1)=2 and D(2)=4.)

The formula. Induct on n by Theorem 1.1.2 (b) for “D(n)=n+n”. Base: D(0)=0=0+0, by the defining equation m+0=m. Step: suppose D(n)=n+n. Then (n+1)+(n+1)=((n+1)+n)+1=((n+n)+1)+1=(D(n)+1)+1=D(n+1), where the first equality is the defining equation of Definition 1.2.1 (a), the second is (a) of Theorem 1.2.3, (m+1)+n=(m+n)+1 with m=n, the third is the hypothesis, and the last is the equation of D. Hence D(n)=n+n for every n∈N.

Alternatively, n↦n+n satisfies the two equations that define D (the computation above, read without the hypothesis, shows (n+1)+(n+1)=((n+n)+1)+1), so it is D by the uniqueness half of Theorem 1.2.1. Either way the double n+n is 2n too: 2n=n⋅2=n⋅1+n=n+n by (f), the defining equation of ⋅, and (e) of Theorem 1.2.3.
