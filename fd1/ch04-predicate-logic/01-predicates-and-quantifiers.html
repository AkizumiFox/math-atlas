4.1  Predicates and Quantifiers

Chapters 1–3 built a complete account of the connectives: rules for using and proving “and”, “or”, “implies”, and “not”, a meaning for every formula through truth tables, and the theorems that the rules prove exactly what the tables say. In all of that, an atomic statement was a closed box. The statements of analysis are not boxes. “For every ε>0 there is an N such that …” has its whole content inside, in the words “for every” and “there is” and in the letters they govern. This section opens the box. It introduces predicates, variables, the domain a statement talks about, and the two quantifiers ∀ and ∃, and it teaches how to read a quantified sentence. It proves no theorem and states no rule: the four quantifier rules come one per section, in Sections 4.3 to 4.6.

4.1.1. An argument the truth table rejects

Here is an argument that nobody would doubt.

Every positive real number has a square root. The number 2 is positive. Therefore 2 has a square root.

It is correct in the plainest sense: if the two premises are true, the conclusion must be. Now try to check it with the tools of Chapters 1–3. The three sentences contain no connective at all, so each is atomic. Give them atoms:

  • p: “every positive real number has a square root”;
  • q: “2 is positive”;
  • r: “2 has a square root”.

The argument has the form p,q∴r. Three different atoms, and nothing connects them. The valuation that makes p and q true and r false makes both premises true and the conclusion false. So by Corollary 3.5.3, p, q⊬r. No derivation, with any rule of Chapters 1 and 2, leads from p and q to r.

There is no contradiction here, and it is worth seeing exactly why. Corollary 3.5.3 is about the form p,q∴r: it says that no derivation leads from two arbitrary statements to a third, unrelated one. That is true. Our argument is correct for a reason that the form cannot see. The first premise speaks about every positive real number. The second says that 2 is one of the things the first premise speaks about. The conclusion says of 2 what the first premise said of all of them. The three statements share parts: a property (“is positive”), another property (“has a square root”), an object (2), and the word “every”. Chopped into atoms, the shared parts disappear.

This is the warning of Section 3.3 come true: a truth table sees only the connectives, and everything inside an atom is invisible to it. Section 3.3 ended that warning with the remark that this chapter looks inside atoms. We now do. The first job is a vocabulary for the parts inside: the properties, the objects, and the words “every” and “some”. Section 4.3 then gives the rule that makes the argument above a derivation, four lines long.

4.1.2. Predicates: statements with holes

Chapter 1 met the sentence “x>2” and called it an open sentence (item (e) of Example (Statements and nonstatements)). It is not a statement, because its truth depends on what x is: it is true when x is 3 and false when x is 0. Put a number in for x and it becomes a statement.

The argument of the last subsection is built from two open sentences of this kind: “x is positive” and “x has a square root”. Each has one hole, marked by x. The premise “2 is positive” is the first open sentence with 2 put into the hole; the conclusion is the second, with 2 put into its hole. The first premise does something else with the holes, which we come to in the next subsection. Open sentences are the missing parts, and they deserve a name.

A predicate is a statement with holes in it; filling every hole with a name of an object gives a statement.

A predicate is an open sentence with one or more marked holes. The number of holes is its arity: a predicate with one hole is one-place (or unary), with two holes two-place (binary), and so on. We write a predicate as a capital letter followed by its holes in parentheses: P(x) for “x is positive”, S(x) for “x has a square root”, D(x,y) for “x divides y”. The letters that mark the holes are variables: x,y,z,u, and in analysis also ε,δ,N,n, and for primes and other natural numbers p,q. A constant is a name of one particular object: 0, 1, 2, or a letter a,b,c that has been given a fixed meaning.

In words: a predicate says something about objects without saying which objects. The variables are placeholders, not objects. “x is positive” is about whatever will be put in for x, and until something is, it is neither true nor false.

Many predicates of mathematics are written with a symbol between their two holes rather than a letter in front: x<y, x≤y, x=y, x∣y. These are two-place predicates like any other; only the way of writing them differs. Membership x∈A, for a fixed set A, is a one-place predicate of x: “x is an element of A”. Sets, Relations, and Cardinality, Chapter 1 develops sets and membership properly. Until then a set is understood informally, as a collection of objects (usually numbers), and nothing in this section uses more about a set A than whether a given object is an element of it. For sets A and B, A⊆B means that every element of A is an element of B; so A⊆R says that A is a set of real numbers.

Objects can also be built from other objects: x+1, x2, |x|, 2⋅y. The symbols that build them (+, squaring, |⋅|, ⋅) are function symbols, and an expression such as x2+1 names an object as soon as x does. A function symbol may also be a letter, f(x). Sets, Relations, and Cardinality, Chapter 1 defines functions as sets of pairs; here a function symbol is simply a way of naming one object in terms of others. Section 4.2 makes all of this exact, under the name term. For now, a term is any expression that names an object: a variable, a constant, or a function symbol applied to terms.

Filling holes is the first way to turn a predicate into a statement.

  • P(2): “2 is positive”. A statement, and true.
  • P(−3): “−3 is positive”. A statement, and false.
  • D(3,12): “3 divides 12”. True.
  • D(3,y): “3 divides y”. Still open: one hole is filled and one is not. It is a one-place predicate of y.
  • P(x2+1): “x2+1 is positive”. Still open, in x. (It happens to be true whatever real number x is, but that is a fact about the numbers, and the sentence still has a hole.)

The last two items show that filling holes is not all or nothing. A predicate with some holes filled is a predicate with fewer holes. Only when every hole is filled, or closed in the way described next, do we have a statement.

Remark. A clash of letters to keep apart. In Chapters 1 and 2, capital letters P,Q,R stood for whole statements, and Chapter 3 read them as atoms or as arbitrary formulas. In this chapter P,Q,R are predicate symbols, followed by their holes: P(x), R(x,y). A bare P or Q in this chapter, in a reference back to Chapters 1–3 or in a review exercise, is a statement letter as before. The parentheses tell the two uses apart. The small letters p,q,r were atoms in the argument that opened this section, which was written in the language of Chapter 3, and they are atoms again wherever a later section reads a formula with a truth table (Section 4.11). A formula of this chapter has no atoms (Section 4.2 replaces them by predicates with their holes), so inside one, p and q are variables, used for primes and other natural numbers. A property P(n) of natural numbers, as in the principle of induction (Axiom 3.2.1), was already a one-place predicate in this sense.

4.1.3. Quantifiers and the domain

There is a second way to turn “x is positive” into a statement, and the first premise of our argument uses it. The premise does not put a particular number into the hole of “x has a square root”. It says that the open sentence “if x is positive, then x has a square root” is true whatever real number is put in. The word “every” closes the hole without filling it.

Two questions have to be answered before “whatever is put in” makes sense. What may be put in? And how many of those things must make the sentence true?

The first question is answered by a domain of discourse, or domain: the collection of objects that the variables range over. For the argument above, the domain is the real numbers, R. In number theory it is often Z or N (in this book N={0,1,2,…}, with 0). A domain always has at least one element; Section 4.11 explains why the book insists on this, and how it handles the empty set instead.

The second question is answered by the quantifier.

“For every” promises something of each object in the domain; “there exists” promises it of at least one.

Let φ be an open sentence in which the variable x marks a hole (it may have other holes too). There are two quantifiers.

  • The universal quantifier: ∀xφ, read “for every x, φ”, “for all x, φ”, or “for each x, φ”. It is true when every element of the domain, put in for x, makes φ true.
  • The existential quantifier: ∃xφ, read “there exists an x such that φ”, “there is an x with φ”, or “for some x, φ”. It is true when at least one element of the domain, put in for x, makes φ true.

In words: ∀x and ∃x each close the hole marked x, so they remove x from the list of holes. ∀xφ makes one claim about the whole domain at once: no element is an exception. ∃xφ claims that there is at least one element for which φ holds, and it does not say which, or how many. “At least one” includes the case of exactly one and the case of all of them. The word “some” in mathematics never means “some but not all”.

With these, the first premise of our argument, over the domain R, is ∀x(P(x)→S(x)), “for every x, if x is positive, then x has a square root”. The second premise is P(2) and the conclusion is S(2). Now the shared parts are visible: P occurs in both premises, S in the first premise and the conclusion, and 2 in the second premise and the conclusion. The rule of Section 4.3 uses the first premise with x replaced by 2, giving P(2)→S(2), and →E finishes.

Notice the → inside the quantifier. The premise does not say that every real number is positive and has a square root; it says that every real number which is positive has one. The subsection on bounded quantifiers below explains why a “for every” restricted to part of the domain always comes with an implication.

Remark. “True” in this section, and up to Section 4.11, means what it means in ordinary mathematics: we look at the domain and ask whether every element, or some element, makes the sentence true. Section 4.11 turns this reading into a definition, with models. Until then the reading is used only to understand sentences and to decide whether they are true as statements about numbers. Every claim that a sentence can be derived from others will be proved by writing a derivation, never by this reading.

The same sentence over different domains

A quantified sentence is a claim about its domain, so changing the domain can change its truth value. Two examples show how.

Take ∀x(x≥0), “every x is at least 0”.

  • Over N it is true: every natural number is at least 0.
  • Over Z it is false: the integer −1 is in the domain, and −1≥0 is false.

One element of the domain that makes φ false is enough to make ∀xφ false. Such an element is a counterexample. To show that the sentence is true over N, on the other hand, we had to say something about every natural number at once.

Take ∃x(x2=2), “some x has square 2”.

  • Over R it is true: the real number 2 has square 2. (Its existence is a school fact here; Analysis on the Real Line, Chapter 1 proves it from the axioms of the real numbers.)
  • Over Q it is false: that no rational number has square 2 is exactly Theorem 2.2.1.

One element that makes φ true is enough to make ∃xφ true. Such an element is a witness. To show that the sentence is false over Q, on the other hand, a theorem about every rational number was needed, and Chapter 2 proved it by contradiction.

The two quantifiers are mirror images. For ∀, a single counterexample refutes and a general argument confirms. For ∃, a single witness confirms and a general argument refutes. Section 4.9 makes the mirror exact: “not every x satisfies φ” says the same as “some x fails φ”.

Quick check. Over which of the domains Z>0={1,2,3,…}, Z, R is the sentence ∃x(x+x=x) true? Give a witness where it is true, and a reason where it is false.

Solution. Only x=0 satisfies x+x=x, since subtracting x from both sides gives x=0. So the sentence is true over Z and over R, with the witness 0. It is false over Z>0, which does not contain 0: every n∈Z>0 has n+n>n, since n>0. (Over N={0,1,2,…} it would be true, again with the witness 0.)

Reading a quantified sentence

Quantified sentences are read from the outside in: the first quantifier governs everything after it, and inside it may sit another quantifier, a connective, or a predicate. Reading aloud slowly, one symbol at a time, is the most reliable way to understand one. Here are three, simplest first.

Example (Reading three sentences)

Read each sentence aloud, say what it claims, and decide whether it is true over the domain given.

  • (a) ∀x(x2≥0), over R.
  • (b) ∃x∀y(x≤y), over N.
  • (c) ¬∃p(Prime(p)∧∀q(Prime(q)→q≤p)), over N, where Prime(p) is the one-place predicate “p is prime”.

Solution. (a) “For every x, x2 is at least 0.” The claim is about every real number, and it is true: the square of a real number is never negative (a school fact about signs: x⋅x is a product of two numbers of the same sign, or 0).

(b) “There is an x such that for every y, x≤y.” Unpack from the outside. The outer quantifier ∃x asks for one natural number x. What must be true of it is the inside, ∀y(x≤y): every natural number y is at least x. So the sentence says that N has a least element. It is true, with the witness x=0: every natural number is at least 0.

(c) The outer symbol is ¬, so the sentence denies what follows. What follows is ∃p(…): there is a p that is prime and such that every prime q is at most p. Such a p would be a largest prime. So the sentence says “there is no largest prime”. It is true: this is the ancient theorem that there are infinitely many primes. Nothing in this book depends on that theorem; here it is only something to read.

Notice the shape inside (c): ∀q(Prime(q)→q≤p), “every prime is at most p”, has an implication under the ∀. It speaks about primes only, and the implication is how a “for every” is restricted to them. The next subsection makes this a rule of writing.

The sentence in (b) has two quantifiers, and they come in a definite order: first ∃x, then ∀y. The order matters, and the subsection “The order of quantifiers” below is about it. First, restricted quantifiers.

4.1.4. Bounded quantifiers

Mathematics rarely says “for every real number”. It says “for every ε>0”, “for every x∈A”, “there is an n≥N”. The quantifier ranges over a part of the domain, described by a condition. There is no new quantifier for this; the condition is written into the sentence with a connective. Which connective turns out to matter.

A “for every” restricted to a condition is an implication; a “there exists” restricted to a condition is a conjunction.

Definition 4.1.1 (Bounded Quantifier)

Let A be a set, x a variable, and φ an open sentence. The bounded quantifiers are the abbreviations ∀x∈Aφstands for∀x(x∈A→φ),∃x∈Aφstands for∃x(x∈A∧φ). In the same way, for a term a in which x does not occur, ∀x>aφ stands for ∀x(x>a→φ) and ∃x>aφ for ∃x(x>a∧φ), and likewise with ≥, <, ≤ in place of >.

In words: “for every x in A, φ” means “for every x whatsoever, if x is in A, then φ”. “There is an x in A with φ” means “there is an x that is in A and satisfies φ”. The condition x∈A, or x>a, is the bound. A bounded quantifier is not a new symbol of the language: it is shorthand, and every statement about it is a statement about the formula it stands for.

The display after Axiom 3.2.1, in Section 3.2, used ∀n∈N as an abbreviation of the words “for every natural number n”. It was already this bounded form: ∀n∈N(P(n)→P(n+1)) stands for ∀n(n∈N→(P(n)→P(n+1))).

Why → under ∀, and ∧ under ∃. Try the other choices and see what they say. Take the domain R, the set A={1,2}, and the open sentence x>5.

  • “Every element of A is greater than 5” is false: 1 is not. The correct form ∀x(x∈A→x>5) is false too, with the counterexample x=1, which is in A and not greater than 5. The wrong form ∀x(x∈A∧x>5) says that every real number is in A and greater than 5. It is false as well, but for a reason that has nothing to do with A’s elements: x=0 is not in A. Change A to {6,7} and the correct form becomes true while the wrong one stays false.
  • “Some element of A is greater than 5” is false for A={1,2}. The correct form ∃x(x∈A∧x>5) is false too: no real number is both in A and greater than 5. The wrong form ∃x(x∈A→x>5) is true, with the witness x=0: since 0∉A, the implication “if 0∈A then 0>5” has a false hypothesis and is true (vacuous truth, the phenomenon behind Proposition 2.1.2).

So a ∀ with ∧ inside claims too much: it says the whole domain lies in A. An ∃ with → inside claims too little: anything outside A is a witness. Neither says what was meant.

Warning. An existential quantifier with an implication directly inside, ∃x(α→β), is almost always a mistranslation. Over R, “some element of {1,2} exceeds 5” is false, but ∃x(x∈{1,2}→x>5) is true, because x=0 makes the hypothesis false. When you write ∃ and then →, check whether you meant ∧.

One domain per formula. The logic of this book has a single domain for all the variables of a formula. Mathematics often mixes kinds of objects in one sentence: in “for every ε>0 there is an N∈N such that for every n≥N, …”, the letter ε is a real number, while N and n are natural numbers. The convention is: the domain is the larger kind (here R), and the smaller kind enters as a bound (∃N∈N, ∀n∈N). So the sentence begins ∀ε>0∃N∈N∀n∈N(n≥N→…), and n ranges over real numbers that happen to be required, by the bound, to be natural numbers. A sequence (an) becomes a function symbol a, with a(n), written an, the n-th term. Its values at real numbers that are not natural numbers are never used, because a is only ever applied to variables bounded by n∈N. We state this convention once, here; every translation in this chapter follows it.

The empty set. Bounded quantifiers make sense even when the bound is never satisfied. Let ∅ be the empty set, the set with no elements (Sets, Relations, and Cardinality, Chapter 1 introduces it properly), so that x∈∅ is false for every x.

  • ∀x∈∅φ stands for ∀x(x∈∅→φ). For every x, the hypothesis x∈∅ is false, so the implication is true. The sentence is true, whatever φ says. For example, “every element of ∅ is greater than 5” and “every element of ∅ is less than 5” are both true.
  • ∃x∈∅φ stands for ∃x(x∈∅∧φ). No x makes the first conjunct true, so the sentence is false, whatever φ says.

Section 2.1 met this phenomenon for implications: a statement whose hypothesis never holds is true, and says nothing. A universal statement about the elements of an empty set is true for the same reason, because there is nothing to test. This is the reading; Section 4.4 derives the universal half with the rules.

Warning. “Every element of A has property φ” does not imply “some element of A has property φ”. It fails when A is empty: “every element of ∅ is greater than 5” is true, and “some element of ∅ is greater than 5” is false. The step from “every” to “some” needs an element, and the bound can remove all of them.

4.1.5. The order of quantifiers

A sentence with two quantifiers of different kinds can change its meaning completely when they are swapped. This is the single most important fact about reading quantifiers, and the definitions of analysis depend on it.

Example (Swapping two quantifiers)

Over the domain R, compare (i)  ∀x∃y(x+y=0)and(ii)  ∃y∀x(x+y=0). Read each aloud, and decide which is true.

Solution. (i) “For every x there is a y with x+y=0”: every real number has an additive inverse. It is true. Given any real x, the number y=−x satisfies x+y=x+(−x)=0.

(ii) “There is a y such that for every x, x+y=0”: one single number y is an inverse of every real number at once. It is false. Whatever real number y is proposed, take x=1−y; then x+y=1≠0. So no y works.

The two sentences have the same letters, the same quantifiers and the same equation. Only the order differs. In (i), the y may be chosen after x is known, so it may depend on x: the witness −x is a different number for each x. In (ii), y must be chosen first, once and for all, and then it must work for every x that comes after.

What makes the pair work as an example? Two properties, and any other pair with the same shape would do as well. First, for each x separately there is a suitable y. Second, no one y is suitable for all x together, because each y serves only one x (here, only x=−y).

Quantifiers as a game. The difference in Example (Swapping two quantifiers) can be felt by reading a sentence as a game between two players. The reading applies to a sentence whose quantifiers all stand at the front, unnegated, followed by an inside with no quantifiers, as in (i) and (ii); a bounded quantifier such as ∀ε>0 counts, its bound being checked with the inside. The challenger chooses a value for each ∀ variable and tries to make the sentence false. The defender chooses a value for each ∃ variable and tries to make it true. They move in the order in which the quantifiers are written, left to right, and each player sees every move made so far. When all variables have values, the inside is checked. The sentence is true exactly when the defender has a way of playing that wins against every choice of the challenger. A quantifier under a ¬, or in the hypothesis of an implication, changes sides: ¬∀xφ is played as ∃x¬φ, with the defender moving. Section 4.9 proves the laws that push a ¬ inward in this way.

  • In (i), the challenger moves first and picks some x. The defender sees x and answers y=−x. The defender always wins.
  • In (ii), the defender moves first and must commit to some y without knowing x. The challenger sees y and answers x=1−y. The challenger always wins.

Read the dependency off the order: a variable may depend on the variables quantified to its left, and only on them. In (i), y is to the right of x, so the choice of y may use x. In (ii), y is to the left, so it may not. Sections 4.4 to 4.6 will show this same dependence as a fact about the boxes of a derivation, and Section 4.10 shows that it is the whole difference between continuity and uniform continuity.

When swapping is harmless. Two quantifiers of the same kind may be swapped. ∀x∀yφ and ∀y∀xφ both say that φ holds for every choice of the pair; in the game, the challenger makes both moves, and the order of the challenger’s own moves gives nothing away. Likewise ∃x∃yφ and ∃y∃xφ both say that some pair works. Section 4.4 derives the first swap with the rules. For quantifiers of different kinds, one direction is always safe: if one y works for every x, then for every x some y works (the same one). Section 4.6 derives this, ∃y∀xφ to ∀x∃yφ, and Example (Swapping two quantifiers) shows that the other direction fails.

Quick check. Over the domain N, swap the two quantifiers in “for every n there is a prime larger than n”, that is, in ∀n∃p(Prime(p)∧p>n). Read the result aloud. Is it true?

Solution. The swapped sentence is ∃p∀n(Prime(p)∧p>n): “there is a prime that is larger than every natural number”. It is false. Whatever p is proposed, take n=p: then p>n is false, so the inside fails. (The original sentence is true; it is another form of the theorem that there are infinitely many primes, which we do not use.) As in Example (Swapping two quantifiers), the original lets the prime depend on n, and the swapped sentence demands one prime for all n at once.

4.1.6. Words that hide quantifiers

English marks quantifiers loosely, and mathematical English has habits that hide them altogether. Three traps are worth naming now, before they cause trouble in a translation.

Warning. The word “any” can mean “every” or “some”, and only the sentence around it decides. “Any x in A is positive” means every element of A is positive: ∀x∈A(x>0). “If any x in A is positive, then A is nonempty” means if some element is positive: ∃x∈A(x>0)→…. When you meet “any”, rewrite the sentence with “every” and with “some”, and keep the one that says what was meant.

Hidden universal quantifiers. A theorem stated as “if n is even, then n2 is even” has no quantifier word in it, and yet it is not about one number. It means: for every integer n, if n is even, then n2 is even. A letter that is not introduced anywhere, in the statement of a theorem, is read with a “for every” in front. Chapter 5 names this convention and lists the others that written mathematics relies on. When translating, put the hidden quantifier back first.

An implication inside ∃. This is the warning after Definition 4.1.1, and it deserves repeating because it comes up in translations of analysis: “there is an N such that, if n≥N, then …” is not the shape of the sentence displayed under One domain per formula above, where the implication n≥N→… sits under ∀n∈N. The implication belongs under a ∀: “there is an N such that for every n, if n≥N, then …”.

4.1.7. What comes next

We can now read quantified sentences and decide, as mathematicians, whether they are true. We cannot yet reason with them in the sense of Chapters 1 and 2: there is no rule for using a “for every”, for proving one, for proving a “there exists”, or for using one. Section 4.2 first makes the language exact, because the rules will need to say precisely what “put 2 in for x” means. Sections 4.3 to 4.6 then give the four rules, one per section, in the same way as Chapters 1 and 2 gave the rules for the connectives.

4.1.8. Exercises

A. Check your understanding

Exercise (A1)
  • (a) Read each sentence aloud, and say over which of the domains N, Z, R it is true: (i) ∀x(x+1>x); (ii) ∃x(x+1=0); (iii) ∀x∃y(y<x); (iv) ∃x(2⋅x=1); (v) ∀x(x⋅x≥x).
  • (b) With domain R, which of the following translates “some element of A is negative”? (i) ∃x(x∈A→x<0); (ii) ∃x(x∈A∧x<0); (iii) ∀x(x∈A∧x<0). For each of the two others, say what it claims instead.
  • (c) What is the arity of the predicate “x+y=z”, and how many holes does “3+y=z” have left?
  • (d) True or false, with a reason: ∀x∈∅(x≠x) is true.

Solution. (a) (i) “For every x, x+1 is greater than x.” True over all three domains: adding 1 always gives a larger number.

  • (ii) “There is an x with x+1=0.” The only solution is x=−1. False over N, which does not contain −1; true over Z and R, with the witness −1.

  • (iii) “For every x there is a y smaller than x.” False over N: for x=0 there is no natural number y<0. True over Z and R: given x, take y=x−1.

  • (iv) “There is an x with 2x=1.” The only solution is x=12. False over N and Z, true over R with the witness 12.

  • (v) “For every x, x⋅x is at least x.” True over N: if x=0, then x⋅x=0=x; if x≥1, then x⋅x≥1⋅x=x. True over Z: an integer is either at least 1, as before, or at most 0, and then x⋅x≥0≥x. False over R: the counterexample x=12 has x⋅x=14<12.

(b) (ii) is the translation (Definition 4.1.1: ∧ under ∃). (i) is true as soon as some real number lies outside A, since that number makes the implication vacuously true; so it can be true when no element of A is negative (for A={1}, say). (iii) claims that every real number is in A and negative, which is false whatever A is (take x=0).

(c) It has three holes, x, y, z, so it is three-place. Filling x with 3 leaves two holes, y and z.

(d) True. It stands for ∀x(x∈∅→x≠x). For every x the hypothesis x∈∅ is false, so the implication is true, even though its conclusion x≠x is false for every x.

B. Practice

Exercise (B1: Ordered quantifiers)

Determine which of the following sentences are true over the domain given. Justify your answer: give the witness a true ∃ asks for (as a function of the earlier variables, if there are any), or the counterexample that refutes a ∀.

  • (a) ∀x∃y(x<y), over N.
  • (b) ∀x∃y(x+y=1), over N.
  • (c) ∃x∀y(x⋅y=y), over R.
  • (d) ∀x∃y(y⋅y=x), over R.

Solution. (a) True. Given any natural number x, the natural number y=x+1 satisfies x<y. The witness depends on x, which the order ∀x∃y allows.

(b) False. The challenger chooses x=2. Then x+y=1 forces y=−1, which is not a natural number; every natural y gives 2+y≥2. So for x=2 no y works. (For x=0 and x=1 the witnesses y=1 and y=0 do exist, so the challenger must choose with care.) (Over Z the sentence would be true, with y=1−x.)

(c) True, with the witness x=1: for every real y, 1⋅y=y. The witness is chosen first and does not depend on y, as the order ∃x∀y demands.

(d) False, with the counterexample x=−1: for every real y, y⋅y≥0>−1, so no y has y⋅y=−1.

Exercise (B2: Order matters)

Give an example of a two-place predicate R(x,y) on the domain N such that ∀x∃yR(x,y) is true and ∃y∀xR(x,y) is false. Check both claims.

Solution. Take R(x,y): “y>x”.

∀x∃y(y>x) is true. Given any natural number x, the natural number y=x+1 satisfies y>x.

∃y∀x(y>x) is false. Whatever natural number y is proposed, take x=y: then y>x is false. So no y is greater than every x.

Any answer must have two properties, and a different answer can be checked against them.

  1. Every x has a partner: for each x∈N there is at least one y with R(x,y).
  2. No y is a partner of every x: for each y∈N there is at least one x with R(x,y) false.

For example, “y≠x” also works: each x has the partner x+1, and each y fails to be a partner of x=y. So does “y≥x”: each x is its own partner, and each y fails to be a partner of x=y+1. A predicate that does not work is “y≥1”: property 1 holds, but property 2 fails, because y=1 is a partner of every x, so ∃y∀x(y≥1) is true.

C. Going deeper

Exercise (C1: A least element)

Decide whether ∃x∀y(x≤y) is true over each of the domains N, Z, [0,1] and (0,1]. Give the witness where it is true, and where it is false show that every proposed x is defeated by some y.

Solution. The sentence says that the domain has a least element: one x that is at most every element y.

Over N: true, with the witness x=0. Every natural number y satisfies 0≤y.

Over Z: false. Let x be any integer. The integer y=x−1 satisfies y<x, so x≤y fails. No integer is least.

Over [0,1]: true, with the witness x=0. Every y∈[0,1] satisfies 0≤y, by the definition of the interval.

Over (0,1]: false. Let x∈(0,1], so 0<x≤1. The number y=x2 satisfies 0<x2<x≤1, so y∈(0,1] and y<x; hence x≤y fails. The defeating y depends on the proposed x, which is allowed, because in the game the challenger chooses y after seeing x.

The last two domains differ by a single point, 0, and that point is exactly the least element of [0,1]. Removing it leaves a set with no least element, although every element of (0,1] is still at least 0. Analysis on the Real Line, Chapter 1 returns to this distinction between a least element and a greatest lower bound.

Exercise (C2: The wrong connective)

Take the domain R.

  • (a) The sentence “every element of A is positive” is mistranslated as ∀x(x∈A∧x>0), and “some element of A is positive” as ∃x(x∈A→x>0). For each mistranslation, give a set A⊆R for which it has a different truth value from the English sentence.
  • (b) Show that the first mistranslation is false for every set A⊆R, and the second is true for every set A⊆R. What does this say about how much each one tells us about A?

Solution. (a) Take A={1} for the first. “Every element of {1} is positive” is true. The mistranslation claims that every real x is in {1} and positive; x=0 is neither, so it is false.

Take A={−1} for the second. “Some element of {−1} is positive” is false, since its only element is negative. The mistranslation is true, with the witness x=0: since 0∉{−1}, the implication “if 0∈A, then 0>0” has a false hypothesis and is true.

(b) For the first, let A⊆R be any set. The real number x=0 does not satisfy x>0, so it does not satisfy x∈A∧x>0, whatever A is. It is a counterexample to the ∀, so the sentence is false.

For the second, let A⊆R be any set, and consider the real number x=1. The conclusion 1>0 is true, so the implication 1∈A→1>0 is true whether or not 1∈A. Hence x=1 is a witness, whatever A is, and the sentence is true.

So neither mistranslation tells us anything about A at all: the first is false and the second is true, whichever set A is. A sentence whose truth value does not depend on A cannot express a property of A. This is the precise sense in which the wrong connective “claims too much” under ∀ and “too little” under ∃.

Marking scheme. (10 points) - 2: a set for the first mistranslation, with both truth values checked. - 2: a set for the second mistranslation, with both truth values checked, and the implication at the witness justified (its hypothesis is false, or its conclusion is true). - 3: for the first, for an arbitrary A, a real number (the same for every A, or chosen by cases covering every A) that fails x∈A∧x>0, with the check. - 3: for the second, for an arbitrary A, a witness (the same for every A, or chosen by cases covering every A) at which x∈A→x>0 holds, with a reason that covers every A (its conclusion is true, or a check in every case). Fatal errors (0 for the step): a witness or counterexample that depends on A in (b) without a case split covering every A; reading ∃x(x∈A→x>0) as “some element of A is positive”.
