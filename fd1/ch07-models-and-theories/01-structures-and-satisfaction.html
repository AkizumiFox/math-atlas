7.1  Structures and Satisfaction

Sections 5.3 to 6.4 derived a good deal, and some searches stalled. The converse of Proposition 5.6.2 could not be finished: every attempt ran into a side condition. The converse of Proposition 5.6.1 stalled in the same way, and so did the search for ∃xP(x)⊢P(c) in Exercise (C2: A witness is not a name). But a search that fails proves nothing, since a cleverer derivation might exist. Chapter 4 met the same problem for the connectives and solved it with meaning: a row of a truth table that makes the premises true and the conclusion false rules out every derivation at once (Corollary 4.6.3). This section builds the meaning of a quantified formula. A row of T and F is replaced by a model: a domain of objects, with a meaning for every symbol. A model that makes the premises true and the conclusion false is a counter-model, and Section 7.2 uses it to settle the stalled searches.

7.1.1. Why a row is not enough

Chapter 4’s semantics gave each atom a truth value and computed the rest. Try it on the stalled sequent of Proposition 5.6.2’s converse, ∀y∃xR(x,y)⊢∃x∀yR(x,y). Neither side has a main connective among ¬,∧,∨,→,↔: each is a quantified formula, and a truth table would have to treat each as one atom. The sequent would become p⊢q, refuted by the row p=T, q=F. That “refutation” is worthless. The same reading refutes ∀xP(x)⊢∃xP(x), which is derivable (Proposition 5.5.1). Treating a quantified formula as an atom throws away exactly the structure that the quantifier rules use.

So what does make ∀y∃xR(x,y) true or false? Section 5.1 read such sentences informally, over a domain: “for every y in the domain there is an x in the domain with R(x,y)”. To decide it we need three things.

  • A domain: the objects the variables range over. Over Z the sentence may be true and over a three-element set false.
  • A meaning for each symbol. R is a predicate symbol, a name with two slots and no meaning of its own (Section 5.2). Read as > on Z, the sentence says “every integer has an integer above it”, which is true; read as < on N, it says “every natural number has a natural number below it”, which is false at y=0.
  • Values for the free variables, if there are any. The formula ∃y(y<x) is neither true nor false on N until we know which number x is.

The first two together are a structure; the third is an assignment. A structure with an assignment decides every formula, by clauses that read the quantifiers as Section 5.1 read them. That is all this section does; Section 7.2 uses the result.

7.1.2. Structures

Situate the notion first. A formula is built from symbols: constants such as c and 0, function symbols such as f and +, predicate symbols such as P, R and <, each function and predicate symbol with its number of argument places, its arity (Section 5.2, Definition 5.2.1 and Definition 5.2.2). The symbol = is special: it is part of the logic, with rules of its own (Definition 5.7.1), and it will always mean the same thing. A structure gives every other symbol a meaning.

A structure is a non-empty set of objects together with a meaning for each symbol: an object for each constant, an operation for each function symbol, and a relation for each predicate symbol.

Definition 7.1.1 (Structure)

Fix a collection of constants, function symbols and predicate symbols, each function and predicate symbol with its arity n≥1. A structure M (also called a model) for these symbols consists of

  • (M1) a non-empty set D, the domain of M;
  • (M2) for each constant c, an element cM∈D;
  • (M3) for each function symbol f of arity n, a function fM:Dn→D, defined at every n-tuple of elements of D;
  • (M4) for each predicate symbol R of arity n, a set RM of n-tuples of elements of D.

The symbol = is not interpreted by M: in every structure it means identity, “is the same element of D as”.

In words. (M1) says what the variables range over, and insists that there is at least one object. (M2) says which object each name names; two constants may name the same object. (M3) makes each function symbol an operation that can be applied to any objects of the domain and always returns an object of the domain. (M4) makes each predicate symbol a relation: RM is the set of tuples for which R “holds”. A one-place predicate symbol P becomes a subset PM⊆D, a two-place one a set of ordered pairs, and so on. Here Dn is the set of n-tuples (d1,…,dn) of elements of D; Sets, Relations, and Cardinality, Chapter 1 develops sets, pairs and functions properly, and this section uses only their everyday meaning.

We usually describe a structure in one line, naming the domain and the meaning of each symbol, and write “M=(Z,<)” for the structure with domain Z in which the symbol < means the usual order. When a symbol has its usual meaning on a familiar set, we say so and do not write <M.

Examples, simplest first.

  • One element. D={a}, with PM={a}. This is the degenerate structure. Every variable must take the value a, so “for every element” and “there is an element” both mean “a”. It will reappear as a test case: a sentence true here and false in some other structure cannot be derivable (by the soundness statement in Section 7.2), and some of the chapter’s non-derivable sequents need at least two elements to refute.
  • Two elements, one relation. D={a,b}, with RM={(a,a),(b,b)}: the relation “is the same as”, written out as a set of pairs. A finite structure can be given completely by listing.
  • The integers with their order. D=Z, with RM={(x,y)∈Z2:x>y}. Here the relation is described by a condition rather than a list.
  • Arithmetic. D=R, with the constants 0 and 1 naming zero and one, the function symbols +, ⋅ and two-place − meaning addition, multiplication and subtraction, the one-place symbols −, (⋅)2 and |⋅| meaning negation, squaring and absolute value, and <, ≤, >, ≥ the usual order. Extended by the other familiar symbols with their usual meanings (numerals, halving, the predicates ∈A, division with its value at a zero denominator fixed arbitrarily as in the non-example below, and a function symbol for each sequence or function an example uses), this is the structure in which the analysis examples of Chapters 5 and 6 have been read all along.

Non-example by minimal change. Take the arithmetic structure and add a one-place function symbol g, meant to be read as x↦1/x. This is not a structure: (M3) asks for a function defined at every element of D, and 1/0 is not defined. Everything else in the description is fine; exactly clause (M3) fails, at the single point 0. There are two repairs. Shrink the domain to (0,∞), where 1/x is always defined; or keep R and give g any value at 0, say gM(0):=0. The second repair is the one this book uses for terms such as 1/n: the value at 0 is fixed arbitrarily and is never looked at, because such terms are used only under a bound n∈Z>0 (as in Exercise (C3: Exit check: formalize, negate, decide)), exactly as a sequence an was read in Section 5.1 as a function symbol whose values off N are never used.

Why this definition. Each clause earns its place.

  • Non-empty. This is a genuine choice, and it is made because of Proposition 5.5.1. A later subsection explains it.
  • Total functions. Clause (M3) is what makes every term name an object: the term g(0) must have a value, or the formula g(0)=g(0), which =I derives from nothing, would have no truth value.
  • Identity for =. The rule =E replaces equals by equals everywhere. If a structure could read = as some other relation, =E would fail. On Z, read x=y as “x and y have the same parity” and P as “is positive”: then −2=2 and P(2) would both hold, while P(−2), which =E derives from them, fails. With = fixed as identity, no such reading exists.

Warning. A structure must interpret every symbol that occurs in the formulas at hand. “Take D=Z” is not yet a structure for ∀y∃xR(x,y): until R is given a meaning, the sentence has no truth value, and the same domain makes it true with R read as > and false with R read as “x⋅x=y” (at y=2). Always write the domain and the meaning of each symbol.

7.1.3. Assignments and the value of a term

A structure names the objects that constants stand for. Variables are different: their whole purpose is to range over the domain, so a structure gives them no fixed value. A separate object records what they stand for at a given moment.

Definition 7.1.2 (Assignment)

Let M be a structure with domain D. An assignment in M is a function ℓ that gives every variable x a value ℓ(x)∈D. For an assignment ℓ, a variable x and an element d∈D, the assignment ℓ[x↦d] is the one that gives x the value d and every other variable the value ℓ gives it: ℓ[x↦d](y):={dif y is the variable x,ℓ(y)if y is any other variable.

In words: an assignment is a choice of value for every variable at once, and ℓ[x↦d] changes that choice at the one variable x, leaving the others alone. The assignment ℓ[x↦d] is what the quantifiers will use: “for every x” will mean “for every d∈D, with x set to d”. Changes can be stacked: ℓ[x↦d][y↦e] first sets x to d and then y to e. When x and y are different variables the order does not matter, since each change touches only its own variable; when they are the same variable, the later change wins.

There are always assignments, because D is non-empty: pick any d0∈D and let every variable have the value d0. Like a valuation in Chapter 4 (Definition 4.4.1), an assignment fixes infinitely many values, and a formula will only ever look at finitely many of them.

With a structure and an assignment, every term names an element of the domain. Terms are built by the clauses of Definition 5.2.1, so the value is defined by recursion on terms, in the pattern of Theorem 4.3.4.

The value of a term is computed from its variables and constants upwards, one function symbol at a time.

For a structure M and an assignment ℓ, the value tM,ℓ∈D of a term t is:

  • xM,ℓ:=ℓ(x) for a variable x;
  • cM,ℓ:=cM for a constant c;
  • f(t1,…,tn)M,ℓ:=fM(t1M,ℓ,…,tnM,ℓ) for a function symbol f of arity n.

The third clause is where (M3) is needed: fM must accept every tuple the terms t1,…,tn might produce.

For example, in the arithmetic structure on R, let ℓ(x)=2 and ℓ(y)=−3. The term x⋅x+y, which is +(⋅(x,x),y) written in the usual way, has value 2⋅2+(−3)=1. Under ℓ[y↦1] it has value 2⋅2+1=5, and under ℓ[x↦0] it has value −3. The term 1+1 has value 2 under every assignment, since it contains no variable.

7.1.4. Satisfaction

Now the central definition. We want to say when a structure and an assignment make a formula true. Formulas are built by the clauses of Definition 5.2.2, so we define it by recursion, one clause per way of building a formula, and each clause reads its connective or quantifier as Chapter 4 and Section 5.1 read it.

A formula is satisfied when the objects its terms name stand in the relations its predicates name, combined by the connectives as in a truth table, with “for every x” and “there is an x” ranging over the domain.

Definition 7.1.3 (Satisfaction)

Let M be a structure with domain D and ℓ an assignment in M. The relation M,ℓ⊨φ, read “M satisfies φ under ℓ”, is defined by recursion on the formula φ:

  • (S1) M,ℓ⊨R(t1,…,tn) if (t1M,ℓ,…,tnM,ℓ)∈RM;
  • (S2) M,ℓ⊨t1=t2 if t1M,ℓ and t2M,ℓ are the same element of D;
  • (S3) M,ℓ⊨⊥ never holds;
  • (S4) M,ℓ⊨¬φ if M,ℓ⊨φ does not hold;
  • (S5) M,ℓ⊨φ∧ψ if both M,ℓ⊨φ and M,ℓ⊨ψ; M,ℓ⊨φ∨ψ if at least one of them holds; M,ℓ⊨φ→ψ unless M,ℓ⊨φ holds and M,ℓ⊨ψ does not; M,ℓ⊨φ↔ψ if both hold or neither does;
  • (S6) M,ℓ⊨∀xφ if M,ℓ[x↦d]⊨φ for every d∈D;
  • (S7) M,ℓ⊨∃xφ if M,ℓ[x↦d]⊨φ for at least one d∈D.

When M,ℓ⊨φ does not hold we write M,ℓ⊭φ. For a list Γ of formulas, M,ℓ⊨Γ means that M,ℓ⊨γ for every formula γ of Γ.

Read it clause by clause. (S1): an atomic formula is satisfied exactly when the values of its terms form a tuple in the relation that interprets its predicate symbol. (S2): an equation is satisfied when both sides name the same object; this is where “= means identity” enters. (S3)–(S5) are the ⊥ half of (V1) and clauses (V2)–(V6) of Chapter 4’s Definition 4.4.2, with “is true under v” replaced by “is satisfied by M under ℓ”: ⊥ is never satisfied, ¬ flips, ∧ needs both, ∨ needs one, → fails only with a satisfied hypothesis and an unsatisfied conclusion, ↔ needs agreement. (S6) and (S7) are the new clauses. To decide ∀xφ, we run through the elements d of the domain, set x to d and leave every other variable alone, and ask whether φ is satisfied each time. For ∃xφ one success is enough. In symbols, for (S6) and (S7): M,ℓ⊨∀xφifffor every d∈D,  M,ℓ[x↦d]⊨φ,M,ℓ⊨∃xφiffthere is d∈D with M,ℓ[x↦d]⊨φ.

Well defined. The clauses define, for each formula, which pairs (M,ℓ) satisfy it, by recursion on the formula: (S1)–(S3) settle the atomic formulas and ⊥, and each of (S4)–(S7) settles a compound formula from its immediate parts. One point needs a word. Clauses (S6) and (S7) consult the immediate part φ under other assignments ℓ[x↦d], not under ℓ. So the recursion must define satisfaction of each formula under all assignments at once, and then (S6) reads off the answer for φ at every ℓ[x↦d]. The recursion is still on the formula alone, and Theorem 4.3.4, applied to formulas built by the clauses of Definition 5.2.2, gives exactly one such relation.

A trace, step by step. Decide ∀x∃y(x<y) in two structures, both with < the usual order: M1 with domain N, and M2 with domain {1,2,3}. Let ℓ be any assignment.

In M1: by (S6) we must check, for every d∈N, that M1,ℓ[x↦d]⊨∃y(x<y). Fix d. By (S7) it is enough to find one e∈N with M1,ℓ[x↦d][y↦e]⊨x<y. Take e=d+1. Under ℓ[x↦d][y↦d+1] the terms x and y have the values d and d+1, and d<d+1, so (S1) holds. Hence the sentence is satisfied. Notice that the witness e=d+1 depends on d: (S7) is checked inside (S6), once for each d.

In M2: (S6) asks the same for d=1,2,3. At d=1 and d=2 the witnesses e=2 and e=3 work. At d=3 no e∈{1,2,3} has 3<e, so (S7) fails for ℓ[x↦3], and (S6) fails. So M2⊭∀x∃y(x<y), and the failure has a name: the element 3 has nothing above it.

The assignment matters for free variables. In M1=(N,<), with ≤ also read as usual, take the formula ∀y(x≤y), in which x is free. Under an assignment with ℓ(x)=0 it is satisfied, since every e∈N has 0≤e (recall that N={0,1,2,…}). Under an assignment with ℓ(x)=1 it is not: e=0 gives 1≤0, which fails. The same formula in the same structure is satisfied under one assignment and not under another; it is a property of x, “x is least”, not a statement.

Degenerate cases. In the one-element structure D={a}, every assignment gives every variable the value a, so ℓ[x↦a]=ℓ and (S6) and (S7) both reduce to “M,ℓ⊨φ”. So ∀xφ and ∃xφ are satisfied together or not at all, and every equation x=y is satisfied. In any structure, ∀x(x=x) is satisfied, since every d is the same element as itself; and ∃x¬(x=x) never is.

Quick check. Is ∀x∃y(y⋅y=x) satisfied in R, in [0,∞), and in C, each with ⋅ the usual product?

Solution. In R, no: at d=−1, (S7) asks for a real e with e⋅e=−1, and every real square is ≥0. In [0,∞), yes: for each d≥0, e=d is in the domain and e⋅e=d; and [0,∞) with ⋅ is a structure, since a product of non-negative reals is non-negative (M3). In C, yes: every complex number has a complex square root (school algebra of complex numbers: r(cos⁡θ+isin⁡θ) with r≥0 has the square root r(cos⁡θ2+isin⁡θ2)). The sentence is the same all three times; only the structure changes.

7.1.5. Only the free variables matter

The example of ∀y(x≤y) above showed ℓ mattering. In the first example it did not: the verdict on ∀x∃y(x<y) was reached for “any assignment ℓ”. That is no accident. A sentence has no free variables (Definition 5.2.4), and every variable it contains is bound, so every value ℓ gives is overwritten by (S6) or (S7) before it is looked at. We prove the general fact, which is the first-order version of Chapter 4’s Lemma 4.4.1: satisfaction depends only on the values of the free variables.

Say that two assignments ℓ and ℓ′ agree on a set of variables if ℓ(y)=ℓ′(y) for every variable y in it. We need the free variables of a formula, recursively defined in Definition 5.2.3: every variable occurring in an atomic formula is free there; ¬φ has the free variables of φ; φ∘ψ, for a binary connective ∘, has those of φ and those of ψ; and ∀xφ and ∃xφ have those of φ other than x.

Lemma 7.1.1 (Free Variables Coincidence Lemma)

Let M be a structure and φ a formula, and let ℓ and ℓ′ be assignments in M that agree on every free variable of φ. Then M,ℓ⊨φif and only ifM,ℓ′⊨φ.

Idea. Structural induction on φ, as for Lemma 4.4.1, after a first induction on terms: a term’s value depends only on the values of its variables. The connective cases are Chapter 4’s. The quantifier case is the only new one, and it explains why the property must be stated for all pairs of assignments: (S6) compares ℓ[x↦d] with ℓ′[x↦d], which are new assignments, so the induction hypothesis must apply to them. They agree at x, since both give it d, and at every other free variable of φ, since those are free in ∀xφ.

Proof. Terms first. We show: if ℓ and ℓ′ agree on every variable occurring in a term t, then tM,ℓ=tM,ℓ′. We use structural induction on terms (Definition 5.2.1; the pattern of Theorem 4.3.1). For a variable x, the variable x occurs in x, so xM,ℓ=ℓ(x)=ℓ′(x)=xM,ℓ′. For a constant c, both values are cM. For f(t1,…,tn), every variable of ti occurs in f(t1,…,tn), so the hypothesis for ti gives tiM,ℓ=tiM,ℓ′ for each i; applying fM to equal tuples gives equal values.

Formulas. We apply structural induction to the property C(φ): for all assignments ℓ, ℓ′ in M that agree on the free variables of φ, M,ℓ⊨φ if and only if M,ℓ′⊨φ.

Atomic formulas. Let φ be R(t1,…,tn), and let ℓ, ℓ′ agree on its free variables. Every variable occurring in φ is free in it (Definition 5.2.3), so ℓ and ℓ′ agree on the variables of each ti, and by the claim for terms tiM,ℓ=tiM,ℓ′. The two tuples in (S1) are equal, so one lies in RM exactly when the other does. The case t1=t2 is the same with (S2). For ⊥, neither side holds, by (S3).

Connectives. Assume C(φ) and C(ψ), and let ℓ, ℓ′ agree on the free variables of φ∧ψ. These include the free variables of φ and those of ψ, so M,ℓ⊨φ if and only if M,ℓ′⊨φ, and likewise for ψ. By (S5), satisfaction of φ∧ψ is decided by these two answers through the same rule for ℓ and for ℓ′, so C(φ∧ψ) holds. The cases ¬φ, φ∨ψ, φ→ψ, and φ↔ψ are the same argument with (S4) and the other parts of (S5), as in the proof of Lemma 4.4.1.

Universal quantifier. Assume C(φ), let x be a variable, and let ℓ, ℓ′ agree on the free variables of ∀xφ. Let d∈D. We claim that ℓ[x↦d] and ℓ′[x↦d] agree on the free variables of φ. At x, both give d. A free variable y of φ other than x is a free variable of ∀xφ (Definition 5.2.3), so ℓ[x↦d](y)=ℓ(y)=ℓ′(y)=ℓ′[x↦d](y). By C(φ), applied to these two assignments, M,ℓ[x↦d]⊨φiffM,ℓ′[x↦d]⊨φ. This holds for every d∈D, so by (S6) M,ℓ⊨∀xφ if and only if M,ℓ′⊨∀xφ. This proves C(∀xφ).

Existential quantifier. The same argument, with (S7) in place of (S6): the displayed equivalence holds for each d, so there is a d making the left side hold exactly when there is one making the right side hold.

Every clause of Definition 5.2.2 has been covered, so C(φ) holds for every formula φ. This proves the lemma.

The lemma has a consequence that the rest of the section uses constantly.

Sentences. If φ is a sentence, it has no free variables, so any two assignments agree on its free variables, and the lemma says that M,ℓ⊨φ either holds for every assignment ℓ or for none. We then write M⊨φ, and say that φ is true in M (or that M is a model of φ), in the first case, and M⊭φ, φ is false in M, in the second. At least one assignment exists because D is non-empty, so a sentence is always exactly one of true and false in M. This is the precise form of Section 5.1’s informal “true over a domain”.

Only finitely many values matter. A formula has finitely many free variables. To decide M,ℓ⊨φ, it is enough to know ℓ on those. So we describe an assignment by the values that matter (“ℓ(x)=2”), exactly as Chapter 4 described a valuation by the values of a few atoms.

Warning. The same sentence can be true in one structure and false in another, and “true” without a structure means nothing. ∀x∃y(x<y) is true in (N,<) and false in ({1,2,3},<), as traced above. A sentence of predicate logic is like a formula of Chapter 4 with atoms: it has a truth value only once the meaning of its symbols has been fixed.

7.1.6. Semantic entailment

Chapter 4 said that Γ entails ψ when every row that makes Γ true makes ψ true (Definition 4.5.3). The row is now a structure with an assignment.

An argument is valid when every structure, under every assignment, that satisfies all the premises also satisfies the conclusion.

Definition 7.1.4 (Semantic Entailment in Predicate Logic)

Let Γ be a list of formulas and φ a formula. We say Γ semantically entails φ, and write Γ⊨φ, if for every structure M for the symbols occurring in Γ and φ, and every assignment ℓ in M, M,ℓ⊨Γ⇒M,ℓ⊨φ. We write ⊨φ when Γ is empty. If Γ⊨φ fails, we write Γ⊭φ; a structure M with an assignment ℓ such that M,ℓ⊨Γ and M,ℓ⊭φ is a counter-model to Γ⊨φ.

In words: “every structure” means every domain and every meaning of the symbols, so an entailment holds for reasons of form and not because of what R happens to mean. “Every assignment” covers every value of the free variables; when Γ and φ are sentences, the assignment makes no difference, by Lemma 7.1.1. And a counter-model is the analogue of Chapter 4’s refuting row: one structure, with one assignment, where the premises hold and the conclusion does not. The symbol ⊨ is the one of Chapter 4, and the context always shows which is meant: a sequent of formulas with quantifiers or predicate symbols is read with this definition.

A structure may interpret symbols that do not occur in Γ or φ. The clauses of Definition 7.1.3 consult only the symbols of the formula at hand, so such extra meanings change nothing.

First examples of entailment. The argument Section 5.1 opened with, “every positive real has a square root; 2 is positive; so 2 has a square root”, is ∀x(P(x)→Q(x)), P(c)⊢Q(c), derived in Section 5.3. Truth tables called it invalid, since they saw three unrelated atoms. It is valid in the new sense: ∀x(P(x)→Q(x)), P(c)⊨Q(c). Let M,ℓ satisfy both premises, and let a=cM. By (S6) for the first premise, with d=a, we get M,ℓ[x↦a]⊨P(x)→Q(x). Under ℓ[x↦a] the term x has value a, and under ℓ the term c has value a; so by (S1), M,ℓ[x↦a]⊨P(x) holds if and only if a∈PM if and only if M,ℓ⊨P(c), which is the second premise. So by (S5) M,ℓ[x↦a]⊨Q(x), that is, a∈QM, and by (S1) again M,ℓ⊨Q(c). Chapter 4’s objection to this argument is gone.

7.1.7. Why domains are non-empty

Clause (M1) of Definition 7.1.1 demands a non-empty domain. Here is the reason. Proposition 5.5.1 derives ∀xP(x)⊢∃xP(x) in three lines: ∀E at the variable x, then ∃I. The matching entailment holds for our structures: ∀xP(x)⊨∃xP(x). Let M,ℓ⊨∀xP(x). Since D is non-empty, choose some d∈D. By (S6), M,ℓ[x↦d]⊨P(x), and this d is the one element (S7) asks for, so M,ℓ⊨∃xP(x).

Now suppose empty domains were allowed. In a structure with D=∅, (S6) says ∀xP(x) is satisfied, since “for every d∈∅” has nothing to check; and (S7) says ∃xP(x) is not, since there is no d at all. So the sequent would be derivable and yet fail in a structure, and the rules would lead from a true premise to a false conclusion. (Worse, no assignment into an empty domain exists, so even the clauses could not be applied as written.) One of two things had to give: the rule ∀E at a variable, or empty domains. The book, like most of mathematics, keeps the rules and makes domains non-empty.

Nothing is lost. Statements about an empty set are handled by the bounded quantifiers of Definition 5.1.1, inside a non-empty domain. The bounded forms ∀x∈∅ φ and ∃x∈∅ φ abbreviate ∀x(x∈∅→φ) and ∃x(x∈∅∧φ), and in a structure with domain R in which the one-place predicate symbol ∈∅ (Section 5.2) is interpreted, by (M4), as the empty subset of R, the first is true (every hypothesis d∈∅ is false) and the second is false (no d is in ∅). Vacuous truth lives in the bound, not in the domain.

7.1.8. Exercises

A. Check your understanding

Exercise (A1)

Let MN, MZ, MQ be the structures with domains N, Z, Q, each with < the usual order. For each sentence in (a)–(d), say in which of the three structures it is true, with a witness or a failing element for each verdict.

  • (a) ∀x∃y(x<y).
  • (b) ∃x∀y¬(y<x).
  • (c) ∀x∀y(x<y→∃z(x<z∧z<y)).
  • (d) ∀x∃y(y<x).
  • (e) True or false: if a sentence is true in some structure, then it is derivable.
  • (f) Why must the domain of a structure be non-empty? Name the derivable sequent that would otherwise fail.

Solution. (a) True in all three: for each d, take y=d+1, which lies in the same domain and is larger.

(b) This says “there is a least element”. True in MN, with x=0: no natural number is below 0. False in MZ and MQ: for any d, the element e=d−1 has e<d, so (S6) fails for ¬(y<x) under ℓ[x↦d].

(c) This says “between any two elements there is a third” (density). False in MN and MZ: at x=1, y=2 there is no integer strictly between. True in MQ: for d<e in Q, z=(d+e)/2 is rational and d<z<e.

(d) This says “no element is least”. False in MN, at x=0. True in MZ and MQ, with y=d−1.

N Z Q
(a) true true true
(b) true false false
(c) false false true
(d) false true true

(e) False. By the soundness statement, a derivable sentence is true in every structure. Sentence (a) is true in MN but false in the structure ({1,2,3},<), so it is not derivable.

(f) The sequent is ∀xP(x)⊢∃xP(x), derived in Proposition 5.5.1 by ∀E at the variable x and ∃I. In an empty domain ∀xP(x) would be true, with nothing to check, and ∃xP(x) false, with no witness; so the rules would lead from a true premise to a false conclusion. (There would also be no assignments at all.)

B. Practice

Exercise (B2: A model on three elements)

Give an example of a structure with exactly three elements in which both ∀x∃yR(x,y)and∀x¬R(x,x) are true. Check both sentences. Which properties must every such structure have?

Solution. Take D={0,1,2} and RM={(0,1),(1,2),(2,0)}: each element is related to the next one around a circle. First sentence: for d=0,1,2, the witnesses e=1,2,0 give pairs in RM. Second sentence: none of (0,0), (1,1), (2,2) is in RM, so ¬R(x,x) is satisfied under ℓ[x↦d] for each d.

The properties every answer must have: the domain has three elements; every element d has some e with (d,e)∈RM; and no pair (d,d) is in RM, so that e is always different from d. Any RM meeting these works, for instance {(0,1),(1,0),(2,0)} or the set of all pairs (d,e) with d≠e.
