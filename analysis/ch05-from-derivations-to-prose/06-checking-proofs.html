5.6  Checking Proofs, and What Is Not Allowed

A reader working alone must judge proofs, including their own, and is the person least able to do it. The remedy is procedural. This section gives two questions to ask of every line and a catalogue of the errors that recur, each tied to the rule of Chapters 1–4 that it breaks, and then checks four short proofs line by line.

5.6.1. Two questions for every line

A proof is correct when every line is licensed: by Definition 1.5.2, each line is a premise (a hypothesis, a proved result or a true school fact), an assumption, or one rule applied to available lines. So checking a proof means asking two questions of every line, with the answers in two columns.

  • Is it true? Is the line correct whenever the hypotheses and the assumptions of the open boxes are true?
  • Does it follow, and by which rule? From which available lines, and by which rule?

The first column finds where to look; the second decides.

The two questions are different. A line can be true and not follow: a correct fact the proof has not earned. This is the dangerous case, because nothing about the line looks wrong. A line can also follow and be false: false in a situation where the hypotheses and open assumptions are true. Since the rules never lead from true lines to a false one (Theorem 3.5.2; Section 4.11 for predicate logic), some line it rests on, neither a hypothesis nor an open assumption, is false there too; follow it back until the second column fails. (Proof C’s “1 is even” is true given its box’s assumption.)

Quick check. A proof that n2≥n for every integer n opens with the line “n2−n=n(n−1)≥0”. Is the line true? Does it follow? Would the answers change if n ranged over the reals?

Solution. For an integer n the line is true: no integer lies strictly between 0 and 1, so n≤0 (both factors ≤0) or n≥1 (both ≥0). But as written it follows from nothing: it is the goal rearranged, without the case split that makes it true. For real n it is false at n=1/2, where n(n−1)=−1/4. The first column depends on the situation; the second fails in both.

5.6.2. The catalogue

Most wrong proofs fail in one of a few ways, each breaking a particular rule.

Example (What is not allowed)

Each entry names the error, the rule it breaks and where that rule lives, and a failing instance whose conclusion is marked true or false: a wrong argument can reach either.

  • (N1) Verifying instances and concluding “for all”. Breaks ∀I, which needs one proof about a fresh name (Definition 4.4.1, Section 4.4). Instance: n2−n+11 is prime for n=0,1,…,10 (the values are 11,11,13,17,23,31,41,53,67,83,101), “so it is prime for every n∈N”. False: at n=11 the value is 121=112.
  • (N2) A witness that depends on a variable introduced later, while uniformity is claimed. Breaks the side conditions of ∃E and ∀I: a witness δ0 obtained inside the box of x0 may not leave it (Section 4.10, Example (The search from C to UC)). Instance: “x2 is continuous at every x, with δ=min{1,ε/(2|x|+1)}; so one δ for each ε serves every x, and x2 is uniformly continuous on R”. False (Example (The square function on the real line)).
  • (N3) Treating the name from ∃E as arbitrary. Breaks the side condition of ∀I: the witness appears in the open assumption of its box (Definition 4.6.1, Section 4.6). Instance: “Some element of A is positive; let x be such an element. Since x was arbitrary, every element of A is positive.” False for A={−1,1}.
  • (N4) Reusing one witness name for two ∃E’s. Breaks the fresh-name condition: the second name may not appear in an open assumption, and the first box’s assumption mentions it (Section 4.6, Example (The sum of two even integers is even)). Sibling boxes may share a name. Instance: “m and n are even, so m=2k and n=2k for an integer k; hence m=n”. False: m=2, n=4.
  • (N5) Proving the converse. Breaks →I, whose box opens with the hypothesis, not the conclusion (Definition 1.5.1, Section 1.5). Instance: “If x2>1, then x>1: suppose x>1; then x2>x>1.” False: x=−2. Argument B of Section 1.1 makes the same move with a true conclusion.
  • (N6) Affirming the consequent; denying the antecedent. Breaks Definition 1.5.2 (Section 1.5), being no rule: P→Q with Q gives no P, and with ¬P gives no ¬Q. Each pattern has a refuting row, so no derivation exists (Corollary 3.5.3, Section 3.5): Example (Affirming the consequent is not valid), and for denying the row P false, Q true. Instances: “a multiple of 4 is even and 6 is even, so 6 is a multiple of 4”; “… and 6 is not a multiple of 4, so 6 is not even”. Both false.
  • (N7) A missing case. Breaks ∨E, which needs one box for each disjunct (Definition 1.7.1, Section 1.7). Instance: “|x|>0 for every real x: every real x has x>0, x=0 or x<0; if x>0, |x|=x>0; if x<0, |x|=−x>0”. False: the case x=0 was dropped, and |0|=0.
  • (N8) Cases that do not exhaust. Breaks ∨E, whose first input must be a disjunction already derived (Section 1.7). Instance: “x2≥x for every real x: either x≥1 or x≤0; in the first case x2=x⋅x≥x, in the second x2≥0≥x”. False: x=1/2 satisfies neither case, and 1/4<1/2.
  • (N9) Citing a line that is not available: the goal itself (circular reasoning), a result proved later, or a general “fact” neither proved nor a true school fact (a false “fact” never qualifies). Breaks Definition 1.5.2: every line is a premise, an assumption, or a rule applied to available lines (Section 1.5). Instances: “if n2 is even, then n is even: suppose n2 is even; since n is even, …” (true, and circular); “x<1, so x2<1, since squaring preserves <” (false: x=−2).
  • (N10) Using an assumption after its box has closed. Breaks the scope rule of Definition 1.5.2 (Section 1.5). Instance: “Suppose n is even, say n=2k; then n2=4k2. Hence if n is even, 4∣n2. Now n2=4k2, so 4∣n2 for every integer n.” False: n=1. Proof D below makes the same move with a true conclusion.
  • (N11) A wrong negation. An RAA box opened with a statement that is not the negation of the goal; a bound negated instead of a quantifier (Proposition 4.9.3); the negation of φ→ψ written as an implication, ¬φ→¬ψ or φ→¬ψ, instead of φ∧¬ψ (Proposition 4.9.2). Breaks RAA, which closes only a box opened with ¬φ (Section 2.5), or the laws of Section 4.9. Instances: “if x>2, then x2>4” is “refuted” because “if x≤2, then x2≤4” holds at x=0 (false: both are true at x=0, so one is not the negation of the other); “an=0 does not converge to 0, since some ε≤0 has |an−0|≥ε for all n” (false).

An entry diagnoses a step, not the conclusion: a false instance shows the step leading from true premises to a false conclusion, and a true one that a correct conclusion does not excuse it. From Chapter 6 on, a warning about one of these errors cites the entry by number, as in “(N3) of Example (What is not allowed)”. Some entries name errors met before: (N1) is the first error of Section 4.4’s list, and two parts of (N11) are warnings of Section 4.9.

Quick check. Which entry does the sentence “choose N larger than every Nε, one for each ε>0” commit, and when is the same move not an error?

Solution. (N2). Each Nε comes from ∀ε∃N, inside the box of its own ε; one N above all of them would be uniform, as if the hypothesis were ∃N∀ε, and usually none exists, since the Nε can grow without bound as ε shrinks. The move is legitimate when ε ranges over finitely many values ε1,…,εk: then max{Nε1,…,Nεk} exists, because a finite set of natural numbers has a maximum.

Warning. A true conclusion does not make a proof correct. “I know the result is true” answers the first column for the last line and nothing else. Argument B of Section 1.1 has a true conclusion and only true sentences, and it is wrong (Proof B below).

5.6.3. Four proofs, checked

Here are four short proofs as a student might write them; two are correct and two are not.

Example (Proof A)

Claim. For a real number x, if x2−3x+2<0, then 1<x<2.

  1. Assume x2−3x+2<0. (2) Then (x−1)(x−2)<0. (3) A product of two real numbers is negative only when one factor is positive and the other negative, so either x−1>0 and x−2<0, or x−1<0 and x−2>0. (4) In the first case, 1<x<2. (5) In the second case, x<1 and x>2, which is impossible. (6) Hence 1<x<2.

Solution.

Line True? Follows? By which rule?
(1) assumption opens the →I box
(2) yes: (x−1)(x−2)=x2−3x+2 =E with the algebraic identity
(3) yes →E with the stated fact about signs; a disjunction of two conjunctions
(4) yes, in this case ∨E, case 1: ∧E gives x>1 and x<2
(5) the case is impossible ∨E, case 2: x>2 and x<1 give 2<1, which clashes with ¬(2<1) (¬E); the case reaches 1<x<2 by ⊥E
(6) yes ∨E on (3), (4), (5); then →I on (1)–(6)

Verdict: correct. The disjunction of line (3) is derived from a stated fact, so the cases exhaust and (N8) does not apply. Line (5) is the one to look at twice: “which is impossible” is ⊥E, which lets a case that cannot occur reach the goal, so that ∨E can combine the cases. By Definition 5.3.2 it could be silent, since the clash is stated.

Example (Proof B)

Claim. For an integer n, if n2 is even, then n is even.

  1. Suppose n is even. (2) Then n=2k for some integer k. (3) So n2=4k2=2(2k2). (4) Hence n2 is even. (5) Therefore, if n2 is even, then n is even.

Solution.

Line True? Follows? By which rule?
(1) assumption opens a box, with “n is even”
(2) yes, given (1) the definition of “even”, then ∃E with a fresh k
(3) yes algebra
(4) yes, given (1) ∃I with the witness 2k2: the definition of “even”
(5) the statement is true, but … does not follow: →I on the box (1)–(4) gives “if n is even, then n2 is even”, not (5)

Verdict: wrong; line (5) fails; entry (N5). Every line is true, and lines (1)–(4) prove the converse. →I turns a box from P to Q into P→Q, with the box’s assumption on the left; writing the claim instead is the step from P→Q to Q→P. That step has a refuting row, P false and Q true, so no derivation makes it (Corollary 3.5.3); and it fails in practice: “if x>1, then x2>1” is true, its converse false at x=−2. This is Argument B of Section 1.1, diagnosed in Section 1.5. The claim is true: Theorem 2.1.3 proves it in a box that opens with “n2 is even”.

Example (Proof C)

Claim. For an integer n, the number n2−2 is not divisible by 4.

  1. Suppose n2−2 is divisible by 4, say n2−2=4k with k an integer. (2) Then n2=4k+2=2(2k+1), so n2 is even. (3) By Theorem 2.1.3, n is even, say n=2m with m an integer. (4) Then n2=4m2, so 4m2=4k+2, and hence 1=2(m2−k). (5) So 1 is even. (6) But 1 is odd, and no integer is both even and odd; this is a contradiction. (7) Hence n2−2 is not divisible by 4.

Solution.

Line True? Follows? By which rule?
(1) assumption opens the ¬I box, with “4 divides n2−2”; then ∃E with a fresh k
(2) yes, given (1) algebra, then ∃I with witness 2k+1
(3) yes, given (2) →E with Theorem 2.1.3 and (2); then ∃E with a fresh m
(4) yes, given (1) and (3) algebra: subtract 4k, divide by 2
(5) yes, given (4) ∃I with witness m2−k, an integer
(6) yes ∧I of (5) and “1 is odd”, then ¬E against “no integer is both even and odd”
(7) yes ¬I on the box (1)–(6)

Verdict: correct. The goal is a negation, and the ¬I box opens with the positive statement: a proof “by contradiction” of face (i) of Section 5.1, with no RAA. The witness names k and m differ, as (N4) requires.

Example (Proof D)

Claim. For a real number x: if x>1, then x2>x; and x2+1>x.

  1. Suppose x>1. (2) Multiplying both sides by x, which is positive, gives x2>x. (3) Hence if x>1, then x2>x. (4) For the second part, x2+1>x2, and x2>x by (2), so x2+1>x.

Solution.

Line True? Follows? By which rule?
(1) assumption opens the →I box for the first conjunct
(2) yes, given (1) →E with “multiplying by a positive number keeps >”; x>0 since x>1>0
(3) yes →I on the box (1)–(2)
(4) “x2>x” is false for x=1/2 does not follow: it cites (2), which lies inside the box closed at (3)

Verdict: wrong; line (4) fails; entry (N10). The claim is a conjunction, so the skeleton is ∧I with two separate proofs. The second cites line (2), derived inside the box that assumed x>1 and closed at line (3), so line (2) is not available. The first column confirms it: at x=1/2, x2=1/4<1/2=x, a counterexample to the illegal step, though not to the claim.

The claim is true. For every real x, x2−x+1=(x−12)2+34>0, since a square is non-negative; so x2+1>x, with nothing from the closed box.

In Proofs B and D every sentence sounds right, and in Proof B every sentence is true. The errors are in the connections, which the rules govern: “which rule, from which available lines?” catches both.

5.6.4. Exercises

A. Check your understanding

Exercise (A1)

Each line below comes from a proof. Name the catalogue entry of Example (What is not allowed) that it commits, and the rule it breaks.

  • (a) “We checked 3n>n2 for n=0,1,2,3,4, so it holds for every n∈N.”
  • (b) “By hypothesis some x∈A has f(x)=0; fix such an x. Since x was arbitrary, f(x)=0 for every x∈A.”
  • (c) “To prove that f(x1)=f(x2) implies x1=x2, suppose x1=x2; then f(x1)=f(x2).”
  • (d) “To prove x≥0, suppose, for a contradiction, that x≤0.”
  • (e) “If n is divisible by 6, then n is even. Since n is even, n is divisible by 6.”
  • (f) “Every real x satisfies x>0 or x<0; we consider the two cases.”

Solution. (a) (N1): ∀I needs one proof about a fresh name, not five instances.

(b) (N3): x was chosen by ∃E and appears in the open assumption f(x)=0, so ∀I on it breaks the side condition. For A={0,1} and f(x)=x the conclusion fails.

(c) (N5): the →I box opens with the conclusion, so it proves the converse, which every function satisfies.

(d) (N11): the negation of x≥0 is x<0, not x≤0, so RAA cannot close this box with x≥0. Closed by ¬I it proves x>0, more than the goal, so it closes only if the hypotheses exclude x=0.

(e) (N6), affirming the consequent. No rule licenses it, so it breaks Definition 1.5.2: P→Q with Q gives no P. Here n=4 is even and not divisible by 6.

(f) (N8): the disjunction is not derived, and it is false at x=0, so ∨E has no valid first input.

B. Practice

Exercise (B1: Two proofs in two columns)

Check each proof in two columns. For a wrong proof, name the first line that fails and its catalogue entry, and say whether the claim is true.

  • (i) Claim. For integers m and n, if m and n are odd, then m+n is even. (1) Assume m and n are odd. (2) Choose integers k and l with m=2k+1 and n=2l+1. (3) Then m+n=2k+2l+2=2(k+l+1). (4) Since k+l+1 is an integer, m+n is even.
  • (ii) Claim. For a real number x, if x2<1, then x<1. (1) Assume x2<1. (2) Suppose, for a contradiction, that x>1. (3) Then x>0, so x2=x⋅x>x>1. (4) This contradicts x2<1. (5) Hence x<1.

Solution. (i)

Line True? Follows? By which rule?
(1) assumption opens the →I box
(2) yes, given (1) ∧E, the definition of “odd”, and two ∃E’s with the different fresh names k and l
(3) yes algebra, =E in a chain
(4) yes ∃I with the witness k+l+1; then the boxes close, and →I

Verdict: correct. In (2) the second witness has a new name, as (N4) of Example (What is not allowed) requires.

(ii)

Line True? Follows? By which rule?
(1) assumption opens the →I box
(2) assumption opens a box with “x>1”, announced as RAA
(3) yes, given (2) →E with order facts
(4) yes (3) gives ¬(x2<1) by order facts; ¬E on (1) and that line
(5) true, given (1), but … does not follow: the box assumed x>1, which is not the negation of x<1; ¬I on it gives only ¬(x>1), that is, x≤1

Verdict: wrong; line (5) fails, because the box of line (2) opened with the wrong statement; entry (N11). The negation of x<1 is x≥1, and the case x=1 is never examined: x=1 has ¬(x>1) and not x<1, a counterexample to the step. The claim is true. Repair: suppose, for a contradiction, that x≥1; then x2=x⋅x≥x≥1, which contradicts x2<1; hence x<1.

Exercise (B2: Find the error)

Find the error in the following proof, name its catalogue entry, and decide whether the claim is true.

Claim. For all real numbers x and y, |x|+|y|=|x+y|.

  1. Let x and y be real numbers. (2) Either x and y are both ≥0, or they are both <0. (3) If both are ≥0, then x+y≥0, so |x|+|y|=x+y=|x+y|. (4) If both are <0, then x+y<0, so |x|+|y|=−x−y=−(x+y)=|x+y|. (5) In either case |x|+|y|=|x+y|.

Solution. Line (2) fails. Its disjunction is not derived, and it is false when x and y have opposite signs, so line (5) combines cases that do not exhaust: entry (N8) of Example (What is not allowed). Lines (3) and (4) are correct in their cases.

The claim is false: for x=1, y=−1, |x|+|y|=2 and |x+y|=0; this pair satisfies neither case of line (2). What is true is |x+y|≤|x|+|y| (Example (The triangle inequality by cases)).

C. Going deeper

Exercise (C1: The second half)

Let f:R→R be continuous at a, as the quantifier pattern of Section 4.8: for every ε>0 there is δ>0 such that |f(x)−f(a)|<ε for every real x with |x−a|<δ. Suppose f(a)>0. Here is a level-1 skeleton for the statement “there is δ>0 such that f(x)>0 for every x with |x−a|<δ”:

Its level-3 prose begins:

Since f(a)>0, the number f(a)/2 is positive. By the continuity of f at a, applied with ε=f(a)/2, choose δ>0 such that |f(x)−f(a)|<f(a)/2 for every real x with |x−a|<δ.

The rest is blank. Name the move, then complete it. Say which skeleton lines your sentences carry, and what δ depends on.

Solution (Hint 1). What is left is the box of x0 and the witness.

Solution (Hint 2). “Let x be a real number with |x−a|<δ. Then …”

Solution. The move: skeleton first: the goal fixes the ∃I of line 13 and the box of x0. Filling it: ∀E at the non-obvious instance ε=f(a)/2 (line 4), ∃E on its δ (line 5), and that δ as the witness.

Completion.

Let x be a real number with |x−a|<δ. Then |f(x)−f(a)|<f(a)/2, so, as −|u|≤u, f(x)−f(a)>−f(a)/2, that is, f(x)>f(a)/2>0. So this δ, which depends only on a, is as required.

“Let x … with |x−a|<δ” opens the two boxes at line 7; “then |f(x)−f(a)|<f(a)/2” is lines 8–9, the ∀E at the obvious term x silent; “so … f(x)>f(a)/2>0” is line 10, which uses line 2. Lines 11 and 12 are silent closings, and the last sentence is lines 13–14, with the δ already chosen as witness. It depends on a (through f(a) and the continuity at a) and on no x: the box of δ0 encloses the box of x0.

Marking scheme. (10 points) - 2: names the move (skeleton first; a hypothesis applied at a chosen ε, then its δ reused as the witness), or the rules ∀E, ∃E, ∃I. - 3: for an arbitrary x with |x−a|<δ, derives f(x)>f(a)/2, with the step from |u|<r to u>−r justified. - 2: concludes f(x)>0 using f(a)>0, and states the conclusion with δ before x. - 2: matches the sentences to the skeleton’s lines. - 1: says δ depends on a and not on x. Second route: refuting f(x)≤0 by |f(x)−f(a)|≥f(a)−f(x)≥f(a)>f(a)/2 earns the second line and the f(x)>0 part of the third. Fatal errors (0 for the step): choosing δ after x; applying continuity at an ε not shown to be positive.

Exercise (C2: A true conclusion)

Here is a proof that 2+3 is irrational, a true conclusion. Find the line that fails and its catalogue entry, give a counterexample to the illegal step, and write a correct proof.

  1. Suppose 2+3=r for some rational number r. (2) Squaring, r2=2+26+3=5+26. (3) Hence 6=(r2−5)/2, which is rational, since r is. (4) But 6=2⋅3 is irrational, being a product of two irrational numbers. (5) This contradiction shows that 2+3 is irrational.

Solution (Hint 1). Run the second column on every line.

Solution (Hint 2). For a correct proof, isolate 3=r−2 before squaring.

Solution. The failing line is (4). Its first half is true, 6=2⋅3, but its reason is not available. “A product of two irrational numbers is irrational” is neither proved nor a school fact: it is false, since 2 is irrational (Theorem 2.2.1), and 2⋅2=2 is rational. So the line cites nothing: entry (N9) of Example (What is not allowed). The product 2⋅2=2 is a counterexample to the illegal step; there is none to the conclusion, which is true. Lines (1)–(3) and (5), and the ¬I skeleton, are correct.

A correct proof. Suppose 2+3=r with r rational. Then r>0, since both square roots are positive. Isolating, 3=r−2, and squaring, 3=r2−2r2+2,so2=r2−12r, where dividing by 2r is legitimate because r>0. The right-hand side is rational, which contradicts Theorem 2.2.1. Hence 2+3 is irrational.

Marking scheme. (10 points) - 3: names line (4) as the failing line, and the illegal step as the unproved general “fact”, entry (N9). - 2: a counterexample to that step (2⋅2=2, or another product of two irrationals that is rational). - 1: says the conclusion is true, so no counterexample to it exists. - 4: a correct proof: the ¬I box on “r rational”, the algebra, the division justified by r≠0, and the clash with Theorem 2.2.1 (or with 3 or 6, its irrationality proved). Fatal errors (0 for the step): “correcting” line (4) by another unproved fact; dividing by r without r≠0.

Exercise (C3: Exit check: four student proofs)

Judge each proof. If it is wrong, give the line that fails, its entry in Example (What is not allowed), and a counterexample to the illegal step. If it is correct, name the rule of its most delicate step and check that step.

  • (1) Claim. For every integer n, if n is a multiple of 4 or a multiple of 6, then n is even. (1) Let n be an integer that is a multiple of 4 or of 6. (2) Case 1: n is a multiple of 4. Choose an integer k with n=4k; then n=2(2k), so n is even. (3) Case 2: n is a multiple of 6. Choose an integer k with n=6k; then n=2(3k), so n is even. (4) In either case, n is even.
  • (2) Claim. For integers m and n, if m and n are even, then mn is divisible by 4. (1) Assume m and n are even. (2) Then m=2k and n=2k for an integer k. (3) So mn=4k2, which is divisible by 4.
  • (3) Claim. For every real x, |x−1|≤|x|+1. (1) Either x≥1 or x≤0. (2) If x≥1, then |x−1|=x−1≤x+1=|x|+1. (3) If x≤0, then |x−1|=1−x=1+|x|. (4) In either case, |x−1|≤|x|+1.
  • (4) Claim. For every real x, if x2=2x, then x=2. (1) Assume x2=2x. (2) Canceling x from both sides, x=2. (3) Hence if x2=2x, then x=2.

Solution (Hint 1). Run the two-column check on every line, and keep the two questions apart: a true claim can have a wrong proof.

Solution (Hint 2). In (1), ask which boxes are open when the second k is chosen. In (3), ask what ∨E needs from line (1).

Solution. (1) Correct. The skeleton is ∀I and →I, then ∨E on the hypothesis itself, so the cases exhaust. The delicate step is the second “choose an integer k”, an ∃E reusing a name. It is legal: the first box of k lies inside Case 1, which closed before Case 2 opened, so k appears in no open assumption, not in the existential and not in the conclusion. Sibling boxes may share a name (Section 4.6); (N4) forbids only a name still in use.

(2) Wrong; line (2) fails; entry (N4) of Example (What is not allowed). The second witness is named k while the box of m=2k is open. Counterexample to the step: m=2, n=4; no integer k has 2=2k and 4=2k. The conclusion is true: with m=2k and n=2l, mn=4kl.

(3) Wrong; line (1) fails; entry (N8). “Either x≥1 or x≤0” is not derived, and is false at x=1/2, a counterexample to the step. The conclusion is true; the missing case repairs the proof: if 0<x<1, then |x−1|=1−x<1<|x|+1.

(4) Wrong; line (2) fails; entry (N9); the claim is false. Canceling uses the “fact” “if ax=bx, then a=b”, which is neither proved nor a school fact, and is false: a=1, b=2, x=0. It needs x≠0, which no line provides. The claim fails at x=0; what is true is “x=0 or x=2”, from x(x−2)=0.

Marking scheme. (10 points: 2.5 per proof) - For each of (2), (3), (4): the verdict “wrong” (1); the failing line and its entry, (N4), (N8), (N9) (1); a counterexample to the illegal step (0.5). - For (1): the verdict “correct” (1); the delicate step named as an ∃E reusing a name in a sibling box (or as the ∨E on the hypothesis) (1); that step checked against the side condition (0.5). For (4), “→E without its antecedent x≠0” is also accepted. Fatal errors (0 for that proof): calling proof (1) wrong as an instance of (N4) because the name k recurs; judging (2) or (3) correct because its conclusion is true.
