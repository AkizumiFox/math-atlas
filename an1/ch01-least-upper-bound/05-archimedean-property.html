1.5  The Archimedean Property

We now have the least upper bound axiom (Axiom 1.3.1) and a way to use it, the characterization of the supremum by ε (Theorem 1.4.1). This section draws the first consequence, one that looks too obvious to need proof: the natural numbers eventually pass every real number. When we first met suprema, we claimed that sup{1−1/n:n∈Z>0}=1 and postponed the proof, because it needs exactly this fact. Here we prove the fact from the axiom, pay off that claim, and then meet an ordered field where the fact is false, so that we can see which line of the proof the axiom is holding up.

1.5.1. Where the natural numbers live

So far R is an ordered field satisfying one extra axiom. The numbers 0,1,2,3,… are in it, since 2 is 1+1, 3 is 2+1, and so on. But “and so on” is not a definition. We want the set you get by starting at 0 and adding 1 again and again, and nothing else. The first half of that description is easy to state as a property of a set.

Definition 1.5.1 (Inductive set)

A subset S⊆R is inductive if

  • (N1) 0∈S, and
  • (N2) for every x∈S, also x+1∈S.

In words: an inductive set contains 0, and it is closed under the step “add one”. Nothing stops it from containing other numbers as well.

Some examples, checked clause by clause.

  • R itself is inductive: it contains 0, and x+1 is a real number whenever x is.
  • [0,∞)={x∈R:x≥0} is inductive: 0≥0, and x≥0 gives x+1≥0+1>0.
  • {0}∪[1,∞) is inductive. From 0 we step to 1, which is in [1,∞), and [1,∞) is closed under adding 1.

A nonexample by minimal change: [0,5] contains 0, so (N1) holds, but 4.5∈[0,5] and 5.5∉[0,5], so (N2) fails. Chopping the top off [0,∞) destroys closure under the step.

The inductive sets above are too big: [0,∞) contains 1.5 and 4.7. What we want is the smallest one. Intersecting all of them throws away everything that some inductive set can do without.

The set of natural numbers is N:={x∈R:x∈S for every inductive set S⊆R}, that is, the real numbers that belong to every inductive subset of R.

Two things are true of N, and both follow at once from the definition.

  • N is inductive. Every inductive set contains 0, so 0∈N. If x∈N, then x lies in every inductive set S, and each such S then contains x+1 by (N2); so x+1∈N.
  • N is contained in every inductive set, since it is their intersection.

The second property is the principle of induction (Logic and Proof, Axiom 4.2.1) in disguise. To prove that a statement P(n) holds for every n∈N, let S:={n∈N:P(n)}. If P(0) holds and P(n) implies P(n+1), then S is inductive, so N⊆S, and P(n) holds for all n∈N.

Example (Every nonzero natural number is at least 1)

Show that n≥1 for every n∈N with n≠0, and deduce that for such n, 1/n is defined and 0<1/n≤1.

Solution. The set {0}∪[1,∞) is inductive, as checked above. Since N is contained in every inductive set, N⊆{0}∪[1,∞), that is, n≥1 for every n∈N with n≠0. In particular such an n is positive, so 1/n is defined. From 0<1≤n Theorem 1.1.2 (f) gives 0<1/n≤1/1=1.

The proof never mentioned a single natural number by name. It found an inductive set containing the property we wanted, and let the definition of N do the rest. That is the whole technique.

The nonzero natural numbers are the positive integers, Z>0:={n∈N:n≠0}={n∈N:n≥1}, the two descriptions agreeing by Example (Every nonzero natural number is at least 1). This is the set {1,2,3,…} that indexed our examples informally before; from here on it is a defined subset of R, and 1/n is defined and positive for every n∈Z>0.

Remark. Logic and Proof, Chapter 3 takes induction as a basic property of N (Logic and Proof, Axiom 4.2.1), and Sets, Relations, and Cardinality, Chapter 2 proves well-ordering and the arithmetic below from it. The set defined here is that same N, now located inside R; it is also the copy 0,1,1+1,1+1+1,… that every ordered field contains (Exercise (C1: Ordered fields contain the counting numbers)), and “N is the smallest inductive set” is exactly the induction principle of Logic and Proof, Chapter 3, in the form “every inductive subset of N is all of N”. From now on we use the familiar arithmetic of N, each item proved by induction in Sets, Relations, and Cardinality, Chapter 2: sums and products of natural numbers are natural numbers; if n∈N and n≥1, then n−1∈N; no natural number lies strictly between n and n+1; and every nonempty subset of N has a least element (well-ordering). The integers are Z:=N∪{−n:n∈N}, and the rationals are Q:={m/n:m∈Z, n∈Z>0}, with Z>0 the positive integers defined above. We also use, again from Sets, Relations, and Cardinality, Chapter 2, that sums, differences, and products of integers are integers. The integers n>0 are exactly the elements of Z>0: such an integer is not −m with m∈N, since −m≤0, so it is a nonzero natural number; conversely, a nonzero natural number is >0 by Example (Every nonzero natural number is at least 1). So Z>0={n∈Z:n>0}.

1.5.2. The natural numbers are not bounded

Is N bounded above in R? Everyone’s picture of the number line says no: the marks 1,2,3,… march off to the right forever. But a picture is not a proof, and here the picture hides something. Nothing in the ordered-field axioms (Definition 1.1.1) forbids a number larger than every natural number. At the end of this section we build an ordered field that contains one. So if R has no such number, the reason must be the one axiom that R has and that field lacks.

Theorem 1.5.1 (Archimedean Property)

The set N is not bounded above in R; in other words, every real number x is exceeded by some n∈N.

Idea. Suppose N had an upper bound. Then the axiom hands us the least one, s=supN. Every natural number n has a successor n+1 that is still a natural number, and so still at most s. Moving back one step, n≤s−1 for every n: the smaller number s−1 is an upper bound too. A least upper bound with a smaller upper bound below it is absurd.

Proof. Suppose, for contradiction, that N is bounded above. The set N is nonempty, since 0∈N. By Axiom 1.3.1, N has a supremum s:=supN∈R.

Let n∈N. Since N is inductive, n+1∈N, and since s is an upper bound of N, n+1≤s, that is, n≤s−1. As n was arbitrary, s−1 is an upper bound of N. Property (S2) of the supremum (Definition 1.2.4) now gives s≤s−1, that is, 1≤0, which contradicts 0<1.

Therefore N is not bounded above. Unwinding the definition (Definition 1.2.2), no x∈R is an upper bound of N: for every x∈R it is false that n≤x for all n∈N. So for every x some n∈N has n≰x, that is, n>x by trichotomy. This proves the theorem.

Each hypothesis of the axiom was used and named: “nonempty” through 0∈N, “bounded above” through the assumption for contradiction. The inductive property of N supplied the jump n↦n+1.

Remark. The contradiction step is ¬I (Logic and Proof, Definition 2.2.1), not RAA (Logic and Proof, Definition 2.5.1), the classical rule of proof by contradiction: we assumed “N is bounded above”, reached a contradiction, and concluded its negation. Inside that box every step is direct. The proof shows that s−1 is an upper bound; it does not argue “s−1 is not an upper bound, so some n exceeds s−1”, a step that would itself need the classical law described next. The proof’s one classical step comes after the ¬I, in its last paragraph. Passing from “not every n satisfies n≤x” to “some n satisfies n>x” is the quantifier law “not all” gives “some not” of Logic and Proof, Chapter 4, and that law is derived there with RAA.

The form we will use most often puts a small number, not a large one, in the role of x.

Corollary 1.5.2

For every ε>0 there is n∈Z>0 with 1/n<ε. In symbols, (∀ε>0) (∃n∈Z>0)1n<ε. Moreover, every m∈Z>0 with m≥n then also satisfies 1/m<ε.

Proof. Let ε>0. Then 1/ε is defined and positive. By Theorem 1.5.1 applied to x=1/ε, there is n∈N with n>1/ε>0; so n∈Z>0. Taking reciprocals reverses a strict inequality between positive numbers (Theorem 1.1.2 (f)), so 1/n<ε. If m≥n, then 1/m≤1/n<ε by the same rule.

Read the quantifiers in order. The ε is given first and the n is found afterwards, so n depends on ε: the proof chose n>1/ε, and a smaller ε forces a larger n. Swapping the quantifiers gives a false statement. “There is n∈Z>0 such that 1/n<ε for every ε>0” would make 1/n smaller than every positive number. Since 1/n>0 (Example (Every nonzero natural number is at least 1)), we could take ε=1/n itself and get 1/n<1/n, which is absurd.

The “moreover” clause says that once one n works, every later one works too. Chapter 2 turns this “from some point on” into the definition of a limit.

Quick check. Find the least n∈Z>0 with 1/n<0.003. Then do the same for ε=0.0003. What does the comparison say about the dependence of n on ε?

Solution. For positive n, 1/n<0.003 is equivalent to n>1/0.003=333.3―. The least positive integer with this property is n=334; indeed 1/333=0.003003… is too big. For ε=0.0003 the condition is n>3333.3―, so the least n is 3334. Dividing ε by 10 multiplied the least n by about 10. No single n serves every ε, which is why the quantifiers read “for every ε there is n” and not the other way round.

1.5.3. Paying an old debt

In Example (A supremum we cannot yet prove) we showed that 1 is an upper bound of A={1−1/n:n∈Z>0} and that A has no maximum. We stopped short of supA=1, because (S2) needed an n with 1/n below a given positive number. That is exactly what Corollary 1.5.2 supplies, and the ε-characterization tells us what remains to be shown.

Example (The supremum is 1)

Let A:={1−1/n:n∈Z>0}. Prove that supA=1.

Solution. The set A is nonempty, since 0=1−1/1∈A.

Upper bound. For every n∈Z>0 we have 1/n>0 (Example (Every nonzero natural number is at least 1)), so 1−1/n<1. Hence 1 is an upper bound of A.

An element in every band below 1. Let ε>0. By Corollary 1.5.2 there is n∈Z>0 with 1/n<ε; this n depends on ε. Then a:=1−1/n∈A and a>1−ε.

Since 1 is an upper bound of A and every band (1−ε,1] contains an element of A, Theorem 1.4.1 gives supA=1.

For a concrete instance, ε=0.01 needs n>100, and n=101 gives the element 1−1/101=100/101>0.99. Together with Example (A supremum we cannot yet prove), A is a set whose supremum 1 is not attained.

The pattern of this example, “upper bound, then an element in every band below it”, is the one every supremum computation in this book follows. The only new input here was Corollary 1.5.2, which turns “1/n is small” into a precise choice of n.

1.5.4. An ordered field without the Archimedean property

We claimed that the Archimedean property does not follow from the ordered-field axioms alone. Now we back that up with a concrete field containing an element larger than every natural number. The field is made of fractions of polynomials, and the element is the variable x itself.

A rational function is a quotient p/q of real polynomials p and q with q not the zero polynomial. Two quotients p/q and p′/q′ are the same element when pq′=p′q, exactly as for fractions of integers. With the usual addition and multiplication of fractions, the rational functions form a field, written R(x). This is the same construction that builds Q out of Z, applied to polynomials; it is algebra, and we take it as known without proof here. The real numbers sit inside R(x) as the constant functions.

The leading coefficient of a nonzero polynomial is the coefficient of its highest power of x. For instance, the leading coefficient of 3−2x2 is −2.

Call a nonzero p/q∈R(x) positive if the leading coefficients of p and q are both positive or both negative, and write f<g when g−f is positive.

Here is the picture behind this definition. For large real t, the value p(t)/q(t) has the sign of the product of the two leading coefficients, because the top powers dominate. So “f>0” means “f(t)>0 for all sufficiently large t”, and f<g means that the graph of g eventually lies above the graph of f. This is only a picture: the definition uses leading coefficients and nothing else.

Positivity does not depend on how the fraction is written. Suppose p/q=p′/q′, so that pq′=p′q, and let α,β,α′,β′ be the leading coefficients of p,q,p′,q′. The leading coefficient of a product of polynomials is the product of their leading coefficients, so αβ′=α′β. Multiplying both sides by ββ′ gives αβ⋅β′2=α′β′⋅β2, and β2,β′2>0. Hence αβ and α′β′ have the same sign: p/q is positive exactly when p′/q′ is.

With this order R(x) is an ordered field. The key facts are that sums and products of positive elements are positive, and that for each nonzero f exactly one of f and −f is positive. Checking these is routine, and Exercise (C2: The order on the rational functions) walks through them. On the constants, the new order is the old one: the constant c is positive exactly when c>0. The example below uses that R(x) is an ordered field, and with it the rules of Theorem 1.1.2, which hold in every ordered field; so it rests on Exercise (C2: The order on the rational functions), where that is proved.

The natural numbers of R(x), the smallest inductive subset in the sense of Definition 1.5.1, are the constants 0,1,2,3,…. Indeed, the constant functions n with n∈N form an inductive subset of R(x): it contains the constant 0, and the constant n plus 1 is the constant n+1. So every natural number of R(x) is such a constant. Conversely, let I be an inductive subset of R(x). The set of n∈N whose constant lies in I contains 0 and passes from n to n+1, so it is an inductive subset of R and contains all of N. So every constant n lies in every inductive subset of R(x).

Example (A non-Archimedean field)

In R(x) with the order just described, show that n<x for every n∈N. Deduce that N is bounded above in R(x), and that Corollary 1.5.2 fails in R(x).

Solution. Let n∈N. Then x−n=(x−n)/1. The numerator x−n has leading coefficient 1 and the denominator 1 has leading coefficient 1. They have the same sign, so x−n is positive, that is, n<x.

Hence x is an upper bound of N in R(x), and N is bounded above there. So the conclusion of Theorem 1.5.1 is false in R(x).

Now take ε:=1/x. It is positive: numerator 1 and denominator x both have leading coefficient 1. For each n∈Z>0 we have 0<n<x, so taking reciprocals gives 1/x<1/n. No positive integer n satisfies 1/n<ε, and Corollary 1.5.2 fails.

The element 1/x is positive yet smaller than every 1/n: an “infinitely small” number. The real line has none, and that is exactly what Corollary 1.5.2 says.

1.5.5. The line of the proof that fails

Every step in the proof of Theorem 1.5.1, except one, is valid in any ordered field. So let us run the proof in R(x) and watch where it breaks.

  • “Suppose N is bounded above.” In R(x) this is true, with upper bound x.
  • “N is nonempty.” True.
  • “By Axiom 1.3.1, N has a supremum s.” This is the line that fails. In R(x), N has no least upper bound at all. Indeed, let M be any upper bound of N in R(x). For each n∈N, also n+1∈N, so n+1≤M, that is, n≤M−1. Hence M−1 is also an upper bound, and it is strictly smaller than M. No upper bound is the least one.
  • The remaining lines, “n+1≤s for every n∈N, so s−1 is an upper bound, and (S2) gives s≤s−1”, use only the ordered-field axioms and the fact that N is inductive. They would go through in R(x) if there were an s to apply them to.

The argument that shows N has no supremum in R(x) is the middle paragraph of the proof of Theorem 1.5.1, with M in place of s. That proof showed that a supremum of N cannot exist in any ordered field; the axiom then says that, in R, a bounded N would have to have one. In R(x) there is no axiom to force it, so no contradiction arises. Two conclusions follow:

  • R(x) is an ordered field in which Axiom 1.3.1 fails, with witness the nonempty, bounded-above set N.
  • In any ordered field, the least upper bound axiom implies the Archimedean property. That is precisely what our proof showed.

Warning. The Archimedean property is not “obvious”, and it is not a consequence of the ordered-field axioms. It is exactly what R(x) lacks, where x exceeds every natural number. In R it holds only because of the least upper bound axiom. A proof that says “choose an integer larger than x” is using Theorem 1.5.1, and should cite it.

Remark. The converse fails: an ordered field can be Archimedean without satisfying the axiom. The field Q is one (Exercise (C3: Archimedean without the axiom)), and it fails the axiom by Theorem 1.2.2. So the Archimedean property is strictly weaker than the axiom. Chapter 11 shows which properties, added to the Archimedean property, bring back the full axiom.

1.5.6. Exercises

A. Check your understanding

Exercise (A1)
  • (a) Write the Archimedean property “for every x∈R there is n∈N with n>x” in symbols, and write its negation in symbols.
  • (b) Which of the following subsets of R are inductive: [12,∞), [0,10], N∪{12}, Z? Name the failing clause for each one that is not.
  • (c) True or false, with a reason: in Corollary 1.5.2, one n can be chosen that works for every ε>0.
  • (d) In the proof of Theorem 1.5.1, which line uses the least upper bound axiom, and which line uses that N is inductive?

Solution.

  • (a) The property is (∀x∈R)(∃n∈N) n>x. Its negation is (∃x∈R)(∀n∈N) n≤x: some real number is an upper bound of N.

  • (b) [12,∞) is not: 0∉[12,∞), so (N1) fails, although x≥12 gives x+1≥32≥12, so (N2) holds. [0,10] is not: it contains 0, but 10∈[0,10] and 11∉[0,10], so (N2) fails. N∪{12} is not: 12 is in it but 32 is not, since 32 lies strictly between the natural numbers 1 and 2; so (N2) fails. Z is inductive: 0∈Z, and k+1∈Z for every integer k.

  • (c) False. Such an n would satisfy 1/n<ε for every ε>0. But 1/n>0 by Example (Every nonzero natural number is at least 1), so ε=1/n is allowed, and it gives 1/n<1/n, which is absurd. The n must depend on ε.

  • (d) The axiom is used in “N has a supremum s”. That N is inductive is used in “n+1∈N”.

B. Practice

Exercise (B1: An infimum)

Prove that inf{1/n:n∈Z>0}=0, and that the set has no minimum.

Solution. Let B:={1/n:n∈Z>0}; it is nonempty, since 1∈B. By Example (Every nonzero natural number is at least 1), 1/n>0 for every n, so 0 is a lower bound of B.

Let L be any lower bound of B; we show L≤0. Suppose instead L>0. By Corollary 1.5.2 with ε=L, there is n∈Z>0 with 1/n<L. This contradicts L being a lower bound of B. Hence L≤0. So 0 is a lower bound that is greater than or equal to every lower bound, that is, infB=0 (Definition 1.2.5).

Since 0∉B (every element is positive), the infimum is not attained, and B has no minimum.

Exercise (B2: Scaled Archimedes)

Let a>0 and y∈R. Prove that there is n∈N with na>y. What does this say when a is the length of a measuring stick?

Solution. Since a>0, the number y/a is defined. By Theorem 1.5.1 there is n∈N with n>y/a; the n depends on y and a. Multiplying by a>0 preserves the strict inequality (Theorem 1.1.2 (c)), so na>y.

In words: laying a stick of length a, however short, end to end enough times carries you past any given point y, however far away. This is the form in which Archimedes used the property.

Exercise (B3: Smaller than every 1/n)

Let x∈R with 0≤x<1/n for every n∈Z>0. Prove that x=0. Then deduce: if a,b∈R satisfy |a−b|<1/n for every n∈Z>0, then a=b.

Solution. Suppose x≠0. Since x≥0, we get x>0. By Corollary 1.5.2 with ε=x, there is n∈Z>0 with 1/n<x, contradicting the hypothesis x<1/n. Hence x=0.

For the second statement, put x:=|a−b|. Then 0≤x<1/n for every n, so x=0 by the first part, that is, a=b.

This is how equality is proved in analysis over and over: show that the distance is nonnegative and smaller than every 1/n.

Exercise (B4: Putting a proof in order)

Here are nine lines. Seven of them, in a suitable order, prove that supA=1 for A:={nn+1:n∈N}. Give an admissible order. Then say why each of the other two lines cannot be used.

  • (i) Let ε>0.
  • (ii) Hence a:=nn+1 is an element of A with a>1−ε.
  • (iii) For every n∈N, n<n+1 and n+1>0, so nn+1<1. Hence 1 is an upper bound of A.
  • (iv) By Corollary 1.5.2 there is n∈Z>0, depending on ε, with 1n<ε.
  • (v) Choose n∈Z>0 such that 1n<ε for every ε>0.
  • (vi) Since ε>0 was arbitrary, every band (1−ε,1] contains an element of A.
  • (vii) Then nn+1=1−1n+1, and 1n+1<1n<ε.
  • (viii) By Theorem 1.4.1, supA=1.
  • (ix) Fix n∈Z>0 and let ε:=1n; then nn+1=1−1n+1>1−ε.

Solution. An admissible order is (iii), (i), (iv), (vii), (ii), (vi), (viii). The line (iii) may stand anywhere before (viii), since it uses nothing but the definition of A. The other lines admit only this order. Inside the block that starts with (i), line (iv) needs the ε of (i), line (vii) needs the n of (iv), line (ii) needs (vii), and (vi) records that ε was arbitrary. Line (viii) needs both (iii) and (vi), the two hypotheses of Theorem 1.4.1.

Line (v) has the quantifiers in the wrong order. It asks for one n that works for every ε, and there is none: ε=1n itself would give 1n<1n. Corollary 1.5.2 gives an n for each ε.

Line (ix) is true, but its ε is of the wrong kind: it is chosen to fit n, instead of being given first. It shows only that the bands of the special widths 1n meet A, while Theorem 1.4.1 needs every band, of every width ε>0. Passing from the special widths to all widths is exactly the work of lines (iv) and (vii), which (ix) skips.

C. Going deeper

Exercise (C1: Exit check: the Archimedean property, and a circular proof)
  • (a) Without looking back, prove the Archimedean property from the least upper bound axiom. Mark the line that uses the axiom, and explain why that line fails in R(x).
  • (b) A student offers the following proof. “Let x∈R. Let n:=⌈x⌉+1, where ⌈x⌉ is the least integer that is greater than or equal to x. Then n>x.” Find the gap. Show that in R(x) the element x has no “least integer greater than or equal to it”.

Solution.

  • (a) Suppose N is bounded above in R. Since 0∈N, the set is nonempty, so by Axiom 1.3.1 it has a supremum s (this line uses the axiom). For every n∈N, also n+1∈N, since N is inductive, so n+1≤s by (S1), that is, n≤s−1. Hence s−1 is an upper bound of N, and (S2) gives s≤s−1, which is false. So N is not bounded above, which means that every x∈R is exceeded by some n∈N.

    In R(x) the set N is nonempty and bounded above by x (Example (A non-Archimedean field)), but it has no supremum. Any upper bound M gives a smaller one, M−1, because n+1≤M for every n∈N forces n≤M−1. So the marked line has nothing to produce, and there the proof stops.

  • (b) The gap is the existence of ⌈x⌉. The set {k∈Z:k≥x} has a least element only if it is nonempty, and it is nonempty exactly when some integer is at least x. That is (a form of) the Archimedean property, the statement being proved. The proof is circular.

In R(x), take the element x and suppose k∈Z satisfies k≥x. If k≤0, then k≤0<1<x. If k≥1, then k∈N and k<x by Example (A non-Archimedean field). Either way k<x, a contradiction. So no integer is greater than or equal to x, and ⌈x⌉ does not exist.

Marking scheme. (10 points) - 1: (a) supposes, for a contradiction, that N is bounded above, and notes 0∈N. - 2: (a) obtains s=supN from Axiom 1.3.1, with both hypotheses checked, and marks this line. - 2: (a) shows that s−1 is an upper bound of N: n+1∈N because N is inductive, so n+1≤s by (S1), that is, n≤s−1, for every n∈N. - 1: (a) applies the “least” property (S2) to the upper bound s−1, reaches s≤s−1, a contradiction, and concludes. - 1: (a) explains why the marked line fails in R(x): every upper bound M of N there has the smaller upper bound M−1. - 2: (b) names the existence of ⌈x⌉ as the gap, and says it already needs an integer at least x, which is what is being proved. - 1: (b) shows that no integer is at least x in R(x). Fatal errors (0 for the step): taking s to be a natural number, or the maximum of N; omitting “for every n” (one n with n≤s−1 does not make s−1 an upper bound); using ⌈x⌉, ⌊x⌋, or the Archimedean property inside (a). A proof of (a) that argues “by (S2), or Theorem 1.4.1 with ε=1, s−1 is not an upper bound, so some n>s−1, and then n+1>s” is also correct and earns the same 3 points for those steps; it uses one more classical step, inside the box (the remark after Theorem 1.5.1). A proof of (a) that applies the axiom to a bounded set of the form {n∈N:n≤x} instead earns full marks for (a) if it reaches a contradiction from the supremum in the same way.

Exercise (C2: The order on the rational functions)

Let P⊆R(x) be the set of positive elements defined in this section, and let f<g mean g−f∈P.

  • (a) Show that every nonzero f∈R(x) can be written as p/q with the leading coefficient of q positive, and that then f∈P if and only if the leading coefficient of p is positive.
  • (b) Show that for every nonzero f, exactly one of f∈P and −f∈P holds.
  • (c) Show that if f,g∈P, then fg∈P and f+g∈P.
  • (d) Deduce the order axioms of Definition 1.1.1 for <: trichotomy, transitivity, f<g⇒f+h<g+h, and f,g>0⇒fg>0.

Solution (Hint 1). Choose good representatives first. Every fraction can be rewritten so that its denominator has positive leading coefficient, and after that only the numerator decides positivity.

Solution (Hint 2). For the sum in (c), with both denominators normalized, write f+g=(p1q2+p2q1)/(q1q2) and split into two cases: the two terms of the numerator have different degrees, or the same degree.

Solution. Write lc(p) for the leading coefficient of a nonzero polynomial p. Recall that lc(pq)=lc(p)lc(q), since the top powers multiply.

  • (a) Let f=p/q. If lc(q)<0, then f=(−p)/(−q) and lc(−q)=−lc(q)>0. So we may assume lc(q)>0. Then “lc(p) and lc(q) have the same sign” means exactly lc(p)>0. By the well-definedness shown in the section, this does not depend on the chosen representation.

  • (b) Write f=p/q with lc(q)>0, as in (a). Then −f=(−p)/q and lc(−p)=−lc(p). Since p≠0, lc(p) is a nonzero real number, so by trichotomy in R exactly one of lc(p)>0 and −lc(p)>0 holds. By (a), exactly one of f∈P and −f∈P holds.

  • (c) Write f=p1/q1 and g=p2/q2 with all four leading coefficients positive, using (a). The product is fg=(p1p2)/(q1q2) with lc(p1p2)=lc(p1)lc(p2)>0 and lc(q1q2)>0, so fg∈P. The sum is f+g=p1q2+p2q1q1q2. Both p1q2 and p2q1 have positive leading coefficient. If their degrees differ, the leading coefficient of the sum is that of the term of higher degree, which is positive. If their degrees agree, it is the sum of the two leading coefficients, which is positive. In both cases the numerator is nonzero with positive leading coefficient, and lc(q1q2)>0, so f+g∈P.

  • (d) Trichotomy. Given f,g, either g−f=0, or g−f≠0 and by (b) exactly one of g−f∈P and f−g=−(g−f)∈P holds. So exactly one of f=g, f<g, g<f holds.

Transitivity. If f<g and g<h, then g−f∈P and h−g∈P, so h−f=(h−g)+(g−f)∈P by (c); that is, f<h.

Addition. If f<g, then (g+h)−(f+h)=g−f∈P, so f+h<g+h.

Products. If f>0 and g>0, then f=f−0∈P and g∈P, so fg∈P by (c); that is, fg>0.

Exercise (C3: Archimedean without the axiom)
  • (a) Prove, without using Axiom 1.3.1, that for every r∈Q there is n∈N with n>r.
  • (b) Deduce that the Archimedean property does not imply the least upper bound axiom in an ordered field.

Solution.

  • (a) Write r=m/k with m∈Z and k∈Z>0. If m≤0, then r≤0<1, and n=1 works. If m≥1, then m∈N. Since k≥1 (Example (Every nonzero natural number is at least 1)) and m>0, we get r=m/k≤m<m+1, and n:=m+1∈N works. No supremum was used: only the arithmetic of integers and the ordered-field rules.

  • (b) By (a), Q is an ordered field in which N is not bounded above, so Q has the Archimedean property. By Theorem 1.2.2, the nonempty set {x∈Q:x>0, x2<2}, which is bounded above by 2, has no supremum in Q. So Q is Archimedean and fails the least upper bound axiom, and the Archimedean property cannot imply the axiom.
