1.6  Density of the Rationals and the Existence of Roots

When we first met suprema, Theorem 1.2.2 showed that the set of positive rationals whose square is less than 2 has no supremum in Q. In R the axiom gives that set a supremum. This section finds out what the supremum is: a positive number whose square is exactly 2. The same template produces every root a1/n. With roots in hand, and with the Archimedean property of the previous section, we then answer a question about arrangement: the rationals and the irrationals are both spread through every interval of the line, however short.

1.6.1. Constructing a point as a supremum

Logic and Proof, Chapter 2 showed that no rational number squares to 2 (Logic and Proof, Theorem 2.2.1). Nothing so far says that any real number does. The ordered-field axioms cannot say it, since Q satisfies them all. So if a square root of 2 exists in R, the least upper bound axiom must produce it.

Theorem 1.6.1 (The Square Root of Two Exists)

There is exactly one real number s>0 with s2=2.

Try it first (ten minutes): the axiom is the only statement we have that produces a real number. To which set would you apply it, and what would you then have to show?

Idea. The obvious attempts do not get started. There is no formula for 2 in terms of rationals, and the decimals 1,1.4,1.41,… of the chapter’s introduction would need a limit, which we do not have yet. The only statement that produces a real number is Axiom 1.3.1, so 2 will have to be a supremum, and Theorem 1.2.2 suggests which one. Collect the positive reals whose square is below 2 into a set S. The candidate is s=supS. The plan has three steps: ① check that S is nonempty and bounded above, so the axiom supplies s; ② rule out s2<2; ③ rule out s2>2. Trichotomy then leaves s2=2.

Each case is ruled out by nudging s. If s2<2, there is still room below 2, so a slightly larger number s+h is still in S. That is impossible for an upper bound. If s2>2, a slightly smaller number s−h still has square above 2, and is therefore still an upper bound. That is impossible for the least upper bound.

The nudges are the ones found in Theorem 1.2.2, where they were derived backwards from the goal. To recall the first: we want (s+h)2=s2+2sh+h2<2. If h≤1, then h2≤h, so (s+h)2≤s2+(2s+1)h. Letting (2s+1)h use half of the room 2−s2 gives h=(2−s2)/(4s+2), and we must then check h≤1. For the second nudge, (s−h)2>s2−2sh, and the right side is 2 exactly when h=(s2−2)/(2s). None of this used rationality. What is new is only that s now exists.

Before reading on: which line of the proof uses the axiom, and what would that line say over Q?

Proof. Let S:={x∈R:x>0, x2<2}. By Example (A set of reals that must have a supremum), S is nonempty (it contains 1) and bounded above by 2, so by Axiom 1.3.1 its supremum s:=supS exists, and 1≤s≤2. In particular s>0 and s2≥1. Throughout we use Theorem 1.1.2 (g): for u,v≥0, u<v if and only if u2<v2.

Case 1: s2<2. Let h:=2−s24s+2, which depends only on s. Then h>0, because 2−s2>0 and 4s+2>0. Also h≤16, because 2−s2≤1 and 4s+2≥6. Hence h≤1, and multiplying by h>0 gives h2≤h. Therefore (s+h)2=s2+2sh+h2≤s2+(2s+1)h=s2+2−s22=1+s22<2, where the last inequality holds because s2<2. Also s+h>0. Hence s+h∈S. But s+h>s, which contradicts (S1), that s is an upper bound of S. So Case 1 is impossible.

Case 2: s2>2. Let h:=s2−22s, which is defined and positive because s>0 and s2>2. Then s−h=(s2+2)/(2s)>0, and (s−h)2=s2−2sh+h2=2+h2>2. We claim that s−h is an upper bound of S. Let x∈S and suppose x>s−h. Since s−h>0, we get x2>(s−h)2>2, contradicting x2<2. Hence x≤s−h for every x∈S. Then (S2) gives s≤s−h, which is false since h>0. So Case 2 is impossible.

By trichotomy, s2=2. For uniqueness, let t>0 with t2=2. If t<s, then t2<s2, and if s<t, then s2<t2; both contradict t2=2=s2. Hence t=s. This proves the theorem.

We write 2 for this number. By Logic and Proof, Theorem 2.2.1 it is not rational, so R≠Q: irrational numbers exist.

Compare this proof with the one of Theorem 1.2.2. The two computations with h are the same, word for word: they are ordered-field algebra, and for a rational s both values of h are rational. What changed is a single line. In Q there was no s to start from: the argument showed that no rational number can be the supremum, since its square cannot be less than 2, more than 2, or equal to 2. In R the axiom supplies s, and the very same argument now shows that its square can only be 2.

The proof is an instance of a move this book uses again and again.

To construct a point: collect the points where “things are still fine” into a set, take its supremum, and rule out each way the supremum could fail to be the point you want.

Here “things are still fine” meant x2<2. The exercises of this section and of the last section of the chapter ask you to run the move yourself, with less and less of the proof given. In Chapter 6 the Intermediate Value Theorem is proved the same way: the point where a continuous function crosses zero is the supremum of the points where it is still negative. In Chapter 4 the Heine–Borel theorem takes the supremum of the points x for which [a,x] is still covered by finitely many of the given open sets.

1.6.2. Roots of every order

The template does not care that the exponent is 2 or that the number is 2. Only the choice of h needs new work.

Theorem 1.6.2 (Existence of Roots)

Let a>0 and n∈Z>0. There is exactly one real number s>0 with sn=a.

We write this number a1/n, or an. For a=0 the only real s≥0 with sn=0 is s=0 (a product of positive numbers is positive), so we also set 0n:=0; every a≥0 then has exactly one nonnegative n-th root.

Idea. Take S={x>0:xn<a} and s=supS, as before, and rule out sn<a and sn>a. The new difficulty is the estimate. For n=2 we expanded (s+h)2 and bounded h2 by h. For general n, expanding (s+h)n is messy. We work backwards from what we need instead.

We need (s+h)n−sn<a−sn. A difference of n-th powers factors: yn−xn=(y−x)(yn−1+yn−2x+⋯+xn−1). With y=s+h and x=s, the first factor is h, which we control. The second factor is a sum of n terms, each at most (s+h)n−1. That still depends on h, and we cannot solve for h while h is on both sides. So we bound it by something a little bigger: if h<1, each term is at most (s+1)n−1. This gives (s+h)n−sn≤h⋅C,C:=n(s+1)n−1. The point is that C depends only on n and s, and not on h. Now it suffices to have hC<a−sn, and h=(a−sn)/(2C) does it, with a factor 12 to make the inequality strict. We needed h<1 along the way, so we cap h at 12.

For s−h the same factorization gives sn−(s−h)n≤h⋅nsn−1≤hC, so the same C, and the same h, serve both cases.

Proof. We first prove a power estimate.

Claim. Let 0≤x<y and k∈Z>0. Then xk<yk: the map x↦xk is strictly increasing on [0,∞). Consequently xm≤ym for every integer m≥0, where u0:=1. Moreover 0<yk−xk≤kyk−1(y−x).

Proof of Claim. Powers are defined by recursion (Sets, Relations, and Cardinality, Chapter 2): u0:=1 and uk+1:=uku, so that u1=u; here only k≥1 is needed.

We first show 0≤xk<yk by induction on k. For k=1 this is the hypothesis. If 0≤xk<yk, then xk+1=xkx≥0, and xk+1=xkx≤xky<yky=yk+1, where the first step multiplies x<y by xk≥0 (Theorem 1.1.2 (c), or equality if xk=0) and the second multiplies xk<yk by y>0. This proves the first statement, and the second follows, since for m=0 both sides are 1.

For the estimate, write Σ:=∑j=0k−1yjxk−1−j. Multiplying out, (y−x)Σ=∑j=0k−1yj+1xk−1−j−∑j=0k−1yjxk−j=yk−xk, since every other term appears once in each sum and cancels. Each term of Σ satisfies 0≤yjxk−1−j≤yjyk−1−j=yk−1, by the second statement with m=k−1−j, multiplied by yj>0; and the term with j=k−1 equals yk−1>0. Hence 0<Σ≤kyk−1. Multiplying by y−x>0 gives the claim.

Let S:={x∈R:x>0, xn<a}.

S is nonempty. Let x0:=a/(1+a). Then 0<x0<1 and x0<a. Since 0<x0<1, multiplying by x0 repeatedly gives x0n≤x0 (by induction on n). Hence x0n≤x0<a, and x0∈S.

S is bounded above by 1+a. If x≥1+a, then x≥1, so xn≥x (again by induction on n), and xn≥1+a>a. So x∉S.

By Axiom 1.3.1, s:=supS exists, and s≥x0>0. Let C:=n(s+1)n−1, which depends only on n and s. Suppose sn≠a, and let h:=min{12, |sn−a|2C}>0. Then hC≤12|sn−a|<|sn−a|.

Case 1: sn<a. Apply the claim with k=n, x=s, and y=s+h. Since s+h<s+1, the claim with m=n−1 gives (s+h)n−1≤(s+1)n−1 (both sides are 1 when n=1). Therefore (s+h)n−sn≤n(s+h)n−1h≤Ch<a−sn, so (s+h)n<a. Hence s+h∈S, although s+h>s. This contradicts that s is an upper bound of S.

Case 2: sn>a. First, s−h>0. Indeed (s+1)n−1≥sn−1 by the claim with m=n−1 (both sides are 1 when n=1), so h≤sn−a2C<sn2C≤sn2nsn−1=s2n<s. Apply the claim with k=n, x=s−h, and y=s: sn−(s−h)n≤nsn−1h≤Ch<sn−a, so (s−h)n>a. Now s−h is an upper bound of S: if x∈S had x>s−h, the claim would give xn>(s−h)n>a, contradicting x∈S. But s−h<s, which contradicts that s is the least upper bound.

Both cases are impossible, so sn=a by trichotomy. If also t>0 and tn=a, then t=s, since t<s or s<t would give tn≠sn by the claim. This proves the theorem.

For n=2 and a=2 the constant is C=2(s+1), slightly larger than the 2s+1 that the direct expansion gave. The general proof pays for its generality with a cruder bound. We never needed a good bound, only one that does not depend on h.

Example (Locating a cube root)

Show that 1.25<23<1.26.

Solution. By Theorem 1.6.2, s:=23 exists and s3=2. Exact arithmetic gives 1.253=1.953125<2<2.000376=1.263. The claim in the proof of Theorem 1.6.2 says that x↦x3 is strictly increasing on [0,∞). If s≤1.25, then s3≤1.253<2; and if s≥1.26, then s3≥1.263>2. Both contradict s3=2, so 1.25<s<1.26.

Remark. With n-th roots we can define am/n:=(a1/n)m for a>0, and check that the usual exponent laws hold for rational exponents. The powers ax with irrational x wait for the exponential function, which Chapter 10 builds from power series.

1.6.3. The integer part of a real number

Before asking where the rationals are, we need to locate every real number between two consecutive integers. This sounds like school arithmetic, and it is. But its proof uses both the Archimedean property and well-ordering, and in R(x) it fails for the element x (Exercise (C1: Exit check: the Archimedean property, and a circular proof)).

Lemma 1.6.3 (Integer Part)

For every y∈R there is exactly one integer m with m≤y<m+1.

This integer is the integer part or floor of y, written ⌊y⌋. For instance ⌊2.7⌋=2 and ⌊−2.7⌋=−3.

Idea. Picture the integers as marks spaced 1 apart. The Archimedean property puts a mark to the right of y, and a mark to the left of y. Among the marks to the right, well-ordering picks out the first one; the mark just before it is ⌊y⌋. Well-ordering is a statement about subsets of N, so we shift the marks so that they start at 0.

Proof. Existence. Let y∈R. By Theorem 1.5.1, there is p∈N with p>−y, and there is j∈N with j>y+p. Hence the set T:={j∈N:j−p>y} is nonempty. By well-ordering (Sets, Relations, and Cardinality, Chapter 2), T has a least element j0. Let m:=j0−p−1, an integer because differences of integers are integers (the remark on N in the previous section). Then m+1=j0−p>y, since j0∈T. It remains to show m≤y. First, 0−p=−p<y by the choice of p, so 0∉T and j0≠0. Hence j0≥1 (Example (Every nonzero natural number is at least 1)), so j0−1∈N (again from that remark), and j0−1∉T because it is smaller than the least element of T. So (j0−1)−p≤y, that is, m≤y.

Uniqueness. Suppose m and m′ are integers with m≤y<m+1 and m′≤y<m′+1, and suppose m<m′. Then m′−m is a positive integer, hence a nonzero natural number (the remark on N in the previous section), so m′−m≥1 by Example (Every nonzero natural number is at least 1); that is, m′≥m+1. Hence y≥m′≥m+1>y, a contradiction. By symmetry m′<m is impossible too, so m=m′.

1.6.4. The rationals are dense

We know now that irrational numbers exist. How are they arranged among the rationals? Could there be a whole interval with no rational number in it? No: every interval, however short, contains a rational.

Theorem 1.6.4 (Density of the Rationals)

Let x,y∈R with x<y. There is q∈Q with x<q<y.

Idea. Think of a ruler whose marks are the fractions k/n, spaced 1/n apart. If the spacing is smaller than the gap y−x, the ruler cannot jump over the interval (x,y): the first mark to the right of x is at most one step past x, and so it lands before y.

The plan: ① choose n with 1/n<y−x, by the Archimedean property; ② let m/n be the first mark strictly to the right of x, that is, m=⌊nx⌋+1; ③ check that m/n<y.

Proof. Let x<y. Then y−x>0, so by Corollary 1.5.2 there is n∈Z>0 with 1/n<y−x; the n depends on x and y, through y−x. By Lemma 1.6.3, let m:=⌊nx⌋+1, an integer, since sums of integers are integers (the remark on N in the previous section). Then m−1≤nx<m. Therefore nx<m≤nx+1<nx+n(y−x)=ny, where the last inequality uses 1<n(y−x), which is 1/n<y−x multiplied by n>0. Dividing by n>0 gives x<m/n<y. Since m∈Z and n∈Z>0, q:=m/n is rational. This proves the theorem.

Example (Running the proof)

Follow the proof of Theorem 1.6.4 to find a rational number between 2 and 32.

Solution. Step ①: the spacing. We need 1/n<32−2, that is, 2<32−1n. By Theorem 1.1.2 (g), applied to the positive numbers 2 and 32−1n, this holds exactly when 2<(32−1n)2. For n=12, 32−112=1712 and (1712)2=289144>288144=2, so n=12 works. (For n=11, (3122)2=961484<2, so 12 is the least n that works, but any n≥12 would do.)

Step ②: the first mark past x. We need ⌊122⌋. Since 162=256≤288=(122)2<289=172, Theorem 1.1.2 (g) gives 16≤122<17, so ⌊122⌋=16 and m=17.

Step ③: the answer. The proof guarantees 2<1712<32. Directly: (1712)2=289144>2 gives the left inequality, and 1712<1812 gives the right one.

The irrationals are just as widely spread. The trick is to shift the rationals by 2.

Corollary 1.6.5

Let x,y∈R with x<y. There is an irrational number z with x<z<y.

Proof. Since x−2<y−2, Theorem 1.6.4 gives q∈Q with x−2<q<y−2. Let z:=q+2. Then x<z<y. If z were rational, then 2=z−q would be a difference of rationals, hence rational, contradicting Logic and Proof, Theorem 2.2.1. So z is irrational.

This is why the existence of 2 came first in this section: the proof of Corollary 1.6.5 needs one irrational number to shift by, and Theorem 1.6.1 supplies it.

Quick check. Name a rational number between 2 and 1.415, and an irrational number between 0 and 10−6. Justify both.

Solution. Rational: 1.4143. Its square is 2.00024449>2, so 1.4143>2 by Theorem 1.1.2 (g), and 1.4143<1.415.

Irrational: z:=2⋅10−7. Since 1<2<2, we get 0<z<2⋅10−7<10−6. If z were rational, then 2=107z would be rational, contradicting Logic and Proof, Theorem 2.2.1.

Warning. “Dense” does not mean “next to each other”. There is no smallest positive rational number and no “next rational after 0”: if q>0 is rational, then q/2 is a smaller positive rational. The same holds for irrationals: if z>0 is irrational, so is z/2, and it is smaller. Between any two distinct rationals there are infinitely many more, and between any two distinct reals there are rationals and irrationals alike.

Density is what makes decimals, and more generally rational approximation, possible. Every real number can be pinned down by rationals from below as closely as we like (Exercise (B1: Every real number is a supremum of rationals)). In Metric and Topological Spaces the word dense becomes a notion in any metric space: a set that meets every ball. The rationals in the real line are the model example.

1.6.5. Exercises

A. Check your understanding

Exercise (A1)

True or false? Give a reason or a counterexample for each.

  • (a) There is a least positive irrational number.
  • (b) Between any two distinct rational numbers there is an irrational number.
  • (c) Between any two distinct irrational numbers there is a rational number.
  • (d) Every nonempty set of rationals that is bounded above has a supremum in R, and that supremum is rational.
  • (e) In the proof of Theorem 1.6.2, the constant C depends on h.
  • (f) Run Case 1 of the proof of Theorem 1.6.1 with the value 75 in place of s (so s2=4925<2): compute h, and check that (s+h)2<2. Which property of a supremum does this show 75 lacks?

Solution.

  • (a) False. If z>0 is irrational, then z/2 is positive, smaller than z, and irrational (if z/2 were rational, so would be z=2⋅(z/2)).

  • (b) True, by Corollary 1.6.5 applied to the two rationals.

  • (c) True, by Theorem 1.6.4 applied to the two irrationals.

  • (d) False. The set A:={x∈Q:x>0, x2<2} is nonempty and bounded above by 2, so it has a supremum s∈R by Axiom 1.3.1. If s were rational, it would be a rational upper bound of A that is at most every real upper bound, and in particular at most every rational one. So s would be a supremum of A in Q, contradicting Theorem 1.2.2. (In fact s=2.)

  • (e) False. C=n(s+1)n−1 depends only on n and s. It has to be independent of h, because h is then chosen in terms of C.

  • (f) Here 2−s2=125 and 4s+2=385, so h=1/2538/5=1190 and s+h=267190. Then (267190)2=7128936100<7220036100=2, and the proof’s bound gives the same: (s+h)2≤1+s22=9950<2. So 267190∈S and 267190>75: the number 75 is not an upper bound of S, so it fails (S1). This is no contradiction, because nothing said that 75 was the supremum. In the proof the same computation contradicts (S1) for s=supS.

B. Practice

Exercise (B1: Every real number is a supremum of rationals)

Let x∈R. Prove that x=sup{q∈Q:q<x}.

Solution. Let A:={q∈Q:q<x}. By Theorem 1.6.4 applied to x−1<x, there is a rational in (x−1,x), so A is nonempty. By definition every element of A is less than x, so x is an upper bound of A.

Let ε>0. By Theorem 1.6.4 applied to x−ε<x, there is q∈Q with x−ε<q<x. Then q∈A and q>x−ε. By Theorem 1.4.1, x=supA.

Exercise (B2: The square root of three, finished)

Here is the start of a proof that there is exactly one real s>0 with s2=3.

Let S:={x∈R:x>0, x2<3}. Then 1∈S, and if x≥2, then x2≥4>3; so S is nonempty and bounded above by 2. By Axiom 1.3.1, s:=supS exists, and s≥1.

Case s2<3. Let h:=(3−s2)/(4s+2). Then h>0. Since 3−s2≤2 and 4s+2≥6, we have h≤13, so h2≤h, and (s+h)2≤s2+(2s+1)h=3+s22<3. Hence s+h∈S, and s+h>s contradicts (S1).

Case s2>3. …

Name the move, then complete it. Give an explicit h for the second case and check that it works; then finish the proof, including uniqueness.

Solution. The move is construct a point as a supremum: the points where “things are still fine” (x2<3) form S, the axiom supplies s=supS, and each way s could fail (s2<3, s2>3) is ruled out. The given text rules out the first; the missing step rules out the second, against (S2) this time.

Case s2>3. Let h:=(s2−3)/(2s), which is defined and positive because s≥1 and s2>3. Then s−h=(s2+3)/(2s)>0 and (s−h)2=s2−2sh+h2=3+h2>3. If some x∈S had x>s−h, then, as s−h>0, Theorem 1.1.2 (g) would give x2>(s−h)2>3, which is impossible for x∈S. So s−h is an upper bound of S, and (S2) gives s≤s−h, which is false since h>0.

Both cases are impossible, so s2=3 by trichotomy. For uniqueness, let t>0 with t2=3. If t<s or s<t, then Theorem 1.1.2 (g) gives t2<s2 or s2<t2, contradicting t2=3=s2. Hence t=s.

Exercise (B3: The cube root of five)

Prove that there is exactly one real s>0 with s3=5. Hence show that 1.70<s<1.71.

Solution. By Theorem 1.6.2 with a=5 and n=3, there is exactly one s>0 with s3=5.

Exact arithmetic gives 1.703=4.913<5 and 1.713=5.000211>5. By the claim in the proof of Theorem 1.6.2, x↦x3 is strictly increasing on [0,∞). If s≤1.70, then s3≤4.913<5; if s≥1.71, then s3≥5.000211>5. Both contradict s3=5, so 1.70<s<1.71.

C. Going deeper

Exercise (C1: Exit check: the square root of two, in both fields)
  • (a) Prove that there is a real number s>0 with s2=2.
  • (b) Prove that the set {x∈Q:x>0, x2<2} has no supremum in Q.
  • (c) Both proofs use the same two values of h. Explain in two or three sentences why the same computation yields an existence theorem in R and a nonexistence theorem in Q.

Solution.

  • (a) This is Theorem 1.6.1. Let S:={x∈R:x>0, x2<2}; it contains 1 and is bounded above by 2, so s:=supS exists by Axiom 1.3.1, and s≥1. If s2<2, then h:=(2−s2)/(4s+2) satisfies 0<h≤16, so h2≤h and (s+h)2≤s2+(2s+1)h=1+s2/2<2, and s+h∈S exceeds the upper bound s: impossible. If s2>2, then h:=(s2−2)/(2s) satisfies s−h=(s2+2)/(2s)>0 and (s−h)2=2+h2>2; every x∈S then satisfies x≤s−h, since x>s−h would give x2>2. So s−h<s is an upper bound, contradicting (S2). By trichotomy s2=2.

  • (b) Let A:={x∈Q:x>0, x2<2}, and suppose r∈Q is a supremum of A in Q, that is, a rational upper bound of A that is at most every rational upper bound. As 1∈A, r≥1. By Logic and Proof, Theorem 2.2.1, r2≠2.

    If r2<2, let h:=(2−r2)/(4r+2). This is rational, and the computation of (a) gives (r+h)2<2. So r+h∈A and r+h>r, contradicting that r is an upper bound.

    If r2>2, let h:=(r2−2)/(2r). Then r−h=(r2+2)/(2r) is rational and positive, with (r−h)2=2+h2>2. As in (a), every x∈A satisfies x≤r−h, so r−h is a rational upper bound of A smaller than r, contradicting the choice of r.

    Both cases are impossible, so A has no supremum in Q.

  • (c) The computation shows, in any ordered field, that a supremum of the set cannot have square less than 2 or greater than 2. In R the axiom guarantees that a supremum exists, so its square must be 2: existence. In Q no element has square 2 (Logic and Proof, Theorem 2.2.1), so no case is left, and no supremum can exist. For rational r the values of h are rational, which is why the argument stays inside Q.

Marking scheme. (10 points) - 1: (a) defines S, checks that it is nonempty and bounded above, and takes s=supS from Axiom 1.3.1. - 2: (a) rules out s2<2 with an explicit h>0, verifying (s+h)2<2 including any side condition such as h≤1, and contradicts (S1). - 2: (a) rules out s2>2 with an explicit h>0, verifying s−h>0 and that s−h is an upper bound, and contradicts (S2). - 1: (b) supposes a rational supremum r and excludes r2=2 by Logic and Proof, Theorem 2.2.1. - 2: (b) in each case checks that the new number is rational and derives the contradiction with “upper bound in Q” or “least among rational upper bounds”. - 2: (c) says that the computation excludes s2<2 and s2>2 in any ordered field, that in R the axiom supplies s so s2=2 remains, and that in Q nothing remains. Fatal errors (0 for the step): using 2 to define S or h; asserting s+h∈S or (s−h)2>2 without the computation; an h that depends on an element of S rather than on s alone. A proof with a different h (for instance h=min{1,(2−s2)/6} in Case 1, using 2s+1≤5) earns full marks if its bound is verified.

Exercise (C2: Dyadic rationals)

A dyadic rational is a number of the form m/2k with m∈Z and k∈N. Prove that between any two real numbers x<y there is a dyadic rational.

Hint: compare 2k with k.

Solution. First, 2k>k for every k∈N, by induction (Logic and Proof, Axiom 3.2.1; Logic and Proof, Exercise (B1) even gives 2k≥k+1): 20=1>0, and if 2k>k, then 2k+1=2k+2k>k+1, since 2k≥1.

Let x<y. By Corollary 1.5.2 there is k∈Z>0 with 1/k<y−x; the k depends on y−x. Then 1/2k<1/k<y−x. By Lemma 1.6.3, let m:=⌊2kx⌋+1. Then m−1≤2kx<m, and 2kx<m≤2kx+1<2kx+2k(y−x)=2ky, using 1<2k(y−x). Dividing by 2k>0 gives x<m/2k<y.

The proof is that of Theorem 1.6.4 with the ruler of step 1/n replaced by one of step 1/2k. Only the choice of step size changed; any family of steps that can be made smaller than every ε>0 would do.

Exercise (C3: Find the faulty line)

A student proves Theorem 1.6.4 as follows. Let x<y.

  • (1) Let R:={r∈Q:r>x}. By Theorem 1.5.1 some natural number exceeds x, so R is nonempty.
  • (2) By well-ordering, R has a least element q.
  • (3) By Corollary 1.5.2, choose n∈Z>0 with 1/n<y−x.
  • (4) Since q−1/n is rational and smaller than the least element q of R, it is not in R. So q−1/n≤x, and hence q≤x+1/n<y.
  • (5) Therefore q∈Q and x<q<y.

Is the statement the student is proving true? Does the argument prove it? Find the line that fails and say why. Show that for x=0 the set R has no least element. Then repair the proof by changing R so that the faulty line becomes correct.

Solution. The statement is true: it is Theorem 1.6.4. So there is no counterexample to the conclusion, and the only question is whether the argument proves it. It does not.

Line (2) fails. Well-ordering says that a nonempty subset of N has a least element. The set R is a set of rationals, not of natural numbers, and it need not have a least element. For x=0, R is the set of positive rationals; if q∈R, then q/2∈R and q/2<q. So no element of R is least. Lines (3)–(5) are correct once a least element is available.

Repair. Fix n first, as in line (3), and replace R by a set of integers: Rn:={m∈Z:m/n>x}. By Lemma 1.6.3, its least element is m:=⌊nx⌋+1: indeed m/n>x, while (m−1)/n≤x. Now line (4) holds with q:=m/n: since (m−1)/n=q−1/n≤x, we get q≤x+1/n<y. This is the proof of Theorem 1.6.4. The point is that the step 1/n is fixed first, so the candidates m/n form a copy of the integers, where “least” makes sense.
