8.6  Checking Proofs, and What Is Not Allowed

A reader working alone must judge proofs, including their own, and is the person least able to do it. The remedy is procedural. This section gives two questions to ask of every line and a catalogue of the errors that recur, each tied to the rule of Chapters 1–7 that it breaks, and then checks four short proofs line by line.

8.6.1. Two questions for every line

A proof is correct when every line is licensed: by Definition 1.4.2, each line is a premise (a hypothesis, a proved result or a true school fact), an assumption, or one rule applied to available lines. So checking a proof means asking two questions of every line, with the answers in two columns.

  • Is it true? Is the line correct whenever the hypotheses and the assumptions of the open boxes are true?
  • Does it follow, and by which rule? From which available lines, and by which rule?

The first column finds where to look; the second decides.

The two questions are different. A line can be true and not follow: a correct fact the proof has not earned. This is the dangerous case, because nothing about the line looks wrong.

It follows It does not follow
It is true the normal case: “n=2k, so n2=2(2k2)”, in a proof that n2 is even when n is the dangerous case: Proof B’s last line, “if n2 is even, then n is even”, true and not earned
It is false the fault is higher up: from the false line “every real x has x≥1 or x≤0”, ∀E at 12 gives “12≥1 or 12≤0”, which follows and is false “x<1, so x2<1”: false at x=−2

“False” means false in some situation where the hypotheses and the open assumptions are true. When a line follows and is false, some line it rests on, neither a hypothesis nor an open assumption, is false there too, because the rules never lead from true lines to a false one (Theorem 4.7.2); follow it back until the second column fails.

A “no” in the first column marks a line to look at first; only the second column decides. The silent steps are those of Definition 8.3.2.

The same holds for derivations with quantifiers and equality, by the soundness statement for predicate logic in Section 7.2 (“From counter-models to non-derivability”).

(Proof C’s “1 is even” is true given its box’s assumption.)

Quick check. A proof that n2≥n for every integer n opens with the line “n2−n=n(n−1)≥0”. Is the line true? Does it follow? Would the answers change if n ranged over the reals?

Solution. For an integer n the line is true: no integer lies strictly between 0 and 1, so n≤0 (both factors ≤0) or n≥1 (both ≥0). But as written it follows from nothing: it is the goal rearranged, without the case split that makes it true. For real n it is false at n=1/2, where n(n−1)=−1/4. The first column depends on the situation; the second fails in both.

8.6.2. The catalogue

Most wrong proofs fail in one of a few ways, each breaking a particular rule. The entries fall into seven families.

Family Entries Slogan
“For all” errors (N1), (N2), (N3) A “for all” needs one argument about a name that is new and arbitrary.
Naming errors (N4), (N12) A new choice gets a new name, and two names may name one thing.
Implication errors (N5), (N6) The box of P→Q opens with P; Q alone gives no P.
Case errors (N7), (N8) Every case, from a disjunction that covers everything.
Scope and citation errors (N9), (N10) Cite only what is proved, given, or open around you.
Negation errors (N11) Negate exactly: an RAA box opens with the negation of the goal; negate the quantifier, not the bound; φ∧¬ψ, not an implication.
Iteration and existence errors (N13), (N14) An “and so on” needs its step; a “the” needs its object.
Example (What is not allowed)

Each entry names the error, the rule it breaks and where that rule lives, and a failing instance whose conclusion is marked true or false: a wrong argument can reach either.

  • (N1) Verifying instances and concluding “for all”. Breaks ∀I, which needs one proof about a fresh name (Definition 5.4.1, Section 5.4). Instance: n2−n+11 is prime for n=0,1,…,10 (the values are 11,11,13,17,23,31,41,53,67,83,101), “so it is prime for every n∈N”. False: at n=11 the value is 121=112.
  • (N2) A witness that depends on a variable introduced later, while uniformity is claimed. Breaks the side conditions of ∃E and ∀I: a witness δ0 obtained inside the box of x0 may not leave it (Section 6.4, Example (The search from C to UC)). Instance: “x2 is continuous at every x, with δ=min{1,ε/(2|x|+1)}; so one δ for each ε serves every x, and x2 is uniformly continuous on R”. False (Example (The square function on the real line)).
  • (N3) Treating the name from ∃E as arbitrary. Breaks the side condition of ∀I: the witness appears in the open assumption of its box (Definition 5.6.1, Section 5.6). Instance: “Some element of A is positive; let x be such an element. Since x was arbitrary, every element of A is positive.” False for A={−1,1}.
  • (N4) Reusing one witness name for two ∃E’s. Breaks the fresh-name condition: the second name may not appear in an open assumption, and the first box’s assumption mentions it (Section 5.6, Example (The sum of two even integers is even)). Sibling boxes may share a name. Instance: “m and n are even, so m=2k and n=2k for an integer k; hence m=n”. False: m=2, n=4.
  • (N5) Proving the converse. Breaks →I, whose box opens with the hypothesis, not the conclusion (Definition 1.4.1, Section 1.4). Instance: “If x2>1, then x>1: suppose x>1; then x2>x>1.” False: x=−2. Argument B of Section 1.1 makes the same move with a true conclusion.
  • (N6) Affirming the consequent; denying the antecedent. Breaks Definition 1.4.2 (Section 1.4), being no rule: P→Q with Q gives no P, and with ¬P gives no ¬Q. Each pattern has a refuting row, so no derivation exists (Corollary 4.7.3, Section 4.7): Example (Affirming the consequent is not valid), and for denying the row P false, Q true. Instances: “a multiple of 4 is even and 6 is even, so 6 is a multiple of 4”; “… and 6 is not a multiple of 4, so 6 is not even”. Both false.
  • (N7) A missing case. Breaks ∨E, which needs one box for each disjunct (Definition 1.6.1, Section 1.6). Instance: “|x|>0 for every real x: every real x has x>0, x=0 or x<0; if x>0, |x|=x>0; if x<0, |x|=−x>0”. False: the case x=0 was dropped, and |0|=0.
  • (N8) Cases that do not exhaust. Breaks ∨E, whose first input must be a disjunction already derived (Section 1.6). Instance: “x2≥x for every real x: either x≥1 or x≤0; in the first case x2=x⋅x≥x, in the second x2≥0≥x”. False: x=1/2 satisfies neither case, and 1/4<1/2.
  • (N9) Citing a line that is not available: the goal itself (circular reasoning), a result proved later, or a general “fact” neither proved nor a true school fact (a false “fact” never qualifies). Breaks Definition 1.4.2: every line is a premise, an assumption, or a rule applied to available lines (Section 1.4). Instances: “if n2 is even, then n is even: suppose n2 is even; since n is even, …” (true, and circular); “x<1, so x2<1, since squaring preserves <” (false: x=−2).
  • (N10) Using an assumption after its box has closed. Breaks the scope rule of Definition 1.4.2 (Section 1.4). Instance: “Suppose n is even, say n=2k; then n2=4k2. Hence if n is even, 4∣n2. Now n2=4k2, so 4∣n2 for every integer n.” False: n=1. Proof D below makes the same move with a true conclusion.
  • (N11) A wrong negation, in three forms. Each breaks RAA, which closes only a box opened with ¬φ (Section 2.5), or the laws of Section 6.2.
      • (a) An RAA box opened with a statement that is not the negation of the goal. Instance: “if x2>9 and x>0, then x>3: suppose, for a contradiction, that x<3; then 0<x<3 gives x2<9, against x2>9; hence x>3” (true: the box should open with x≤3, and the case x=3 is never examined).
      • (b) A bound negated instead of a quantifier (Proposition 6.2.3). Instance: “an=0 does not converge to 0, since some ε≤0 has |an−0|≥ε for all n” (false).
      • (c) The negation of φ→ψ written as an implication, ¬φ→¬ψ or φ→¬ψ, instead of φ∧¬ψ (Proposition 6.2.2). Instance: “if x>2, then x2>4” is “refuted” because “if x≤2, then x2≤4” holds at x=0 (false: both are true at x=0, so one is not the negation of the other).
  • (N12) Distinct letters taken for distinct objects. Two names introduced separately are treated as naming different objects, though no line says they differ. Breaks ∀I: a box opened for two arbitrary names must cover every pair, including the pairs in which both name one object (∀E may put the same term for both, Definition 5.3.1). Instance: “if a and b are roots of x2−5x+6=0, then a+b=5: the two roots give x2−5x+6=(x−a)(x−b), and comparing coefficients, a+b=5”. False: a=b=2 are roots, and 2+2=4.
  • (N13) An “and so on” with nothing behind it. A step is repeated “and so on”, and its outcome is used for every stage, but the passage from each stage to the next, or the reason the process ends, is never proved. Breaks Axiom 4.2.1 (or Theorem 4.2.2): →E on the axiom needs its step as a line, and “and so on” is not that line. Instance: “a non-empty set A of positive rational numbers has a least element: take a1∈A; if it is not least, take a2∈A with a2<a1, and so on, until the least element is reached” (false: {1/n:n∈Z>0} has no least element, and the process never ends).
  • (N14) An object named before it is shown to exist. A step names an object, with “the …” or “let … be the …”, and so presupposes that such an object exists (for “the”, exactly one), though no line states or proves it. In (N9) the step asserts a fact that is not available; here the missing premise is never asserted at all, because it hides inside a name. Breaks ∃E, which opens its box only by citing a line ∃xφ (Definition 5.6.1), and the use of “the” (Section 5.8), which needs existence and uniqueness. Instance: “let N be the largest natural number; then N+1≤N, so 1≤0” (false: the presupposed premise, that a largest natural number exists, is false).
↺Second readingTrue conclusions behind an ‘and so on’ and a ‘the’

Both new kinds of error can reach a true conclusion. The words of (N13)’s instance, said of a non-empty set of natural numbers, reach a true conclusion, but they leave out why the process ends: a strictly decreasing list of natural numbers that starts at a1 has at most a1+1 terms, which needs an induction. “Let m be the least positive integer with m2>50; since 72=49 and 82=64, m=8” reaches a true conclusion too, but the existence of a least such integer is a premise the proof must state: it is (N14). The barber who shaves exactly the villagers who do not shave themselves is (N14) as well; Section 5.6 shows that no such barber can exist (Theorem 5.6.3).

An entry diagnoses a step, not the conclusion: a false instance shows the step leading from true premises to a false conclusion, and a true one that a correct conclusion does not excuse it. Some entries name errors met before: (N1) is the first error of Section 5.4’s list, and parts (b) and (c) of (N11) are warnings of Section 6.2.

The catalogue lists steps that can lead from true lines to a false one. A step can also be valid but improper. “For all reals a and b, a2+b2≥2ab; so for all reals b and a, a2+b2≥2ab”, taken as one line, never leads from truth to falsehood, but no rule of the book writes it in one line, TAUT included (Section 8.3). That is a matter of level (Definition 8.3.1), not an error: at level 0 it is ∀E twice and ∀I twice, and in prose it needs no words.

Older books name some of these errors as fallacies:

Traditional name Entry
hasty generalization (N1)
equivocation: one name for two things (N4)
affirming the consequent; denying the antecedent (N6)
false dichotomy (N8)
begging the question (N9)
a presupposition (“the …”) (N14)

Affirming a disjunct is a common error of Section 1.6.

Quick check. Which family, and which entry, does this belong to: “Some integer n has n2=n+6; fix such an n. Since n was arbitrary, every integer n satisfies n2=n+6”?

Solution. A “for all” error, (N3): a name chosen by ∃E is not arbitrary. The premise holds at n=3; the conclusion fails at n=0.

Quick check. Which entry does the sentence “choose N larger than every Nε, one for each ε>0” commit, and when is the same move not an error?

Solution. (N2). Each Nε comes from ∀ε∃N, inside the box of its own ε; one N above all of them would be uniform, as if the hypothesis were ∃N∀ε, and usually none exists, since the Nε can grow without bound as ε shrinks. The move is legitimate when ε ranges over finitely many values ε1,…,εk: then max{Nε1,…,Nεk} exists, because a finite set of natural numbers has a maximum.

Warning. A true conclusion does not make a proof correct. “I know the result is true” answers the first column for the last line and nothing else. Argument B of Section 1.1 has a true conclusion and only true sentences, and it is wrong (Proof B below).

8.6.3. Four proofs, checked

Here are four short proofs as a student might write them; two are correct and two are not.

Example (Proof A)

Claim. For a real number x, if x2−3x+2<0, then 1<x<2.

  1. Assume x2−3x+2<0. (2) Then (x−1)(x−2)<0. (3) A product of two real numbers is negative only when one factor is positive and the other negative, so either x−1>0 and x−2<0, or x−1<0 and x−2>0. (4) In the first case, 1<x<2. (5) In the second case, x<1 and x>2, which is impossible. (6) Hence 1<x<2.

Solution.

Line True? Follows? By which rule?
(1) assumption opens the →I box
(2) yes: (x−1)(x−2)=x2−3x+2 =E with the algebraic identity
(3) yes →E with the stated fact about signs; a disjunction of two conjunctions
(4) yes, in this case ∨E, case 1: ∧E gives x>1 and x<2
(5) the case is impossible ∨E, case 2: x>2 and x<1 give 2<1, which clashes with ¬(2<1) (¬E); the case reaches 1<x<2 by ⊥E
(6) yes ∨E on (3), (4), (5); then →I on (1)–(6)

Verdict: correct. The disjunction of line (3) is derived from a stated fact, so the cases exhaust and (N8) does not apply. Line (5) is the one to look at twice: “which is impossible” is ⊥E, which lets a case that cannot occur reach the goal, so that ∨E can combine the cases. By Definition 8.3.2 it could be silent, since the clash is stated.

Example (Proof B)

Claim. For an integer n, if n2 is even, then n is even.

  1. Suppose n is even. (2) Then n=2k for some integer k. (3) So n2=4k2=2(2k2). (4) Hence n2 is even. (5) Therefore, if n2 is even, then n is even.

Solution.

Line True? Follows? By which rule?
(1) assumption opens a box, with “n is even”
(2) yes, given (1) the definition of “even”, then ∃E with a fresh k
(3) yes algebra
(4) yes, given (1) ∃I with the witness 2k2: the definition of “even”
(5) the statement is true, but … does not follow: →I on the box (1)–(4) gives “if n is even, then n2 is even”, not (5)

Verdict: wrong; line (5) fails; entry (N5). Every line is true, and lines (1)–(4) prove the converse. →I turns a box from P to Q into P→Q, with the box’s assumption on the left; writing the claim instead is the step from P→Q to Q→P. That step has a refuting row, P false and Q true, so no derivation makes it (Corollary 4.7.3); and it fails in practice: “if x>1, then x2>1” is true, its converse false at x=−2. This is Argument B of Section 1.1, diagnosed in Section 1.4. The claim is true: Theorem 2.1.3 proves it in a box that opens with “n2 is even”.

Example (Proof C)

Claim. For an integer n, the number n2−2 is not divisible by 4.

  1. Suppose n2−2 is divisible by 4, say n2−2=4k with k an integer. (2) Then n2=4k+2=2(2k+1), so n2 is even. (3) By Theorem 2.1.3, n is even, say n=2m with m an integer. (4) Then n2=4m2, so 4m2=4k+2, and hence 1=2(m2−k). (5) So 1 is even. (6) But 1 is odd, and no integer is both even and odd; this is a contradiction. (7) Hence n2−2 is not divisible by 4.

Solution.

Line True? Follows? By which rule?
(1) assumption opens the ¬I box, with “4 divides n2−2”; then ∃E with a fresh k
(2) yes, given (1) algebra, then ∃I with witness 2k+1
(3) yes, given (2) →E with Theorem 2.1.3 and (2); then ∃E with a fresh m
(4) yes, given (1) and (3) algebra: subtract 4k, divide by 2
(5) yes, given (4) ∃I with witness m2−k, an integer
(6) yes ∧I of (5) and “1 is odd”, then ¬E against “no integer is both even and odd”
(7) yes ¬I on the box (1)–(6)

Verdict: correct. The goal is a negation, and the ¬I box opens with the positive statement: a proof “by contradiction” of face (i) of Section 8.1, with no RAA. The witness names k and m differ, as (N4) requires.

Example (Proof D)

Claim. For a real number x: if x>1, then x2>x; and x2+1>x.

  1. Suppose x>1. (2) Multiplying both sides by x, which is positive, gives x2>x. (3) Hence if x>1, then x2>x. (4) For the second part, x2+1>x2, and x2>x by (2), so x2+1>x.

Solution.

Line True? Follows? By which rule?
(1) assumption opens the →I box for the first conjunct
(2) yes, given (1) →E with “multiplying by a positive number keeps >”; x>0 since x>1>0
(3) yes →I on the box (1)–(2)
(4) “x2>x” is false for x=1/2 does not follow: it cites (2), which lies inside the box closed at (3)

Verdict: wrong; line (4) fails; entry (N10). The claim is a conjunction, so the skeleton is ∧I with two separate proofs. The second cites line (2), derived inside the box that assumed x>1 and closed at line (3), so line (2) is not available. The first column confirms it: at x=1/2, x2=1/4<1/2=x, a counterexample to the illegal step, though not to the claim.

The claim is true. For every real x, x2−x+1=(x−12)2+34>0, since a square is non-negative; so x2+1>x, with nothing from the closed box.

In Proofs B and D every sentence sounds right, and in Proof B every sentence is true. The errors are in the connections, which the rules govern: “which rule, from which available lines?” catches both.

Remark (Looking ahead). From Sets, Relations, and Cardinality, Chapter 1 on, a warning about one of these errors cites its entry by number, as in “(N3) of the catalogue”.

8.6.4. Exercises

A. Check your understanding

Exercise (A1)

Each line below comes from a proof. Name the catalogue entry of Example (What is not allowed) that it commits, and the rule it breaks.

  • (a) “We checked 3n>n2 for n=0,1,2,3,4, so it holds for every n∈N.”
  • (b) “By hypothesis some x∈A has f(x)=0; fix such an x. Since x was arbitrary, f(x)=0 for every x∈A.”
  • (c) “To prove that f(x1)=f(x2) implies x1=x2, suppose x1=x2; then f(x1)=f(x2).”
  • (d) “To prove x>0, suppose, for a contradiction, that x<0.”
  • (e) “If n is divisible by 6, then n is even. Since n is even, n is divisible by 6.”
  • (f) “Every real x satisfies x>0 or x<0; we consider the two cases.”

Solution. (a) (N1): ∀I needs one proof about a fresh name, not five instances.

(b) (N3): x was chosen by ∃E and appears in the open assumption f(x)=0, so ∀I on it breaks the side condition. For A={0,1} and f(x)=x the conclusion fails.

(c) (N5): the →I box opens with the conclusion, so it proves the converse, which every function satisfies.

(d) (N11) (part (a)): the negation of x>0 is x≤0, not x<0, so RAA cannot close this box with x>0; the case x=0 is never examined, and ¬I on the box gives only x≥0.

(e) (N6), affirming the consequent. No rule licenses it, so it breaks Definition 1.4.2: P→Q with Q gives no P. Here n=4 is even and not divisible by 6.

(f) (N8): the disjunction is not derived, and it is false at x=0, so ∨E has no valid first input.

Exercise (A2: Drill)

Name the entry of Example (What is not allowed) that each line commits, if any, and say whether its conclusion is true.

  • (a) “We checked that n2+n is even for n=1,…,6, so it is even for every n.”
  • (b) “Let ε>0 and choose N with |an−L|<ε for n≥N; since ε was arbitrary, this one N works for every ε.”
  • (c) “x and y are odd, so x=2k+1 and y=2k+1.”
  • (d) “If n is divisible by 4, then n is even; n is not divisible by 4, so n is not even.”
  • (e) “n3−n is even for every integer n: if n is even, say n=2k, then n3−n=2(4k3−k); so n3−n is even.”
  • (f) “Suppose x>0; then x2>0. Hence if x>0, then x2>0. Since x2>0, …”
  • (g) “The negation of ‘for every ε>0, |x|<ε’ is ‘for some ε≤0, |x|≥ε’.”
  • (h) “To prove ‘if n2 is odd, then n is odd’: suppose n is odd; then n2 is odd.”
  • (i) “Let x and y be solutions of x2=9. Then x2−y2=0, so (x−y)(x+y)=0, and since x≠y, x+y=0.”
  • (j) “a1=2 and an+1=an2−2. Then a2=2, a3=2, and so on, so an=2 for every n≥1.”
  • (k) “Let n be the positive integer with n2=2. Then 1<n2<4, so 1<n<2.”
  • (l) “From ‘x>0’ and ‘(x>0 implies y>0) and (y>0 implies z>0)’, conclude ‘z>0’ in one line.”

Solution.

  • (a) (N1); true (n2+n=n(n+1)), still not a proof.

  • (b) (N2); in general false.

  • (c) (N4); false (x=1, y=3).

  • (d) (N6), denying the antecedent; false (n=2).

  • (e) (N7), a missing case: the odd case is never written. The conclusion is true (n3−n=(n−1)n(n+1), and of n−1, n one is even), still not a proof.

  • (f) (N10); “x2>0” is false at x=0.

  • (g) (N11), part (b); false. The stated “negation” holds for every x (take ε=−1), also at x=0, where the original holds too, so it is not the negation; the negation is “for some ε>0, |x|≥ε”.

  • (h) (N5); the claim is true, but the proof proves the converse.

  • (i) (N12) (the “since” also cites the unavailable line x≠y, an (N9) step); false: x=y=3 gives x+y=6.

  • (j) (N13); true. The step “if an=2, then an+1=4−2=2” is one line, and the proof must write it, as the step of an induction.

  • (k) (N14). The presupposed premise, that such an integer exists, is false, and so is the conclusion that an integer lies strictly between 1 and 2.

  • (l) No entry. No primitive rule writes the step in one line: at level 0 it is ∧E twice and →E twice. From Section 6.3 on, a single TAUT line on the propositional skeleton (Proposition 6.3.1), citing both premises, also writes it (Section 8.3). Either way it is a matter of level, not an error.

B. Practice

Exercise (B1: Two proofs in two columns)

Check each proof in two columns. For a wrong proof, name the first line that fails and its catalogue entry, and say whether the claim is true.

  • (i) Claim. For integers m and n, if m and n are odd, then m+n is even. (1) Assume m and n are odd. (2) Choose integers k and l with m=2k+1 and n=2l+1. (3) Then m+n=2k+2l+2=2(k+l+1). (4) Since k+l+1 is an integer, m+n is even.
  • (ii) Claim. For a real number x, if x2<1, then x<1. (1) Assume x2<1. (2) Suppose, for a contradiction, that x>1. (3) Then x>0, so x2=x⋅x>x>1. (4) This contradicts x2<1. (5) Hence x<1.

Solution. (i)

Line True? Follows? By which rule?
(1) assumption opens the →I box
(2) yes, given (1) ∧E, the definition of “odd”, and two ∃E’s with the different fresh names k and l
(3) yes algebra, =E in a chain
(4) yes ∃I with the witness k+l+1; then the boxes close, and →I

Verdict: correct. In (2) the second witness has a new name, as (N4) of Example (What is not allowed) requires.

(ii)

Line True? Follows? By which rule?
(1) assumption opens the →I box
(2) assumption opens a box with “x>1”, announced as RAA
(3) yes, given (2) →E with order facts
(4) yes (3) gives ¬(x2<1) by order facts; ¬E on (1) and that line
(5) true, given (1), but … does not follow: the box assumed x>1, which is not the negation of x<1; ¬I on it gives only ¬(x>1), that is, x≤1

Verdict: wrong; line (5) fails, because the box of line (2) opened with the wrong statement; entry (N11). The negation of x<1 is x≥1, and the case x=1 is never examined: x=1 has ¬(x>1) and not x<1, a counterexample to the step. The claim is true. Repair: suppose, for a contradiction, that x≥1; then x2=x⋅x≥x≥1, which contradicts x2<1; hence x<1.

Exercise (B2: Find the error)

Find the error in the following proof, name its catalogue entry, and decide whether the claim is true.

Claim. For all real numbers x and y, |x|+|y|=|x+y|.

  1. Let x and y be real numbers. (2) Either x and y are both ≥0, or they are both <0. (3) If both are ≥0, then x+y≥0, so |x|+|y|=x+y=|x+y|. (4) If both are <0, then x+y<0, so |x|+|y|=−x−y=−(x+y)=|x+y|. (5) In either case |x|+|y|=|x+y|.

Solution. Line (2) fails. Its disjunction is not derived, and it is false when x and y have opposite signs, so line (5) combines cases that do not exhaust: entry (N8) of Example (What is not allowed). Lines (3) and (4) are correct in their cases.

The claim is false: for x=1, y=−1, |x|+|y|=2 and |x+y|=0; this pair satisfies neither case of line (2). What is true is |x+y|≤|x|+|y| (Example (The triangle inequality by cases)).

Exercise (B3: Correct, or which entry?)

Each proof below is correct, or commits one of (N12), (N13), (N14); you are not told how many of each. For a correct proof, name its most delicate step. For a wrong one, name the entry, say whether the claim is true, and give a counterexample to the claim or a repair of the proof.

  • (i) Claim: for all integers m, n, if m and n are odd, then mn is odd. Proof: write m=2k+1 and n=2l+1 with integers k, l; then mn=4kl+2k+2l+1=2(2kl+k+l)+1.
  • (ii) Claim: for all real a, b, if a2=b2, then a=b or a=−b. Proof: (a−b)(a+b)=a2−b2=0, and a product of real numbers is 0 only if a factor is.
  • (iii) Claim: for all integers m, n, m2+n2≥1. Proof: two different integers are not both 0, so one of m2, n2 is at least 1.
  • (iv) Claim: every integer n≥2 is a product of primes. Proof: if n is prime, it is a product of one prime. If not, n=ab with 1<a,b<n; split a and b in the same way, and so on, until only primes remain.
  • (v) Claim: 1 is a solution of x2+x+1=0. Proof: let x be the real solution. Then x3−1=(x−1)(x2+x+1)=0, so x3=1, and since x is real, x=1.

Solution. (i) Correct. The delicate step is the second ∃E, which uses a second name l. The case m=n is covered, since nothing stops k=l: the names are distinct, the objects need not be.

(ii) Correct. The delicate step is the product fact. It gives “a−b=0 or a+b=0” (→E, citing it), which is the claim, and no distinctness is assumed.

(iii) (N12); the claim is false: m=n=0 gives 0. The proof took m and n to be different integers.

(iv) (N13); the claim is true. The “and so on” hides why the splitting ends: each factor is at least 2 and smaller than the number split. Repair by strong induction (Theorem 4.2.2): if every k with 2≤k<n is a product of primes, so is n, being prime or ab with a, b in that range.

(v) (N14); the claim is false: 1+1+1=3≠0. The presupposed premise “x2+x+1=0 has a real solution” is false, since x2+x+1=(x+12)2+34>0.

Look-alikes: (i) and (iii) both use two letters; only (iii) assumes the letters differ.

Marking scheme. (10 points: 2 per part) - 1: the verdict. - 1: for a correct proof, the delicate step named; for a wrong one, the entry with a counterexample (iii, v) or a repair (iv). Fatal errors (0 for that part): calling (i) an instance of (N12) because k and l might be equal; calling (iv) correct.

Exercise (C2: A true conclusion)

Here is a proof that 2+3 is irrational, a true conclusion. Find the line that fails and its catalogue entry, give a counterexample to the illegal step, and write a correct proof.

  1. Suppose 2+3=r for some rational number r. (2) Squaring, r2=2+26+3=5+26. (3) Hence 6=(r2−5)/2, which is rational, since r is. (4) But 6=2⋅3 is irrational, being a product of two irrational numbers. (5) This contradiction shows that 2+3 is irrational.

Solution (Hint 1). Run the second column on every line.

Solution (Hint 2). For a correct proof, isolate 3=r−2 before squaring.

Solution. The failing line is (4). Its first half is true, 6=2⋅3, but its reason is not available. “A product of two irrational numbers is irrational” is neither proved nor a school fact: it is false, since 2 is irrational (Theorem 2.2.1), and 2⋅2=2 is rational. So the line cites nothing: entry (N9) of Example (What is not allowed). The product 2⋅2=2 is a counterexample to the illegal step; there is none to the conclusion, which is true. Lines (1)–(3) and (5), and the ¬I skeleton, are correct.

A correct proof. Suppose 2+3=r with r rational. Then r>0, since both square roots are positive. Isolating, 3=r−2, and squaring, 3=r2−2r2+2,so2=r2−12r, where dividing by 2r is legitimate because r>0. The right-hand side is rational, which contradicts Theorem 2.2.1. Hence 2+3 is irrational.

Marking scheme. (10 points) - 3: names line (4) as the failing line, and the illegal step as the unproved general “fact”, entry (N9). - 2: a counterexample to that step (2⋅2=2, or another product of two irrationals that is rational). - 1: says the conclusion is true, so no counterexample to it exists. - 4: a correct proof: the ¬I box on “r rational”, the algebra, the division justified by r≠0, and the clash with Theorem 2.2.1 (or with 3 or 6, its irrationality proved). Fatal errors (0 for the step): “correcting” line (4) by another unproved fact; dividing by r without r≠0.

Exercise (C3: Exit check: four student proofs)

Judge each proof. If it is wrong, give the line that fails, its entry in Example (What is not allowed), and a counterexample to the illegal step. If it is correct, name the rule of its most delicate step and check that step.

  • (1) Claim. For every integer n, if n is a multiple of 4 or a multiple of 6, then n is even. (1) Let n be an integer that is a multiple of 4 or of 6. (2) Case 1: n is a multiple of 4. Choose an integer k with n=4k; then n=2(2k), so n is even. (3) Case 2: n is a multiple of 6. Choose an integer k with n=6k; then n=2(3k), so n is even. (4) In either case, n is even.
  • (2) Claim. For integers m and n, if m and n are even, then mn is divisible by 4. (1) Assume m and n are even. (2) Then m=2k and n=2k for an integer k. (3) So mn=4k2, which is divisible by 4.
  • (3) Claim. For every real x, |x−1|≤|x|+1. (1) Either x≥1 or x≤0. (2) If x≥1, then |x−1|=x−1≤x+1=|x|+1. (3) If x≤0, then |x−1|=1−x=1+|x|. (4) In either case, |x−1|≤|x|+1.
  • (4) Claim. For every real x, if x2=2x, then x=2. (1) Assume x2=2x. (2) Canceling x from both sides, x=2. (3) Hence if x2=2x, then x=2.

Solution (Hint 1). Run the two-column check on every line, and keep the two questions apart: a true claim can have a wrong proof.

Solution (Hint 2). In (1), ask which boxes are open when the second k is chosen. In (3), ask what ∨E needs from line (1).

Solution. (1) Correct. The skeleton is ∀I and →I, then ∨E on the hypothesis itself, so the cases exhaust. The delicate step is the second “choose an integer k”, an ∃E reusing a name. It is legal: the first box of k lies inside Case 1, which closed before Case 2 opened, so k appears in no open assumption, not in the existential and not in the conclusion. Sibling boxes may share a name (Section 5.6); (N4) forbids only a name still in use.

(2) Wrong; line (2) fails; entry (N4) of Example (What is not allowed). The second witness is named k while the box of m=2k is open. Counterexample to the step: m=2, n=4; no integer k has 2=2k and 4=2k. The conclusion is true: with m=2k and n=2l, mn=4kl.

(3) Wrong; line (1) fails; entry (N8). “Either x≥1 or x≤0” is not derived, and is false at x=1/2, a counterexample to the step. The conclusion is true; the missing case repairs the proof: if 0<x<1, then |x−1|=1−x<1<|x|+1.

(4) Wrong; line (2) fails; entry (N9); the claim is false. Canceling uses the “fact” “if ax=bx, then a=b”, which is neither proved nor a school fact, and is false: a=1, b=2, x=0. It needs x≠0, which no line provides. The claim fails at x=0; what is true is “x=0 or x=2”, from x(x−2)=0.

R. Review

Exercise (R1: A dialogue)

Two students discuss a claim.

Ana: For every integer n, n2+n is even.

Ben: Why?

Ana: Take n=3: 9+3=12. Take n=4: 16+4=20. It always works.

Ben: That is two numbers.

Ana: All right. n2+n=n(n+1). If n is even, the product has an even factor. If n is odd, n+1 is even, so again it has an even factor. Either way n2+n is even.

Ben: You only did positive numbers.

Ana: I never used that n is positive.

  • (a) Which entry of Example (What is not allowed) does Ana’s first argument commit?
  • (b) Write her second argument as a level-3 proof, and name the rule each sentence carries.
  • (c) Is Ben’s last objection right?
  • (d) On which fact does the case split rest, and where was it stated?

Solution. (a) (N1) of Example (What is not allowed): two instances, then “always”.

(b) “Let n be an integer [∀I]. Then n2+n=n(n+1) [algebra]. By (E1), n is even or odd [∨E, with the reason the cases exhaust]. If n is even, say n=2k [∃E], then n(n+1)=2(k(n+1)) is even [∃I, witness k(n+1)]. If n is odd, say n=2k+1, then n+1=2(k+1), and n(n+1)=2(n(k+1)) is even [∃E, ∃I]. In either case n2+n is even [∨E, closing; silent at level 3].”

(c) No. The box of n assumed only that n is an integer, and no line used more, so ∀I (Definition 5.4.1, Section 5.4) gives the claim for every integer: n is in no premise, and the conclusion is about the bound variable. A proof that used n>0 would have had to assume it in the box.

(d) (E1), “every integer is even or odd”, stated in Section 2.1 as a school fact, before Theorem 2.1.3.
